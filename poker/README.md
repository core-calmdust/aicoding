# ポーカー（poker/）

6人卓（キャッシュゲーム）でCPU 5人と対戦する「研究できる」ポーカー。メインはテキサスホールデム、ほかにオマハ（PLO）・ショートデッキ（6+）・7カードスタッド・5カードドロー。ソリティアのベース（カード画像・デザイン・ダイアログ・CSS）をそのまま使っている。

## ファイル
| ファイル | 役割 |
|---|---|
| `engine.js` | ルールエンジン（DOMなし、Workerでも動く）。役判定 `evalCards`（1〜7枚、ショートデッキの順位対応）、オマハの `bestOmaha`（手札ちょうど2枚＋場3枚）、ゲーム種類の登録 `register`、ベット進行（NL/PL/FL・サイドポット・ブリングイン・ドロー） |
| `equity.js` | 勝率（モンテカルロ／残り2枚以下は全数）、レンジ（上位x%）、CPUの判断 `decide`（4つのスタイル×4段階）、コーチ `coach`（勝率・必要勝率・EV・推奨・理由）、ドローの交換案 `drawPlan` |
| `pre.js` | プリフロップ169通りの勝率表（相手1〜5人、各2,500回のシミュレーションで生成） |
| `worker.js` | 勝率・コーチの計算を裏で行うWeb Worker |
| `cards.js` | カードの描画（`../solitaire/img/` の絵札・全面画像を共用） |
| `app.js` | 進行・卓の描画・アクションバー・右欄（勝率・コーチ・ログ・セッション）・統計・新しいゲーム／設定ダイアログ・効果音 |
| `review.js` | ハンド履歴（直近60ハンド）と振り返り（1手ずつ再生、自分の判断ごとにコーチの評価） |
| `tools.js` | 研究：勝率・EV計算機（2〜6人・レンジ指定・ボード）、スターティングハンド表（13×13、相手人数・ポジション別レンジ）、役と確率 |
| `lessons.js` | レッスン（5カテゴリ17レッスン。説明＋毎回エンジンで作る5問、4問正解で合格） |
| `tutorial.js` | 実戦チュートリアル（本物の卓で決まった1ハンドを遊ぶ。スポットライト＋吹き出しで案内、CPUの行動と配りは固定、指定の操作だけ受け付ける）。初回はおすすめの案内ボックス（「次から表示しない」で非表示） |
| `rules.js` | チュートリアル式ルール（`shared/ruletour.js`、ゲーム種類ごとのタブ） |
| `i18n.js` | 画面の文言（10言語）。レッスン・ルールの文言はそれぞれのファイル内 |

## ゲーム種類の追加
1. `engine.js` で `register({ id, hole, board:[3,1,1] or null, stud, draw, short, limits, streets, ... })`。
2. 役の作り方が特殊なら `handInfo`／`scoreOf` を分岐（オマハ参照）。
3. `i18n.js` に `v.<id>`・`vg.<id>`、`rules.js` に `RULES[<id>]` と `RT[言語][<id>]`、`app.js` の `GART` にカード絵。

## コーチ・評価
- 推奨は勝率（相手のレンジに対して）と必要勝率＝コール額÷（ポット＋コール額）、EV＝勝率×（ポット＋コール額）−コール額から決める。
- 自分の判断は ◎最善／○許容／△疑問／✕悪手 の4段階で記録し、統計の「好判断率」と振り返りに使う。

## 描画
- 卓と右欄は差分更新（`patch`：data-k・data-c で要素を対応づけ、変わらない要素はそのまま）。全体を書き換えるのは配るときだけ。演出の再生や画像の読み直しによるちらつきを防ぐ。

## 保存
- `localStorage['aicoding-poker']`：設定、遊び途中の卓、ゲーム種類別の統計（VPIP・PFR・AF・WTSD・W$SD・bb/100・収支グラフ・判断の内訳）、ハンド履歴
- `aicoding-poker-lessons`：レッスンの最高点・合格、`aicoding-poker-rules-<種類>`：ルール説明の進み、`aicoding-poker-rules-seen`、`aicoding-poker-tut-hide`（案内ボックスを出さない）・`aicoding-poker-tut-done`（チュートリアル完了）

## 画面
- 共通仕様どおりPCは卓＋右欄360px。ヘッダーのメニューは 新しいゲーム／精算（投了の代わり）／ヒント／ルール／レッスン／研究／統計。
- テーマカラーはネイビー×ゴールド。卓はフェルト＋レール、デザイン（裏面・カード・テーブル）はソリティアと共通の選択肢。
