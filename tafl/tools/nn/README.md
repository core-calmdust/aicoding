# ネファタフルの学習評価関数（tools/nn）

手作りの形勢評価（18項目）に代えて、学習したネットで形勢を評価するための一式です。
データ作り（自己対局）→ 学習（PyTorch）→ 手作り評価との対局で確認、の順に進めます。

## ネットの形
- 入力：攻め手・守り手・王の3面 × 盤のマス（11×11なら363）。
- 隠れ層：H個（既定128、8の倍数で256まで）。活性化は clamp(x, 0, 1)²。
- 出力：手番ごと（攻め手番・守り手番）に、隠れ層の重み付き和 ＋ 手作り評価の16項目（`engine.c` の `handFeat`）の重み付き和 ＋ バイアス。
  脱出路の数など読みに近い項目は手作りの計算をそのまま入力に使い、駒の配置の良し悪しをネットが学びます。
- 値は守り手から見た期待得点のロジット。エンジンでは「値 × scale（既定400）」を評価値にします。
- ルール（コペンハーゲン0・ブランドゥブ1・タブルット2）ごとに別のネットです。まずはコペンハーゲン（0）から。

## 1. データ作り
```sh
cd tafl
tools/nn/gen.sh 0 500 10 data 8      # 8プロセス × 500局、1手1万局面（10k）で読む自己対局
```
- 1行が1局面：`ルール 手番 手数 探索値 結果 src 盤面 特徴16個`（結果 1=攻め手勝ち 2=守り手勝ち 0=引き分け）。
- 序盤の2〜8手はランダムに指して、毎局ちがう展開にします。
- 目安：1手1万局面で1局およそ1〜3秒（端末による）、1局100〜300局面。100万局面以上あると安心です。
- 読みを深く（`nodesK` を 20〜50）すると教師の質が上がり、引き分けが減ります（浅いと取りのない200手の引き分けが多くなります）。

## 2. 学習
```sh
pip install torch numpy
python3 tools/nn/train.py --variant 0 --out tafl-v0.nnue data/v0-*.txt
```
- Apple Silicon の GPU（mps）・CUDA・CPU を自動で選びます（`--device cpu` などで指定）。
- 主なオプション：`--hidden 128`（隠れ層）、`--epochs 30`、`--lam 0.5`（教師のうち探索値の割合。残りは勝敗）、`--scale 400`。
- 探索値は手作り評価の単位で大きな定数のずれがあるため、勝敗に合わせて自動で較正してから教師にします（ログの `teacher = sigmoid(...)`）。
- 盤の8通りの対称（回転・裏返し）でデータを水増しします。
- 検証用の損失が下がったエポックごとに `--out` のファイルを書き出します。

## 3. 確認（手作り評価との対局）
```sh
cc -O3 -DNATIVE -w -o /tmp/tafl tools/native.c -lm
NNUE=tafl-v0.nnue /tmp/tafl nmatch 0 100 10        # 100組（攻守入れ替えで200局）、1手1万局面
NNUE=tafl-v0.nnue NNSCALE=600 /tmp/tafl nmatch 0 100 10   # scale を変えて試す（探索の枝刈りの幅と釣り合う値を探す）
NNUE=tafl-v0.nnue /tmp/tafl nrole 0 50 20 2       # 役割ごとの比較（攻め手2万・守り手2千局面で、手作りどうしと同じ序盤で比べる）
NNUE=tafl-v0.nnue /tmp/tafl nncheck 0 data/v0-xxx.txt 5   # ネットの値（守り手から見たロジット）を数局面だけ表示
```
- `net score` が0.5を超えればネットの方が強いです。攻め手・守り手それぞれの勝ち負けも出ます。
- 局面数で区切っているので、評価が重くなった分（ネットは手作りより少し遅い）は差し引かれずに比べています。
  時間で比べるときは、`bench` で速さも見てください。

## 4. 2周目以降
ネットで自己対局したデータを足して学習し直すと、さらに伸びることが多いです。
```sh
tools/nn/gen.sh 0 500 10 data2 8 tafl-v0.nnue
python3 tools/nn/train.py --variant 0 --out tafl-v1.nnue data/v0-*.txt data2/v0-*.txt
```

## 攻め手の勝ちが多いデータ
`DEFK=2` を付けると守り手だけ読みを浅く（2千局面）して対局します。攻め手が勝つ対局が増え、攻め手の指し方を学ぶ材料になります。
```sh
DEFK=2 tools/nn/gen.sh 0 3000 20 dataA 8
python3 tools/nn/train.py --variant 0 --hidden 256 --epochs 40 --lam 0.7 --out tafl-v2.nnue data/v0-*.txt data20/v0-*.txt dataA/v0-*.txt
```
