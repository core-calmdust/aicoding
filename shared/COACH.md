# コーチ・戦績・スマホ下タブ — 全ボードゲーム共通テンプレ

手本（完成形）：**将棋** `shogi/coach.js` ＋ `shogi/coach-i18n.js` ＋ `shogi/index.html` の組み込み。
共通部品：`shared/coachkit.js`（見た目・スイッチ・用語解説）、`shared/record.js`（戦績）、`shared/infotabs.js`（スマホ下タブ）。
**共通部品は書き換えない**（足りない機能があれば、そのゲームの coach.js 側で実装する）。

## 1. コーチ（`<game>/coach.js`、10言語）
- オン／オフのスイッチ：`CoachKit.sw({ mount: '.brand-r', get, set, label })` を **HeaderBar.init より前**に呼ぶ。スイッチは**コーチ欄（ボックス）の見出し `h3.ck-h` の右上**に自動で入る（上部メニューには置かない。#coachCard がないときだけ mount に入る）。設定は既存の「コーチ」設定（なければ `settings.coach` を新設、既定 ON）と連動。
- 欄：`<div class="card ck-card hidden" id="coachCard">` を形勢カードの近くに置く。
  - 使える場面（AI戦・ローカル対戦。レート戦・オンライン・レッスン・パズル・編集・検討中は除く）では常に表示。
  - **オフのときも欄とタブは残し**「コーチ機能はオフです。右上のスイッチをオンにすると…」と出す（`ck-off` クラス、PCでは小さく）。
  - 使える場面かどうかを `body.ck-tab` で示す（infotabs がスマホのコーチタブを出す条件）。振り返りカードがあれば `data-itc="coach"`。
- 自分の手番に出す内容（上から）
  1. 要約チップ `CoachKit.summary`：形勢（勝率）・材料差・局面の段階、**戦型／定石の型（確定前は「◯◯模様」）**、陣形・囲いなどの状態（自分／相手）。
  2. 推奨方針 `CoachKit.rec`（バッジ＋理由。最善と次善の差が大きい／小さいときの一言）。
  3. **分かれ道** `CoachKit.branches`：AIの上位候補（3〜4手）を「方針」で分類（攻め・守り・駒得・展開…ゲームごとに定義）して、方針タグ、**どの駒・どこの手か必ず分かる題名**（例「４八の銀を動かす」「e筋のポーン」）、最善との差、方針の解説。手そのもの（行き先）は［手を見る］で表示、行ホバーで盤に矢印。
  4. 考え方のヒント `CoachKit.tips`：局面から確実に読める事実（取られそうな駒、詰み／勝ち筋、脅威、形の良し悪し、段階別の格言…）を優先度順に、3つ＋「ほかのヒント」。
  5. 前の手の評価 `CoachKit.verdict`：◎○△✕、AIの第一候補（方針つき）、疑問手・悪手には💡コツ。
- **序盤は評価値ではなく定跡・定石で指導（規定）**：初手〜数手は代表的な分岐（定番2つを先に、変わり種を後に）を解説付き・手も表示で。定跡データ（ブック）がある範囲では採用率・頻度順に候補を出し、定跡の手を悪手扱いしない。
- 相手の手番：「次の手を予想してみよう」＋前の手の評価。
- 専門用語は `CoachKit.gloss`（点線、PCホバー・スマホタップで解説）。
- **リサーチ必須**：そのゲームの定跡・定石・格言・典型的な形・戦型名を必ず調べてから書く（記憶で書かない）。内容は確実な事実だけ。

## 2. 戦績（`shared/record.js`）
- `GameRecord.init({ game, lang: () => LANG, menu: '.controls', sides: () => [先手名, 後手名] })` を HeaderBar.init より前に。
- 終局時に `GameRecord.add({ mode: 'ai'|'rated'|'online', res: 'w'|'l'|'d', side, opp: '相手の表示名', key: '集計キー', n: 手数, why: '終わり方' })`。観戦・レッスン・パズル・未着手の投了は記録しない。
- 入口はスマホ＝下タブ「オンライン」の左（自動）、PC＝ヘッダーバーのメニュー（自動）。

## 3. スマホ下タブ（`shared/infotabs.js`）
- 「コーチ｜形勢｜棋譜｜戦績｜オンライン」。`#coachCard` があれば自動でコーチタブが付く。オンラインの表記は「オンライン」だけ。

## 4. 確認と公開
- PC（1440×900）とスマホ（390×844、タッチ）で画面を確認：コーチ欄の各段・オフ表示・戦績ダイアログ・下タブ。
- 10言語：ja・en を書いてから他の8言語（zh ko es fr pt de hi ar）を用意。
- 変更したファイルの `?v=` を上げる。作業ブランチ → PR → main にマージ（CLAUDE.md）。

## 5. 画面の共通ルール（2026-10-30 追加）
- ボタンの文字は2行に折り返さない（スマホ 390px・長い言語でも）。収まらなければボタンを2段に並べる。手本：shogi の結果ダイアログ。
- スマホの縦の間隔：上部メニュー → 相手の欄 → 盤 → 自分の欄 → 下の箱 は、すべて同じ 8px。
- 対局後：コーチ欄は対局中（最新局面で自分の手番を待つ間）だけ。終局後・過去の局面を見ている間はコーチを消し、振り返りカード（`data-itc="coach"`）をコーチタブに出す。振り返り前は「分析する」ボタン付きの短い案内。振り返りが出たらスマホは自動でコーチタブへ。手本：shogi/coach.js render()。
