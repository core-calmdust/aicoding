# Model Card: Gomoku / Renju evaluation (`nn_renju.bin.gz`, `eval_std.bin`)

学習済みの形勢評価は2つあります。連珠ルールでは小さなニューラルネット（`nn.c` → `nn.wasm`）、標準・自由ルールでは線形のパターン評価を使います。
探索エンジン `engine.js`（αβ探索＋四追い・三四の読み切り）と組み合わせ、ブラウザ上（Web Worker）で動きます。

- **ゲーム**: https://core-calmdust.github.io/aicoding/gomoku/
- **ライセンス**: Apache License 2.0（リポジトリの `LICENSE`）
- **バージョン**: v1（2026-10-20）

## 連珠：ニューラルネット評価（v3, 2026-10-20）
| 項目 | 内容 |
|---|---|
| 構造 | 空点ごとに4方向×前後4マスの並び（左右反転を同一視して3,321通り）を、手番側・相手側の目で読み、埋め込みベクトル（32次元、役割×色ごとの表）を合計。黒の禁点には専用ベクトルを加算 → clipped ReLU → 全空点で合計 → 32 → 1 の全結合層 → 手番側の勝率のロジット |
| パラメータ数 | 約43万（埋め込みは int16、Q=256。gzip後 約540KB） |
| 実装 | `nn.c` を WebAssembly SIMD にビルド（`nn.wasm`）。PyTorch の学習結果と一致を確認（ロジット誤差 0.03 未満） |
| 学習データ | Gomocup 連珠リーグの局面と、その派生局面 約36万。うち約24万は Rapfi の評価値（1万ノード）を教師値にし、残りは勝敗。AIの読みの中に出てくる「悪手を含む局面」に強くするため、実戦の局面に1〜3手ランダムな候補手を加えた局面も Rapfi で採点して加えた |
| 学習 | PyTorch、Adam、8通りの盤の対称で水増し、8エポック |
| 評価 | Rapfiの勝敗判定との一致率：手作り評価 63% → 線形学習 68% → このネット 79%（派生局面を含む検証用データ）。同じ探索・同じノード数（1手2万ノード）、互角の局面から先後入れ替えの対局で 95勝64敗1分（160局、勝率60%、約+68 Elo。前版 v2 は同条件で +26）。評価の計算による1手あたりの遅れは約1割 |

## 標準・自由：線形のパターン評価
| 項目 | 内容 |
|---|---|
| 種類 | 線形の評価関数（パターン重みの合計）。差分更新で計算 |
| 特徴量 | 空点ごとに、①4方向の並びの種類の組み合わせ（715通り＋禁点）、②その点の黒・白の形の組（100通り）、③各方向の前後10マスの並びそのもの（左右反転を同一視して29,646通り）。それぞれ「手番側／相手側」×「黒／白」で別の重み |
| パラメータ数 | 121,650（Int8、gzip後 約44KB） |
| 出力 | 手番側から見た評価値（600 ≒ 勝率のロジット1。エンジン内部では16倍して従来の評価と同じ尺度にしている） |

## 学習データ
- [Gomocup](https://gomocup.org/)（世界コンピュータ五目並べ選手権）2017〜2025年の15路盤の対局棋譜（標準・自由ルール 約3.3万局）。棋譜そのものはリポジトリに含めていません。
- 局面の約2.6万を、オープンソースの強豪エンジン [Rapfi](https://github.com/dhbloo/rapfi)（GPL-3.0）の評価値（1万ノード探索）で採点し、教師値にしました。Rapfiは採点のためだけに手元で使い、コードもネットワークもこのリポジトリには含めていません（Rapfiのネットワーク重みは CC0）。

## 学習方法
1. 勝敗（手番側の勝ち＝1）を目標にロジスティック回帰（Adam、L2正則化、対局単位で1割を検証用）。
2. その重みから始めて、Rapfiの勝率（評価値/200 のシグモイド）を目標に追加学習。

## 評価
同じ探索・同じノード数（1手2万ノード）で、互角の局面（Rapfi評価±120以内）から先後を入れ替えて対局：

| 比較 | 結果 |
|---|---|
| 学習評価 vs 手作り評価（標準ルール） | 69勝49敗2分（勝率58%、約+58 Elo） |

連珠ルールでは線形評価では有意な差が出なかったため、上のニューラルネット評価を使っています。

## 制限
- 線形モデルなので、ニューラルネット評価の強豪エンジンには及びません。
- 勝ちを読み切る部分（四追い・三四の追い）は別の探索が受け持ち、この評価は使いません。
