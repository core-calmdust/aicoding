# レーティング戦（AI とのレート対局）のレーティング表

新しい対局の「レーティング戦」では、AI の各レベルに **固定のレーティング** を割り当て、プレイヤーのレーティング（端末ごと、`localStorage` の `c4-rated-v1`）との Elo 計算で増減させます。オンライン対戦のレーティングとは別物です。実装は `rated.js`。

## 決め方

- レベル同士を実際に対戦させて測りました（`engine.js` の `think` を Node で実行、最初の2手はランダム、先後交互）。
  全 444 局の結果から Bradley–Terry（Elo）の最尤推定で各レベルの差を求め、Lv.1 = 400 に合わせて 10 単位で丸めています。
- Lv.5 と Lv.6 は AI 同士ではほぼ互角（推定差 −4）だったので、順序を保つため Lv.6 を +40 にしています。
- Lv.8 は1手目から完全プレイ（先手なら必ず勝ち、後手でも理論上の勝ち・引き分けを逃さない）なので最上位です。
  先手の Lv.8 には誰も勝てず、後手の Lv.8 に勝てるのは完全に指す先手だけです。先後はランダムなので、
  人間が到達できるレーティングは事実上 Lv.8 の値（1480）前後が上限になります。
- AI 同士の差は人間相手より縮みやすく（どのレベルも即詰み・即勝ちは逃さない）、表は目安です。

## 計算とルール

- プレイヤーの初期値 1000。K = 48（最初の10局）、以降 K = 24。期待値 E = 1 / (1 + 10^((相手R − 自分R) / 400))。勝ち 1・引き分け 0.5・負け 0。
- 相手の選び方：目標 = 自分の R + ずらし幅（80% は ±100 以内、10% は +150〜+300 の格上、10% は −150〜−300 の格下）に、表でいちばん近いレベル（同値なら低いレベル）。ダイアログに今回の相手（レベル・R・格上／互角／格下）を表示し、その相手で始めます。
- 先後はランダム。対局中は待った・ヒント・脅威マス表示・形勢（評価バー・グラフ）・分析は使えません。棋譜を戻して見ることはできますが、途中の局面から打ち直すことはできません。終局後は振り返りできます。
- 対局中に別の対局・レッスン・パズル・棋譜読込へ移ると確認のうえ中断＝負け（共有リンクで別の棋譜を開いた場合も負け）。再読み込みしても続きから再開し、結果は対局 ID で 1 回だけ記録します。

## 保存形式

`c4-rated-v1`

```json
{ "r": 1049, "n": 5, "w": 2, "l": 3, "d": 0,
  "hist": [ { "id": "mvf1ley4wpb8t", "t": 1792401542769, "lv": 3, "or": 900, "s": 0, "d": -31, "r": 1049, "why": "end" } ] }
```

- `r` 現在のレーティング、`n` 局数、`w`/`l`/`d` 勝・負・分
- `hist` 直近 100 局（古い順）。`id` 対局ID、`t` 時刻(ms)、`lv` AIレベル、`or` AIのR、`s` 得点(1/0.5/0)、`d` 増減、`r` 対局後のR、`why` `"end"` または `"abandon"`
- `dots-rated-v1` と同じ形（盤の大きさ `sz` だけ無し）。同期のマージ案：`hist` を `id` で和集合して `t` 順に並べ、`r`/`n`/`w`/`l`/`d` は最後（`t` 最大）の記録を持つ側の値を使う。

`c4-rated-cur-v1`（端末内のみ）：盤上のレーティング戦 `{ id, human, lv, or, my, tag, done? }`
