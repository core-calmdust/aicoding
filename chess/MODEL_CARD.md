# Model Card: Chess evaluation (`nnue.bin.gz`)

チェスのAIが局面の良し悪しを判断するための評価関数（学習済み重み）です。
探索エンジン `engine.c`（WebAssembly にビルドした `engine.wasm`）と組み合わせて、ブラウザ上（Web Worker）で動作します。

- **ゲーム**: https://core-calmdust.github.io/aicoding/chess/
- **ライセンス**: Apache License 2.0（リポジトリの `LICENSE` を参照）
- **作成**: core-calmdust（AIコーディングによる制作）
- **バージョン**: v1（2026-10-19）

## モデル概要

| 項目 | 内容 |
|---|---|
| 種類 | NNUE（効率的に差分更新できるニューラルネット） |
| 構造 | (768 → 384) × 2視点 → 1、活性化 SCReLU、出力は残り駒数で8つに分岐 |
| 入力 | 駒の種類（6）× 色（2）× 升（64）。手番側の視点と相手側の視点（盤を上下反転）の2つ |
| 出力 | 手番側から見た評価値（センチポーン相当。勝率 ≒ sigmoid(評価値/400)） |
| パラメータ数 | 約30万（第1層は Int16 で ×255、出力層は Int16 で ×64 に量子化） |
| ファイルサイズ | 約600KB（gzip圧縮後 約380KB） |

## 学習データ

[Lichess の評価済み局面データベース](https://database.lichess.org/#evals)（`lichess_db_eval.jsonl.zst`、**CC0**）の先頭から約1億2千万局面を使いました。各局面には Lichess ユーザーのクラウド解析（Stockfish）による評価値が付いています。

- 最も深い解析の最善手の評価値を教師値にしました（±3000で打ち切り、詰みは±3000）。
- 王手がかかっている局面と、最善手が駒取り・昇格の局面は除外しました（静かな局面のみ）。
- 解析の深さが12未満の局面は除外しました。
- 条件を満たした約1億800万局面すべてで学習しました。

## 学習方法

- 損失: 予測勝率 sigmoid(出力) と教師値 sigmoid(評価値/400) の二乗誤差。
- 最適化: Adam、ミニバッチ16,384、8エポック（後半で学習率を 0.3倍・0.1倍に減衰）。
- 重みは ±1.98 に制限して量子化しても精度が落ちないようにしています。
- 学習器は C で自作しました（`engine.c` と同じ特徴量の定義）。

## 対戦評価

Stockfish 17.1（GPL-3.0）の強さ制限モード（`UCI_LimitStrength` / `UCI_Elo`）を物差しにしました。Stockfish は手元での計測にのみ使い、同梱していません。表の「目安」は Stockfish の Elo 表記（CCRL基準）で、人間のレーティングとは尺度が異なります。開始局面は定跡からランダム、各20局（先後入れ替え）。

**学習の効果（同じ探索・同じ持ち時間での対局）**

| 比較 | 条件 | 結果 |
|---|---|---|
| NNUE（2,700万局面・1エポック） vs 手作り評価関数 | 1手0.1秒・20局 | 16勝4敗（+241 Elo相当） |
| NNUE 256（5,400万局面） vs 同（2,700万局面） | 1手0.1秒・60局 | 27勝22分11敗（+95） |
| **NNUE 384（1億800万局面、採用版）** vs NNUE 256（5,400万局面） | 1手0.3秒・140局 | 56勝55分29敗（+68） |

**旧AI（JavaScript版）との比較（1手0.5秒）**

| 比較 | 結果 |
|---|---|
| 新エンジン（評価関数は採用版より前の版） vs 旧AI | 18勝2分0敗 |
| 旧AI vs Stockfish Elo1800 / 2200 | 80% / 55%（旧AIの目安 約2200） |

**レベルごとの目安**

Lv.3〜7 は採用版より前の評価関数（NNUE 256）で計測した値で、採用版ではやや強くなっています。

| レベル | 設定 | 相手 | 結果 | 目安 |
|---|---|---|---|---|
| Lv.3 | 2手読み＋ゆらぎ | Elo1320 | 65% | 約1400 |
| Lv.4 | 3手読み＋ゆらぎ | Elo1320 | 88% | 約1650 |
| Lv.5 | 4手読み＋ゆらぎ | Elo1700 | 80% | 約1950 |
| Lv.6 | 1,500局面 | Elo2000 | 60% | 約2050 |
| Lv.7 | 8,000局面 | Elo2300 | 78% | 約2500 |
| Lv.8 | 0.5秒（採用版） | Elo3000 | 6勝8分6敗（50%） | 約3000 |
| Lv.9 | 1.5秒（採用版） | Elo3190（上限） | 0勝4分8敗（17%） | 約2900〜3000（上限の Stockfish には届かず） |
| Lv.10 | 4秒 | — | — | Lv.9 よりさらに上 |
