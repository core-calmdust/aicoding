# リバーシ 最上位レベルの計測（Mac・全スレッド・実際の持ち時間）

Lv.21〜25 の間隔を、作業環境（2コア共用）の短い対局からの外挿ではなく、Mac の全コア・本番の持ち時間で測って決め直すための手順です。

## あなたがやること

- [ ] 1. **GitHub Desktop で main を Pull**
- [ ] 2. **ベンチ（約5分）**：PC の Chrome で <https://core-calmdust.github.io/aicoding/reversi/bench.html> を開く（初回は自動で1回再読み込み）→ ほかのアプリを閉じて［開始］→ 終わったら［結果をコピー］→ Claude に貼り付け
- [ ] 3. ターミナルを開いて
  ```
  cd /Users/core_tan/Documents/GitHub/aicoding/reversi
  node tools/levelmatch.js --dry
  ```
  （見込み時間が出るだけで、対局はしません）
- [ ] 4. **レベル対局（既定：約8時間。寝る前に）**：電源アダプタをつなぎ、ふたを開けたまま
  ```
  caffeinate -is node tools/levelmatch.js
  ```
  半分の時間で済ませたいときは `caffeinate -is node tools/levelmatch.js --scale 0.5`（約4時間、下の注意を参照）
- [ ] 5. 終わったら（途中でも可）
  ```
  node tools/levelmatch.js report | pbcopy
  ```
  → Claude に貼り付け（`pbcopy` でクリップボードに入ります）

途中で止めたいときは Ctrl+C。**同じコマンドをもう一度打てば続きから**始まります（そのとき対局中だった1〜2局だけやり直し）。ベンチとレベル対局は同時に動かさないでください（コアを取り合うため）。

## 1. ベンチ（reversi/bench.html）
- 対局ページと同じ仕組み（`sw.js` の Document-Isolation-Policy で分離、`mt-worker.js` ＋ `engine_mt.wasm` の Lazy SMP、終盤の完全読みはルート分割）で、1・2・4・8・14 スレッドの速さを測ります。
- 中盤：残り36マスの8局面を1局面3秒ずつ読み、nps（全スレッドの合計）・届いた深さ・**全スレッド数が届いた共通の深さまでの時間**・その深さでの最善手の一致（1スレッドと比べて）。
- 終盤：残り24マスの8局面の完全読みの時間と石差（どのスレッド数でも一致するはず）。
- 画面の上に `crossOriginIsolated`（true でないとスレッドを使えない）と、実際に起動したスレッド数が出ます。
- 所要は約5分（中盤 8局面×3秒×5通り＝2分＋終盤は機種しだいで2〜3分）。

## 2. レベル対局（reversi/tools/levelmatch.js、Node）
- 対局ページの「時間で考えるAI」と同じ読み方を Node の worker_threads で再現します（`engine_mt.wasm` を共有メモリで、補助スレッドは別の手から読み、終盤はルート分割）。**先手・後手それぞれが自分のスレッドの組と置換表**を持ちます。
- 既定は **2局を同時 × 1局あたり7スレッド**（14コアを使い切る。対局ページは8スレッドなので、ほぼ同じ条件）。ページとまったく同じ8スレッドで1局ずつにしたいときは `--conc 1 --threads 8`（時間は約2倍）。
- 開始局面：定石（`book.bin`）をランダムにたどって（各手は最善から0.8石以内、レベルが実際に打つのと同じ）、**定石が終わった局面**から。20局面 × 先後入れ替えの2局。どの対局の組も同じ20局面を使います。
- 既定の対局（各40局）：
  - 隣どうし：Lv.20↔21、21↔22、22↔23、23↔24、24↔25 → Lv.20 を 0 とした各レベルの Elo
  - 時間2倍の梯子（Lv.20 の形のまま目安の時間だけ 2秒↔4秒、4↔8、8↔16）→ **本番の時間で時間2倍あたり何 Elo か**
- 1局ごとに `tools/levelmatch-out/results.jsonl` に追記し、毎局その時点の表（勝敗・Elo ±1σ・1手の平均と最長の秒数・深さ・nps）を表示します（`report.txt` にも保存。この2つは Git には入りません）。

### 時間の目安（14コアの Mac、2局同時）
| コマンド | 内容 | 見込み |
|---|---|---|
| `node tools/levelmatch.js` | 既定（隣どうし5組＋時間2倍3組、各40局） | 約8時間 |
| `node tools/levelmatch.js --scale 0.5` | 同じ対局を全員の時間を半分で | 約4時間 |
| `node tools/levelmatch.js --games 20` | 各20局（誤差は約1.4倍） | 約4時間 |
| `node tools/levelmatch.js --plan adjacent` | 隣どうしだけ | 約6.5時間 |
| `node tools/levelmatch.js --plan ladder` | 時間2倍の梯子だけ | 約2時間 |

見込みは最初は表の値（1手あたりの想定時間から）、対局が進むと実際にかかった時間から出し直します。`--plan L23:L25,T4:T16` のように組を自分で並べることもできます（L17〜L25 と T<秒>）。

### --scale について
`--scale 0.5` は全レベルの目安の時間と上限（`time`・`max`）を同じ割合で縮めます。中盤の読みはおおむね同じ比で縮みますが、終盤の完全読み・勝敗読みの深さ（マス数）はそのままなので、終盤の比重が少し変わります。**できれば 1.0（本番）**、時間が足りなければ 0.5 まで。倍率の違う結果は別々に集計されます（混ざりません）。
