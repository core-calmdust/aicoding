# すぴーど数独 仕様 v10

4×4（2×2の箱）・数字1〜4の数独を、制限時間内にどれだけ解けるかを競うタイムアタック。
単独アプリ `speed-sudoku/` と、まいにち数独 `sudoku/` の両方で遊べる（まいにち数独ではホームのゲーム選択で「すぴーど」を選ぶ）。

## ファイル
- `sudoku/speed-engine.js` 4×4生成・解答・難易度判定、デイリー出題（dsec / dgoal で日付ごとの秒数・目標）、変則ルール一覧と同時に出さない組（CLASH）。node でも動く
- `sudoku/tools/gen-speed.js` → `sudoku/speed_puzzles.json`（40コース・500ステージ。コース名キーは各コースの nk/dk。新しいコースは配列の末尾に足す＝既存コースの問題が変わらない。段階の移動は MOVE、段階内の表示順は `o`）
- `sudoku/speed.js` / `speed.css` すぴーど本体（ホーム部品・ゲーム画面・結果・実績・ランキング・ごほうび表 REWARD）
- `sudoku/online.js` ランキング通信（まいにち数独・すぴーど数独で共用）。Firebase の読み込み・ログイン確認には時間切れがあり、止まったままにならずエラー表示になる（読み込み 12秒、ログイン確認 8秒、リダイレクト結果 3秒、匿名ログイン 10秒）
- `sudoku/icons.js` キャラ（SP＝すぴーど限定 500〜536、SPX 表と spProp の小物）
- `sudoku/bg.js` 背景（すぴーど用：speedway, clocktown, skyrail, rocketbase, cloudtrack, beachrun, neoncity, rainbowrun）
- `sudoku/tutorial.js` キャラ「すうぴょん」のチュートリアル（まいにち／すぴーど両方）
- `sudoku/i18n-speed.js` すぴーど＋チュートリアル＋ゲーム選択の10言語文言（後から変えた文言はファイル末尾、閉じカッコの前の add() で上書き）
- `sudoku/app.js` / `app.css` 両アプリ共通の本体。`SUDOKU_MODE='speed'` で単独版
- `speed-sudoku/index.html` 単独版

## ホームの構成
- まいにち数独：タブ「デイリー／コレクション／変わり種」＋右端にゲーム選択（プルダウン：すうどく／すぴーど）
  - ゲーム選択は `DB.gm`（'su' / 'sp'）。ホームを開くたびに短い吹き出し（約2.8秒）で今のゲームと切りかえ場所を知らせる
  - すぴーどを選ぶと：デイリー＝すぴーどデイリー、コレクション＝問題集（入門〜チャレンジ）、変わり種のタブ名が「ミックス」＝上級・達人
  - ボタン色はホーム背景に関係なく：すうどく＝オレンジ（data-th=de）、すぴーど＝青（data-th=spd）。ホーム背景の設定はモードごとに別（homeBg / homeBgS）
  - スマホのすうどくデイリーには「今日のすぴーど数独」カードを出さない（PCは両方）
  - すうどくのコレクションは難易度ごと（初級6・中級12・上級9・達人13コース、app.js の CTIERS）に区切り、ジャンプボタン付き。変わり種は各セット内に難易度が混ざるので区切らない
  - 旧「すぴーど」タブを使っていた人は自動ですぴーどモードに移行
- 単独アプリ：タブ「デイリー／問題集／ミックス」。ボタンは青
- スマホの一覧（すぴーど問題集・すうどくのコレクション・変わり種）：小さい絵＋名前のコンパクトなカード。上部に段階ジャンプのボタン（タブの下に固定）

## 共有と独立
- 同じ localStorage キー `mainichi-sudoku-v1`（すぴーどは `DB.sp`。コース記録は `DB.sp.cc`、キーは「コースID(nk).ステージ番号」）、同じFirebase とクラウド同期 → 進行は自動で連動
- 共通：コイン（DB.pts）、キャラアイコン、プロフィール、ガチャ、図鑑、設定
- 独立：実績（DB.sp.ach）、ランキング（`spd/` 以下）、スコア（DB.sp.sc）

## ルール
- 正しい数字だけ入る。まちがい＝−2秒・コンボリセット。入力後は次の空きマスへ自動移動。フリック ↖1 ↗2 ↙3 ↘4
- コンボ：ノーミスで解き続けると1問ごとの点数が+10%ずつ（最大2倍）。デイリーの獲得スコア・コインに効く
- デイリー：銅・銀・金の3つ。1問解くごとに+5秒。1日3回までランキング挑戦（いちばんいい記録が残る）
  - 2026-10-22から：30秒（銅・目標4問）／45秒（銀・6問）／60秒（金・8問）
  - 〜10/21：30秒（4問）／60秒（8問）／90秒（10問）
  - 内部キーは 30 / 60 / 90 のまま（＝銅・銀・金の枠。記録・Firebase パス `spd/d/{date}/{30|60|90}`・DBルールはそのまま）。実際の秒数・目標は SE.dsec(date, key) / SE.dgoal(date, key)
  - 「ベスト何問」実績のしきい値：30秒枠 6/9、45秒枠 9/13、60秒枠 11/16
  - とちゅうボーナス：時間切れのとき、解きかけの問題に正しく置いた数字の分だけ、その問題の点数の半分を割合で加算（例：8マス中4マスなら 1/4）。最低1点。途中でやめた（もどる）ときは付かない。結果画面に「とちゅうボーナス +○ pt（○マス分）」と表示。スコア・ランキング・コインに含まれる
- デイリーの変則ルール（銅=1種、銀=2種、金=3種。日替わり）：〜10/21は最初の8種、2026-10-22からは全25種
- ★：クリア／残り25%以上／さらにノーミス
- 難しさの方針：変則ルールは簡単にしすぎない（ふうせんを減らす調整は「3つくらい出ても余裕」とのことで取り消し）

## ミックス（上級・達人）
- 上級：2種同時（後半は3種も）、20ステージ×5コース：ふしぎコンボ（動くもの）／びっくりコンボ（数字の見え方・入力が変わる）／みえないトリオ（見えにくい）／てんやわんや（入力のじゃま）／なんでもミックス（全25種）
- 達人：強めの2〜3種、すぴーどマスターだけ最大4種（全25種から）。ハリケーンは常に3種
- 5種以上の同時出題はしない
- 同時に出さない組（CLASH）：くだもの・けいさん・さいころ（どれか1つ）、うらがえし×モザイク、ぐるぐる×ゆらゆら、まぜまぜ×あまのじゃく、じゅんばん×ばくだん、すぽっと・ていでん・ねむねむ・のぞきまどの暗くする系は重ねない

## 変則ルール（25種、強さ★1〜3）
- おじゃまむし：数字を食べる。タップで追い払う
- モザイク：最初からある数字に一定周期でモザイク
- ぐるぐる：一定間隔で盤が90°回る
- すぽっとらいと：動く光の中だけ見える（暗い所もうっすら・入力可）
- くだもの：数字→果物。キーは果物＋左上に小さく数字
- まぜまぜキー：キーの並びが入れかわる。画面のキーだけ使える
- とうめいインク：書いた数字が消える
- こおり：タップで割ってから書く
- ばくだん：空きマスにばくだん。うめないと−3秒
- いれかわり：同じ太線内の2行（★2〜は列も）が入れかわる
- くもり：雲が横切って下のマスを隠す（下にも書ける）
- けいさん：最初からある数字が式に（★3は×÷も）
- うらがえし：最初からある数字が裏向きカード。タップで少しめくれる
- もぐら：空きマスをふさぐ。タップか入力で追い払う
- さかさま：数字が横・逆さま（★3は鏡文字・向きが変わる）
- ふうせん：下から上がってきて盤を隠す。タップで割る。割らずに上まで逃がすと−5秒・コンボリセット（ながれぼしと同じ「−5秒」の演出）。同時に出る数 ★1:2 ★2:3 ★3:4、間隔 1.8／1.35／1.0秒
- ていでん：数秒おきに一瞬真っ暗（入力は可）
- ゆらゆら：盤が船のように揺れる
- ペンキ：マスに塗られて隠れる。タップでふく（時間で乾く）
- じゅんばん：番号つきのマスは1,2,3…の順にしか書けない（★1:3マス、★2:5、★3:8）。順番外は弾かれるだけ
- のぞきまど：選んだマスのたて・よこ・箱しか見えない（★2はたて・よこ、★3は箱だけ）。（わくなしの代わり）
- ながれぼし：横切る時間 ★1 2.3秒／★2 1.9秒／★3 1.55秒。タップでキャッチ＝+2秒、のがす＝−5秒・コンボリセット（赤い「−5秒」の札＋灰色に落ちる絵＋タイマーが赤く揺れる。speed.js の missed()）
- あまのじゃく：色のついたマス（★1:2、★2:4、★3:5マス・ときどき場所が変わる）に入力すると反対の数字（1↔4、2↔3）。キー・キーボード・フリック共通
- さいころ：数字がさいころの目（★1は最初からある数字だけ、★2はキーも、★3はキーの小さい数字なし）
- ねむねむ：入力が止まると1〜2秒で盤が急に暗くなる（★3はほぼ真っ暗）。書くと起きる

## ランキング（Firebase `spd/`、ルール反映済み）
- デイリー `spd/d/{date}/{30|60|90}/{uid}` {n,i,s,c,t,a}（30/60/90 は銅・銀・金の枠キー）
  - 2026-10-22から：スコア（コンボボーナス・とちゅうボーナスこみの獲得スコア R.pts）で競う。同点なら早く解き終えた方が上
    - s = 10,000,000 ＋ スコア×1000 ＋ (999 − 最後に解いた時刻(0.1秒単位))（speed.js の SOFF / dBest）。旧方式の値より必ず大きいので「s は増える一方」のDBルールのまま切り替え可能。スコア上限 19,999
    - ローカル記録 DB.sp.d[date][key] は {c, t, p(=スコア), a, m}。ベスト判定・クラウド合流も dBest で比較
    - 表示：スコア ≥ SOFF の行は「○○ pt」、それより前の行（10/21以前・切替前）は「○問」
  - 〜10/21：解いた数×100000＋(99999−最後に解いた時刻ms)
- `spd/m/{ym}`, `spd/t`（スコア）, `spd/c`（★と クリア数）
- ルールは `sudoku/database.rules.json`（プロフィールのアイコンIDは1000未満なので 536 まで問題なし）
- 2026-10-22 早朝「今日のランキングが読み込み中のまま」の報告：本番で新規・記録ありの両方を試すと正常表示。端末側で Firebase への接続やログイン確認が返ってこないと待ち続ける作りだったため、時間切れを入れてエラー表示（再表示で再試行）にした
