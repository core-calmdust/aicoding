# 博物館 洗練度の採点基準（rubric）

ユーザー指示（2026-11-24）：
- 博物館の改善ループは、コンテンツの追加ではなく**洗練度合い**を上げるループにする。
- 指標はデザイン性・UX・アクセシビリティ・プラットフォームを問わないこと（スマホ／タブレット／PC、RTL）など。
- **評価は厳しく**つける。新しい課題が見つかったら、その都度ここに指標として加える（`tools/museum-audit.js` で測れるものはそちらにも入れる）。

## 進め方（1周）
1. 自動の採点を回す。
   - `node tools/museum-audit.js`：部屋6つ × 画面6種（320×640・375×812・390×844 アラビア語・768×1024・1024×768・1440×900）
   - 全スキンの文字の見やすさ（`tools/museum-skin-qa.js`）
2. 目視で採点する。各部屋を 375 と 1440 でスクリーンショットし、下の「目視の項目」に 1〜5 点をつける。
3. 一番悪い項目から直し、PR→マージ。直した結果の数字は spec（`claude/museum-spec.md`）に残す。
4. 新しく見つけた課題を、この表と audit に足す。

## 目視の項目（1〜5点。4 未満は直す対象）
| 項目 | 5点の状態 |
|---|---|
| D1 一枚の紙 | 博物館全体が1枚の面に収まり、スキンの上に文字や小さな紙片が直接浮かない |
| D2 階層 | 見出し → 部屋タブ → 部屋の説明 → 中身、の順が文字の大きさ・太さ・余白で一目で分かる |
| D3 統一 | カードの角丸・枠・影・余白が部屋をまたいでそろっている（同じ役割は同じ見た目） |
| D4 余白とリズム | 部品の間隔が 4/8 の倍数の数段階に収まり、詰まりすぎ・空きすぎの所がない |
| D5 色 | アクセント色は 1〜2 色、選択中の表示が全部屋で同じ |
| U1 1画面目 | スマホ・PC とも、見出し・タブ・中身の始まりが最初の画面に入る |
| U2 迷わない | いまどの部屋・どの項目を見ているか、戻る方法が常に分かる |
| U3 操作の重さ | 選ぶだけの部品（道具の切り替えなど）が大きなカードになっていない |
| A1 キーボード | Tab でタブ・カード・ボタンを順にたどれ、フォーカスが見える |
| A2 読み上げ | タブは role=tab と aria-selected、アイコンだけのボタンに名前がある |
| A3 動き | `prefers-reduced-motion` で大きな動きが止まる |
| P1 画面幅 | 320〜1440px のどこでも崩れず、タブレット（768・1024）で間延びしない |
| P2 RTL | アラビア語で左右が正しく入れ替わる（矢印・余白・並び） |
