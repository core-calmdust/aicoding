# まいにち数独 問題の品質ルール（今後作る問題すべて）

新しく作る問題（コレクション・デイリー・変わり種）は、「人が理屈で解ける」に加えて「解いていて面白い」ものだけを採用する。既に公開済みの問題は作り直さない。

## 条件
- 人間のテクニックだけで最後まで解ける（`engine.js` の `grade` が solved、総当たり不要）。答えは1通り。
- 面白さスコア（`sudoku/tools/fun.js` の `funScore`、0〜100）が **70以上**。候補を必要数の **3倍以上** 作り、スコア上位から採用する。

## 面白さスコアの中身
- **入り口の多さ (18%)**：最初の時点で置けるマスが多い（どこから手をつけてもよい）
- **技のバリエーション (27%)**：使う技の種類が多く、同じ技ばかりにならない（初級は単一候補の種類で見る）
- **山場 (22%)**：いちばん難しい手が序盤ではなく中盤（25〜85%）に来て、そのあと盤面が開ける
- **流れ (20%)**：置けるマスが1つしかない状態が長く続かない（探し回るだけの退屈さを避ける）
- **配置 (13%)**：全ブロックにヒント数字があり、行・列・ブロックの数字の偏りが少ない

## 使い方
- 標準数独：`tools/gen_fun.js` の `generateFun(E, rng, { level, count, oversample: 4, minFun: 70 })`
- 変わり種：`E.setVariant(spec)` のあと `funScore(E, puzzle)` で同じように選別（`pickFun` も利用可）
- 参考値（既存問題の中央値）：初級91・中級74・上級79・達人84。中級は技の種類が少なくなりやすいので特に選別の効果が大きい。
