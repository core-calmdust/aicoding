# クロキノール（crokinole）仕様

キャロムに続く「3D専用」タイトル（2D版はない）。2026-11-09 公開（同日にBETAを外して正式公開）。キャロムの操作・効果音・操作カードを流用し、カナダのおはじきとして発展させたもの。

## ルール（NCA／世界選手権のシングルス）
- 盤：直径26インチの盤面（cm で計算）。線は 24／16／8 インチ（5・10・15 の円）、中央に 1⅜ インチの穴（20点）、15の線上に8本のペグ（(k+½)·45°）。盤面の外は溝（ditch）。ディスク 1¼ インチ。
- 各ラウンド8枚ずつ、交互に1枚ずつ打つ。打つ位置は自分の四分円の5の線上（ディスクの中心が線上）。
- 盤上に相手のディスクがあれば、打ったディスク（または自分のディスク経由）で当てなければ反則。相手のディスクがなければ、15の円に触れるか内側に止まらなければ反則（20に入れば可）。
- 反則：打ったディスクと、それが動かした自分のディスクを取り除く（相手のディスクは溝へ落ちたまま）。
- 穴に入ったら20点（その場で取り分ける）。止まったディスクは触れている線のうち低い方の点。止まった時点で5の線に触れているものは溝へ。
- 得点はラウンドの終わりに盤上のディスクで数え、差がその勝者へ。
- ゲームの長さ（サイズ選択）：4ラウンド（世界選手権方式：ラウンド勝ち2点・引き分け1点、同点なら延長ラウンド、8ラウンドで決まらなければ引き分け）または100点先取（差点方式）。
- 先手はラウンドごとに交代（後手＝ハンマー）。

## 物理（`simulate`）
- 一定の減速 62cm/s²（磨いて粉を振った盤）、最大初速 320cm/s、ディスク同士の反発 0.9、ペグ 0.55。刻み 1/480秒、最大14秒。
- 穴：中心が穴の上を 20cm/s より遅く通ると落ちる（速いと乗り越える）。盤面の縁を越えたら溝へ。
- 対局は「先に全部を計算 → 60fpsの記録を再生」（キャロムと同じ）。

## AI（Lv.1〜20、`think`）
- 候補：20狙い、相手のディスクへの当て（はじき出し・残し）、15の円の内側への置き（ペグの陰を含む）。評価は点差・反則・残り枚数。
- 手のぶれ（角度・強さ）は Lv が低いほど大きく、下限あり（毎回20が入らないように）。

## 操作（キャロムと同じ `Hand`）
- 対局中は拡大鏡・ダブルタップのズーム・文字選択が出ない（`Hand` が `html.hand-on` を付ける。キャロムと共通、2026-11-10）。
- 手のぶれ（`wobble`）：人の打ちは毎回少しだけばらつく（同じ狙い・同じ％でも同じにはならない）。角度と強さに正規分布のぶれ、1標準偏差で弱い打ち ±0.8°／±4%、全力 ±1.6°／±7%（強さの2乗で増える）。狙いどおりの空き盤の20はおよそ5回に4回入る。AIは従来どおりレベルごとのぶれ（`perform`）。ルールコースの課題には入れない。
- 左右でディスクの位置（自分の四分円の5の線上）、引いて離して打つ。力の対応は `v = 20 + 300·pw²`（弱い打ちを細かく）。点線は最初に当たるもの、5の線上の帯が置ける範囲。
- 盤面反転（左下 `.ckflip`）と視点切り替え（その右 `.ckview`、スマホでは右下）。`atlas-flip-crokinole`・`atlas-crokinole-view` に記憶。
- 盤の名前（一覧の順）：「寄木細工 3D」（`marq`、既定）「クラシック 3D」「モダンアート 3D」(`modern`)「ミッドセンチュリー 3D」(`mcm`)「カナダの冬 3D」(`winter`)「ネオン 3D」（`N3`、14言語）。トップページ・一覧のスクショは既定の寄木細工盤。選択は `atlas-crokinole-look`（table3d.js の `stamp()` に含める）、サムネイル `atlas/img/board-crokinole-<look>.webp`（tools/boards.html）。
- クラシック（以前の既定）：メープルの単板、板目（中央に山形の木目、晩材の線、繊維、まばらな導管）をラッカー仕上げ。黒い線、20の穴に赤い輪、ウォルナットの枠、緑の溝、真鍮のペグにゴムの鞘。ディスクは赤と黒（染めたメープル、ろくろ目）。
- ネオン：黒い盤面に光る線、虹色に流れるLED（キャロムの `rgbify`）、ぶつかると光る（控えめ）。
- 寄木細工：15と5の線の間はメープルとチェリーの16の放射状の板。15の内側は小さな三角の寄木（メープル・チェリー・ウォルナット、木目の向きは木片ごと）。5の外側の帯は同じ3種の木片を輪に沿って組む：三角格子を盤の周に沿わせて曲げ（象嵌線の間に2列）、木片ごとに樹種・色味・木目の向きを変え、木片の間に接着の目地。濃いウォルナットは上向きの三角にだけ使い、辺で接して連続しないようにする（15の内側も同じ）。輪の境にメープルとウォルナットの象嵌線。ウォルナットの線、メープルのペグ、ウォルナットの枠にメープルの象嵌線、茶色のスエードの溝。ディスクはチェリーと黒檀にメープルの象嵌リング。
- カナダの冬：霜と細いひびの入った氷の盤面、淡い雪の結晶、穴の下に赤いメープルリーフ、オーロラ色（青緑→緑→紫）の線。白樺の枠に赤い線、紺のフェルトの溝、クロムのペグに赤い鞘。ディスクはつやのある赤と紺黒に白い輪。
- ミッドセンチュリー：濃いオイル仕上げのチーク、クリーム色の線。穴の周りにサンバースト時計（長短24本の光線と玉）、10の線の内側に目盛り、四分円ごとにアトミック期のモチーフ（スプートニク・ブーメラン3つ・原子の軌道・イームズ風の玉の房）ときらめき。色はクリーム・マスタード・バーントオレンジ・ティール・オリーブ。濃いチークの枠に真鍮の輪、マスタードのフェルトの溝。ディスクはバーントオレンジとチャコールに原子の軌道。
- モダンアート：温かい紙に4つの区画の色面（テラコッタ・サフラン・ティール・インク）、15〜10の間に弧の輪、穴の周りに円の花、リソグラフ風の粒子。インクの線、マットな紺の枠に真鍮の輪、テラコッタの溝。ディスクはマットなコーラルとインクに真鍮の点。
- ディスクの色はどの盤でも「赤系」と「黒系」（2人対戦の色名は赤／黒のまま）。HUDの色見本は盤ごとの色（`userData.dot`）。
- 展示用（3Dビュー）のディスクとルールコースのディスクはペグに重ならない位置に置く（ペグ＋ディスク＝中心間2.14cm以上）。
- スマホ（縦長）の初期の画角：盤面が画面幅いっぱいで、枠の左右は画面からはみ出す大きさ（`fit` の w・d＝盤の0.8倍）。
- 上部のHUD：AIが考えている間は「AIが狙っている…」（スマホは折り返さないよう「AIの番」だけ）。左右に両者の点と残り枚数、中央にラウンド・点数（小さく）と手番。「相手の駒に当てよう／15の円まで届かせよう」は盤より上（HUDの下）に白地（テーマ色の縁取り）のポップアップ（`.cktask`）で出し、狙っている間・相手の番は消す。
- 溝に落ちたディスクは溝を転がって止まる演出。ラウンドの終わりに得点表示 → 次のラウンド。
- テスト用に `window.__crokinoleTable._debug`。

## ルールコース（9ページ）
紹介 → 盤（穴をタップ）→ 置いて打つ → 盤が空のとき（15の円へ）→ 当てる → 20 → 反則（お手本）→ 得点（15のディスクをタップ）→ 勝ち方。はじく課題はキャロムと同じく狙いと強さを少し助ける。14言語。
