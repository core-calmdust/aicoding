# キャロム（carrom）仕様

大百科で初めての「3D専用」タイトル（2D版はない）。2026-11-09 公開、BETA。

## 構成
| ファイル | 役割 |
|---|---|
| `carrom/engine.js` | ルール・物理・AI（DOMなし。ポータル・ルールコース・ワーカーで共用） |
| `carrom/worker.js` | AIの思考（`CarromEngine.think` をワーカーで） |
| `atlas/models/carrom.js` | 3D盤2種（モダンアート `modern`＝既定・王道 `classic`）と駒・クイーン・ストライカー |
| `atlas/games/carrom.js` | 3D卓での対局（`Atlas3D.carrom`） |
| `atlas/rules/carrom.js` | ルールコース（案内役：カワウソのオットー、`images/atlas/av/otter-1.webp`） |
| `atlas/historia/s/carrom.json`・`atlas/historia/<lang>/carrom.json` | ヒストリア（14言語）。図は historia.js の `carrom` 型 |
| `atlas/tools/topdown.html` | 3D盤を真上から透明背景で撮る道具（トップページ `images/carrom.webp` と一覧 `atlas/shots/carrom.webp` はこれで既定のモダンアート盤を撮る） |

- 台帳：`shared/atlas.js` の GAMES に `only3d: true`（ポータルの「2Dで遊ぶ」リンクを出さない）、`href: 'atlas/#games/carrom'`（トップページからは大百科の3Dビューへ直接開く）。カテゴリは新設の `action`（アクション・おはじき、14言語）。テーマ色 #c23a7a（ラニピンク）。
- トップページ：GAMES に `cat:'action'`・`beta:1`、`GX_CATS` に `action`、アイコン `images/icons/carrom.svg`。

## ルール（ICFの競技規則・シングルス）
- 盤 74cm 四方、ポケット直径4.45cm、駒3.18cm（5.5g）、ストライカー4.13cm（15g）。物理はこの実寸（cm）で計算する。
- 初期配置：中央にクイーン、周りに白黒交互の6枚、外周12枚（白3枚が内側の白と「Y」字に並び、その間を黒・白・黒）。
- ブレイクした側が白。ブレイクは駒に当てる（3回外したら相手がブレイク）。
- ストライカーはベースラインの2本線の間（両端の丸を含む）に置く。駒に重ならない位置だけ。
- 自分の駒を入れたら続けてもう一打。相手の駒だけなら交代（入った駒は相手のもの）。
- クイーン：自分の駒を1枚以上入れた後に入れられる（それより前・ペナルティが残っている間は中央へ戻る）。入れたら同じ一打か次の一打で自分の駒を入れて「カバー」。できなければ中央へ戻る。
- ストライカーがポケットに落ちたら反則：その一打で入れた自分の駒は戻し、さらに1枚をペナルティ（Due）として戻す。自分の駒も入れていれば続けて打てる。戻す駒がないときは借りにして、次に入れたときに戻す。
- 戻す駒はクイーンは中央、ほかは中央の円にかからない外周円の内側の空いた所へ自動で置く。
- 最後の1枚：クイーンがカバーされる前に自分の最後の駒を入れたら、その駒を戻してペナルティ1枚・交代（簡略化。ICFでは相手に3点）。相手の最後の駒を入れたら反則（戻してペナルティ・交代）、クイーンがカバー済みなら相手のボードの勝ち。
- ボードの勝ち：9枚すべて入れてクイーンがカバー済み。点数＝相手の残りの駒＋自分でカバーしたクイーン3点（自分の点が22以上なら0）。
- ゲームの長さ：1ボード、または25点マッチ（最大8ボード。ブレイクはボードごとに交代）。

## 物理（`simulate`）
- 2Dの円盤：一定の減速（摩擦 92cm/s²）、駒どうしは反発係数0.93、クッションは0.74（接線方向0.96）、ポケットは中心が穴の中に入ったら落ちる。刻み 1/480秒、最大14秒。
- 対局は「先に全部を計算 → 60fpsの記録を再生」。再生中にタップすると3倍速。

## AI（Lv.1〜20、`think`）
- 候補：自分の駒（条件を満たせばクイーン）×4ポケットの「ゴースト球」の狙い（ベースラインの位置を数か所、強さ3段）、Lv.8 以上はクッションの返しも。ブレイクは中央めがけた強打。入らないときは自分の駒の固まりへ軽く当てる。
- 評価：入れた駒・ペナルティ・クイーン（カバー・保留）・もう一打のときの次の入れやすさ、交代するときは相手の入れやすさ。
- 段階：Lv が上がるほど読む候補が多く（6〜約200）、Lv.11以上は上位の手を手のぶれ込みで試して崩れにくい手を選ぶ。手のぶれ（狙いの角度・強さ）は Lv.1 約4.8° ／ Lv.20 約0.2°。Lv.1〜6 は上位から少しランダムに選ぶ。
- 着手は即時（考えたらすぐ、ストライカーを動かして一瞬狙いを見せてから打つ）。

## 操作（3D卓・ルールコース共通。`Atlas3D.carrom.Hand`）
- マウス：ボタンを押さずに左右へ動かすとストライカーの位置が決まる。左ボタンを押したまま引くと狙い：ストライカーから見て引いた方向の反対へ打つ（下へ引くと上へ、上へ引くと下へ）。引いた距離が力（ストライカーのそば約3cmより外から）、左右で角度。離すと打つ。ストライカーのそばまで戻すとやり直し（位置決めに戻る。ボタンを押したまま動かすと位置決め、離して押し直すと再び狙い）。
- スマホ：左右にスライドで位置（指の動きぶんだけ動く）。そこから下へスライドすると狙いに入り、引いた距離が力、左右で角度。指を離して打つ。狙いに入った所まで戻すとやり直し。
- PCの ← → でも位置を動かせる。点線＝最初に当たる所、輪＝そのときのストライカーの位置、緑の線＝当たった駒の行き先、矢印の色が力（緑→赤）。
- 待った（AI戦：自分の前の手番まで）・ヒント（Lv.20の手：ストライカーを置いて、狙いを桃色の点線で表示、強さを％で）・投了。2人対戦は手番の側が手前に来るよう盤が回る。
- 操作の説明は最初の手番に画面上部へ1回だけ出す（端末に合わせてマウス用／タッチ用。`HOW`）。ブレイクの声かけの後で改行する。お知らせ（トースト）は白地に濃い文字、縁取りの色で種類（ふつう＝テーマ色・成功＝緑・反則＝赤）。

## ルールコース
- 9ページ（操作のチュートリアルを兼ねる。本番と同じ操作）：紹介 → 盤とポケット（ポケットをタップ）→ 位置を決める（印まで動かす）→ 引いて離して打つ（まっすぐ引いて白に当てる）→ 角度をつけて入れる → 自分の色ともう一回（カット）→ クイーンとカバー（2打）→ ストライカーが落ちたら（お手本）→ 勝ち方と点数。操作の言い回しは端末（マウス／タッチ）で切り替える。
- はじく課題は少し助ける：正しい狙いから9°以内なら狙いをぴったりに、強さも入る強さにして打つ。外れたらひと言のあと同じ局面に戻す。
- 正解で自動的に次へ（台詞を読める時間の後）、台詞の文字送りに声の効果音、前と同じ駒は動かさず新しい駒だけ落とす（共通ルールどおり）。
