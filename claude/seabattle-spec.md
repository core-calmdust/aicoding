# 海戦ゲーム（seabattle/）仕様

URL: https://core-calmdust.github.io/aicoding/seabattle/ （**2026-11-16 時点は未掲載の BETA**：トップページ・大百科ポータルには未登録、URL 直打ちで遊べる）。テーマ色 #0a2230（ペトロールブルー＋シーフォーム #8fe6d4、命中はコーラル #ff8f6b。既存の紺・青緑系より緑寄りの青）。

名称：商品名（Battleship）は使わず、一般名の「海戦ゲーム／Sea Battle」。艦名も一般名（空母・戦艦・巡洋艦・潜水艦・駆逐艦）。

## ルール
出典（2026-11 確認）：Wikipedia「Battleship (game)」（第一次世界大戦のころからの紙と鉛筆のゲーム。最初の商品は 1931 年 Starex 社の「Salvo」、1967 年に Milton Bradley がプラスチック盤。艦は 5・4・3・3・2。Salvo は残っている艦の数だけ撃つ変種）。

- 10×10 の海が2つ。各自 5 隻（長さ 5・4・3・3・2＝17 マス）をたて・よこに置く。相手の海は見えない。
- 手番にマスを1つ撃つ。艦がいれば命中、いなければはずれ。全マスに命中した艦は撃沈（撃沈した艦は姿を見せる）。相手の5隻を先に全部沈めた方の勝ち。
- ゲームタブの4ルール（タクティクスは下の節）（`engine.js` の RULES）：

| キー | 名前 | 内容 |
|---|---|---|
| `classic`（既定） | クラシック | 1発ずつ交代。 |
| `streak` | 連続攻撃 | 命中したらもう1発（外すまで続く）。 |
| `salvo` | 一斉射撃 | 残っている自分の艦の数だけ撃てる。**本作の取り決め**：結果は1発ごとにすぐ出す（1931 年版の「まとめて撃ってから結果」ではない）。 |

| `tactics` | タクティクス | 場の艦を交互に選んで編成し、艦ごとのスキルで戦う（2026-11-16、ユーザー案）。 |

### タクティクス（`engine.js` の TYPES・draft*・useSkill）
- **場（毎局ランダム）**：駆逐艦＋ほかの25種から6種、各2隻（計14隻）。6種には攻撃系（空母・戦艦・巡洋艦・砲艦・ロケット艦・超弩級戦艦・軽空母・魚雷艇）・情報系（潜水艦・水上機母艦・レーダー艦・哨戒艇・掃海艇）・防御／支援系（装甲艦・煙幕艦・旗艦・電子戦艦・工作艦・防空巡洋艦・機雷敷設艦・囮ブイ・モニター艦・補給艦・病院船・制圧艦）が最低1種ずつ入る（`field`）。
- **編成（ピック）**：**先・後・後・先・先・後…** の順に1隻ずつ選ぶ（後攻で撃つ側が先に選ぶ）。コストは 20 まで、3〜6隻、**同じ艦は1隻まで**（`MAXSAME`）。3隻以上なら「これで出撃準備」で打ち切れる。買える艦がなくなれば自動で終わり。相手の編成は公開（位置だけ隠す）。選び終えたら通常どおり配置。
- 艦とスキル（スキルはその手番の攻撃のかわりに使う。クールタイムは自分の手番で数え、開始時は半分たまった状態。**艦が沈むとそのスキルは使えない**）：

- 盤の値：`shots` は 0 未知／1 はずれ／2 命中／**3 へこみ**（命中として見えるが、もう一度撃てる）。煙の下の結果は `view()` で **4（？）** に隠す（`fogged`）。煙幕・号令・妨害・修理・機雷はマスを選ばない（`NOAIM`、ボタンを押すと即発動）。
- AI：編成は種類ごとの重み（`DRAFT_W`）と乱数。相手のスキル艦が多いほど電子戦艦、自分のスキル艦が多いほど旗艦を好む。対局は確率マップから各スキルの期待値（命中数の見込み、魚雷は命中確率＋見える海、ソナー・偵察は索敵中だけ、煙幕は自分の海の残りに応じて、号令は短縮できる量、妨害は敵のたまりそうなスキル、連射は上位2マス）を出し、通常の1発と比べて最大のものを選ぶ。へこみがあれば先に撃つ。低レベルはスキルをあまり使わない。
- 実測（`node seabattle/tools/test_tactics_balance.js 3000 <seed>`、Lv.20 同士・ランダムの場）：その艦を入れた側の勝率は全26種で 48〜52%（2026-11-20 第8弾の後、4000局×2。制圧艦はコスト3・CT5で 47〜48% だったので 2・4 に。魚雷艇はコスト3・CT5で 53%／入れない側 39% だったので 4・6、軽空母は CT6、レーダー艦はコスト3、哨戒艇は CT5 に。病院船はコスト3で入れない側が 44〜46% だったので 4 に。モニター艦はコスト5で 46%、哨戒艇はクールタイム3で入れない側が 38% だったので、4・4 に。機雷敷設艦はコスト3・クールタイム5では 45% だったので 2・4 に。第1弾の調整前は砲艦 54%／入れない側 35%、電子戦艦 47%。工作艦はコスト4・クールタイム6では 47%・選ばれ率 43% だったので 3・5 に）。先攻 47〜48%、詰まった局 0。AI の修理の価値は `REPAIR_V`（0.65、相手が自分の命中を追っているときは +0.15）、機雷は `MINE_V`（0.5、追われているときは 0.15）。敵の残りの機雷の数は公開情報（敷設・触雷・掃海の記録）から数える（`minesLeft`）。範囲スキルは相手に防空巡洋艦がいれば 1 発ぶん割り引いて評価。休みの手番は戦況ログに `rest` として残る。
- 画面：編成中は右欄（スマホは盤の下）に場の艦・両者の選んだ艦と残りコスト。対局中はスキルのボタン（使える／あとn／喪失）。押すと狙いモード（PC はマウスの下に範囲が光る）、盤を押して発動、もう一度押すと解除（マスを選ばないスキルは押すと発動）。敵のスキルの状態は艦隊欄に表示。ソナー・偵察の結果は盤に点線の箱と数字で残る（新しい3つ）。煙の下の盤は霧がかかり、結果は「？」。

- ルールタブ：AI の強さ（Lv.1〜20）、先攻（あなた／ランダム／AI）、艦の置き方（となり合ってよい＝既定／離して置く＝角も接しない）。
- 待ったはない（見えた情報を取り消せないため）。同じ端末の2人対戦もない（相手の海が見えてしまうため）。

## エンジン（engine.js、純 JS・同期。Node でも require 可）
- マスは r×10＋c。`newGame({rule, adj, fleets:[自分, 相手], first})`、`fire(st, cell)` → `{by, cell, hit, sunk, win, again}`。
- AI が見るのは公開情報だけ（`view(side)`：撃った結果と、撃沈した艦のマス）。相手の配置は読まない。
- **確率マップ**（`heat`）：残っている各艦の、公開情報に合う置き方を全部数え、マスごとに重ねる。未撃沈の命中マスを含む置き方は 6^k 倍（k＝含む命中の数）、未撃沈の命中があるときはそれを含む置き方だけで決める。全マスが命中済みになる置き方は除く（撃沈と告げられているはず）。「離して置く」では撃沈艦のまわりも除く。
- **艦隊まるごとのサンプリング**（`jointHeat`、ヒント用）：公開情報に合う艦隊を一様に引いて、マスごとの「艦がいる確率」を出す。未撃沈の命中があるときは、最初の命中をおおう（艦, 置き方）を全部試し、残りの艦を引く（引いた空間の大きさで重み付け）。受理が少なければ `heat` を正規化して代用。
- 20段階（Lv.表記）：どのレベルも同じ確率マップを読む。違いは「考えずに撃つ」割合（eps＝((20−Lv)/19)^0.7）と、命中のあと隣を追う割合（0.2→Lv.13 で 1）。Lv.20 は常に確率マップの最大。
  - 実測（`node seabattle/tools/test_engine.js 300`、艦隊を沈め切るまでの平均弾数）：Lv.1 80.9／Lv.3 67.5／Lv.5 60.9／Lv.7 57.9／Lv.9 54.3／Lv.11 53.2／Lv.13 51.1／Lv.15 49.1／Lv.17 47.4／Lv.20 44.3。5 レベル上は 61〜96% 勝つ。
  - 試して採らなかったもの：上位レベルを艦隊サンプリングの最大にする（45.1〜45.6 発で `heat` の 44.5 発より良くならない）。
- **形勢**（`winProb`）：公開情報だけのロールアウト。両方の海について「知っていることに合う艦隊」を引き、確率マップ撃ちで沈め切るまでの弾数を数えて比べる（8 回ずつ）。実測の当たり具合：予測 0–20% → 実際 19%、80–100% → 80%。
- 未着手：Praline（マルチスレッド）への乗せ換え、Lv.20 より上（数手先の情報量を読む）、レート戦。

## 画面（index.html・app.js・board.js・tour.js）
- 盤は SVG（`board.js` の `SeaBoard.draw / fx / cellAt`。1マス＝10、ラベル用の余白つき）。艦5種は形が違う（空母＝飛行甲板と艦橋、戦艦・巡洋艦・駆逐艦＝砲塔の数、潜水艦＝カプセル形）。
- **主画面は1つ**：自分の番は「敵の海域」、AI の番は自動で「自分の艦隊」に切り替わり、撃たれる所を見せてから戻る。もう一方の海は右欄（スマホは盤の下）の小さな盤に出し、押すと手動で切り替え。
- 配置：開いた時点で艦隊はランダムに置いてある。ドラッグで移動、タップ／クリックで向きを変える（置けない向きなら近くの置ける所へ寄せる）。「並べ直す」「出撃」。
- 攻撃の演出：照準が閉じる → 命中は閃光、はずれは波紋 → 中央に「命中／はずれ／◯◯を撃沈」。撃沈で盤が揺れる。音は Web Audio の合成（ファイルなし）。
- ヒント：敵の海に確率マップを重ね（明るいほど艦がいる確率が高い）、最有力のマスに照準、状態欄に「C2 が最有力（艦がいる確率 54%）」。もう一度押すと消える。撃つと消える。
- 右欄（360px）：小さな盤＋両艦隊の残り（自分の艦は被弾数も）→ 状態 → 形勢（バー・グラフ）→ 戦況ログ。一斉射撃は盤の見出し右に残り弾数の点。
- 終局：負けたら敵の残りの艦を見せる。結果は勝敗・弾数・両者の命中率、［閉じる］［もう一度］。
- 対局設定：ゲーム（3ルールのカード）｜ルール｜デザイン（海4種：深海＝既定・海図・レーダー・黎明。押した瞬間に反映）。
- ルール（RuleTour）：紹介 → 艦隊と海 → 艦を配置する → 攻撃する → 命中のとなりを狙う → 撃沈する → 3つのルール。
- 共通部品：headerbar・resign・ruletour・rulesoffer・record・ngtabs・nglux・langsel・infotabs。メニューは 新規＞投了＞ヒント＞ルール。
- 言語：**ja・en のみ**（残り12言語が揃うまで言語メニューに出さない）。オンラインなし（`body.no-online`）。

## 確認の道具
- `node seabattle/tools/test_engine.js [局数]`：ルール、レベルごとの平均弾数（単調に強くなること）、レベル差の勝率、ヒントの確率の正直さ、形勢の当たり具合。
- `node seabattle/tools/test_tactics.js`：ピック編成、全スキルの発動、AI のスキル、復元（PC・スマホ）。
- `node seabattle/tools/test_tactics_new.js`：新しい艦を両軍に持たせた対局を直接作り、機雷・ロケット（防空で1発落ちる）・修理をタップで使い、最後まで打つ・弾幕・レーダー・囮・探信射撃・モニター艦の反撃・病院船で沈んだ艦のスキル・機銃掃射・横魚雷・制圧・掃海（PC・スマホ）。
- `node seabattle/tools/test_tactics_balance.js [局数] [seed]`：Lv.20 同士の自己対局。艦ごとの場に出た率・選ばれた率・入れた側／入れない側の勝率、スキルの使用回数。
- `node seabattle/tools/test_ui.js [画像の出力先]`（playwright＋Chrome、`python3 -m http.server 8765` を先に）：配置（ドラッグ・向き・重なり拒否）、3ルールを最後まで、ヒント、投了、結果、保存と復元、ルール説明の4課題、英語。
