# 雀華（じゃんか）〜姫たちの麻雀〜 仕様 v0.5（仮称）

4人打ちリーチ麻雀。スキルで点数がインフレする「スキル戦」と、通常ルールの「標準戦」。ガチャで女の子キャラを集める独自ポータル型（経済圏は独自）。`mahjong/`。
公開：GitHub Pages（core-calmdust.github.io/aicoding/mahjong/）と、クリックで遊べる claude.ai アーティファクト（`tools/build-artifact.py` で生成した束を publish。1回の publish は255ファイルまでなので、追加と削除は分けて送る）。

## 確定（ユーザー指示）
- 4人打ちリーチ麻雀（雀魂準拠）。三麻は後で追加
- キャラ画像はユーザーが生成して提供（4K PNG → 2K 1080×1920 WebP に圧縮して使う）
- **髪色が同じキャラは姉妹。画像1枚＝キャラ1人**（差分ではなく別キャラ）
- **キャラにレア度（N/R/SR/SSR/UR）。上位ほどフレームが派手、リーチ等のカットインも上位ほど派手**
- **スキルはガチャで手に入れたときにランダムで付く。スキルにもレア度（N/R/SR/SSR）があり、上位スキルは少しだけ効果が強い**
- **同じキャラで複数のスキルを持てる。対局ごとに使うスキルを1つ選ぶ**
- スキルは2種類：点数倍系は「配牌時に使うか選ぶ」、それ以外は「自分の手番で好きなときに使う」。どちらも1局1回
- コストは1回目無料、2回目はスキルごとの値、以降は倍（供託へ）。値はシミュレーションで決めた
- 3D卓（雀魂風・リアルな全自動卓）、横画面専用。スマホは縦持ちでも画面全体を90°回して横レイアウト（ホームから）
- PCで縦長・正方形のウィンドウでも、対局画面は横長の比率（幅÷高さ 1.36〜2.4）に収めて中央に置く
- ホームのパートナー画像をタップ → キャラ表示＋選択画面
- ツモ牌は手牌から少し離す。河は隣と重ならない（卍型にずらす）
- 公開・更新の報告には毎回クリックで遊べるアーティファクトを付ける

## 牌の見た目（2026-11-14）
- 牌の絵と文字は上海（大百科）と共通：日本式の実物の牌の写真からなぞったシート（`atlas/img/shanghai-glyphs.png`・`shanghai-art.png`、`atlas/tools/shanghai-glyphs.py`）を `tiles.js` が読み込んで描く（`MJTiles.ready()`、読み込めないときは以前の描画）。赤ドラは全部を赤に塗り替え。地は白 #fafaf6。
- 3Dの牌（`table3d.js` roundTile）：角と縁を丸めた白い本体＋紫の背（ユーザー指定：裏面は紫）。面は彫り（`MJTiles.normal`：塗りは平ら、文字のすぐ外の白い縁が溝へ落ちる法線マップ、墨入れなし）。
- 牌の背（2026-11-14）：濃い袱紗の紫に、ごく控えめな石目とつや（ユーザー：素材感は薄く、紫は濃く、模様はもっと目立たなく＝雲状の濃淡はなし、筋はかすか）。最初は淡いラベンダーの磨いた石（キャンバスの石目＋クリアコート＋小さなスタジオの映り込み、隣と模様がそろわないよう4通りの切り出し）。2D表示の牌の背と側面も同じ色味に。
