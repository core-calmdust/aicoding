# 雀華（じゃんか）〜艶やかなる姫君の雀宴〜 仕様 v0.5（仮称）

4人打ちリーチ麻雀。スキルで点数がインフレする「スキル戦」と、通常ルールの「標準戦」。ガチャで女の子キャラを集める独自ポータル型（経済圏は独自）。`mahjong/`。
公開：トップページの開発室に ALPHA（アルファ版）として掲載（2026-11-14 に PRE で掲載、2026-11-17 に ALPHA へ昇格。開発室の先頭。アイコンはユーザー指定の紫苑の立ち絵から顔を角丸で切り抜き images/icons/mahjong.webp）。GitHub Pages（core-calmdust.github.io/aicoding/mahjong/）と、クリックで遊べる claude.ai アーティファクト（`tools/build-artifact.py` で生成した束を publish。1回の publish は255ファイルまでなので、追加と削除は分けて送る）。

## 確定（ユーザー指示）
- 4人打ちリーチ麻雀（雀魂準拠）。三麻は後で追加
- キャラ画像はユーザーが生成して提供（4K PNG → 2K 1080×1920 WebP に圧縮して使う）
- **髪色が同じキャラは姉妹。画像1枚＝キャラ1人**（差分ではなく別キャラ）
- **キャラにレア度（N/R/SR/SSR/UR）。上位ほどフレームが派手、リーチ等のカットインも上位ほど派手**
- **スキルはガチャで手に入れたときにランダムで付く。スキルにもレア度（N/R/SR/SSR）があり、上位スキルは少しだけ効果が強い**
- **同じキャラで複数のスキルを持てる。対局ごとに使うスキルを1つ選ぶ**
- スキルは2種類：点数倍系は「配牌時に使うか選ぶ」、それ以外は「自分の手番で好きなときに使う」。どちらも1局1回
- コストは1回目無料、2回目はスキルごとの値、以降は倍（供託へ）。値はシミュレーションで決めた
- 3D卓（雀魂風・リアルな全自動卓）、横画面専用。スマホは縦持ちでも画面全体を90°回して横レイアウト（ホームから）
- PCで縦長・正方形のウィンドウでも、対局画面は横長の比率（幅÷高さ 1.36〜2.4）に収めて中央に置く
- ホームのパートナー画像をタップ → キャラ表示＋選択画面

- 効果音（録音、images/mahjong/snd/）：牌の音3種をランダムで、捨て牌が河に置かれた瞬間と鳴いた牌が副露に置かれた瞬間に（手牌から取る時ではない。TB.onTileLand）、点棒（リーチ棒・スキル代を供託へ）は点棒の音3種をランダム、掛け声はリーチ・ツモ・ロン・ポン・チー・カン・テンパイ・ノーテン（流局時は自分のテンパイ／ノーテンだけ）。未読込のあいだは合成音。チー・ポン・カン・ロンの選択肢が出た瞬間に軽い合成音（2音の上昇、`SND.callAsk`。2026-11-18）
