# 雀華（じゃんか）〜姫たちの麻雀〜 仕様 v0.5（仮称）

4人打ちリーチ麻雀。スキルで点数がインフレする「スキル戦」と、通常ルールの「標準戦」。ガチャで女の子キャラを集める独自ポータル型（経済圏は独自）。`mahjong/`。
公開：トップページの開発室に PRE（プレアルファ）として掲載（2026-11-14〜、WYRMSPHERE の後ろ。アイコンはユーザー指定の紫苑の立ち絵から顔を角丸で切り抜き images/icons/mahjong.webp）。GitHub Pages（core-calmdust.github.io/aicoding/mahjong/）と、クリックで遊べる claude.ai アーティファクト（`tools/build-artifact.py` で生成した束を publish。1回の publish は255ファイルまでなので、追加と削除は分けて送る）。

## 確定（ユーザー指示）
- 4人打ちリーチ麻雀（雀魂準拠）。三麻は後で追加
- キャラ画像はユーザーが生成して提供（4K PNG → 2K 1080×1920 WebP に圧縮して使う）
- **髪色が同じキャラは姉妹。画像1枚＝キャラ1人**（差分ではなく別キャラ）
- **キャラにレア度（N/R/SR/SSR/UR）。上位ほどフレームが派手、リーチ等のカットインも上位ほど派手**
- **スキルはガチャで手に入れたときにランダムで付く。スキルにもレア度（N/R/SR/SSR）があり、上位スキルは少しだけ効果が強い**
- **同じキャラで複数のスキルを持てる。対局ごとに使うスキルを1つ選ぶ**
- スキルは2種類：点数倍系は「配牌時に使うか選ぶ」、それ以外は「自分の手番で好きなときに使う」。どちらも1局1回
- コストは1回目無料、2回目はスキルごとの値、以降は倍（供託へ）。値はシミュレーションで決めた
- 3D卓（雀魂風・リアルな全自動卓）、横画面専用。スマホは縦持ちでも画面全体を90°回して横レイアウト（ホームから）
- PCで縦長・正方形のウィンドウでも、対局画面は横長の比率（幅÷高さ 1.36〜2.4）に収めて中央に置く
- ホームのパートナー画像をタップ → キャラ表示＋選択画面
- ホームはAAAタイトル風（2026-11-14）：部屋いっぱいの背景（パートナーの絵をぼかした色・金の格子・光の筋・リアルな光の粒のcanvas（柔らかいスプライトを加算合成：遠くの細かな粒・瞬いて小さな光芒を出す近くの粒・大きなボケ玉。キャラの手前に重ね、ポインタで奥行きの視差））、中央にパートナーを枠なしで大きく（呼吸・マウスで視差、タップで台詞の吹き出し）、左上にプレイヤー（顔・対局数・平均順位→スタッツ）、右上はコイン・設定・ホームのみ、金箔ロゴに光が走る、左にメニュー（ガチャ・キャラ・戦績・スタッツ・準備中3つ）、足元に名前プレート（レア度・姉妹・名前・肩書き・スキル・キャラ変更）、右にPICK UPバナー（未所持の最上位キャラ→ガチャ）と対局設定＋大きな対局開始。開くたびに各要素がスライドイン。PCは対局画面と同じ横長の箱（幅÷高さ1.36〜2.4、正方形寄りのウィンドウでは上下に帯）に収め、スマホは1000×560のステージを拡大縮小。スマホの縦持ちは今のまま（画面ごと90°回転）。言語・サウンド・軽量モードは設定ダイアログ
- 効果音（録音、images/mahjong/snd/）：牌の音3種をランダムで、捨て牌が河に置かれた瞬間と鳴いた牌が副露に置かれた瞬間に（手牌から取る時ではない。TB.onTileLand）、点棒（リーチ棒・スキル代を供託へ）は点棒の音3種をランダム、掛け声はリーチ・ツモ・ロン・ポン・チー・カン・テンパイ・ノーテン（流局時は親から順に宣言）。未読込のあいだは合成音
- リーチ時の演出曲：誰かがリーチするとユーザー提供の三味線曲（snd/bgm-riichi.mp3、128kbps）がフェードインしてループ、局の終わり（和了・流局・次局・退出）でフェードアウト。サウンドオフ・画面非表示では止まる
- キャラ画面もホームと同じ部屋の演出（2026-11-14）：左にガラスのパネルで一覧（すべて・所持・レア度のタブ）、中央にキャラを枠なしで大きく（未所持は暗いシルエット＋ガチャへの案内）、右に名前プレート・スキル・プロフィール・姉妹・パートナーにするボタン
- 画面上の文字の範囲選択と画像のドラッグは不可（入力欄以外）
- ツモ牌は手牌から少し離す。河は隣と重ならない（卍型にずらす）
- 他家の理牌（2026-11-14）：打牌を河に置いた手がそのまま手牌に戻り、ツモ牌を持ち上げて正しい位置へ差し込む（間の牌は横にずれて場所を空ける）。鳴いた後などツモ牌がない打牌は、手で右側の牌を押して隙間を詰める。自分の手牌は自動で詰める
- 河とドラ表示の牌は隣同士ぴったり付ける（くっつけるが融合しない）
- 河は重ならない（2026-11-14）：各列を他家の河の牌と当たり判定し、当たる列だけ列の方向に最小限ずらす（ずらせない時だけ自分側へ下げる）。半透明にはしない
- ウィンドウが前面にないときは対局を進めない（shared/focusgate.js で performance.now が止まり、待ち時間 sleep も止まる）
- 左上の箱：ドラ表示牌（3D牌を正面からパースなしで撮った画像 `TB.tileShot`、まっすぐ並べる、縁は卓の牌より鋭め、「ドラ」の文字なし）、その下に供託（1000点棒アイコン×本数）と積み棒（100点棒アイコン×本場）。中央の点数表示機は点数と「◯局」「余◯」だけ
- 卓の明るさ：中央にスポットを当て、周辺は軽く暗く（場所で明るさが変わる）。フェルトは濃紺
- 画面左上から薄いゴッドレイ（光の筋＋筋の中で瞬く細かな光の粒、HUDの下、#game .rays。見える程度に）
- 卓の下の床に暗い赤の絨毯（参考写真のトルクメン系：赤地に暗色の八角形ギュルの列と枝模様、段々模様の縁。卓より少し大きく縁が見える。照明は当てず、目立たないが少し見える程度。rugTex）
- 牌の丸み：面から側面へ回り込む縁を大きめの丸に（面取り 0.15×0.15、5段）。紫の背面側はドラ表示の牌と同じ鋭めの縁（0.05）。正面から見た角の丸さは従来どおり、絵の大きさも従来どおり
- ドラの演出：卓上の牌は牌全体（全方向）を覆う膜に、常に薄いピンク＋縁の光（見る角度で縁が明るい）＋縁を一周する光＋表の星＋牌を斜めに横切る光の帯（約2.6秒ごと）。手牌（HTML）も同じ見た目（薄いピンク・ピンクの縁を走る光・横切る光の帯・星）
- アニメ速度：卓上の動きは記述の1.6倍速（table3d.js SPD）、待ち時間は0.8倍（app.js PACE）
- ロン優先：BOTに先に応答させ、BOTがロンしたら自分にはポン・チーを出さない（自分もロンできるならロンだけ聞く＝ダブロン）
- 手は手タレのように明るく綺麗な肌（内側からほのかに発光、影で黒くならない）
- 先読み：効果音・掛け声・リーチ曲はページを開いた直後から裏で1つずつ（ブラウザが暇なときに）読み込んで展開しておく。リーチ曲は丸ごとメモリへ。ドラのシェーダーは対局開始時に先にコンパイル、カットイン絵も先に展開
- 点数移動の矢印：向かいの席への矢印は中央を通す。矢印に沿って控えめな白い光が受け取る側へ流れ続ける（「動いているかな」程度）。点数の箱は角を欠かない角丸。局の終わりの画面（和了・点数移動）はゲームの枠（横長の箱）の中に出し、「次へ」ボタンも枠内・一回り小さく
- 中央の表示機：丸い画面を広げ、「◯局」「余◯」を大きく
- 手の袖は各席のキャラの姉妹の色の錦（色を深めた地に金の柄、明るい色はそのまま明るく）
- 公開・更新の報告には毎回クリックで遊べるアーティファクトを付ける

## 牌の見た目（2026-11-14）
- 牌の絵と文字は上海（大百科）と共通：日本式の実物の牌の写真からなぞったシート（`atlas/img/shanghai-glyphs.png`・`shanghai-art.png`、`atlas/tools/shanghai-glyphs.py`）を `tiles.js` が読み込んで描く（`MJTiles.ready()`、読み込めないときは以前の描画）。赤ドラは全部を赤に塗り替え。地は白 #fafaf6。
- 3Dの牌（`table3d.js` roundTile）：角と縁を丸めた白い本体＋紫の背（ユーザー指定：裏面は紫）。面は彫り（`MJTiles.normal`：塗りは平ら、文字のすぐ外の白い縁が溝へ落ちる法線マップ、墨入れなし）。
- 牌の背（2026-11-14）：濃い袱紗の紫に、ごく控えめな石目とつや（ユーザー：素材感は薄く、紫は濃く、模様はもっと目立たなく＝雲状の濃淡はなし、筋はかすか）。最初は淡いラベンダーの磨いた石（キャンバスの石目＋クリアコート＋小さなスタジオの映り込み、隣と模様がそろわないよう4通りの切り出し）。2D表示の牌の背と側面も同じ色味に。
- 牌の絵の清書と彫り（2026-11-14、Fable）：
  - 索子・筒子・一索は `atlas/tools/shanghai-svg/gen.py` が SVG を生成（手で直さない）。索子は定番の配置（2〜9本、5・7・9 と一索に赤、8索は M と W）、竹は上・中・下に丸い節＋稈のまん中に白い筋。一索は定番の構図（上に丸い尾羽＝とげの縁と白い輪に赤い芯の目玉、下に翼を扇に広げた正面の孔雀、横を向いて口を開ける、赤い脚）を**線画ではなく太い面**で描く。筒子は定番の柄を再現する（ユーザー指示）：太い外の輪 → 白いすき間 → 細い内の輪 → 6枚のしずく形の花びら → 芯。小さい丸（6〜9筒）だけ内の輪を省いて外の輪と花びらを太くする。一筒は外の輪 → 赤と紺の葉の帯 → 内の輪 → 8枚の大きな花。**線・すき間は 280 幅のセルで 7 以上**（手牌の表示で約2px）を守り、それより細かい模様は潰れるので描かない。
