# DREADNOUGHTS: FLEET TACTICS（dreadnoughts/）

海戦ゲーム（seabattle/）とは別枠の3D専用タイトル。開発室に ALPHA で掲載（2026-11-21 ユーザー決定）。
2D版は「海戦ゲーム」の名前のまま、3Dの海（デザイン「3D 外洋」）も2D版に残す。

## 構成
- `dreadnoughts/index.html` … 全画面の3Dキャンバス＋独自HUD（暗いガラス・真鍮の細線・切り欠き角。大百科のテンプレは使わない）。フォント Cormorant Garamond / Shippori Mincho B1 / Rajdhani / Zen Kaku Gothic New。
- `dreadnoughts/world.js` … 3Dの世界（`window.World`）。1つの夕暮れの外洋に海域を2つ（自軍 z=+7、敵 z=−7、各10×10）。水面シェーダーにマス・グリッド・命中跡・索敵範囲・照準・波紋を描く。艦は `seabattle/ships3d.js` の50種モデル。カメラは HUD の空き領域（safe rect）に海域が収まるように合わせ、海域間を弧を描いて移動。タイトルでは艦隊が航行。カード用の艦の静止画（portrait）とドラフト／図鑑の回転プレビューもここ。
- `dreadnoughts/game.js` … 画面と進行。ルール・AI（Lv.1〜20、Lv.19〜20はワーカーで先読み）・ドラフトモデル・テキストは2D版（`seabattle/engine.js` `ai-worker.js` `draft-model.js` `i18n.js`）を共用。独自の文言は game.js の `DN`（ja/en）。
- 保存キー `aicoding-dreadnoughts`（設定と配置・対局中の手順）。効果音は `atlas-sfx` と共通。

## 画面
タイトル（出撃・艦艇図鑑・ブリーフィング）→ 出撃設定（ルール4種・タクティクスが既定、AIの強さ、先攻、艦の置き方）→ フリートドラフト（タクティクスのみ）→ 配置 → 戦闘 → 結果（VICTORY / DEFEAT・命中率など）。
- ドラフト：カードは艦の3D静止画つき・高さ統一。タップで選択、もう一度タップで外し、決定で確定（複数選べる手番はまとめて決定）。右に選んだ艦の回転3Dプレビュー、両軍の編成、下に残りコストのゲージ（選択中の分は斜線）。
- 戦闘HUD：左に自軍艦隊（静止画・被弾・クールタイム）、右に敵艦隊・形勢・戦況ログ、下にスキルのドック（リングでクールタイム表示）、左下に「敵の海域／自軍の海域」切り替え（PCは Tab でも）。命中・撃沈は画面中央の大きな文字。
- スマホ：自軍艦隊は下の横スクロール帯、敵パネルは出さない、スキルの範囲は1回目のタップで表示・同じマスの2回目で発射。

## テスト
`node dreadnoughts/tools/test.js`（ローカルサーバー :8765、SwiftShader の WebGL）。PC とスマホで タイトル→図鑑→設定→ドラフト→配置→砲撃→勝利→タイトル を通す。
