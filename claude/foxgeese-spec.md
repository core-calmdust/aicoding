## ルール
出典（2026-11 確認）：bead.game「Fox and Geese」（15羽の配置：片方の腕の6点＋腕のすぐ上の7点＋中央の列の両端2点）、Wikipedia「Fox games」（『グレティルのサガ』のハラタフル、遅くとも14世紀。エドワード4世の「狐2匹と猟犬26匹」。13羽は狐有利で、15・17・18羽や狐2匹がより釣り合う。取りは強制でない。ヴィクトリア女王。各国の呼び名。同じ盤のペグ・ソリテール）、ウォータールー大学 Elliott Avedon Museum「Fox and Geese Games」（17羽、狐が先手、上手なガチョウがたいてい勝つ）、M. Winther「Fox and Geese, classic version」（H. J. R. Murray に基づく：13羽は後ろにも動ける／17羽は縦横のみで後退不可／ガチョウ5羽以下で狐の勝ち）。

- 盤：十字形の33点。点は縦横の線でつながり、(行＋列) が偶数の点には斜めの線もある（アルケルケ型。中央は8方向）。
- 狐（P1）1匹は中央（どのルールでも同じ）、ガチョウ（P2）は手前側。**既定は狐が先手**（Avedon Museum。資料によりガチョウ先手もある）。**先手は選べる**（2026-11-16、下の「手番の選択」）。
- 狐：線に沿って1歩。となりのガチョウの真後ろが空いていれば跳び越えて取る。続けて何回でも跳べ、途中で止まってよい。**取りは任意**。
- ガチョウ：線に沿って1歩（向きの制限はルールによる。下の表）。跳べない・取れない。「前」＝狐の側（盤の上、行番号が増える向き）。
- ガチョウの勝ち：狐が1歩も動けず跳べもしない。狐の勝ち：ガチョウが5羽以下（Winther）、またはガチョウが動けない。
- **4つのルール（2026-11-16 ユーザー決定）**。すべての一覧・タブ・種目でこの順（`engine.js` の RULES / RULE_ORDER、既定は `DEFAULT_RULE`＝g15）：

- **本作の取り決め（2026-11-16 変更：引き分けをなくした）**：ガチョウは狐を囲まなければ勝てないので、進まない対局は狐の勝ちにする。①同じ局面（同じ手番）が3回目 → 狐の勝ち（`REP_MAX`、理由 `rep`。`judge(pos, hashes)` に対局の履歴を渡す）②取り合いなしで**30手ずつ（60手）**→ 狐の勝ち（`QUIET_MAX`＝60、理由 `quiet`。2026-11-17 に60手ずつから変更、下の計測）。3D卓のHUDに残りの手数（⏳あと◯手、狐とガチョウの間。各自の手数＝(QUIET_MAX−quiet)/2 の切り上げ、残り10以下で赤。2026-11-17 ユーザー）。各地のルールは「ガチョウが囲めなくなったら狐の勝ち」としか書いておらず、回数はこのゲームの決まり。AI：探索は対局の履歴で3回目になる局面を狐の勝ちと読み（`setHist`）、形勢は取りのない手数が増えるほど狐に傾く。計測（各6局、g13 のころ）：Lv.12 以上のガチョウは Lv.12・15 の狐を全局で囲む（平均 90〜126手）、Lv.8 以下のガチョウは囲めず狐の勝ち。狐の連続跳びは1手に7回まで（手の符号化の上限）。

### 取り合いなしの上限の決め方（2026-11-17、ユーザー：60手ずつは長すぎる、最適な値を）

- 60手（30手ずつ）が、おすすめの g15 と g17 の上位で同レベルの勝率が五分に近く（35〜55%）、レベルの差（狐が上／ガチョウが上）でも上の側が勝ち越す。対局も短くなる（g15 12対12 平均104手）。g13n・g13（後退ありの伝統）は上限によらず狐が有利（ルールの性質）。

### AI 対 AI の計測（`foxgeese/tools/match.js`）
`node foxgeese/tools/match.js <rule> <狐Lv> <ガチョウLv> <局数> <seed>`。局ごとに最初の2手（狐1手・ガチョウ1手）を seed 付きの乱数で決め、あとは両者 think()。1行の JSON：狐／ガチョウの勝ち数、終わり方（trap＝閉じ込め、few＝ガチョウ5羽以下、stuck＝ガチョウが動けない、rep＝同じ局面3回目、quiet＝取りなし60手ずつ）、`escaped`＝quiet/rep のうち終局時に狐がガチョウ全員より後ろへ出ていた局（狐の本当の成功）、平均手数、1手あたりの ms。`FG_ENGINE=…` で別のエンジン（旧版のコピー）、`FG_GEESE_ENGINE=…` でガチョウだけ別エンジン。以下は seed 7。

## 手番の選択（2026-11-16 ユーザー決定）
- **エンジンへの依頼には必ず `first` を付ける**（2026-11-18 修正：解析（runReview）と検討ボックス（RvBox の req）に `first` がなく、ガチョウが先手の対局を狐の先手で読み直して全手が「分析の対象外」になっていた）。
- 狐の位置は中央のまま。**先手を選べる**：新しい対局の設定の「あなたの駒と手番」＝1つのプルダウン（`#ddOrder`、見た目は shared/pickdrop.js の .pd）。AI 対戦は「狐・先手（既定）／狐・後手／ガチョウ・先手／ガチョウ・後手」、二人で対戦・AI同士は「狐が先手／ガチョウが先手」（ラベル「先に動く側」）。「ここから再開」では対局の先手は変えない（側だけ選べる）。旧「ランダム」はなくした（保存値 0 は狐に読み替え）。
- エンジン：`setFirst(P1|P2)`（開始局面の手番。Worker へのメッセージに `first`）。局面 spec（レッスン・パズル）は自分の手番を持つので影響しない。
- 保存：設定 `settings.first`、対局 `first`（aicoding-foxgeese）。共有 URL は `&f=2`（ガチョウ先手）、棋譜テキストは `[First "Geese"]`（タグがなくても「1...」で始まればガチョウ先手と読む）。読み込みは先手を戻してから手を検証する。棋譜の跳び（`d4xd6`）も読めるようにした。
- レート戦：これまでどおり狐が先手、側はランダム。オンライン（準備中）も狐が先手。
- 大百科：カードの「手番」を `adapter.sideOpts`（4択、値 1 狐・先手／3 狐・後手／4 ガチョウ・先手／2 ガチョウ・後手。1・2 は従来どおり）＋ `optInfo(...).icon` のアイコン付きドロップダウン（`atlas/app.js` の data-pick="drop" に icon を足した）。ちゃぶ台対局（`atlas/games/foxgeese.js`）とフル機能版への `?side=`（skin が color と first に直す。二人で対戦にも `&side=` を渡す）。
- **手番のアイコン**：`foxgeese/img/ic-fox.svg`（狐の顔）・`ic-goose.svg`（ガチョウ）。🦊／🪿 の絵文字のかわり（🪿 は古い端末で出ないため）。ヘッダーの手番チップ・対局者カード・盤の上下のプレート・結果画面（`.pdisc.p1/.p2`）、手番プルダウン、大百科のちゃぶ台 HUD と手番ドロップダウンで使う。明るい背景・暗い背景のどちらでも読めるよう濃い茶の縁取り。

## エンジン（engine.js、純JS・1スレッド、Web Worker）
- 盤は 7×7 の配列（index = r×7＋c、33点だけ使う）。手 m は通った点の列を64進で詰めた数（Σ(点＋1)×64^i）。1歩は2点、k回跳びは k＋1 点。`E.path(m)`・`E.jumped(m)`（跳び越えたガチョウ）・`E.pack(points)`。
- 棋譜：1歩 `d4-d5`、跳び `d4xd6`、2回跳び `d4xd6xb6`。
- 評価（狐から見た値）：ガチョウの数100、狐の1歩で動ける点6、すぐ跳べる数26。
  - g13（後退あり）：狐が歩いて行ける点の数（囲いの広さ）9、後ろの空いたガチョウ4、ガチョウの前進5（旧来のまま、`evaluate`）。
  - **後退なしの3ルール（g15・g17・g13n、2026-11-16、`evaluateN`、重みは `EWN`）**：ガチョウは戻れないので「囲いの穴は二度とふさげない」前提。囲いの広さ20（取りなしの手数が増えるほど重く）、**抜け出し450**（狐が全ガチョウより後ろの列へ歩いて行ける＝もう閉じられない）、**深い点10**（その列か後ろにガチョウが4羽未満しかいない列の囲いの点：埋められる駒が足りない）、**狙われるガチョウ**（後ろが空いていて、狐が跳ぶ位置まで1歩34・2歩12・それ以上4）、**通り過ぎたガチョウ20／列**（狐の列より前に出たガチョウ。前進の加点は狐の列まで）、孤立して前に出たガチョウ22、**手詰まり**（ガチョウの動ける手が4未満で14ずつ、0なら3倍）。中心値 `EV0N`（g15 1130・g17 1370・g13n 890、開始局面が 0）。重みは Lv.12 の自己対局で調整（ガチョウの前進加点を0、通り過ぎを20 にしたのが一番効いた）。Node では `FG_EWN='{"area":30}'` のように重みを上書きして試せる。
- negamax＋置換表＋キラー＋静止探索（跳び）。置換表は 2026-11-16 から固定長の型付き配列（2^18、Map をやめて GC の止まりをなくした）。
- 20段階（Lv.表記）：Lv.1〜10 は深さ1〜5＋ノイズ、Lv.11〜18 は局面数（4千〜35万）、Lv.19・20 は 1.5 秒・3 秒。
- ソルバー：`goalGood / goalMin / goalReply`（goal 'take'＝狐が N 手以内に1羽取る、'win'＝N 手以内に勝つ（ガチョウなら閉じ込め）。相手は最長抵抗）。
- 既知の課題：上位レベルの g15・g17 はガチョウがほぼ全勝（上の「AI 対 AI の計測」）。下位レベルのガチョウは穴を空けて抜かれる。完全解析・WASM 化・マルチスレッド・レート基準値は未着手。
