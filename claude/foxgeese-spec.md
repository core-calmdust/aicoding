# 狐とガチョウ（foxgeese/）仕様

URL: https://core-calmdust.github.io/aicoding/foxgeese/ （cat: hist＝ヒストリカル。**2026-11-16 時点は未掲載の BETA**：トップページ・大百科ポータルには未登録、URL 直打ちで遊べる）。テーマ色 #5d6a1f（オリーブ＝牧草地。既存の緑系（リバーシ・アマゾンズ・チャンギ）より黄み）。

## ルール
出典（2026-11 確認）：Wikipedia「Fox games」（『グレティルのサガ』のハラタフル、遅くとも14世紀。エドワード4世の「狐2匹と猟犬26匹」。13羽は狐有利で、15・17・18羽や狐2匹がより釣り合う。取りは強制でない。ヴィクトリア女王。各国の呼び名。同じ盤のペグ・ソリテール）、ウォータールー大学 Elliott Avedon Museum「Fox and Geese Games」（17羽、狐が先手、上手なガチョウがたいてい勝つ）、M. Winther「Fox and Geese, classic version」（H. J. R. Murray に基づく：13羽は後ろにも動ける／17羽は縦横のみで後退不可／ガチョウ5羽以下で狐の勝ち）。

- 盤：十字形の33点。点は縦横の線でつながり、(行＋列) が偶数の点には斜めの線もある（アルケルケ型。中央は8方向）。
- 狐（P1）1匹は中央、ガチョウ（P2）は手前側。**狐が先手**（Avedon Museum。資料によりガチョウ先手もある）。
- 狐：線に沿って1歩。となりのガチョウの真後ろが空いていれば跳び越えて取る。続けて何回でも跳べ、途中で止まってよい。**取りは任意**。
- ガチョウ：線に沿って1歩。跳べない・取れない。
- ガチョウの勝ち：狐が1歩も動けず跳べもしない。狐の勝ち：ガチョウが5羽以下（Winther）、またはガチョウが動けない。
- ゲームタブの2ルール（`engine.js` の RULES）：

| キー | 名前 | 内容 |
|---|---|---|
| `g13`（既定） | ガチョウ13羽 | 伝統形（Murray の言う本来の形）。ガチョウはどの線にも1歩、後退も可。狐がやや有利とされる。配置：手前の腕6点＋その上の1列7点。 |
| `g17` | ガチョウ17羽 | 13羽＋その1つ前の列（中央の列）の左右2点ずつ。ガチョウは縦横の前か横だけ（斜め・後退は不可）。ガチョウ有利とされる。出典：Ludii「Fox and Geese (Seventeen Geese)」（配置と動きが文章で一致）。 |

- 15羽版（斜め可・後退不可）は配置を文章で確認できる出典がなかったので入れていない。
- **本作の取り決め**：取り合いなしで80手ずつ（160手）続いたら引き分け（`QUIET_MAX`）。狐の連続跳びは1手に7回まで（手の符号化の上限）。

## エンジン（engine.js、純JS・1スレッド、Web Worker）
- 盤は 7×7 の配列（index = r×7＋c、33点だけ使う）。手 m は通った点の列を64進で詰めた数（Σ(点＋1)×64^i）。1歩は2点、k回跳びは k＋1 点。`E.path(m)`・`E.jumped(m)`（跳び越えたガチョウ）・`E.pack(points)`。
- 棋譜：1歩 `d4-d5`、跳び `d4xd6`、2回跳び `d4xd6xb6`。
- 評価（狐から見た値）：ガチョウの数100、狐の1歩で動ける点6、すぐ跳べる数26、**狐が歩いて行ける点の数（囲いの広さ）9**、後ろの空いたガチョウ4、ガチョウの前進5。negamax＋置換表＋キラー＋静止探索（跳び）。
- 20段階（Lv.表記）：Lv.1〜10 は深さ1〜5＋ノイズ、Lv.11〜18 は局面数（4千〜35万）、Lv.19・20 は 1.5 秒・3 秒。
- ソルバー：`goalGood / goalMin / goalReply`（goal 'take'＝狐が N 手以内に1羽取る、'win'＝N 手以内に勝つ（ガチョウなら閉じ込め）。相手は最長抵抗）。
- 既知の課題：中位以下の AI 同士は取り合いが起きず引き分けになりやすい（ガチョウの囲い方の評価が弱い）。完全解析・WASM 化・マルチスレッド・レート基準値（コナネの値のまま）は未着手。

## 画面（latrunculi/ から派生）
- 盤6種（tools/gen_art.py。線と点はページが描く、十字の外の四隅は暗くする）：オーク材（既定）・石盤とチョーク・リネンの刺しゅう・牧場・ナイト・ペーパー。駒4種：木のペグ（既定、狐の顔とガチョウ）・ガラス玉・ピューター・塗り駒。
- 盤は自動では回さない（ガチョウがいつも手前）。上のプレート＝狐の取った数、下＝ガチョウの残りと「あと何羽で狐の勝ち」。
- 入力：駒→行き先。狐の連続跳びは1点ずつタップし、まだ跳べる所で止まるときは狐をもう一度タップ（点線の輪）。
- ルール（RuleTour）：紹介 → 盤と駒 → 狐の動き → 跳び越えて取る → 続けて跳ぶ → ガチョウの動き → 後ろを守る → ガチョウの勝ち → 狐の勝ち → 2つのルール。
- レッスン6（tools/gen_content.js、正解集合はエンジンで計算）：狐3（取れるガチョウを探す・続けて取る・2羽を同時に狙う）、ガチョウ3（跳ばれない・閉じ込める・2手で閉じ込める）。各5問。準備ステップ（ramp）は未実装。
- パズル（PZBook v2、g13）：閉じ込めろ＝w2・w3・w4（ガチョウ番）、取れ＝t2・t3（狐番）。最短がちょうど N 手・初手は2通りまで。正解でない手を「ミス」とは言わず、手数切れまで指せる。
- コーチ（ja/en）：狐＝勝ち筋・続けて取る・取る・2羽を狙う・狙う・広い所へ・位置を変える／ガチョウ＝閉じ込める・守る・詰める・形を整える・誘う。
- オンライン：Firebase プロジェクト未作成のため準備中。言語：**ja・en のみ**（残り12言語が揃うまで言語メニューに出さない）。
