# 掼蛋（guandan/）品質評価表

新作「掼蛋」を公開・更新する前に、この表で検品する。**「必須」は1つでも不合格なら出さない。**
数値で測れる項目は `node guandan/tools/test.js`（ルール）と `node guandan/tools/arena.js`（AI）で確かめる。

## A. ルールの正しさ（必須・自動テスト）
| # | 項目 | 合格の条件 |
|---|---|---|
| A1 | 役 | 単張・対子・三張・三帯二・順子（5枚）・三連対・鋼板・炸弾（4〜10枚）・同花順・四大天王を判定。A は順子・三連対・鋼板・同花順で 1 としても使える（A2345 が最小、10JQKA が最大） |
| A2 | 比べ方 | 同じ形・同じ枚数だけ比べる。三帯二は三張だけ、連続役は一番上の札で比べる |
| A3 | 炸弾の序列 | 四大天王 ＞ 6枚以上の炸弾（枚数→数字）＞ 同花順 ＞ 5枚炸弾 ＞ 4枚炸弾 ＞ 普通の役 |
| A4 | 級札 | 単張・対子などでは 大王＞小王＞級札＞A＞K…＞2。連続役では本来の位置 |
| A5 | 逢人配 | ハートの級札2枚は王以外のどの札にもなれる（炸弾は最大10枚） |
| A6 | 手番・接風 | 反時計回り。全員パスで最後に出した人が親。上がった人の札が流れたら相方が親（接風） |
| A7 | 終わり方 | どちらかのチームが2人とも上がったらハンド終了 |
| A8 | 昇級 | 頭游のチームが 相方2位＋3／3位＋2／4位＋1。A を超えない |
| A9 | 進貢・還貢・抗貢 | 単貢（末游→頭游、ハートの級札以外で一番大きい札）／双貢（大きい方が頭游へ、同じなら上家へ）／還貢は10以下（なければ最小）／大王2枚で抗貢／先に出す人 |
| A10 | 打A | A のチームが頭游かつ相方が末游でなければ勝ち。3回失敗で2へ |
| A11 | 長時間の乱数試験 | 2,000 マッチ分の自動対戦で、ルール違反・止まり・札の増減が 0 件 |

## B. AI（必須）
| # | 項目 | 合格の条件 |
|---|---|---|
| B1 | 合法手だけ | 全レベルで違反 0 件（A11 の中で検査） |
| B2 | 強さの順 | 達人チーム対やさしいチームで達人のハンド勝率 75% 以上、強い対ふつうで 58% 以上（各 1,000 ハンド以上） |
| B3 | 相方との協力 | 相方の出した札を必要なく上から潰さない／相方が残り1〜2枚なら通しやすい札を出す（テスト局面で確認） |
| B4 | 止めに行く | 相手が残り少ないときは炸弾を使ってでも止める（テスト局面で確認） |
| B5 | 速さ | 1手の平均 60ms 以下（達人は 400ms 以内で打ち切り）。画面が固まらない |

## C. 進行・操作（必須）
| # | 項目 | 合格の条件 |
|---|---|---|
| C1 | 手番が分かる | 手番の人が光る／自分の番は操作バーに「あなたの番」 |
| C2 | 出せる・出せないが分かる | 選んだ札が役になっていないとき・場に勝てないときは理由を出す。出せる札がないときは「パス」だけを強調 |
| C3 | ヒント | 出せる手を弱い順に順番に選んでくれる |
| C4 | 進貢の流れ | 誰が誰に何を渡したかを卓の上で見せ、自分の進貢・還貢は選べる札だけ選べる |
| C5 | 級の表示 | 両チームの級・今回の級札・逢人配の札・打Aの残り回数が常に見える |
| C6 | 報牌 | 残り10枚以下の人は枚数を表示 |
| C7 | 再開 | ページを開き直すと続きから（ハンドの途中も） |
| C8 | 停滞なし | どの場面でも次に押すものが1つは明示されている |

## 検品の記録
検品した日・結果をここに追記する。

### 2026-11-24（公開時）
- A（ルール）：`node guandan/tools/test.js 2000` → 94項目すべて合格、2000試合・12611ハンドを止まらず完走（進貢・双貢・抗貢・接風・打A・3回失敗で2へ、を含む）。
- B（AI）：B1 達人 vs やさしい 90.0%（120ハンド）、B2 強い vs ふつう 62.4%（800ハンド）、B5 1手平均 0.2ms（達人 41ms・最大288ms）。B3・B4 はテスト局面で確認。
- C（進行）：PC 1440×900・1280×720・1100×1300、スマホ 390×844 で、配り→進貢→対局→ハンド結果→次のハンドを実際に操作。ダイアログ表示中は進行が止まる。開き直すとハンドの途中から再開。
- D（学び）：ルール説明14ページ（課題13）と用語集、レッスン12（各生成器300回の検証）、実戦チュートリアル11ステップを ja・en・fr で最後まで通した。ルール説明はスマホ 390×664 でスクロールなし（ar の RTL も確認）。
- E（シリーズ）：ヘッダー順・3タブの設定・投了・戦績・スマホ下タブ・ALPHA・14言語（`node tools/i18n-langs.js coverage guandan` 未翻訳0）。
- F（見た目）：スマホで横の席の出した札と自分の名札が重ならないよう、手札の高さに合わせて位置を自動で決める（公開前に修正）。自分の名札の「あなた」の重複表示も解消。
- 直したこと：de・fr・es・pt の「{c}」の冠詞の不一致（「Tisch: Einzelkarte.」のような書き方に統一）、ru・tr の格語尾。
