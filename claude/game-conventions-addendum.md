## 更新情報（NEWS）とUPDATEバッジ（規定・2026-11-08）
- **特筆すべきアップデートをしたら、大百科の更新情報（NEWS）に追加する**：`shared/atlas.js` の `UPDATES` に1行（`[日付, ゲームid, ja, en, {zh, zh-TW, ko, es, fr, de, pt, ru, tr, id, hi, ar}]`、**14言語すべて**、既存の行と同じ書き方）。同じPRで行う。
  - 特筆すべき＝新機能・新しいレベル・AIの強化・新モード・オンライン機能など、遊ぶ人に分かる変化。不具合修正・キャッシュ番号の更新・内部の整理は入れない。AIの高速化は、待ち時間がはっきり変わる大きな伸び（目安2倍前後）のときだけ。
  - **同じゲーム・同じ日は1行**にまとめる（その日の行があれば文を足す。新しい行を足さない）。**新作を公開した日は公開の行がその1行**（最重要：「新作「…」を公開」で始める）で、同じ日の大きな更新（3D盤・レッスン・パズルなど）はその行に併記する（ユーザー指定 2026-11-10）。他のアカウントも同じ日に足すので、PRの直前に rebase して `UPDATES` の衝突を丁寧に解く。
  - `shared/atlas.js` を変えたら、読み込んでいる**全ページ**の `atlas.js?v=` を同じ新しい番号にそろえて上げる（トップページ `index.html` も読む）。
- **NEWS で一番大きく取り上げるのは新作タイトル**（2026-11-08）：「すべての更新」（日ごとの紙面）では、その日に公開された新作の行を**その日の見出しカード**（大きい絵・ゲーム色の背景）にする（`atlas/app.js` の `openUpdSheet`）。また、大百科の更新情報の列（先頭のカード）とスマホのNEWSティッカー（先頭）は、公開から14日以内の新作（BETA含む）があれば**いちばん新しく公開された新作を先頭**に置く（`shared/atlas.js` の `news()`）。残りは日付の新しい順のまま。同じ日に既存ゲームの更新を足しても、新作の先頭は動かない。
- **アップデートしたゲームには一定期間 UPDATE バッジを付ける**：最新の `UPDATES` の行が更新（公開日 `released` より後の日付）で、**14日以内**なら UPDATE。公開日以前の行は公開の行とみなす（行にラベルを付けない）。
  - **優先順は BETA ＞ NEW ＞ UPDATE**：BETAの間はNEWもUPDATEも出さない（BETAだけ）。NEW（公開14日以内）の間はUPDATEを出さない（NEWだけ）。オリジナルタイトルは NEW の後 ORIGINAL と UPDATE が並ぶ（ORIGINAL が先。下の「大百科のORIGINALバッジ」）。1枠しかない場所（更新情報の列・アイコン一覧）は先頭のバッジだけ。
  - 出す場所はNEWと同じ：大百科の更新情報の列・アイコン一覧・ゲーム一覧・ゲームカード、トップページ `index.html` の詳細パネル（カテゴリ行とタグ）。判定は `shared/atlas.js` の `badges()` 1か所（トップページも同じものを読む）。
  - 文字：**バッジはどの言語も英語表記**（NEW・BETA・ORIGINAL・UPDATE。2026-11-08 ユーザー指示。訳さない）。色は大百科＝スカイ（NEW コーラル、BETA グレープ）、トップページ＝シアン（NEW はゴールド）。

## AI戦のボスと観戦キャラ（規定・2026-11-09、`atlas/npc/`）
- **3Dで遊ぶAI戦**（各ゲームの `?skin=atlas` と大百科の3D卓）では、レベル3つごと（Lv.1〜3、4〜6、…）に**そのゲームのボス**が相手になり、ときどきしゃべる。ボスは発祥地や歴史上の人物（故人）をモチーフにしたぬいぐるみ風キャラで、Lvが高いほど強そう（太い眉・王冠・マント、最上位はUR）。名簿は `atlas/npc/roster.js`（全24タイトル167体、`LEVELS` は大百科のレベル数）、3Dは `atlas/avatars/sp-boss.js`（`atlas/tools/bosses.html` で `images/atlas/av/boss-<game>-<n>-<2|3>.webp` に書き出し）。
- しゃべる場所は**ルール説明の案内役と同じ形**（キャラの丸い絵＋吹き出し）で、どこでも**一定時間で消える吹き出し**（7.5秒以上、長いセリフほど長く表示）。フル機能版のPCは**画面全体の中央、盤の下端とオンラインのバーの中間**（2026-11-09。すき間が吹き出しより狭いときはバーのすぐ上で、盤の下端に重なってよい。バーには重ねない）、スマホは下タブの上、大百科の3D卓はPCがアクションバーの上・画面の中央、**スマホ縦画面はアクションバー（投了などのボックス）に重ねる**（2026-11-11。上に出すと盤にかぶるため）。右欄にはカードを置かない（2026-11-09 改定）。 スマホの吹き出しは小さめ（絵46px・文字13px）。**スマホ縦画面は下タブの位置**（下タブの上に重ねて一定時間表示）、**スマホ横画面は盤を優先して表示しない**（短い辺600px未満の横向き。大百科の3D卓も同じ）。キャラか吹き出しをタップすると消せる（PCもクリックで消せる）。
- **「キャラ会話」のオン・オフ**（2026-11-09）：フル機能版はオプション（歯車）の「キャラ会話」トグル、大百科はヘッダーのサウンドの右のボタン。同じ設定（`localStorage['atlas-npc']`、'0' でオフ）。オフでも会話を出さないだけで、ボスに勝ったときのアバターはもらえる（お知らせも出る）。
- 毎手は話さない：**数手（目安2〜4手）に1回**か、**形勢が大きく動いたとき**（ゲームの評価値、人間側から見て −1〜1 で 0.26 以上の変化）だけ。ボスは優勢で煽る・劣勢でぼやく・好手を喜ぶ・相手の好手を悔しがる、終局で勝ち誇る／悔しがる。**序盤の落ち着いた局面では観戦キャラ**（ガチャのキャラ、持っていればその中から）が**まめちしき**を話す（1局4つまで）。同じセリフを続けて言わない。
- セリフは口調（14種：王様・武士・博士・お嬢様・海賊・クール・熱血・いたずら・仙人・神官・商人・騎士・ねむねむ・魔王）ごとに用意し、ボスごとに口調を割り当てる。称号・まめちしき（各ゲーム4つ、確実な事実だけ）とともに `atlas/npc/t/<lang>.js` に**14言語**。
- **観戦キャラは複数**（2026-11-09）：1局に2〜3体（同じ種類は重ならない）が順に来る（約8秒・32秒・62秒、来たときにあいさつ）。まめちしき・応援などは来ている中から、直前に話していない1体が話す。終局では2体目もひとこと。**言語を切り替えると、表示中の吹き出しもその場で新しい言語に**（セリフは各言語で同じ並びなので同じ番号の行に差し替える）。
- **セリフの追加分と観戦キャラの口調**（2026-11-09）：`atlas/npc/t2/<lang>.js` が `AtlasNPC.more(lang, {voice, fan, fanv})` で t/ のセリフに足す（ボスの口調ごとに各場面3〜5種）。観戦キャラはガチャのキャラの口調（`AtlasNPC.VOICE`、無指定は cute）で話す（`fanv[口調]`：join・cheer・worry・close・nice・oops・win・lose・draw。8割は口調のセリフ、2割は共通の `fan`）。ボスの形勢が大きく動いたときは観戦キャラも4割で反応（nice／oops）。t2 は現在 ja・en。ほかの言語は t2 がなければ従来のセリフだけ。
- **セリフはどのゲームでも通じる言い方にする**（2026-11-10）：「指す」「打つ」「対局」「一局」など将棋・囲碁だけの言葉は使わず、「遊ぶ」「勝負」「一戦」などにする（キャロムやルドーでも違和感がないように）。ゲーム固有の称号・まめちしきは別。
- **ボスに勝つとアバターがもらえる**：ボスの3レベルのうち**1つ目で勝つとN、2つ目でR、3つ目でSR**（Lv.1＝N、Lv.2＝R、Lv.3＝SR、Lv.4＝次のボスのN…、`AtlasNPC.tier`）。各1回だけ、上部にお知らせ。見た目はNが素の姿＋持ち物、Rが＋帽子、SRが＋衣装。**SSR・URはガチャ専用**（各ゲームの最上位ボスがUR）。N〜SRはガチャ・ショップに出さない（`AtlasArt.items` の `boss` / `nogacha`）。
- 大百科の「AIの強さ」シートには、3レベルごとに**ボスの見出し（アイコン・名前・称号・レベル範囲）**を出し、各レベルに勝つともらえるレア度（N/R/SR）を付ける。入手済み（クリアしたレベル）はレア度の印を薄くし、**名前の右・レベルメーターの左に緑の丸い✓**を出す（2026-11-10、以前はレア度の印の中に✓）。レベルのボタン（「Lv.1 入門」など）の文字のすぐ右にも、そのレベルのボス（勝つともらえるN/R/SRの姿）を小さく出す。
- ゲームの状態は各ページの変数を読むだけ（`atlas/npc/npc.js` の `PROBE`、共通テンプレのゲームは `settings`・`moves`・`evalAt`・`humanColor`）。終局は `GameRecord.add` で知る。新しいゲームを足したら `roster.js`・`PROBE`（テンプレと違うとき）・14言語の称号とまめちしきを足し、画像を書き出す。

## 完全解析レベルと挑戦モード（規定・2026-11-08、手本：モリスのシックス）
- 全局面を解いたデータベースを配信できるゲーム（またはルール）は、最上位の上に**「完全解析」レベル**を足す（モリスは Lv.11、シックスのときだけスライダーに出す）。名前は14言語。データは必要になったとき（そのルールの分析か、そのレベルの手番）に初めて読み込む。URL に `?v=`。
- 手の選び方：勝ち＝いちばん早く決める手（DTZ なら z 最小）、引き分け＝引き分けを保つ手の中で罠（相手の負け応手の割合）と従来の評価・探索で自然に、負け＝いちばん長く粘る手（「AIの負け局面での振る舞い」と同じ）。同一局面の繰り返しなど、データベースの外のルールは手の値を出すときに上から当てる。
- 分析・ヒント・振り返り・コーチは、データベースのある局面では正確な「勝ち・引き分け・負け」（取るまでの手数など）を出す。
- **レート戦には入れない**（強さが測れない・勝てない相手）。代わりに**挑戦モード**：初期局面から、ヒント・形勢・コーチ・待った・合意の引き分けなし（レート戦と同じ隠し方）で、引き分け以上なら称号。戦績にはそのレベルとして記録。

## 新作のBETAバッジ（規定・2026-11-08）
- 出来たばかりのゲームには BETA バッジを付ける。対象はチャンギ以降に追加したタイトル（現在：チャンギ・アマゾンズ。ルドーは 2026-11-09、テーブルホッケーは 2026-11-10 に正式版）。**これから追加するゲームも最初から付ける**。
- 付け方：トップページ `index.html` のゲーム定義に `beta:1`（アイコンの BETA と詳細パネルの「β版」タグ）、ポータル `shared/atlas.js` の GAMES に `beta: true`（大百科の BETA バッジ。NEW・UPDATE の代わりに出る）。`shared/atlas.js` を変えたら全ページの `atlas.js?v=` を上げる。
- **BETAはNEWの代わりに出す**（2026-11-08）：BETAの間はNEWを出さない。大百科トップ（更新情報の列・ゲーム一覧・ゲームカード）は `shared/atlas.js` の `badges()` がBETAを先頭にしてNEWを外す。トップページも詳細パネルのNEWを出さない。BETAを外すと、出てから14日以内ならNEWに戻る。
- **トップページのアイコンの左上はBETAが優先**（2026-11-08）：BETAの間は ONLINE（や ORIGINAL）の印を出さない。BETAを外すと ONLINE などに戻る（`index.html` のアイコン描画で `g.beta` を先に見る）。
- 外すタイミングはユーザーが指示する（Claude の判断で外さない）。外すときは両方の印を消し、更新情報（UPDATES）に「正式版に」の行を足す（ソリティアの例）。

## 持ち時間のフィッシャー（規定・2026-11-08、共通部品 `shared/fischer.js`）
- 持ち時間を選べるゲームは、選択肢に **フィッシャー**（持ち時間＋1手ごとの加算、秒読みなし）を必ず入れる。既存の選択肢（なし・秒読み・切れ負け・1手○秒など）はそのまま残す。
- プリセットは **1+1・3+2・5+3・10+5・15+10・30+20**（分＋秒、`Fischer.PRESETS`、既定 5+3）。将棋だけ従来の 5+10（floodgate）も残す。表記は「5分＋1手3秒」（`Fischer.label`）、ボタンは「5分+3秒」／「5+3」（`Fischer.short`）。文言は部品に14言語。
- 2D の対局設定：時計の選択肢に「フィッシャー」ボタンを足し、選んだときだけその下にプリセット（3列、スマホは `pickdrop.js` のプルダウン）と説明1行を出す（`Fischer.picker(el, { lang, get, set, presets })`）。設定は `settings.fis`（'分+秒'）に保存し、同期のあるゲームは `SET_KEYS` に `fis` を足す。
- 時計：手を指し終えた側の残り時間に加算する（**1手目も加算**）。残り時間を使い切ったら負け。待った・振り返りでは加算も減算もしない（待ったで時間は戻さない、従来どおり）。ページを開き直して再開した対局は、次の1手まで時計を止める（game-conventions「時計の開始」）。時報音は残り5秒から（`CountTick`）。
- AI 戦は今までどおり人の時計だけが進む（AI の時計は動かさない）。AI に持ち時間で考えさせるときは `Fischer.budget(残りms, 加算ms)`（残り/30＋加算×0.8、残りの1/5まで）を使い、時間切れにしない。
- 大百科フル機能版（`atlas/app.js` の TCS）：どのゲームの時計にも同じ6つのプリセットを足す（ID は `f<分>`、以前の f3・f10・f15 はそのまま）。
- オンライン：持ち時間はレコードの `tc` で不変（secrules.py の `tcs` に (main, 0, inc)）。新しい持ち時間を足すときは secrules.py に足してルールを作り直し、**新ルールにしかない読める節（例：`secf`）で検出できたときだけ**その持ち時間を出す（旧ルールのままでも今までどおり動く）。将棋・リバーシのオンラインに「フィッシャー 5分＋1手10秒」（`tc: 'fis'`、プローブ `secf`）を追加済み（ルールの貼り替えが必要：`claude/online-security-setup.md`）。
- 対応済み（2026-11-08）：将棋・リバーシ（対局設定＋オンライン）、ウル・セネト（対局設定）、大百科フル機能版の全ゲーム。もともとフィッシャーだけのゲーム（チェス・五目並べ・チェッカー・シャンチー・タフル・ヘックス・モリス・アゴン・ファノロナ・ウゴルキ・コナネ・囲碁のオンライン等）はそのまま。

## オプションボタン（規定・2026-11-07、`shared/headerbar.js`）
- ゲームの中では、ヘッダー右側のアイコンのうち **盤面反転（`#btnFlip`）・縦横／横画面の切り替え（`#btnLand`・`#btnRot`・`.land`）・戦績（`#btnRecord`／`#atlasRec`、歯車のすぐ左。2026-11-08）・ホーム以外は、すべて1つのオプションボタン（歯車）にまとめる**。押すと歯車の下に小さなパネルが開き、サウンド・言語・ゲーム独自の項目（カードゲームの設定、五目並べの手順番号など）が**アイコン＋名前（14言語）**の行で並ぶ。オン／オフのある項目（サウンド等）は行の右にスイッチで状態を出す。
- 右側の並び：**盤面反転 → オプション → 横画面切替（あるゲームのみ）→ ホーム**。オプションボタンの高さは他のアイコンボタンと同じ（PCヘッダーは36px）。
- 2D版（`.brand-r`）もフル機能版（`?skin=atlas` のポータルのバー、`atlas/skin/common.js`）も同じ。2D版は `headerbar.js` が自動で既存のボタンをパネルへ移す（ボタンの処理・状態はそのまま）。ゲーム側で `.brand-r` に足したボタンも自動でパネルに入る。外に残したいボタンは上の id／class にする。
- 隠されている項目は行も出さない（スマホのサウンド＝`phonesnd.js`。戦績ボタンも下部タブに戦績があるときは出さない）。項目が1つもなければ歯車も出さない。

## ヘッダーバーとメニューの幅合わせ（規定・2026-11-07、`shared/headerbar.js`）
- **まず文言を短く**：メニューボタン（PCヘッダーとスマホの上部メニュー）は、その言語に自然な短い言い方があれば1語にする（日本語の「新規」と同じ考え方）。短い表記は `shared/headerbar.js` の `SHORT`（言語ごとに「ゲームの元の名前 → 短い名前」）で置き換え、元の名前は title／aria-label に残す。ダイアログなどの文言は元のまま。同じメニュー内で他のボタンと同じ名前になる場合は置き換えない。例：Offer draw→Draw?、Remis anbieten→Remis?、Lektionen→Lernen、Abandonner→Abandon、Подсказка→Совет、Teka-teki→Soal、Pelajaran→Belajar、Bulmacalar→Bulmaca。新しいゲームのボタン名も最初から短く付ける（「新しい対局」ではなく「対局」「New」）。
- **PCヘッダーバーは画面からはみ出さない**（全言語・全幅）。それでも収まらないときだけ、次の順に段階的に詰める：①間隔を狭める → ②言語ボタンを言語コード（DE など）だけに → ③情報チップを先頭2つに → ④メニューボタンを**後ろから**アイコンだけに（ルール・レッスン・パズル・引分提案など。名前は title／aria-label に残る）→ ⑤情報チップを先頭1つに → ⑥最後に対局・待った・投了・ヒントもアイコンだけに。日本語は 1280px の見た目を保つため、①より前に情報チップを先頭1つに減らす。**題名・ロゴ（世界のボドゲ大百科／海外向けの横長ロゴを含む）は詰めない・変えない**（デザイン確定済み）。日本語の 1280px 以上はほぼ従来どおり。
- **中央の情報チップ（手番・手数・評価など）**は、主要なチップ（`.opt` 以外）が入る幅（最大でバーの30%、最低でも先頭2つ。上の③⑤の段で2つ→1つに減らす）を確保する。それでも入らないチップは**途中で切らずに後ろから丸ごと外す**（先頭の1つだけは最後の手段として … で縮む）。ゲーム側で新しく出すチップは `class="hb-chip"`、省いてよい補足は `hb-chip opt`。
- **スマホの上部メニューと下部タブ**：名前がボタンに収まらないものだけ、文字を最小78%まで小さくする（省略記号・はみ出しを出さない）。それでも入らない複数語の名前（de「Remis anbieten」など）は同じボタンの中で単語の切れ目で2行に、1語の名前（fr「Abandonner」）は最小70%まで。それでも長すぎる文言は短い表記にする（例：引分提案 ru「Ничья?」tr「Berabere?」）。
- レイアウトを変えたら 1280×720・1440×900・390×844 で14言語を計測する（`header.hb` の scrollWidth＝clientWidth、画面外の要素なし、省略された文字なし）。

## ルールコース（規定・2026-11-05）
- **課題に正解したら次の問題（ステップ）へ自動で進む**。キャラの反応（done の台詞）を読める時間（約1.6秒＋文字数×45ms、最大4.8秒）をおいてから。最後のページは除く。手動の「つぎへ」も残す。
- 実装：ポータルの3Dルールコース（`atlas/rules/*.js` の `autoNext()`、ウルは `ok()`）、フル機能版の2Dルール説明は `shared/ruletour.js` の `ok()`（約1.8秒で自動）。新しいゲームでも必ず入れる。

- **案内役はキャラクターに徹する（規定・2026-11-07）**：3Dルールコースの台詞（説明・課題・正解・不正解・注意の全部）は、案内役の口調で**全ページ・全14言語**に書く（2Dルールツアーの文言は代替にしか使わない。ツアー文の流用で「です・ます」が混ざるのは不可）。口調は真面目すぎず、モリス（モリフク）のようにちょっとふざけて、子どもが笑えるひと言（キャラの体や性格にちなんだボケ・言い間違い・自虐など）を各ページに入れる（2026-11-07）。**基本方針は「コンパクトに、でも面白く」**：説明は1ページ2〜3文（日本語でおよそ60〜90字）に収め、ボケは短いひと言を1つだけ。長い前置きや同じ説明の繰り返しはしない。説明は簡素な箇条でなく、驚き・ひと言の感想・コツ（「ここがおもしろいところ」「2がいちばん出やすいから29は特等席」など）を交えて語る。駒は色と形で呼ぶ（「白い糸巻きの駒」「黒い円錐の駒」）。手本：セネト `atlas/rules/senet.js` の `VOICE`。

- **ポータルのゲームアイコン（`images/atlas/<id>.webp`、320×320）**：絵の下端を他のアイコンとそろえる（不透明部分の下端 y≈305〜313）。上に寄った絵は下へずらす。

- **3Dポータルの場所（ダイニング・フェルト卓・テラス・書斎、2026-11-07）**：どの場所も床・壁・天井で閉じた部屋にし、ドラッグ（上下の傾き）やズームで背景の端・何もない所が見えないこと（変更したら傾き±0.35×ズーム0.55〜1.7の全組み合わせで確認）。テーブルは盤が収まる広さにし、盤の中心から半径約9.5以内には小物を置かない。時間帯（朝・昼・夕方・夜）は「2D準拠」以外の全場所で選べる（屋内も窓の外と灯りが変わる）。窓の光を床や卓に乗せるときは加算合成にしない（iPhone で白い紙のように見えた）。
- **横スクロールの行（2026-11-07）**：場所・盤の選択、カテゴリのチップなど横にスクロールする行には、続きがある側に半透明の ‹ › ガイドと薄いフェードを出す（`atlas/app.js` の scrollGuide が自動で付ける）。
- **ヒストリアの博物館は博物館のライティング固定（2026-11-07）**：`Table3D.museum(true)` の間は、選んでいる卓（ちゃぶ台・テラス等）の映り込み（`scene.environment`）・明るさ設定を使わず、博物館専用の映り込み（`museumEnv()`）と露出 `MUSEUM_EXP` にする。閉じたら卓のものに戻す。
- **被写界深度（2026-11-07）**：ポータルの3D部屋（ビュー表示）は、盤より奥を軽くぼかす（`atlas/table3d.js` の `dof()`：描き終えた画面をコピーして半分の解像度でぼかし、盤の奥側の縁より上に重ねる。シーンの再描画はしない）。PCのみ（タッチ・軽量モードでは切る）、`?nodof` で無効。
- **ウィンドウが非アクティブのとき（2026-11-07）**：3Dの絵は消さない。連続描画は止めるが、ウィンドウの大きさが変わった（ブラウザのサイドパネルを開いた等）・盤が動いた・kick など絵が変わる時だけ短い描画（約0.4〜0.85秒）をして止まる（`atlas/table3d.js` の `blurBurst`）。キャンバスはリサイズで消えるので、描き直さないと盤が空になっていた。
- **3Dフル機能版の負荷（2026-11-04）**：`atlas/table3d.js` が描画直前に同じ形・材質の駒（鏡像・接地影含む）を InstancedMesh に自動でまとめる。影マップは1024・盤の範囲だけ・kick中か駒の増減時だけ更新（静的影）。新しいスキンも個別にインスタンス化を書かなくてよいが、駒は形・材質を共有して作ること。
- **カードゲームは2D専用（2026-11-05）**：poker / blackjack / baccarat / solitaire はパズル系と同じく3D盤を作らず、ポータルのボードカードに「カードゲームは2Dで遊ぶよ」の案内（`atlas/app.js` CARD2D）。

## AIの着手は即時（規定・2026-11-08）
- AI と対戦（レート戦を含む）では、**エンジンが手を返したらすぐ指す**。「考えているふり」の最低待ち時間（以前の 350〜420ms など）は置かない。定跡・作戦の手（探索なし）も同じ。
- 待つのは**直前の手のアニメが終わるまでだけ**（2つの手のアニメを重ねない）。例：`animating ? moveDur() : 0` から経過時間を引く、リバーシは石が返り終わる時刻（`flipEndAt`）、将棋は駒の移動（`mvEndAt`）、コネクトフォーは駒が落ち切る時刻（`dropEndAt`、3Dスキンは3Dの落下時間）。
- 駒の移動・裏返しのアニメそのものは変えない。読ませたい案内（リバーシのパス、ウル・セネトの「もう一回」など）だけは短い間を残してよい。
- **AI同士（観戦）は今までの間**を保つ（追えるように）。レッスン・パズル・チュートリアルの台本の返し手の間も変えない。オンラインは対象外。
- 新しいゲームも同じ形で作る（大百科ポータル `atlas/games/*.js` も前の手のアニメ完了後に呼ばれるので待ちは 0）。

## AIの負け局面での振る舞い（規定・2026-11-04）
- 全手が負けと分かっている局面でも適当な手を指さない。**いちばん遅く負ける手**を選び、同じなら**相手の即勝ち（四・脱出路など）の片方をふさぐ手**、次に反撃の脅威を作る手を選ぶ（人間らしい粘り・演出）。勝ち・引き分けが残る局面の選び方は変えない。実装：コネクトフォー・タフル・五目並べ（`Engine.resist`）。
- 詰めパズルの防御側も同じ：最長抵抗の受けが複数あるときは、手の生成順の先頭ではなく**エンジン評価が最も良い手**を選ぶ（例：チェッカー `pzDefence`、チェス `pzTieBreak`、五目・象棋・モリス・ファノロナ・ヘックス `pickDefenceBest`、将棋は無駄合を受けとして数えない）。
- 問題の点検スクリプトは各ゲームの `tools/audit_puzzles.js`（将棋 `tools/tsume/audit_replies.js`）。

## 引き分けの提案・共有画像・その他（規定・2026-11-06）
- **引き分けの提案ボタン**：引き分けの多いゲーム（チェス・チェッカー・シャンチー・ウゴルキ・タフル・ファノロナ／アルケルケ・アゴン・モリス）は、オンラインだけでなく**AI対局と同じ端末の2人対局でもメニューに「引分提案」**を出す（2D・3Dスキンとも同じページ）。共通部品 `shared/drawoffer.js`（`DrawOffer.init / sync`）。AI対局はゲームの判定（AIが不利でなければ同意、数手おきに1回）、2人対局は「引き分けにしますか？」いいえ／はい（`Resign.confirm({ kind: 'draw' })`）。表示中はパズルボタンを省く（headerbar.js）。新しいゲームでも引き分けがあるものは入れる。
- **AI同士の対局（チェス）**：千日手模様（今の局面か次の手の後の局面が前にも出ている）で、形勢に1ポーン以上の差があれば**不利な側が投了**する。互角ならそのまま千日手の引き分け。

- **PCの右欄の高さ＝盤の高さ**（盤の縁の厚みまで含めて下端をそろえる。盤下の手番・パスなどのバーは少しはみ出してよい）。下に検討ボックスが出ているときも、棋譜ボックスの下端を盤の下端にそろえる。

- **棋譜ボックスの大きさ（PCの右欄）**：対局中は全ゲームで同じ基準の高さ `clamp(110px, 44vh − 200px, 240px)`（1440×900 で約200px、1920×1080 で240px）。主役はコーチなので大きくしすぎない。右欄に入りきらないときは棋譜・コーチが縮む（中でスクロール）。振り返りカード・盤下の振り返りボックス・レッスン／パズル・オンライン欄の圧縮表示中はゲーム側の大きさ。`shared/headerbar.js` が指定。
- **右欄は盤の下端を越えない（全ゲーム・全状態）**：`shared/headerbar.js` の `sideTight` が配置のたびに測り、はみ出すときだけ `html.side-tight`（振り返り・棋譜・コーチが縮んで中でスクロール、グラフを低く）→ `side-tighter`（グラフと補足行を隠す）→ `side-tightest`（右欄ごとスクロール）の順に詰める。レイアウトを変えたら 1440×900・1280×720・1100×1300・1600×1000・1920×1080 で、対局中・振り返りカード表示・盤下の振り返りボックス表示の各状態を必ず計測して確かめる。
- **［分析］を押したら必ず下の検討ボックスを出す**（全ゲーム・2026-11-06）：1手目からでも、対局中（AI戦・2人）でも、終局後でも同じ。レート戦・オンライン・レッスン・パズル中は除く。新しい手を指すと解析が古くなるので箱は閉じる。
- **下の検討ボックスの左端は盤の外枠（盤のカード・額縁）の左端、右端は右欄の右端に揃える**。盤の中の遊ぶ面ではなく、描かれている一番外側の枠に合わせる。変更したら実際に［分析］を押した状態で 1440×900・1280×720・1920×1080 を計測して確かめる。

## 最強解析ページ（複数スレッド）（規定・2026-11-07、手本：チェス → 将棋・タフル・リバーシ・シャンチー・チャンギ）

- エンジンは同じ `engine.c` を `-DMT` で作った `engine_mt.wasm`（Lazy SMP・共有メモリ）。スレッドごとの状態は `TLS` マクロ（通常版では空にして、通常版の wasm を1バイトも変えない）。補助スレッドには読み方の違い（1手深く始める、ルートの手の順をずらす等）を入れ、効くほうを測って選ぶ。

- 効果は 2スレッド対1スレッドの対局か、同じ深さまでの時間で確かめ、各ゲームの MODEL_CARD に書く。トップページの紹介文の末尾に「PCの複数コアで深く読む「最強解析」ページも。」（14言語）を足す。

## 対局設定の Pro モード（規定・2026-11-08、共通部品 `shared/proset.js`、手本：チェス・将棋・リバーシ）
- AI と対戦できるゲームは、対局設定の「AIの強さ」（`#fLevel`）の右上に小さな **PRO** ボタンを置く。ふだんは閉じていてレベルを選ぶだけ。押すとその欄の中に「高度な対局設定」のパネルが開く（開閉の状態は端末ごとに覚える）。
- パネルの項目は**すべて「このレベルの既定」（● 印）から始まり、変えた項目だけが使われる**。既定と違う項目があると PRO ボタンが塗りつぶし表示になり、対局者名・情報行に「PRO」と出る。「レベルの既定に戻す」ボタンで全部戻す。対局設定は下書きで、［対局開始］で保存、［閉じる］で捨てる。
- **レート戦では使わない**（ボタンも出さない）。オンライン・レッスン・パズルも対象外。戦績は PRO で変えた対局を `ai:pro`（相手名に「PRO」）として記録し、レベル別の記録には数えない。
- 保存はゲームの `settings.pro`（クラウド同期の `SET_KEYS` に `pro` を足す）。同期のないゲームは `localStorage` の `aicoding-pro:<game>`（部品の既定）。
- 項目（エンジンにあるものだけ出す。新しい機能は作らない。グループは「読み」「指し方（石のゲームは打ち方）」「その他」）：
  - **思考の制限**（読み）：時間（秒）／深さ（手）／局面数。レベルが使っている方式が既定。範囲はゲームごと（例：時間 0.1〜60 秒、深さ 1〜30、局面数 1千〜1億）。
  - **スレッド数**（読み）：本編のマルチスレッドがオンのときだけ。時間で考えるときだけ有効。`MTEngine` のプールに `mtThreads`（主スレッド込みの数）を渡すと、補助をその数だけ使う。
  - **定跡**（指し方）：オン／オフ。**手のばらつき**：なし／小／大（大きいほど弱く人間らしい。弱いレベルの既定はそのレベルのばらつき）。**評価関数**：NNUE／手作り（両方あるゲームだけ）。
  - **AIの投了**（その他）：AI が投了するゲームだけ。
  - ゲーム独自：リバーシの「完全読み」「勝敗読み」（残り何マスから読み切るか）など。
  - 「持ち時間に合わせる」（AIが自分の残り時間から1手の時間を決める）は部品にあるが、2026-11-08 時点で AI 側の時計が動くゲームがないため未使用。
- 組み込み方（ゲーム側）：
  `var PRO = ProSet.init({ game, lang: () => LANG, level: () => draft.level, show: () => draft.mode === 'ai' || draft.mode === 'watch', defaults: lv => ({ limit: { k: 'nodes', v: 8000 }, book: true, var: 0, … }), params: [{ key: 'limit', kinds: { time: [0.1, 60], depth: [1, 30], nodes: [1e3, 1e8] } }, { key: 'book' }, …], store: { get: () => settings.pro, set: v => { settings.pro = v; } } })`
  AI に考えさせるとき `PRO.get(level)`（変更なしなら null、レート戦では呼ばない）から、そのゲームのレベル設定と同じ形の設定を作ってエンジンへ渡す（例：チェス `think` の `cfg`、将棋 `opts`、リバーシ `opts.cfg`）。`const PRO` にしない（描画が先に走ると TDZ エラー。`var` にする）。文言は部品に14言語、ゲーム独自の項目は `label` / `help` / `unit` を14言語で渡す。
- フル機能版（?skin=atlas）も同じダイアログなのでそのまま出る（明るい配色は部品の CSS）。
- 確認：PC 1440×900 と 390×844 でパネルを開いたスクリーンショット、値を変えて対局しエンジンに届くこと（深さ・時間・局面数）、レート戦で出ないこと、戻す・再読み込み後の保持。
- 対応済み（2026-11-08）：チェス・将棋（本将棋・ランダム将棋）・リバーシ・チェッカー・シャンチー・チャンギ・ウゴルキ・アゴン・ファノロナ／アルケルケ・コナネ（この7つは `ProSet.ladder()`。2026-11-10 にアマゾンズも ladder で対応）・モリス・マンカラ・ヘックス・五目並べ・囲碁・タフル。未対応：コネクトフォー（完全解析の solver・定跡木が中心）、ドット＆ボックス（盤の大きさ別の solver）、バックギャモン・ウル・セネト・ルドー（サイコロのゲームで、強さはレベルだけ）。各ゲームの項目は MODEL_CARD／spec の「対局設定の Pro モード」。

## 大百科3D卓の盤は上下中央（2026-11-09）
- 卓で遊ぶ画面では、盤を「上のバー（手番の表示）の下〜下の操作バーの上」の帯の上下中央に置く。`atlas/app.js` の `fitStage` が上のバーの高さも `Table3D.setInset(下, 上)` に渡し、`atlas/table3d.js` の `centreBoard` が、傾いたカメラで描いた fit の長方形（w × d、高さ y。脚付き碁盤のように注視点が盤面より下なら fit.cy に盤面の高さ）の上下の端の真ん中を帯の真ん中へ縦のレンズシフトで合わせる（注視点だけで合わせると、手前が大きく写るぶん盤が下寄りになっていた）。fit に `cx/cz`（ルドーの手番フォーカス）・`up`・`roll` があるときは行わない。
- 盤のズーム・スライドのアニメーション（2026-11-09、セネトで判明）：枠の高さや盤の width を毎フレーム変えない（ページ全体の再レイアウトと3Dスキンのキャンバスのリサイズが毎フレーム起き、重くガクガクする）。最大拡大の大きさで1回だけレイアウトし、表示はすべて transform（縮小方向）で動かす（止まってからレイアウトし直すと3Dキャンバス・床が変わってガクッとなる）。3Dスキンを使うときは `#atlasGL` にも同じ写像の transform をかける。`atlas/skin/common.js` の alignTo は何度呼んでもリスナーを1回しか登録しない。

## 重い盤のテクスチャは画像に焼き込む（2026-11-10）
- 3D盤の手描き（canvas）テクスチャのうち描くのに時間がかかるもの（キャロム・ホッケー・クロキノールの盤面、ちゃぶ台の木目、将棋・象棋・チャンギ・ヘックス盤など約50枚）は、あらかじめ画像 `atlas/img/tex/b/<key>.webp` にしてあり、`atlas/table3d.js` の `canvasTex()` は `window.ATLAS_TEX`（`atlas/img/tex/baked.js`）に載っている key なら描かずに画像を読む。読めなかったとき・他のテクスチャの描画の途中で使うとき・`window.TEX_DRAW = true` のときは今までどおり描く。
- 画像は大きいサイズで焼いてあり、スマホなど小さいサイズを頼んだときは読み込み時に縮める。
- table3d.js を読むページは、その前に `atlas/img/tex/baked.js` を読む（新しい3Dページを作るときも同じ）。
- **焼き込んだテクスチャの描き方を変えたら焼き直す**：リポジトリ直下で `python3 -m http.server 8765` を起動し、`cd atlas && python3 tools/texbake.py 25`（25 = 何ms以上かかるものを焼くか）。全モデル・全盤を描いて測り、画像と baked.js（版番号つき）を作り直す。焼き直さないと古い見た目の画像が出る。
