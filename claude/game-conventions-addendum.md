# 全ゲーム共通の必須仕様：追補（2026-10-28、2026-10-30、2026-11-04、2026-11-05 更新）

`claude/game-conventions.md` への追加・変更。食い違う場合はこちらを優先する。

## ルールコース（規定・2026-11-05）
- **課題に正解したら次の問題（ステップ）へ自動で進む**。キャラの反応（done の台詞）を読める時間（約1.6秒＋文字数×45ms、最大4.8秒）をおいてから。最後のページは除く。手動の「つぎへ」も残す。
- 実装：ポータルの3Dルールコース（`atlas/rules/*.js` の `autoNext()`、ウルは `ok()`）、フル機能版の2Dルール説明は `shared/ruletour.js` の `ok()`（約1.8秒で自動）。新しいゲームでも必ず入れる。
- キャラクターが可愛く進行し、硬い口調にしない（楽しくルールが分かる台詞）。10言語。

- **横長盤のPCレイアウト（変更）**：マンカラ・バックギャモン・ヘックスは、PCでは「盤を上段に横幅いっぱい、情報（対局者・形勢・振り返り・棋譜）を盤の下に横一列」。右欄2列にはしない。大きな画面では盤を大きく広げる。
  - マンカラ（分析中）：振り返り → 形勢グラフ → 棋譜 の順。
  - バックギャモン：対局中も振り返り時も同じ並び（左の広い列＝コーチ／振り返り時は解説ボックス、中央＝対局者の下に形勢、右＝振り返り・ヒントの下に棋譜）。オンライン欄を開いても棋譜を消さない。
  - ヘックス：対局者カードは盤の上側の空き角（左右）に置き、盤下の段はコーチ 1/2・形勢 1/4・棋譜 1/4。スマホも対局者は盤の空き角（赤＝左下、青＝右上）。
  - ファノロナ（2026-11-05）：先手・後手のボックスは横1列にまとめ、空いた分で形勢グラフを見せる（盤下の配置・ワイドの右列配置とも）。コーチ欄は情報行の全高。
- **パズル・レッスンのカード操作（規定・2026-11-04 変更）**：`shared/cardbar.js` で統一。パズルは「ヒント・やり直す・答え・一覧」をSVGアイコンの1列にまとめ、主ボタンは「次の問題」1つだけ（正解で金色）。**やめるは×ではなく、アイコン行の下の右寄せ行に「〈モード名〉をやめる」の文字ボタン**（詰将棋をやめる／詰めチェスをやめる／レッスンをやめる／定跡をやめる／復習をやめる。名前は各ゲームの i18n から取り、取れなければ「パズルをやめる」。10言語）。文字ラベルは title / aria-label に。レッスンは一覧・自動再生をアイコン、ヒント（場面で文言が変わる）と次へは文字ボタン。
- **固定高さの箱の下端ボタン（規定）**：一覧ダイアログなど高さ固定の箱では、閉じる・戻るなどのボタンは中身が短くても箱の最下部に置く（縦flex＋本体 `flex:1`、フッター `margin-top:auto`）。
- **デザインは絵で選ぶ（規定）**：対局設定の駒・盤・スキンの選択肢は、すべて絵（ミニ盤・駒のサムネイル）付きのタイルにする。文字だけのタイルは作らない。駒と盤は別々に選べ、選んだものが常に反映されること。デザイン欄はプルダウンにしない。
- **カラーテーマは他のゲームと被らない色に**：新しいゲームや再テーマ時は全ゲームの配色を調べて重複を避ける。画面下のオンライン欄もそのゲームのテーマ色に揃える。
- **「定番」タグ**：伝統的な定番ゲームには付け、パズル・オリジナルゲームには付けない（`shared/atlas.js`）。オリジナル作品には ORIGINAL バッジ／タグ。プレミアムのタグ・バッジは廃止。
- **3Dポータルの負荷**：外した盤のマテリアル・テクスチャは全端末で解放、直近の展示盤だけ保持。目安の三角形数（PC）：部屋 約6万以下、展示盤 8万以下（チェスは映り込み込み12万以下）。ファノロナは駒込み約5.8万。
- **3Dフル機能版の負荷（2026-11-04）**：`atlas/table3d.js` が描画直前に同じ形・材質の駒（鏡像・接地影含む）を InstancedMesh に自動でまとめる。影マップは1024・盤の範囲だけ・kick中か駒の増減時だけ更新（静的影）。新しいスキンも個別にインスタンス化を書かなくてよいが、駒は形・材質を共有して作ること。
- **カードゲームは2D専用（2026-11-05）**：poker / blackjack / baccarat / solitaire はパズル系と同じく3D盤を作らず、ポータルのボードカードに「カードゲームは2Dで遊ぶよ」の案内（`atlas/app.js` CARD2D）。

## AIの負け局面での振る舞い（規定・2026-11-04）
- 全手が負けと分かっている局面でも適当な手を指さない。**いちばん遅く負ける手**を選び、同じなら**相手の即勝ち（四・脱出路など）の片方をふさぐ手**、次に反撃の脅威を作る手を選ぶ（人間らしい粘り・演出）。勝ち・引き分けが残る局面の選び方は変えない。実装：コネクトフォー・タフル・五目並べ（`Engine.resist`）。
- 詰めパズルの防御側も同じ：最長抵抗の受けが複数あるときは、手の生成順の先頭ではなく**エンジン評価が最も良い手**を選ぶ（例：チェッカー `pzDefence`、チェス `pzTieBreak`、五目・象棋・モリス・ファノロナ・ヘックス `pickDefenceBest`、将棋は無駄合を受けとして数えない）。
- 問題の点検スクリプトは各ゲームの `tools/audit_puzzles.js`（将棋 `tools/tsume/audit_replies.js`）。

## レッスンの段階化（規定・2026-11-04）
- 難しい概念のレッスンは、採点問題の前に採点しない「準備 i/n」ステップを置く：①考え方（盤に矢印・枠で概念を示し「次へ」）→ ②例題（答えが明らか、正解後に理由）→ ③やさしい練習1〜2問 → 既存の採点問題。
- ヒントは3段階（考え方 → 見るところを光らせる → 答え）。誤答は局面を戻してやり直し。「準備をとばす」リンク。レッスンid・進捗・採点（満点20・合格75）は変えない。10言語。
- データは lessons.json の `warm`（リバーシ）／`ramp`（他）。生成 `tools/ramps.js`、検証 `tools/check_lessons.js`（局面の合法性・正解＝ルール上の正解の全集合・10言語）。
- 実装済み：リバーシ・チェス・将棋・五目並べ・チェッカー・コネクトフォー・シャンチー・囲碁・マンカラ・ウゴルキ。未：タフル・モリス・バックギャモン・ドット・ヘックス・ファノロナ・アルケルケ。

## 画面の共通ルール（2026-10-30）
- ボタンの文字は2行に折り返さない（収まらなければボタンを2段に）。レッスン合格ダイアログも同様。
- スマホ縦の間隔：上部メニュー → 相手の欄 → 盤 → 自分の欄 → 下の箱 はすべて 8px。
- 上部右側アイコンの並び：サウンド → 言語 → 横画面切替（あるゲームのみ）→ ホーム（手本：バックギャモン）。
- 盤上の印：コーチの候補は明るい緑 #3df59a＋暗い縁（全ゲーム共通）。どの盤デザインでも読めること。囲碁は半透明。

## 対局設定ダイアログ（スマホ、`shared/ngtabs.js`・`shared/pickdrop.js`、ポーカー準拠）
- 全画面シート：上に設定（入りきらなければここだけスクロール）、その下に「閉じる／対局開始」、最下部にタブ「ゲーム｜ルール｜デザイン」。
- ゲームタブ：種目・ルール違い（将棋の本将棋／5五将棋／はさみ将棋、タフル・モリス・マンカラ・五目並べ・ウゴルキの各ルール）を絵と説明付きカードで。`data-ng="game"`。ルールタブの下に選んだゲーム名。選べないモードではタブを出さない。
- デザインタブ：`data-ng="design"`。駒・盤・スキンはアイコンで選ぶ。
- ルールタブ：それ以外。4択以上のボタン列・select は独自UIのプルダウンに（pickdrop）。
- クレジットは設定ボックスの最下部・中央寄せ。デザイン（駒画像など）のクレジットはデザインタブのときだけ。
- 「ここから再開」は同じダイアログを「この局面から再開」モードで開く（AIと対戦／二人／AI同士、持つ側・強さ・持ち時間・表示・デザインだけ。局面が変わる設定は隠す。`shared/resumeng.js`）。
- **ルールへの案内は「ボックスの中にルールボタン」形式（規定・2026-11-04、手本：将棋）**：対局設定ダイアログの見出しのすぐ下に「はじめての方へ：…［ルールを見る］」のボックス（`shared/rulesoffer.js` の `RulesOffer.init`）を置く。ラベル横の下線リンク「ルールを覚える」（`#ngRulesHelp`）は全ゲームで廃止し、新しいゲームでも作らない。新作は `rulesoffer.js` の T にゲームID の紹介文（10言語）を足して init する（ファノロナ・アルケルケ・ウゴルキも追加済み）。

## コーチ（規定・2026-10-30、手本：ポーカー → 将棋で実装）
- **共通部品** `shared/coachkit.js`。中身はゲームごとに `<game>/coach.js`（＋10言語の `coach-i18n.js`）。テンプレの詳細は `shared/COACH.md`。
- **オン／オフのスイッチはコーチ欄（ボックス）見出しの右上**（上部メニューには置かない）。枠なし・横長。切り替え時は画面中央に ON/OFF 表示し、スクロール位置を保つ。
- **オフのときもタブ・欄は残す**：「コーチ機能はオフです。右上のスイッチをオンにすると…」。
- **コーチタブは全ゲーム・全モードで残す**：レッスン・パズル・定跡練習・レート戦・AI同士・検討・編集・オンライン中は欄を消さず `ck-rest` で「お休み」の案内だけ出す（計算・盤の印・前の対局の助言は出さない）。body のモードクラス（in-lesson / in-puzzle / in-online / in-edit 等）の変化で描き直す。2026-11-04 に全ゲームで統一（手本：リバーシ）。
- 内容：要約チップ（形勢・材料・段階・戦型「◯◯模様」・囲い）、推奨方針、分かれ道（どの駒・どこの手か必ず分かる題名）、考え方のヒント、前の手の評価。候補手はタップ／ホバーで盤に表示（iOSのタップも対応）。
- **序盤は定跡で指導（規定）**：定番2つを先に、変わり種を後に。定跡の手は悪手扱いしない。
- 対局後はコーチ欄を消し、振り返りカードをコーチタブで見せる。

## スマホの下部タブ（規定・`shared/infotabs.js`、全ゲーム共通）
- アイコン＋短いラベル：「コーチ｜形勢｜棋譜｜戦績｜オンライン」。オンラインのタブ名は「オンライン」だけ。
- 挙動はポーカー準拠：ページ全体はスクロールさせず、上端〜下タブの間だけがスクロール。タブを押すとその箱の先頭まで（形勢は最下部）、同じタブをもう一度押すと盤面を画面中央に。繰り返し可。
- 手順ナビ（|< < ▶ > >|）は下タブのすぐ上の帯に。
- マンカラ・バックギャモンの横画面：右端にタブ列、タップで右から盤の上に箱が出る（スワイプで開閉、戦績・オンラインも同様）。形勢と棋譜は1ページ。レッスンタブはルール・レッスン・パズルの小さなサブメニュー。レッスン中は課題カードを箱に出し、回答後は自動で出す。上部メニューは1行（ルール・レッスン類は出さない）。振り返りのナビは画面下中央の箱。

## 勝敗記録（戦績）（規定・テンプレ：`shared/record.js`）
- 対局が終わるたびに自動で記録（このブラウザに最大500局、`atlas-rec-<game>`）。AI戦・レート戦・オンラインを記録（観戦・レッスン・パズル・未着手の投了・途中から引き継いだAI戦は記録しない）。
- 戦績ダイアログ：タブ（すべて／AI／レート戦／オンライン）、勝・負・分の大きな数字、勝率バー、連勝、先後別、相手別、最近の対局30件、記録を消す。
- 入口：スマホは下部タブの「オンライン」の左、PCはヘッダーバーのメニュー。

## 仕様書の置き場所と引き継ぎ（規定・2026-11-06）
- 仕様書の正本はリポジトリの `claude/` フォルダ。複数のアカウント・エージェントで作業するため、プロジェクトの資料ではなくリポジトリを基準にする。
- 作業前に `claude/handoff-common-rules.md` と、関係する `claude/<game>-spec.md` を読む。
- 仕様が決まったり変わったりしたら、該当の spec（共通ルールはこの追補）を同じPRで更新する。新しいゲームは `claude/<game>-spec.md` を新しく作る。
- 仕様書のないゲーム（将棋・チェス・リバーシ・五目並べ・シャンチー・タフル・ヘックス・モリス・マンカラ・バックギャモン・ドット＆ボックス・コネクトフォー・まいにち数独・COMET OUTBURST+・WYRMSPHERE）は、各フォルダの `MODEL_CARD.md`・`README.md` などのコードが実質の仕様。
