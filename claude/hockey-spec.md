# テーブルホッケー（hockey）仕様

大百科の3D専用タイトル（2D版なし）。キャロム・クロキノールに続く「アクション」カテゴリ。2026-11-09 公開（BETA）、2026-11-10 正式版。リアルタイムの対戦（ターン制ではない）。

| `atlas/games/hockey.js` | 3D卓での対局（`Atlas3D.hockey`）。モード選択メニュー、入力（マウス・タッチ・キー・ゲームパッド）、HUD、効果音 |

## リンクと物理（cm）
- 遊ぶ面 40×62cm（x 横、y 縦。プレイヤー0＝赤＝手前 +y、プレイヤー1＝黄＝奥 −y）。両端の壁の中央に幅13cmのすき間＝ゴール。
- パック半径2cm、パッド半径3.1cm。パッドは自分の半分の中だけ（中央線は越えない）。目標位置へ動く：人のパッドは最大 1200cm/s（ほぼ指・マウスに付いてくる。600だと手に遅れて遅延に感じた）、AIは 600cm/s×レベルの上限。
- パック：減衰 0.4/s、壁の反発 0.85、パッドの反発 0.85（パッドの速度が乗る）。速さの上限 100cm/s（エッジショット・スピードアイテム中は 140）は Lv.1 の速さ。AIのレベルが上がるほど少しずつ速く、Lv.20 で1.5倍（`newMatch({speed})`、2人対戦は1.2倍）。この小さな卓をエアホッケーの速さで遊ぶのは無理なので、2026-11-09・11-10 の3回で大きく遅くした。
- 打った向き（2026-11-10、エアホッケーの手ざわり）：振ったパッドが当たると、パックは**パッドを動かしている向き**へ飛ぶ（当たった角度は15%だけ混ぜる）。速さはパッドの速さ×1.15（上限の3倍まで）で、パッドより速く離れ、0.2秒ほどかけて卓の速さへ落ちる。打った直後0.2秒は同じパッドに当たらない（ガチャガチャ当たらない・音は1打1回）。引いていないパッドからは自分のゴールの方へは飛ばない。止まっている（引いている）パッドにパックが当たったときは普通に跳ね返る。
- **エッジショット**：パッドが 70cm/s 超で動いていて、当たる向きがパッドの進行方向から 50〜80°ずれている（かすめる当たり）と、パックの速さが1.3倍（0.8秒はスマッシュの上限まで）（効果音と「エッジショット！」の表示）。
- 1フレームを 1/240 秒の刻みに分け（パッドが速く動くときはさらに細かく、1刻みで0.8cmより動かない。速い振りでパックの中心を飛び越えて後ろへ弾く不具合の対策、2026-11-10）、パッドの目標は刻みに沿って線形に動かす（フレームレートが低くても振りがなめらか）。
- ゴールでその点が入り、全部のパックを片付けて1.1秒後に**失点した側の陣地に**パックを置き直す（少し待ってから動く）。2.5秒（隅・端の壁ぎわは1.2秒）止まったままのパックは、卓の中央へ向けて軽く押し出す。

## 盤（2026-11-10。盤を選ぶとゲームが変わる。以前のモード選択はこれに置き換え）
開始時は ①操作の説明カード（キャロム・クロキノールと同じデザイン：丸いアイコン付きの手順・もう表示しない・OK。「もう表示しない」にしていなければ）→ ②盤選びのメニュー（「もどる」でゲームの画面へ・「スタート」）→ ③3-2-1。メニューで盤を選ぶ（ポータルの盤の列と同じ `atlas-hockey-look`。メニューで選ぶとその場で卓の中身を入れ替える＝卓のグループはそのままで部品だけ差し替え。`T3.show()` を呼ぶとカメラが部屋の眺めに戻るので使わない。ゲームパッドでも選べる）。PC（幅900px以上）ではメニューを画面幅の82%（最大1120px）まで広げ、大きな絵のカード3列×2段。盤の名前に「3D」は付けない（`tables3d.js` の `boardName(k, lang, id)` のゲーム別の名前）。14言語。
| 盤 | 見た目 | ゲーム（`hockey/engine.js` の `BOARDS`） |
|---|---|---|
| クラシック `classic`（既定） | 紺のフェルト・白樺合板 | 特別なルールなし |
| エアホッケー `air` | 白いつやのある面に空気穴の点々、赤と青の線、黒い枠に赤い帯。パックは黄色、パッドの台は白 | 減衰 0.07（止まりにくい）、壁の反発 0.93、パッドの反発 0.9、速さの上限 1.2倍 |
| ネオン `neon` | 黒い面に光る線と薄い格子。**ゲーミング演出**：線と枠の光が色を変え続ける、パックの光の軌跡、当たるたびの光の輪（エッジショットは大きく）、ゴールで盤が光る | モンスター＋アイテム |
| ピンボール `pinball` | 紫の面に放射状の光と星、赤い枠に光る帯。バンパーではじくと枠が光る | バンパー4本（パックは1つ）。壁の反発 0.9 |
| からくり工房 `gear` | 茶色の革に真鍮の歯車、ウォルナットの枠に真鍮の帯。バーは真鍮の梁に大きな歯車（中央）と小さな歯車（両端）、鋲 | 回るバー（毎秒0.9rad）が左右にゆっくり動く（中心 x = 8·sin(0.42t)。バーの速さもはね返りに乗る） |
| スペース `space` | 黒紺に星と星雲、紫の光る帯。**キラキラ**：3層の星がまたたき、ときどき流れ星、枠の光と盤がゆっくり揺らぐ | 無重力＝エアホッケーと同じ物理（減衰 0.07・壁 0.93・パッド 0.9・速さ1.2倍）。左右のワームホール＋アイテム（ワームホール拡大＝穴が8秒2倍に、スピード、分裂） |
- アイテムの種類（ネオン）：中央付近に5〜9秒ごとに出る（同時に2つまで、12秒で消える）。パックが通ると最後に打った側が取る：スピード（5秒、炎）・分裂（パックが3つに）・巨大化（パッド1.6倍、8秒）・シールド（自分のゴールを8秒ふさぐ）・凍結（相手のパッドが3.5秒遅くなる）。
- 盤の部品：回るバー（半長9cm、当たると速さが増して跳ね返る）・モンスター（中央の帯 |y|<15 をうろつく2体、ときどきダッシュ、当たるとパックが少しランダムに跳ねる）・バンパー（±9, ±12）・ワープの穴（入ったパックは反対の穴から内向きに出る）。
- エンジンは古いモード名（`newMatch({mode})`：classic・block・monster・items・bumper・warp・multi・chaos）も受け付ける（ルールコースのお手本が使う）。
- 3Dビュー（ポータルの部屋の卓）でも、ネオンは光の色が変わり続け、スペースは星がまたたき枠の光が揺らぐ（盤の面の `onBeforeRender` で動かし、表示中は描画を続ける）。対局中はゲーム側の演出（軌跡・光の輪・流れ星も）。
- 卓の下の台座・床板は枠の外側の面よりわずかに内側（同じ面が重なって側面がちらついた、2026-11-10）。
- サムネイル `atlas/img/board-hockey-<look>.webp`（tools/boards.html、480×320）。
- 操作の説明カードは「もう表示しない」で消せる（`atlas-hockey-howto`）。

## 操作
- マウス：ボタンを押さずに動かすとパッドがついてくる（ポインタの位置へ）。
- 遅延対策（2026-11-10）：自分のパッドは速さの上限なしでポインタの位置にそのまま置く（1刻み0.8cm以下に分けて計算するので、すり抜けない）。Chrome では `pointerrawupdate`（フレームを待たないマウスの知らせ）も使う。低遅延キャンバス（desynchronized）は試験環境で描画が止まったため入れていない。
- タッチ：自分の半分を指でなぞる。パッドは指の4.5cm先（指で隠れない）。
- キー：WASD・矢印。2人対戦ではWASD＝赤（手前／左）、矢印＝黄（奥／右）。
- ゲームパッド：左スティック・十字キー。1台目＝赤、2台目＝黄。2人対戦でパッドが1台なら黄（赤はマウス・キー・タッチ）。
- 対局中は卓の上でマウスのポインタを消す（`html.hk-play`）。マウスホイールでの拡大縮小はしない（誤操作が多い。Ctrl＋ホイールは除く）。
- P・Esc で一時停止。ウィンドウからフォーカスが外れる（別のウィンドウ・アプリが前に出る）・タブが隠れると一時停止（ウィンドウに戻ると自動で再開。クリック・Pでも再開）。
- 2人対戦：横長の画面では卓を90°回して**左右で対戦**（赤が左）。縦長（スマホ）は上下に分かれて同じ画面で（指は自分の半分）。
- 待った・ヒントはなし（投了のみ）。
- モード選択中もパッドは両端の定位置、パックは中央に置いて見せる（2026-11-10。以前は両パッドが中央に重なり、黄色い玉がパックに見えた）。サーブ待ちのパックも隠さない。
- キャラの会話（`npc-float`）は盤にかぶらないよう、画面下のボタンの帯に収める：PCはボタンの右横（同じ高さ、2行まで）、スマホはボタンのすぐ上の細い帯（顔36px・1〜2行、`--hk-bar` で帯の高さを測る）。`html.hk-on` のときだけ効く。

## AI（Lv.1〜20、`aiTarget`）
- AIのパッドは腕のように加速・減速する（加速度に上限、目標に近づくと減速。2026-11-10、不自然に速く飛び回らない）。速さの上限は 600cm/s×レベルの上限。
- 見ているパックは少し遅れる（反応 0.4→0.03秒）。パッドの速さの上限 22%→100%。狙いのずれ 6→0.6cm（2026-11-10、Lv.1が弱すぎたので少し戻した）。低いレベルはときどきよそ見する（0.5〜1秒、パックを追わない）。自分の陣地で止まっている（遅い）パックは、0.15秒でどのレベルでも打ちにいく（開始・失点後のサーブもすぐ打ち出す。低いレベルはゆっくり）。レベルの効き方はゆるやかな曲線（序盤はやさしいまま。2026-11-10 に弱めた）。
- 自分のゴールに向かってくる球は守備ライン上で迎え撃つ（壁の反射も読む）。自分の陣地の遅い球は、相手ゴールへの線の後ろに回り込んで打ち抜く。Lv.9以上は壁を使ったバンクショットも。それ以外はパックとゴールの間で構える。
- 隅・壁ぎわ（2026-11-10）：パックの後ろに回れないときは、打つ向きを少しずつ回して届く位置を探す（壁に向かって打つ向きは使わない。パッドの位置が少しずれても、かすめて壁沿いに出せればよい）。それでも打てない隅のパックには近づかず、押し出しを待つ。止まったパックに張り付いて0.9秒たったら0.7秒下がる（ぶつかり続けない）。攻めるかどうかの判断は0.5秒ごと（毎フレーム迷わない）。
- 正面待ちへの対策（2026-11-10、ユーザー指示）：Lv.4（初級）以上は、止まったパック（サーブ）を打つとき、相手のパッドが中央線側でまっすぐのコース上に待っていたら、正面には打たずに相手のいない側の壁へ打つ（ゴールを壁に映したバンク。`mem.dodge`）。正面で待って打ち返すだけで点が取れていた（Lv.4〜20で6〜8割）のが約5%に。Lv.1〜3（入門）は今までどおり。
- ゲームの長さ：5・7・10点先取（既定7）。パネルの見出しは「何点先取」、ボタンは「5点」など短く（英語は数字だけ）。スマホ幅でもはみ出さない。

## 見た目（クラシック・ネオンの詳細。ほかの盤は上の表）
- クラシック：紺のフェルト、白い線（中央線・円・ゴール前の半円・点数の目盛り1〜6）、白樺合板の枠とゴールの受け箱、合板の脚。パッドは黒い台・黒い棒・色の玉（赤／黄）、パックは白。
- ネオン：黒い面に光る線（シアン／マゼンタ）、黒い枠に光るライン、光る玉。
- 選択は `atlas-hockey-look`（table3d.js の `stamp()` に含める）。

## ルールコース（7ページ）
紹介 → パッドを動かす（光る輪まで、端末別の説明）→ ゴールを狙う（実際の物理でパックを奥のゴールへ）→ エッジショット（お手本）→ ゴールと試合（お手本）→ いろいろなモード（カオスを7秒見る）→ 勝ち方。14言語。
