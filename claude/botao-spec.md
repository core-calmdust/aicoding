# フチボウ・ジ・ボタン（botao）仕様

ブラジル生まれのボタンのサッカー（Futebol de Botão）。キャロム・クロキノール・テーブルホッケーに続く「アクション・おはじき」カテゴリの3D専用タイトル（2D版はない）。2026-11-15 公開（ALPHA）。ターン制で、腕前（はじく正確さ）と読み（パス・位置取り・シュートの選択・キーパーの構え）の両方が問われる。

## ルール（CBFM「12タッチ」を卓用に簡略化）
原典：CBFM の Regra 12 Toques（2020 v7 / 2025 v8）。
- 各チーム：ボタン10個＋ゴールキーパー（8×3.5cm のブロック）。フィールド 167×104cm、ゴール幅15cm（当初12.5cm。キーパー8cmに対して狭すぎ、ほとんど入らなかったので2026-11-15に広げた）、ペナルティエリア 60×30cm、ゴールエリア 30×11cm、PKマークはゴールラインから20.5cm、センターサークル半径16cm。フィールドの外にサイド8cm・エンド10cmの台（ピスタ）があり、その外は枠。
- **タッチ**：ボールを持っている側が自分のボタンを1つはじく。1回の保持で**12タッチまで**、**同じボタンは3回続けてまで**（4回目は選べない）。12タッチ目までにシュートしなければ相手の間接フリーキック（ボールの止まった所）。
- **シュート**：ボールが**相手陣内**にあり、タッチが残っているときに「シュート宣言」→ 守る側が**キーパーをゴールエリア内で構える**（人：ドラッグ＋「構えOK」、10秒で自動確定。AI：レベルに応じた位置）→ 攻める側がシュート。宣言のないゴールは無効（ゴールキック）。オウンゴールは、はじいた側が自分のゴールに入れたときだけ（宣言なしの打ちが守備側のボタンに当たって入っても得点にならない。2026-11-15：AIが守備側のボタンに当てて入れる手を覚えたため）。シュートの後はゴール以外すべて守備側のボール。
- **キックオフ**：最初の2タッチはシュート不可。ゴールの後は失点した側のキックオフ（全員を初期配置に戻す）。
- **ボールが相手に渡る**：最後にボールに触れたのが相手のピース（ボタン・キーパー）、はじいたボタンがボールに当たらない（空振り＝フラーダ）、自分の別のボタンに先に当たる、ボールが相手のゴールエリアで止まる（キーパーのボール＝最初のタッチはシュート不可）。
- **ファウル**：はじいたボタンが**ボールより先に相手のピースに当たる**と相手のフリーキック（当たった所）。相手陣内なら直接（すぐシュート宣言できる）、自陣なら間接。ファウルした側の自陣ペナルティエリア内なら**PK**（マークにボール、キッカー以外はエリアの外、キーパーはゴールライン上、シュートは宣言済み扱い）。
- ボールに当たった後で相手のボタンを動かしたら、残りタッチは最大3。
- **外に出たら**：サイドライン＝相手のスローイン（最初のタッチはシュート不可）、エンドライン＝最後に触ったのが攻撃側ならゴールキック、守備側ならコーナー（直接シュート可）。
- リスタートでは、相手のボタンはボールから7cm離れ、蹴る側のいちばん近いボタンがボールのすぐ後ろへ自動で動く。
- **試合の長さ**（サイズ選択）：前後半 各3分／各5分（既定）／各10分（公式）、または3点先取。時計は自分の番・AIの番・アニメーションの間も進む（ウィンドウが前面にない間は止まる）。時間切れはプレーの切れ目で判定（シュート宣言中は打ち終わるまで待つ）。後半は前半と逆の側のキックオフ。前後半制は引き分けあり。
- 簡略化（原典との違い）：キーパーはボールを持てない（ゴールエリアで止まったボールは、そこからボタンで再開）、キーパーのボール保持中の移動・投げは省略、時間の空費（cera）などの技術的ファウルはなし、フリーキックの壁は自動。

## 物理（`simulate`）
- 2Dの円盤と球（ゴール幅15cm）。ボタン半径2.4cm・8g、ボール半径0.8cm・0.6g（実物は直径1cm・0.2g前後。卓で見やすく扱いやすいよう大きく重くした）。
- ボタンは一定の減速 140cm/s²。ボールは 45 + 0.6×速さ cm/s² の減速。反発：ボタン同士 0.75、ボタンとボール 0.85、枠 0.55、キーパー 0.45、ゴールの枠 0.5。キーパーとゴール枠は軸に沿った箱。刻み 1/360秒、最大12秒。
- ボールの中心がゴールラインを両ポストの間で越えたらゴール（ネットの奥で止まる）。サイド・エンドを越えたら外。
- 対局は「先に全部を計算 → 60fpsの記録を再生」（キャロムと同じ）。再生中にタップで3倍速。

## AI（Lv.1〜20、`think`）
（2026-11-15 全面見直し。ユーザー：「敵のAIも挙動がめちゃくちゃ」。旧版はフラーダ（空振り）の打ち合い・遠くのボタンの無理打ち・わざとのファウルが多かった）
- 候補：レベルの手の届く範囲（22〜44cm）のボタン＋**必ずボールに近い4個**（届く範囲に誰もいない／全部ふさがれていても、無理なファウルより遠目の当てを選べるように）× ボールの飛ぶ向き（8〜24方向＋そのボタンからまっすぐ当てる向き）× 転がす距離（7〜95cm）。狙いは `aimRoll`（ゴースト球＋「ボタンがボールまで減速しても届き、ボールが指定の距離を転がる」速さ。到着時に少し余裕を持たせ、弱い打ちでも届かず空振り、を防ぐ）。
- 評価（`attackValue`）：前進（×0.35/cm）・横の位置・**次のタッチの確かさ**（自分のボタンがボールに当てられる確率をレベルの手のぶれから見積もり、ボールの後ろからなら満点、前からなら0.6倍。×70。保持は次に当てられるボタンがあってこそなので前進より重い）・シュートの見込み（距離・角度・ゴールへの筋×次のタッチの確かさ）・残りタッチ（×1.5）。相手に渡る＝相手から見た同じ評価のマイナスと守りの形。スローイン（−30）・コーナー（−18）を自分のものにする手は割り引く（相手に当てて外へ出しては取り直す手を繰り返していた）。
- 細い当たりの空振り確率を全レベルで期待値に入れる。上位8手（重複除く）はレベルの手のぶれで3〜5回打ち直して平均で選ぶ（完璧なときだけうまくいく手を選ばない）。Lv.1〜7 は上位から少しランダム。
- シュート宣言：キーパーの構えを3通り予想して平均の入る見込み（各シュートはぶれ込みで5回試す）が、しきい値（Lv.1 0.30〜Lv.20 0.38、残りタッチが少ないほど下げる）を超えたら宣言。
- キーパーの構え：ゴールエリア内の格子でボールから見たゴールの隠れる割合が最大の位置に、レベルごとの誤差（Lv.1 約6cm〜Lv.20 約0.6cm）。
- 手のぶれ：Lv.1 約2.4°〜Lv.20 約0.3°、強さ 7%〜2.5%（旧 4.6° はでたらめに見えた）。弱さは主に読みの浅さ（候補の数・打ち直しの回数・上位からのランダム）とキーパーで出す。人の打ちも毎回少しぶれる（1標準偏差で弱い打ち ±0.5°／±3%、全力 ±1.1°／±5.5%。盤ごとの「手ごたえ」でキャロムと同じ倍率）。
- 目安（AI同士、/tmp の統計）：Lv.8 で空振り 4%・ファウル 2%・1回の保持 3.6手・約50〜75手に1点。Lv.20 対 Lv.8 は 16−1、Lv.14 対 Lv.8 は 12−7、Lv.4 対 Lv.1 は 9−2。

## 操作（3D卓）
- 自分の番になると、ボールにいちばん近いボタンが選ばれている（金色の輪。輪はボタンの高さの半分に置き、見た目のボタンを囲む）。カメラはボールとそのボタンが両方入るように寄る。ほかのボタンはクリック／タップで選ぶ（3回続けて使ったボタンは赤い輪で選べない）。Tab / Shift+Tab でも切り替え（ボールに近い順）。
- **ボールを飛ばしたい向きと反対へ引っぱって離す**（2026-11-15 ユーザー：「玉の進む方向とおはじきを弾く方向がてんでバラバラ」）。引く向きで決めるのは**ボールの向き**で、ボタンの走る向きは `ballAim` が求める（切りの限界を超える向きは内側へ寄せる）。引く量は**ボールの転がる距離**（2〜152cm、画面のピクセルで測る：14px までは取り消し、画面の短辺の30%＝110〜230px で最大）。表示：ボタンから指の側へ伸びる帯（色が強さ）、ボタンがボールまで走る点線と当たる位置の輪、**ボールの通り道（緑の線、最初に何かに当たるか止まるまで、`ballPath`）と止まる所の輪**（ゴールなら金、外なら赤）。相手のピースに先に当たる向きなら赤い輪（反則の警告）。
- ボールの上に**金色の目印**（浮かぶ円すい、全体視点では大きめ）。ボールは小さいので常に見えるように。AIもはじく前にボタンと狙い（水色の線）を0.9秒見せる。
- **視点を動かす**（2026-11-15 ユーザー要望）：ボタン以外の所をドラッグ（マウスは右・中ボタンならどこでも）、矢印キー。ホイール／2本指でズーム（Table3D の pzoom）。C でボールへ戻る。次にだれかがはじくとまたボールを追う。
- 「シュート宣言」ボタン（または S キー）はシュートできるときだけ出る。キーパーを構える番では盤のどこでもドラッグでキーパーが動き、「構えOK」（または Enter）で確定（10秒で自動確定）。
- F で盤面反転、V で視点切り替え（近い／全体）。
- カメラ：既定は**ボールを追う斜めの近い視点**（ゆっくり追従）。左下の右のボタンで「フィールド全体を見る」（ほぼ真上）と切り替え（`atlas-botao-view`）。2人対戦はボールを持っている側が手前になるよう盤が回る。
- 最初の対局で操作カード（5項目：選ぶ・引く・緑の線・宣言・視点。`atlas-botao-howto`=`off` で以後出さない）→ 盤選び（キャロムの `BoardPick`、盤ごとに手のぶれの個性）→ 試合。
- 待った（AI戦、自分の番：前の自分の番へ。シュート宣言中は不可）・ヒント（Lv.20 の手を桃色で）・投了。

## 3D卓（6種、`atlas-botao-look`）
- `classic`（既定）クラシック：緑のセロテックス（最初のルールの名前「Foot-Ball Celotex」の繊維板）に白い線、ニス塗りのインブイアの枠。ボタンは赤×白い紋章（手前）と白×紺の紋章（奥）。
- `retro` レトロ：色あせたオリーブの塗りに手描きのクリーム色の線、クリーム色の縁に二重線、松の枠。ボタンは本物のコートのボタン（骨と角、4つ穴）。
- `night` ナイトゲーム：縞に刈った芝と照明の光だまり、黒い枠に白い縁。カナリアイエローとロイヤルブルー。
- `praia` コパカバーナ：砂のフィールドに青いロープの線、周りの台はコパカバーナの遊歩道の白黒の波模様。コーラルとティール。
- `madeira` ウッド：淡いメープルの長い板にウォルナットの象嵌線、ウォルナットの枠。ローズウッドとエボニー。
- `neon` ネオン：黒地に光る線（虹色に流れる）、光るボタン。
- ボタンの紋章の数字は背番号（2〜11、キーパーが1）。盤の名前は tables3d.js の NG.botao（14言語）、手のぶれの個性（CFEEL）：classic=std、retro=hard、night=precise、praia=power、madeira=aim、neon=finest。
- 寸法：K = 0.066（1cm あたりのワールド単位、台の外寸 約13×8.6）。台の天板の高さ 0.3。

## ルールコース（9ページ）
紹介 → ボールとボタン（ボールをタップ。カメラはセンターに寄り、ボールに金色の目印。タップはボールから6cmか48px以内）→ はじいてみよう（ボールに当てる）→ 12タッチと3回まで（緑の円の中へパス。円は味方の#9の手前に置き、駒に重ねない）→ 相手に先に当てたら反則（お手本）→ シュート宣言（キーパーの横のすき間へゴール）→ キーパーで守る（点線の上にキーパーを置いて「構えOK」→ 相手のシュートを止める）→ 外に出たら（お手本）→ これで遊べる。
- 狙いは対局と同じ（ボールの向きと距離）。お手伝い：ボールの向きがページの正解から12°以内なら正解の向きにそろえ、距離は成功する範囲のうち近い値に寄せる（2.2倍以上ずれていたら寄せない）。
