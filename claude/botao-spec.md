# フチボウ・ジ・ボタン（botao）仕様

ブラジル生まれのボタンのサッカー（Futebol de Botão）。キャロム・クロキノール・テーブルホッケーに続く「アクション・おはじき」カテゴリの3D専用タイトル（2D版はない）。2026-11-15 公開（ALPHA）、同日ユーザー指示で BETA に。ターン制で、腕前（はじく正確さ）と読み（パス・位置取り・シュートの選択・キーパーの構え）の両方が問われる。

## ルール（CBFM「12タッチ」を卓用に簡略化）
原典：CBFM の Regra 12 Toques（2020 v7 / 2025 v8）。
- 各チーム：ボタン10個＋ゴールキーパー（8×3.5cm のブロック）。フィールド 167×104cm、ゴール幅15cm（当初12.5cm。キーパー8cmに対して狭すぎ、ほとんど入らなかったので2026-11-15に広げた）。ボタン直径6cm・ボール直径2.6cm（当初4.8cm・1.6cm。実物の写真と比べて小さく、ボールが見えにくかった。2026-11-15）。ボールの転がり抵抗を強めた（遠くまで転がりすぎて誰も届かない場面が多かった）。ボールはサッカーボールの柄（黒い五角形）、ペナルティエリア 60×30cm、ゴールエリア 30×11cm、PKマークはゴールラインから20.5cm、センターサークル半径16cm。フィールドの外にサイド8cm・エンド10cmの台（ピスタ）があり、その外は枠。
- **タッチ**：ボールを持っている側が自分のボタンを1つはじく。1回の保持で**12タッチまで**、**同じボタンは3回続けてまで**（4回目は選べない）。12タッチ目までにシュートしなければ相手の間接フリーキック（ボールの止まった所）。
- **シュート**：ボールが**相手陣内**にあり、タッチが残っているときに「シュート宣言」→ 守る側が**キーパーをゴールエリア内で構える**（人：ドラッグ＋「構えOK」、10秒で自動確定。AI：レベルに応じた位置）→ 攻める側がシュート。宣言のないゴールは無効（ゴールキック）。スローイン・コーナー・ゴールキックは「線を越える前に最後に触ったチーム」の相手のボール（線を越えた後に卓の中で触れたものは数えない。2026-11-15 修正）。オウンゴールは、はじいた側が自分のゴールに入れたときだけ（宣言なしの打ちが守備側のボタンに当たって入っても得点にならない。2026-11-15：AIが守備側のボタンに当てて入れる手を覚えたため）。シュートの後はゴール以外すべて守備側のボール。
- **キックオフ**：最初の2タッチはシュート不可。ゴールの後は失点した側のキックオフ（全員を初期配置に戻す）。
- **ボールが相手に渡る**：最後にボールに触れたのが相手のピース（ボタン・キーパー）、はじいたボタンがボールに当たらない（空振り＝フラーダ）、自分の別のボタンに先に当たる、ボールが相手のゴールエリアで止まる（キーパーのボール＝最初のタッチはシュート不可）。キーパーのボール（シュート後・ゴールエリアで停止）は、ボールをキーパーの正面（キーパーの前の面から2.5cm、ゴールエリアの幅に収める）に置き直し、守備側が蹴る人を置いて再開（2026-11-15：止まった場所のままだとキーパーに接して誰も届かず、試合が進まなくなった）。
- **ファウル**：はじいたボタンが**ボールより先に相手のピースに当たる**と相手のフリーキック（当たった所）。相手陣内なら直接（すぐシュート宣言できる）、自陣なら間接。ファウルした側の自陣ペナルティエリア内なら**PK**（マークにボール、キッカー以外はエリアの外、キーパーはゴールライン上、シュートは宣言済み扱い）。
- ボールに当たった後で相手のボタンを動かしたら、残りタッチは最大3。
- **外に出たら**：サイドライン＝相手のスローイン（最初のタッチはシュート不可）、エンドライン＝最後に触ったのが攻撃側ならゴールキック、守備側ならコーナー（直接シュート可）。
- リスタートでは、相手のボタンはボールから7cm離れ、蹴る側のいちばん近いボタンがボールのすぐ後ろへ自動で動く。
- **ルールと長さ**（2026-11-15 ユーザー：「プルダウンで手数制・点数制、点数は1・2・3点。面白そうなルールも同じ形式で」）：カードの「ルール」プルダウン（`adapter.rule`、ポータル共通の仕組み：選んだルールで「試合の長さ」の選択肢が切り替わる。サイズの値が両方を表すのでゲームはサイズだけ読む）。
  - 手数制：前後半 各30手／各50手（既定）／各80手（両チームのはじいた回数の合計。シュート宣言は数えない。当初は各3／5／10分の時計だったが「時間制だと問題が多い」）。HUD は「前半 あと○手」。後半は前半と逆の側のキックオフ。引き分けあり。待ったは手数も戻す。
  - 点数制：1点先取／2点先取／3点先取（サイズ 101〜103）。
  - PK戦：3本／5本（サイズ 203・205）。**PK戦のゴールはキーパー3体分の幅（24cm、`D.PK_GW`、エンジンは `s.pk` のある局面で `ghw(s)`、盤は `U.goalWidth(w)` でポストとネットを広げる）**（2026-11-15 ユーザー：中央に構えられるとほぼ入らない。通常の試合は15cmのまま）。HUDはPKの記録だけ（タッチ数は出さない）。交互にペナルティマークから。**読み合い**（2026-11-15 ユーザー：ただの運ゲー → キーパーを操作できるように／相手がどの方向に打ち出すのか見えないほうがいい）：AIが蹴るときは、キーパーを構える前に、左・中・右のどこかにキーパーがいると仮定した狙いを先に決めておき、人のキーパーは**その場で動かす**：マウスの左右（スマホはドラッグ）にキーパーが付いてきて、「構えOK」はない。AIは1.8〜3.4秒の助走ののち、その瞬間のキーパーの位置でシュート（狙いの線は出さない）（2026-11-15 ユーザー：マウスの左右などで動かせる、構えは不要）。AIが守るときは、キーパーは中央に立ったまま、はじいた瞬間に自分で選んだ左・中・右（37%・26%・37%）へ跳ぶ。2人対戦は従来どおり。n本ずつで決着しなければサドンデス（1本ずつ、本数がそろって差がついたら終わり）。途中でも逆転できなくなったら終わり。HUD に ●× の記録。待ったなし。
- 簡略化（原典との違い）：キーパーはボールを持てない（ゴールエリアで止まったボールは、そこからボタンで再開）、キーパーのボール保持中の移動・投げは省略、時間の空費（cera）などの技術的ファウルはなし、フリーキックの壁は自動。

## 物理（`simulate`）
- 2Dの円盤と球（ゴール幅15cm）。ボタン半径2.4cm・8g、ボール半径0.8cm・0.6g（実物は直径1cm・0.2g前後。卓で見やすく扱いやすいよう大きく重くした）。
- ボタンは一定の減速 140cm/s²。ボールは 45 + 0.6×速さ cm/s² の減速。反発：ボタン同士 0.75、ボタンとボール 0.85、枠 0.55、キーパー 0.45、ゴールの枠 0.5。キーパーとゴール枠は軸に沿った箱。ぶつかり合いで押されてキーパーにめり込んだピースは毎刻み押し出し、止まった時点でも重なっていればフィールド側へ出す（ボールがキーパーの中に残り進行不能になった不具合の対策）。刻み 1/360秒、最大12秒。
- ボールの中心がゴールラインを両ポストの間で越えたらゴール（ネットの奥で止まる）。サイド・エンドを越えたら外。
- 対局は「先に全部を計算 → 60fpsの記録を再生」（キャロムと同じ）。再生中にタップで3倍速。

## AI（Lv.1〜20、`think`）
（2026-11-15 全面見直し。ユーザー：「敵のAIも挙動がめちゃくちゃ」。旧版はフラーダ（空振り）の打ち合い・遠くのボタンの無理打ち・わざとのファウルが多かった）
- 候補：レベルの手の届く範囲（22〜44cm）のボタン＋**必ずボールに近い4個**（届く範囲に誰もいない／全部ふさがれていても、無理なファウルより遠目の当てを選べるように）× ボールの飛ぶ向き（8〜24方向＋そのボタンからまっすぐ当てる向き）× 転がす距離（7〜95cm）。狙いは `aimRoll`（ゴースト球＋「ボタンがボールまで減速しても届き、ボールが指定の距離を転がる」速さ。到着時に少し余裕を持たせ、弱い打ちでも届かず空振り、を防ぐ）。
- 評価（`attackValue`）：前進（×0.35/cm）・横の位置・**次のタッチの確かさ**（自分のボタンがボールに当てられる確率をレベルの手のぶれから見積もり、ボールの後ろからなら満点、前からなら0.6倍。×70。保持は次に当てられるボタンがあってこそなので前進より重い）・シュートの見込み（距離・角度・ゴールへの筋×次のタッチの確かさ）・残りタッチ（×1.5）。相手に渡る＝相手から見た同じ評価のマイナスと守りの形。スローイン（−30）・コーナー（−18）を自分のものにする手は割り引く（相手に当てて外へ出しては取り直す手を繰り返していた）。
- 細い当たりの空振り確率を全レベルで期待値に入れる。上位8手（重複除く）はレベルの手のぶれで3〜5回打ち直して平均で選ぶ（完璧なときだけうまくいく手を選ばない）。Lv.1〜7 は上位から少しランダム。
- シュート宣言：キーパーの構えを3通り予想して平均の入る見込み（各シュートはぶれ込みで5回試す）が、しきい値（Lv.1 0.30〜Lv.20 0.38、残りタッチが少ないほど下げる）を超えたら宣言。
- キーパーの構え：ゴールエリア内の格子でボールから見たゴールの隠れる割合が最大の位置に、レベルごとの誤差（Lv.1 約6cm〜Lv.20 約0.6cm）。
- 手のぶれ：Lv.1 約2.4°〜Lv.20 約0.3°、強さ 7%〜2.5%（旧 4.6° はでたらめに見えた）。弱さは主に読みの浅さ（候補の数・打ち直しの回数・上位からのランダム）とキーパーで出す。人の打ちも毎回少しぶれる（1標準偏差で弱い打ち ±0.5°／±3%、全力 ±1.1°／±5.5%。盤ごとの「手ごたえ」でキャロムと同じ倍率）。
- 目安（AI同士、/tmp の統計）：Lv.8 で空振り 4%・ファウル 2%・1回の保持 3.6手・約50〜75手に1点。Lv.20 対 Lv.8 は 16−1、Lv.14 対 Lv.8 は 12−7、Lv.4 対 Lv.1 は 9−2。

## 操作（3D卓）
- 自分の番になると、ボールにいちばん近いボタンが選ばれている（金色の輪。輪はボタンの高さの半分に置き、見た目のボタンを囲む）。カメラはボールとそのボタンが両方入るように寄る。ほかのボタンはクリック／タップで選ぶ（3回続けて使ったボタンは赤い輪で選べない）。Tab / Shift+Tab でも切り替え（ボールに近い順）。
- **はじきたい向きと反対へ引っぱって離す（キャロム／クロキノールと同じ）**（2026-11-15 ユーザー：「コマを弾いた時の挙動はクロキノールそのまま持ってくる感じの方がいい」「強弱がつかない」）。狙うのは**ボタンの進む向き**（一時「ボールの向きで狙う」にしたが、ボタンがボールに近いと物理的に狭い範囲しか出せず「はじける範囲が30度くらいなのはルール？」と混乱したのでやめた。範囲の制限はルールではない）。引く量は**卓の上のcm**で測る（ボタンから3.2cm＝タッチは1.6cm までは取り消し、そこから20cmで最大。スマホは指の動きを縮めて約210pxで最大）。強さは `E.powV`（2026-11-15 ユーザー：「緑くらいだとほとんど前に進まない」「このゲームの距離感に合わせた強弱」）：引く量80%までは、まっすぐ当てたボールが約 5＋155×引く量 cm 転がる速さ（10%で約20cm、30%で約50cm、50%で約80cm）、残り20%で最大200cm/sまで上がる（遠くから走る・強いシュート用）。
- **表示は向きだけ**（ユーザー：「どっち方向に進むかわかればよく、どこまで飛ぶかは強弱の塩梅でプレイヤーが考える」）：ボタンから狙いの向きへ矢印（長さと色が強さ：緑→赤、先に三角）、ボタンが走る白い点線（最初に当たる所か、ひとりで滑って止まる所まで）、ボールが飛ぶ向きの金色の矢印（14cm、どこまで飛ぶかは出さない）、**自分のボタンが止まる所**（平らな白い円とうすい影。ぶつかりも含めた計算。ユーザー：「コマの飛び先は表示したほうがいい」）。相手のピースに先に当たるなら、そのピースに赤い平らな円（反則の警告）。指のそばに %。
- 選んだボタン・マウスを乗せたボタン・3回続けて使えないボタンの印は、卓の上の**平らな円**（ユーザー：「フォーカスしたコマ周囲のエフェクトは2Dのフラットな円でOK」）。
- 自分の番のカメラは、ボールとボタンと、ボタンの後ろ18cm（引っぱる場所）が入るように寄る。そのときは卓の端の制限をゆるめる（ユーザー：「スローインで横幅が狭くなりすぎて全然飛ばせない」）。
- キックオフのボタンはボールから2.5cm、リスタートの蹴る人は3cm離して置く。
- **リスタートの蹴る人の位置は自由**（2026-11-15 ユーザー：「スローインは上下に自由に打ち出せない、コーナーは90度どの角度も狙いやすく」）：スローイン・コーナー・ゴールキック・フリーキック（間接も）・キーパーのボールでは、蹴るボタンがボールを軸に回る（中心から RB+RBALL+3cm の円周上）。**別の「置く」段階はない**（2026-11-15 ユーザー：「置いたらOKのステップは抜いて」）。マウスはカーソルの動きにボタンが勝手に付いてくる（ボタンはカーソルの側、ボールは反対へ。他の自分のボタンに乗っているときは動かない）。そのままボタンを掴んで引けば、通常どおり強さと向きを決めてはじく。タッチは、ボールのまわり（ボタン以外）からのドラッグで回し、ボタンを掴んで引けばはじく。ボールから蹴る向きに金色の点線、置ける範囲（スローインはタッチラインの外側の半円、コーナーはコーナーの外側の四分円、ほかは全周）は細い円弧。ほかのボタンを選べば回さない。盤のほかの場所のドラッグや右／中ボタンは視点の移動（コーナーで盤面をドラッグできなくなった不具合の修正）。AIは12方向×2距離（接する＋0.6cm〜＋10cm）の位置を、その位置からの最善手で比べて選ぶ（`E.placeFor`、ワーカー）。キックオフ・PKは固定。
- ボールの上に**金色の目印**（浮かぶ円すい、全体視点では大きめ）。ボールは小さいので常に見えるように。AIもはじく前にボタンと狙い（水色の点線と金色の矢印）を0.9秒見せる。
- **視点を動かす**（2026-11-15 ユーザー要望）：ボタン以外の所をドラッグ（マウスは右・中ボタンならどこでも）、矢印キー。ホイール／2本指でズーム（Table3D の pzoom）。C でボールへ戻る。次にだれかがはじくとまたボールを追う。
- 「シュート宣言」ボタン（または S キー）はシュートできるときだけ出る。キーパーを構える番では盤のどこでもドラッグでキーパーが動き、「構えOK」（または Enter）で確定（10秒で自動確定）。
- F で盤面反転、V で視点切り替え（近い／全体）。
- カメラ：既定は**ボールを追う斜めの近い視点**（ゆっくり追従）。左下の右のボタンで「フィールド全体を見る」（ほぼ真上）と切り替え（`atlas-botao-view`）。2人対戦はボールを持っている側が手前になるよう盤が回る。

## 3D卓（6種、`atlas-botao-look`）
- `classic`（既定）クラシック：緑のセロテックス（最初のルールの名前「Foot-Ball Celotex」の繊維板）に白い線、ニス塗りのインブイアの枠。ボタンは赤×白い紋章（手前）と白×紺の紋章（奥）。
- `retro` レトロ：色あせたオリーブの塗りに手描きのクリーム色の線、クリーム色の縁に二重線、松の枠。ボタンは本物のコートのボタン（骨と角、4つ穴）。
- `night` ナイトゲーム：縞に刈った芝と照明の光だまり、黒い枠に白い縁。カナリアイエローとロイヤルブルー。
- `praia` コパカバーナ：砂のフィールドに青いロープの線、周りの台はコパカバーナの遊歩道の白黒の波模様。コーラルとティール。
- `madeira` ウッド：淡いメープルの長い板にウォルナットの象嵌線、ウォルナットの枠。ローズウッドとエボニー。
- ボールの軌跡：どの盤でもボールが動くと薄い白の軌跡（2026-11-15 ユーザー要望）。ネオンは虹色に光る軌跡（加算合成）。軌跡の円は作った瞬間に大きさ・色・透明度を決める（以前はネオンの描画ループで初めて設定していたので、ウィンドウにフォーカスがないと半径1m相当の白い円が残った）。
- `neon` ネオン：黒地に光る線（虹色に流れる）、光るボタン。**ゲーミング演出**（2026-11-15 ユーザー要望）：台のふちの光る帯が虹色に流れる、ゴール枠の色が回る、ボタンが呼吸するように明滅、ボールが色を変えながら光の軌跡を残す、ぶつかるたびに台が光る、ゴールで虹色のストロボ。材質は共有なので終わるときに元に戻す（`neonReset`）。
- ボタンの紋章の数字は背番号（2〜11、キーパーが1）。盤の名前は tables3d.js の NG.botao（14言語）、手のぶれの個性（CFEEL）：classic=std、retro=hard、night=precise、praia=power、madeira=aim、neon=finest。
- 寸法：K = 0.066（1cm あたりのワールド単位、台の外寸 約13×8.6）。台の天板の高さ 0.3。

## ルールコース（9ページ）
紹介 → ボールとボタン（ボールをタップ。カメラはセンターに寄り、ボールに金色の目印。タップはボールから6cmか48px以内）→ はじいてみよう（ボールに当てる）→ 12タッチと3回まで（緑の円の中へパス。円は味方の#9の手前に置き、駒に重ねない）→ 相手に先に当てたら反則（お手本）→ シュート宣言（キーパーの横のすき間へゴール）→ キーパーで守る（点線の上にキーパーを置いて「構えOK」→ 相手のシュートを止める）→ 外に出たら（お手本）→ これで遊べる。
- 狙いは対局と同じ（ボールの向きと距離）。お手伝い：ボールの向きがページの正解から12°以内なら正解の向きにそろえ、距離は成功する範囲のうち近い値に寄せる（2.2倍以上ずれていたら寄せない）。
