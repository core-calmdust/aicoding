# だつごくスライダー！（jailbreak/）仕様メモ（2026-10-28 改修）

旧名「だつごく！スライド」。ブロックをずらして囚人を出口へ逃がすスライドパズル。

## 構成
- **コース**（stages.json v2 `courses`）：各10フロア×10ステージ＝100。フロアは前のフロアを6問クリアで解放。コースは最初から全部開放。
  - 脱獄コース（mix＝クラシック＋特殊ルール混在）：ハルデン（初心者・最初の3問は操作確認、2F〜9Fで1ルールずつ導入）／シンシン（初級）／サン・クエンティン（中級）／アバシリ（上級）／アルカトラズ（超上級）
  - クラシック（ブロックのみ）：フォルサム（初級）／レブンワース（中級）／ラ・サンテ（上級）／デビルズ島（超上級）
- **ルールモード**（`modes`）：key plate oneway ice patrol twin dig tilt silent big ×50。
- 20手以上＝「超上級」バッジ。2〜3手の問題はハルデン冒頭の操作確認だけ。7〜17手が中心。
- 各ステージは保存キー `k` を持つ（旧版から残したステージは旧キー `c123` / `key.5` のまま → ★が引き継がれる）。称号の★は過去に取った分も数える。

## 問題の作り方・検証（tools/）
- `plan.js` 枠（ルール×最短手数）、`gen2.js` 候補採掘、`fun.js` 面白さスコア＋ルール関与チェック、`assemble.js` 組み立て（`--daily` でデイリー中級の不適格問題を差し替え、プレイ済みの日は据え置き）。
- ルール関与チェック（不合格は採用しない）：一方通行＝カートを動かさずに解けない／看守＝解答中に2歩以上歩き、看守が結果に影響する／二人で脱獄＝どちらも単独で3手未満では出られない／氷＝氷なしより最短が長くなる／穴掘り＝内側のヒビが効いている／感圧板＝最初は空いている／カギ＝2手以上運ぶ。
- 面白さ（0〜100）：同じブロックを何度も使う割合・往復・囚人がいったん下がる・最短解の少なさ・正解手の選びにくさ。

## UI
- ヘッダー：実績｜ルール｜設定｜ホーム（言語・効果音は設定内、ガチャ・図鑑・ランキングはプロフィールから）。
- プレイ画面：盤のすぐ上に1行の操作バー（手数/最短の1ボックス・★・ヒント・待った・やり直し）。スマホは盤を左右いっぱい（ヘッダーは隠す）、PCは高さいっぱいで中央。
- ヒントはステージごとに無料3回、以降1回30コイン。
- 看守に「あと何手で歩くか」の数字バッジ（完全情報）。感圧スイッチはブロックの下でも印を上に表示。氷の床は床デザインに関係なく氷に見える。
- サーチライトのカウントダウンはルール説明のOK後に開始。
- 画面遷移は履歴（pushState）で管理：ブラウザの戻る・スマホの端スワイプ・ホームでの左右スワイプで前の画面へ。
- 結果画面は固定オーバーレイ、ボタンは常に見える。
- 各コース・モードに「続きから」。
