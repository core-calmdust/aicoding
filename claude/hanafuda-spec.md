## 札の図案の決まり事（調査メモ）
- 柳の光札は江戸〜明治初期は柳の木だけ。1886年ごろ前田喜兵衛の働きかけで八八花の図柄が斧定九郎（雨降小僧）から小野道風に差し替えられた。柳のカスは赤く塗った鬼札→八八花で雷の太鼓の図（Wikipedia「花札」）。
- 芒の月の色は 無地・薄青 →（幕末）黄・薄紅 →（明治）真っ赤（同）。
- 赤短の文字は「あかよろし」（「か」は変体仮名で「の」に見える）、桜は「みよしの」（サザノ https://sazano123.com/ の短冊の文字の記事）。
- 19世紀の実物（BnF 所蔵、京都・赤田製）：墨の主版の線の上に、型紙で色（艶のある藍がかった黒、朱、黄）を刷毛で刷る。色は線から数ピクセルずれ、黒の塊の縁は細い線の外にはみ出したり引っ込んだりする。札の縁は黒い裏紙を表に折り返した額縁状。

## 絵柄の作り方（`hanafuda/tools/art/`、2026-11-28 v3）
- 親の検品で v2（座標を手置き）は不合格（形が不正確・線が均一幅）。v3 は**図案を下敷きにして描き直す**方式（コーディネーター経由で了承：パスの流用・同梱は不可、輪郭を下敷きに自分の線で描き起こすのは可）。
- `hftrace.py`：下敷き（参考 SVG を描画）を色ごとに分け、①色の面＝型紙として切り直し（手で切った揺らぎを加える）、②線＝中心線（細線化）をたどって一本ずつ**筆で引き直し**（入りは重く・抜きは細く・太さがゆっくり揺れる、自由端は細く抜く）、③太い黒（冠・傘の頭・目）は墨の型紙。アンチエイリアスの縁は線か隣の色に振り分ける。
- `hfprint.py`（質感＝ユーザーが「方向性は合っている」と評価、維持。2026-11-28 ノイズ対策：線の密な所はむら・縁の溜まりを弱める、色は隣の線の下まで回して版ずれで紙の白が出ないようにする、版ずれは控えめ、紙の斑点は広い紙地だけ）：①墨の主版 →②色の型紙（版ずれ・刷毛の筋・むら・縁の溜まり・顔料の粒）→ 和紙（雲状のむら・繊維・斑点・紙の歯）→ 黒い裏紙の折り返し（額縁の合わせ目・擦れ）。
- `cards4t.py`：4枚の生成（下敷きの場所は環境変数 `HF_REF`、既定 `/mnt/user-data/uploads`。参考ファイルはリポジトリに入れない）。菊に盃は下敷きの字を消して**自分で筆で書いた「寿」**、盃の口に金の縁、漆の照り。
- `cards4.py`（v2、座標の手置き）は残すが本番には使わない。
- 顔料の色：墨 `#161416`、黒い塊は墨の薄い重ね（線が透けて見える）`#34323a`、朱 `#ba3024`、雌黄 `#dcb846`、黄丹 `#d47a2e`、紫 `#604a7e`、浅い群青 `#6ea2be`、金 `#cea03e`。現行品の鮮やかな黄 `#FFEB5C`・赤 `#D81E1E` は使わない。
- 出力：1280×2120（`img/cards/<id>@2x.webp`）と半分（`<id>.webp`）。
- 検品：参考と同寸で左右に並べた比較画像を作って見比べる。

## AI
- Lv.1〜20。自作：相手の手札と山の並びを、見えていない札から抽選した「ありうる局面」をいくつも作り（相手が取らずに場に捨てた月の札は持っていない可能性が高い、という推定で重み付け＝Lv.8〜）、各候補手を簡易方針の打ち切りまでのプレイアウトで期待得点を比べる。こいこいの判断も「続けた場合の期待値」と「今止めた点」の比較（Lv.5〜）。レベルで標本数・ぶれ・うっかりを変える。
- 計測：`node hanafuda/tools/bench2.js A B 配り数 [aiA] [aiB]`（同じ配りを席を入れ替えて2回、1か月あたりの平均得点差±標準誤差）。
- 2026-11-28 の計測（各200〜300か月）：Lv5−Lv1 +1.58±0.54、Lv10−Lv5 +0.55±0.56、Lv12−Lv10 +0.29±0.42、Lv16−Lv12 +0.37±0.49、Lv20−Lv16 +0.20±0.47。上位はプラスだが誤差の範囲。プレイアウト方針の強化版（quick2：取り札の価値を自分と相手の両方で評価、こいこいの判断の改良）は旧方針に −0.59±0.45 で改善が確認できず、無効にした。花札は運の要素が大きく、レベル差を測るには数千か月の対局が必要。
- 未：上位の段差の強化（相手手札推定の精度、決定論的な読み）。

## 画面のレイアウト（2026-11-28 ユーザー指示で改訂）
- ソリティアのような「上に卓・下にUI」：PCは画面上部に横幅いっぱいの卓（相手の手札・取り札／山札・場札／自分の手札・取り札）、その下に情報の箱を横一列（月・点数・手番｜コーチ｜記録｜オンライン）。右欄は廃止。ヘッダーの空きに月・点数・親・AIの強さ（レート戦はR）。
- 札の大きさは卓に合わせて計算（場は12枚分の場所を取って月の途中で大きさが変わらないようにする。手札は場札の1.12倍、取り札は0.58倍）。
- 卓の色・質感はそのまま（木の縁・金線・透かしロゴは付けない）。
- UIの点検：`node hanafuda/tools/ui-audit.js <URL> <出力先> [言語]` が PC 1280/1440/1920・スマホ390 で全画面（対局・新しい対局の各タブ・ルール全ページ・レッスン全問・チュートリアル全ステップ・設定・戦績・こいこい・結果・振り返り）を撮り、空の札枠・ボタン文字の折り返しや切れ・画面外にはみ出すダイアログ・ラベルの折り返し・下段の箱の中身の切れ（scrollHeight>clientHeight）・トーストが札や下段の箱やヘッダーに重なっていないか（スマホはスクロール位置を変えて、帯の上にあるか）・ボタンが文字の上に重なっていないかを検査する（2026-11-28：問題0）。
- 下段の情報の箱（PC、高さ214px固定）：手番の箱は幅330px（「あなたの番：…」が1行に収まる）、コーチは「おすすめ」を見出しのすぐ下に置き、自分／相手の役の進み具合を2列に並べる（各3件まで、危険の注意があるときは2件）。振り返りの一覧と記録は箱の中でスクロールし（振り返りの「次の月へ」は箱の見出しの行に置き、一覧に重ねない）、記録は最新の行が見えるように下までスクロールする。
- トースト：PCは卓の上部、相手の手札と相手の取り札の間の空いた帯の中央に出す（下段の箱・札に重ねない）。スマホは卓のいちばん上に状態の帯（手番の案内、不透明）を置き、卓が見えている間は画面上端に貼り付く（sticky）。トーストはその帯の上にちょうど重ねて出し、スクロールに追従する。卓が画面外のときは画面上端の不透明な帯として出す。
- ルール説明・レッスンのミニ盤のクラスは `hfr-*`（共通部品 ruletour の `.rt-row` と名前がぶつかって「前へ／閉じる／次へ」が縮んでいた不具合を直した）。札の絵は読み込み直後に先読みする（読み込み中に空の枠に見えないように）。

## 画面（2D、`hanafuda/index.html` ほか）
- 構成：`engine.js`（ルール）・`ai.js`＋`worker.js`（AI、Worker で考える）・`cards.js`（札の絵、`?v=N`）・`app.js`（進行・対局設定・コーチ）・`rules.js`（RuleTour のルール説明 7ページ、14言語）・`lessons.js`（レッスン）・`i18n.js`／`i18n-more.js`（14言語）。
- 卓：上に相手の手札（裏）と取り札、中央に山札と場、下に自分の手札と取り札（光・タネ・短冊・カスに分けて重ねる）。手札にマウスを乗せると取れる場の札が光る。取れない手札は少し暗くする。場に同じ月が2枚あるときは光る札から選ぶ。
- PC：右に固定幅360pxの情報欄（月・得点・親・こいこい・手番表示 → コーチ → 記録 → オンライン準備中）。ページはスクロールしない。スマホ：卓 → 情報欄、下部タブ（コーチ｜オンライン｜記録）。
- 札の裏：実物の黒い裏紙のように、少し温かい黒（焦げ茶寄り）の地に、つながった不規則な斑状の粒（大小混在、明るい粒はやや暖色の灰で少なめ）とごく弱い繊維・むら。白黒のごま塩ノイズに見えないこと（2026-11-28 ユーザー指摘で粒を大きく・斑状に・暖色寄りに）。縁は同じ紙の折り返しで少し擦れて灰色。`hanafuda/tools/art/hfback.py` で 1280×2120 に描いて @1x 360×596・@2x 720×1193 の `img/cards/back-black|red(@2x).webp` に縮小（縮小しても粒が残る）。裏が出る所（相手の手札・山札・ルール説明・チュートリアル・レッスン）はすべて CSS の `.hf.back` でこの画像を使う。赤は同じ粒の赤い紙。
- 対局設定：ゲーム（こいこいのカード・AIの強さ Lv.1〜20・月数）｜ルール（型のプリセット＋各ルール差、独自プルダウン）｜デザイン（札の裏 黒・赤、卓 藍の布〔#17435a、2026-11-28 に紺 #1c2c44 から藍染めの青緑寄りへ。アイコンも藍〕・漆の盆、最下部に札の絵のクレジット）。
- 初めて開いたときは、標準ルール・Lv.5 で1か月目を配って待つ（ダイアログは出さない）。親は札を1枚ずつ引いて決める（トーストで表示）。
- AIの手番・山札めくりは、ウィンドウが前面にないとき進めない。
- コーチ（右上スイッチ）：自分と相手の役の進み具合（あと何枚）、相手があと1枚の役の札を場に残す危険、Lv.14 のおすすめの手。こいこいの判断では「続けた場合の見込み点／今の点」を表示（Lv.16）。
- 戦績：`shared/record.js`（AI戦、月数ぶんの対局を1局として記録）。オンライン・レート戦：未実装（オンラインは「準備中」表記）。

## レッスン（`lessons.js`）
- 3カテゴリ×2問：札と月（菖蒲と藤／場に3枚ある月）、役（四光と雨四光／月見で一杯）、こいこいの判断（相手が迫っているとき＝勝負／序盤で1点＝こいこい）。
- こいこいの2問は、同じ局面をAI（Lv.20、6回の平均）で読ませて確認：相手があと1枚で猪鹿蝶の局面は 勝負5点 対 こいこい −1.4点、タネ1点で相手が役から遠い局面は 勝負1点 対 こいこい 約6.2点（`/tmp` の検証スクリプトで計測、2026-11-28）。
- 文言は日本語・英語のみ（他の12言語は英語で表示。要追加）。
