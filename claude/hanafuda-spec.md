## ルール（出典つき）
標準（既定）＝任天堂「こいこい」の遊び方に合わせる。

| 項目 | 標準 | 出典 |
|---|---|---|
| 親の決め方 | 1枚ずつめくり月の早い方が親（同月は札の格が上の方） | 任天堂 howtoplay／Wikipedia「こいこい」「Koi-Koi」 |
| 配り方 | 場8枚・手札8枚ずつ。2枚ずつ場→子→親を4回 | 任天堂 |
| 場に同じ月4枚 | 配り直し | 任天堂 |
| 場に同じ月3枚 | 4枚目で3枚とも取る | Wikipedia「こいこい」 |
| 手役（手四・くっつき） | 6点で即終了 | Wikipedia「こいこい」（任天堂サイト例）、BGA |
| 7点以上 | 2倍 | 任天堂 |
| こいこい | 相手がこいこい後に自分が上がれば2倍（7点以上と重なれば4倍）。こいこいした側は0点 | 任天堂、Wikipedia「Koi-Koi」 |
| こいこいの回数 | 標準は「こいこい後は次にどちらかが役を作った時点で終わり」（任天堂）。ルールタブで「何度でも」を選べる | 任天堂、Wikipedia「こいこい」 |
| 役なしで手札切れ | ノーゲーム・親交代（任天堂）。ルールタブで「親権（親に6点・親続投）」 | 任天堂、gamepedia、BGA |
| 次の親 | 勝者（任天堂）。ルールタブで「交代」 | 任天堂、BGA |
| 月数 | 12か月（12回戦）。6か月・3か月も選べる | 任天堂、gamepedia、BGA（既定6回戦） |
| 菊に盃 | タネとカスの両方に数える（任天堂）。ルールタブで「カスに数えない」 | 任天堂、gamepedia |
| 花見で一杯・月見で一杯 | あり（各5点）。ルールタブで「なし」「雨で流れる（柳の光を取っていると無効）」 | Wikipedia「こいこい」（任天堂のオプション役）、BGA |
| 猪鹿蝶・赤短・青短の加点 | なし。ルールタブで「1枚増えるごとに+1」 | gamepedia |

役と点数：五光10／四光8／雨四光7／三光5（柳を含む3枚は不成立）／花見で一杯5／月見で一杯5／猪鹿蝶5／赤短5／青短5／赤短・青短の両方10／タネ5枚で1点（以後1枚ごと+1）／タン5枚で1点（同）／カス10枚で1点（同）。光の役は重複しない。それ以外は重複して数える。

プリセット（ルールタブの先頭）：任天堂式（標準）／アプリ風（何度でもこいこい・加点あり・親権）／ソフト（自分のこいこい回数＋1倍、7点倍なし、雨流れ、6か月。BGA の Soft Koi を参考）。

## 札の図案の決まり事（調査メモ）
- 柳の光札は江戸〜明治初期は柳の木だけ。1886年ごろ前田喜兵衛の働きかけで八八花の図柄が斧定九郎（雨降小僧）から小野道風に差し替えられた。柳のカスは赤く塗った鬼札→八八花で雷の太鼓の図（Wikipedia「花札」）。
- 芒の月の色は 無地・薄青 →（幕末）黄・薄紅 →（明治）真っ赤（同）。
- 赤短の文字は「あかよろし」（「か」は変体仮名で「の」に見える）、桜は「みよしの」（サザノ https://sazano123.com/ の短冊の文字の記事）。
- 19世紀の実物（BnF 所蔵、京都・赤田製）：墨の主版の線の上に、型紙で色（艶のある藍がかった黒、朱、黄）を刷毛で刷る。色は線から数ピクセルずれ、黒の塊の縁は細い線の外にはみ出したり引っ込んだりする。札の縁は黒い裏紙を表に折り返した額縁状。

## 絵柄の作り方（`hanafuda/tools/art/`）
- `hfart_geom.py`：曲線・揺らぎ・筆の太さ変化（入り・抜き）の道具。
- `hfprint.py`：刷り。①墨の主版（線）→②色版（合羽刷り）を版ごとに版ずれ・刷りむら（斑・刷毛の筋・顔料の粒）・縁の溜まり→③和紙（雲状のむら・繊維・斑点・紙の歯）→④黒い裏紙の折り返し（額縁の合わせ目・縁の擦れ）。色は描いた順に後の形が前の形を隠す（色の重ね刷りで濁らせない）。後から置いた形は、その下の線も隠す。`paper` は刷らずに紙の地を残す指定。
- `cards4.py`：4枚の構図。点の座標を手で置いて描き起こす。参考画像のパスは使わない（照合のみ）。
- 顔料の色：墨 `#161416`、黒い塊は墨の薄い重ね（線が透けて見える）`#34323a`、朱 `#ba3024`、雌黄 `#dcb846`、黄丹 `#d47a2e`、紫 `#604a7e`、浅い群青 `#6ea2be`。現行品の鮮やかな黄 `#FFEB5C`・赤 `#D81E1E` は使わない。
- 出力：1280×2120（`img/cards/<id>@2x.webp`）と半分（`<id>.webp`）。

## AI
- Lv.1〜20。自作：相手の手札と山の並びを、見えていない札から抽選した「ありうる局面」をいくつも作り（相手が取らずに場に捨てた月の札は持っていない可能性が高い、という推定で重み付け＝Lv.8〜）、各候補手を簡易方針の打ち切りまでのプレイアウトで期待得点を比べる。こいこいの判断も「続けた場合の期待値」と「今止めた点」の比較（Lv.5〜）。レベルで標本数・ぶれ・うっかりを変える。
- 計測：`node hanafuda/tools/bench-ai.js A B 手数`（Lv.A 対 Lv.B の1回戦あたりの平均得点差）。
