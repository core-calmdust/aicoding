# ペグソリテール（peg/）仕様

URL: https://core-calmdust.github.io/aicoding/peg/ ／ 2026-11-11 BETA公開（2D版）。大百科のカテゴリはパズル（cat: puzzle、定番タグ）。テーマ色 #7d5ba6（夜のすみれ色、アクセントは真鍮色 #f1c879）。名前は元のフランス語名に寄せて「ペグソリテール」（ユーザー決定）。

## ルール・盤（engine.js、DOMなし・Worker／node 共用）
- 玉は縦か横（三角は斜めの2線も、6方向）の隣の玉を跳び越え、その先の空いた穴へ。跳び越えた玉を取る。跳べる玉がなくなったら終わり。1本残せば成功、◎の穴なら「完璧」。連続して跳ぶのは1回ずつ別の手（「最短18手」は続けて跳ぶのを1手と数えたときの数）。
- 盤は5種（ユーザー決定）：英国式33穴・欧州式37穴・三角15穴・ダイヤ41穴・ドイツ式（ヴィーゲルブ）45穴。
- 定番のスタートとゴール（`START`／`GOAL`）：英国式・ドイツ式は真ん中→真ん中。三角は上の角→同じ角。欧州式は2段目の真ん中→下から2段目の真ん中、ダイヤは3段目の真ん中→下から3段目の真ん中（どちらも真ん中から1本にはできない）。
- 「3の規則」（位置の類）：穴を (r+c) mod 3 と (r−c) mod 3 で色分けすると、1回跳ぶごとに各色の数が1ずつ変わるので、色の数の和の偶奇は変わらない（`sig`／`canEnd`）。四角い盤で、始めと終わりの偶奇が合わない問題は解けない。欧州式とダイヤでは、スタートの穴にそのまま1本残す問題は1つも作れない。
- 出典（2026-11 確認）：Wikipedia「Peg solitaire」。1697年のルイ14世の宮廷の記録、同年8月の『メルキュール・ギャラン』に盤とルール、ベレーの版画（スービーズ公妃）、英国式の最短18手（Bergholt 1912、Beasley 1964 に最短と証明）、欧州式は真ん中から解けないこと（位置の類）。

## ソルバー（ヒント・問題の作成）
- `solve`：深さ優先、内側へ跳ぶ手から、対称形をまとめた「行き止まり表」つき。玉が18本以下なら完全探索（「もう1本にできない」と言い切れる）。
- `beam`：玉の数ごとの段で、ゴールからの距離と孤立した玉の数で上位 K 個だけ残す探索。完全ではないが、大きい盤でも1秒以内に見つかる（ドイツ式・真ん中から：K=500 で約0.6秒）。
- `findPath`（ヒント）：3の規則で先にふるい分け → 18本以下は完全探索 → 多ければ beam を K=300→1200→5000 と広げ、残りの時間で完全探索。Worker（engine.js 自身）で6秒まで。結果は「次の一手」（青い輪と点線）、または「この形からは1本にできない（待ったで戻る）」か「見つからなかった」。
- 問題集の問題で、記録した解答の途中にいるあいだは、その次の手をすぐに出す。

## 画面（index.html・app.css・app.js）
- PC：ヘッダーバー（`shared/headerbar.js`）に 新規／待った／最初から／ヒント／ルール／パズル。左が盤、右の欄（360px）に状態（残りの本数・手数・ゴール・跳べる手の数）・パズルカード・今日の問題・ベスト記録。スマホ：タイトル → メニュー → 盤 → カードの縦並び。
- 盤は1枚のSVG：ろくろで挽いた丸い木の盤（三角は角を丸めた三角）、穴、ビー玉。取った玉は盤の縁の溝（三角は下の溝）へ転がる。玉はタップ→跳び先の穴のタップか、ドラッグで動かす（行ける穴は金の輪）。跳ぶときは弧を描いて少し大きくなる。
- 待ったは無制限（←キー・Backspace）、「最初から」で盤を戻す。Hキーでヒント。
- 左上のタイトル（h1.to-board）を押すとこのゲームのトップへ：ダイアログを閉じ、パズル中ならやめてフリープレイの盤に戻る（チェス・将棋と同じ）。
- 盤はできるだけ大きく（2026-11-11 ユーザー指示）：盤の縁を細く（穴の外 1.22、溝は縁から 0.48）、PC の余白 clamp(12px, 2.4vmin, 32px)、盤の上限 980px（スマホ 680px）。
- 状態カードは盤の名前・モード・残りの本数・手数だけ（◎の説明と跳べる手の数は出さない、ユーザー指示）。右上のアイコンは戦績（shared/record.js：フリープレイの1局ごと、残り1本＝勝ち・2本以上＝負け、盤ごとの切り替え）・設定・ホーム（反転なし）。
- ルールとパズルは1つの箱（大きさは常に同じ・固定）。ルールとパズルは同じ1つのダイアログ（#puzzleOverlay の中の #rulesView／#pzListView／#pzGridView）で、タブはその中のページを切り替えるだけ（ダイアログの出し直しなし）。閉じるボタンは箱のいちばん下（ほかのゲームと同じ）：どちらのダイアログも上に「ルール｜パズル」のタブ（.ls-tabs）、大きさは同じ（PC 1000×880 まで）。切り替えはアニメなしでその場で。
- フリープレイの結果：残り1本で ◎ なら「完璧！」（👑）、1本「1本残し！」、2本「あと一歩！」、3本「お見事」、4〜5本「まずまず」、6本以上「もう一度挑戦」。盤とスタートの穴ごとにベスト（最少本数・完璧）を記録し、右の欄に定番スタートのベストを5つの盤の絵つきで表示。
- 新しいゲームのダイアログ（`shared/ngtabs.js`＋共通の Luxury デザイン `shared/nglux.js`、デザインの行は .bdrow のタイル）：ゲーム＝5つの盤のカード、ルール＝スタートの穴（定番／自分で選ぶ：プレビューの盤で穴をタップ）とゴール（◎の穴に1本／どこでも1本）、デザイン＝盤4種（ウォルナット既定・メープル・大理石・夜の漆）と玉4種（ビー玉既定・真珠・鋼球・木のペグ）。デザインは押した瞬間に反映。自分で選んだスタートのゴールは、3の規則でそのスタート穴に残せるならその穴、だめなら残せる穴のうち真ん中にいちばん近い穴。
- ルール説明（`rules.js`、`shared/ruletour.js`）：紹介 → 跳び越えて取る → ななめは跳べない → 続けて跳ぶ → 最後の1本を◎へ（十字架の形）→ 三角の盤のななめ線。各ページの盤は実際に動かせる小さな盤で、判定は engine.js。

## 盤と玉のデザイン（2026-11-11 作り直し、ユーザー指示「実在感のある高級な盤と駒、テーマ性とディテール」）
- 2Dの盤と玉は絵（`peg/img/bd-<look>-<盤>.webp`＝SVG の viewBox 全体、`m-<玉>-<k>.webp`）。`tools/render_boards.py`（numpy：高さマップ＋色・つや・金属のマップから陰影・映り込み・くぼみの陰・卓への影）。穴・溝・縁の位置は app.js の geo() と同じ（R＝穴の外 1.22、溝は縁から 0.48）なので、ライブの穴と絵の穴がぴったり重なる。geo.json は app.js と同じ計算で作る。
- 盤（キーは設定の bd のまま、2026-11-11 ユーザーの見直し：四隅の飾りはなし＝気が散る、縁の黒い切れ目のような線もなし）：walnut＝ウォルナット（ほぼ直線の淡い木目・明るめ、柘植と黒檀の象嵌線、溝の外に真鍮の縁）、maple＝ヴェルサイユ（黒檀、溝まで続く金銅の縁、穴に金の縁、溝は赤いビロード）、stone＝大理石と真鍮（カッラーラ大理石、真鍮の線1本）、night＝アブストラクト（写実なし：藍の地に平らな色面の円・クリームの細い弧と線・クリームの溝・平らな穴、ユーザー指示「抽象的な表現」）。
- 玉（どれも6色、穴ごとに (i×7+3) mod 6）：glass＝アンティークのビー玉（中に3枚の羽根）、pearl＝陶器の玉（青磁・藍・黄土・朱・白・墨の釉薬、真珠はやめた）、steel＝宝石（丸い磨いた宝石：ルビー・サファイア・エメラルド・アメジスト・トパーズ・アクアマリン、中のきらめき）、peg＝漆塗りの木のペグ（赤・青・緑・黄・紫・白、ろくろの溝に木地）。
- 大百科の3D盤も同じ絵を盤面に貼る（atlas/models/peg.js：ろくろの胴の上に絵の板、盤の切り替えは setSet で材質をその場で入れ替え＝残っていた盤でも選んだデザインになる）。取った玉は盤面の溝の絵の上に置く。盤面の板は不透明＋alphaTest、胴の縁やビードは絵より下に収め（突き抜けるとチカチカする）、玉は平らな盤面に載る高さ（中心 R×0.97）、接地の影は盤面より上。3Dの玉の色も2Dの6色の組に合わせる。
- 駒「アブストラクトの駒」（settings.pg='mod'、2026-11-11）：アブストラクト盤に合わせた平らな色の円盤。テラコッタ・マスタード・ティール・クリーム・インディゴ・コーラルの6種に、半分割り・輪・沈む日・四分割・輪と角・斜めの帯の模様を1つずつ（render_boards.py の 'mod'、陰影はほぼなし）。3Dは低い円柱で、上面に同じ絵（m-mod-<k>.webp）を貼る。

## パズル（puzzles.json、`shared/pzbook.js`）
- 面白さスコア `tools/fun.js`（0〜100、共通ルール claude/puzzle-fun-score.md）：解答の途中の各局面を完全探索で測り、F1 罠（行き止まりの手の割合）30・F2 鋭さ（2手以上のうち正解が1つだけの局面）20・F3 意外性（初心者が選びがちな手＝真ん中寄り・まとまる手が行き止まり）15・F4 見せ場（1つの玉の連続跳び、3回以上で満点）15・F5 すっきり（ひとかたまり・ほどよい本数・ゴールが玉の固まりの真横でない）20。玉が18本を超える問題は測らない。
- 2026-11-11 全面見直し（ユーザー指示「既存の問題も評価し直し、超初級は数問」）：`tools/gen_more.js` が元の問題集（tools/puzzles.orig.json）から作り直す。どれも逆向きに作るので必ず解け、記録する解答は作ったときの手順。候補は必要数の3倍以上（基準に届くまで増やす）、スコア70以上の上位だけ。
  - 基本：はじめの一歩10問（超初級3問＝3〜4本＋5〜8本の7問）、形パズル14問（古典の7形＋左右対称の形で70以上）、英国式の中盤80問（10〜16本）、連続跳び60問（最後に1つの玉が3回以上続けて跳ぶ）。
  - 世界の盤：三角22・欧州式33・ダイヤ32・ドイツ式31（古い問題で70以上のものを先に、足りない分を新しく）。全面23問（そのまま）。計337問。
- 今日の問題は2種類（daily.json）：通常 `list`（9〜15本、70以上）と EASY `easy`（4〜8本、60以上）、各366問。連続日数は通常だけ、EASY は日ごとの済み（`aicoding-peg-daily` の easy）。右の欄の「今日の問題」の横に EASY ボタン、パズルのホームに2枚のカード。
- 星：★★★＝ヒントも待った・やり直しもなし、★★＝ヒントか待った・やり直しあり、★＝答えを見た。途中の手の良し悪しは言わない（共通ルール）。終わったときだけ「もう跳べません（残りn本）」「◎の穴ではありません」。
- 今日の問題（daily.json、366問）：1年の何日目かで選ぶ。英国式が約半分、ほかの盤から残り。解いた日・連続日数（`aicoding-peg-daily`：days・streak・best・last）。
