# ファノロナ（fanorona/）仕様メモ（2026-11-05 更新）

- チェッカー（checkers/）を土台に作成。共通仕様（game-conventions.md / 追補）準拠。
- 盤（対局設定「ゲーム」タブで選択、settings.rule）：
  - sivy＝ツィヴィ 9×5（標準・22枚ずつ）、dimy＝ディミ 5×5（12枚ずつ、中段 `bw.bw`、同ルール）、telo＝テロ 3×3（3枚ずつ交互に置く→線に沿って1歩動かす、3つ並べたら勝ち・取りなし。完全解析済み：先手必勝）。
  - 点の番号は全盤共通で i = r*9 + c（小さい盤は左下の部分を使う）。engine.js `setRule()`、engine.c `set_rule(w,h)`。終盤DB・学習評価・定跡は 9×5 専用。
  - レッスン／パズル／序盤／レーティング戦は常に 9×5。共有URLは `&r=dimy`、棋譜は `[Variant "Dimy"]`。
- ルール（9×5）：白先手、接近・離脱（両方可能なら一方を選択）、取りの義務、連続取りは任意（毎回向きを変える・同じ点に戻らない）。勝ち＝全部取る／相手が動けない。引き分け＝同一局面3回・取りなし80手。
- 指し手表記：パイカ `d3-e3`、取り `f2-e3A` / `d3-e3W`、連続 `d3-e3A-e4W`、テロの配置 `b2`。
- エンジン：engine.c（wasm, u64 ビットボード、1ターン＝1手、取りの静止探索、4枚以下の終盤DB、学習評価）。20段階（15級〜五段、デフォルト15級）。テロは JS の完全解析。
  - ビルド（`tools/build.sh`、2026-11-08〜）：`engine_simd.wasm`（`-msimd128`。学習評価の層の足し算が4レーンずつになるだけで、浮動小数の計算順は同じ＝結果は1ビットも変わらない）と、SIMD 非対応ブラウザ用の `engine.wasm`。engine.js が判定して選ぶ（アルケルケのページも同じ）。40局面・レベル15/16で最善手・評価値・深さ・局面数が完全一致のまま **約1.2倍**（WASM、約57万→約69万局面／秒）。
- デザイン：盤＝アカシア／メープル／ウォルナット／ローズウッド／モダン（無地）／ランバ（布・tools/gen_lamba.py のオリジナル柄）。駒＝木の玉／貝殻／石／翡翠／フラット／円盤。
- レイアウト：PC はバックギャモン準拠（盤が上、情報行が下）。スマホ横向きは landtabs.js（右タブレール＋引き出し）。
- コーチ：解析の深さ6以上の結果だけで推奨を出す（浅い読みの貪欲な取りを避ける）。
- オンライン：Firebase プロジェクト fanorona-multi、App Check（reCAPTCHA Enterprise）。database.rules.json は shared/tools/secrules.py（fanorona: v=sivy/dimy/telo、持ち時間 8分+5秒／4分+3秒／2分+2秒）。指し手は3文字（from+1, to, 同じ from/to 内の番号）。共通アカウント（atlas-account.js GAME_AUTH）に登録済み。
- ポータル：shared/atlas.js・atlas/app.js（R3）に登録、タグ online / variants。

## 3D盤（2026-11-05）
- 盤モデル atlas/models/fanorona.js：アカシアの一枚板（板目の帯を接ぎ合わせた木目）に線と点を彫って焦がした色（法線マップ＋色）、両側の長辺に取った玉を置く丸い溝（実ジオメトリ）。玉はマットな木（白＝白木、黒＝黒檀）。盤の外寸＝(点の列数+2)×(行数+3)、9×5/5×5/3×3 すべて対応。溝の玉は2/3サイズ（22個入る）。
- フル機能版 atlas/skin/fanorona.js（fanorona/?skin=atlas）：2D本編と同じレイアウト（PC横長・ワイド時は右列）。DOMの枠＝板の外形。玉は線に沿って転がり、取られた玉は取った側の溝へ跳ねて並ぶ。テロは置く前の玉が溝で待つ。デザインタブに「3D盤」タイル（2D盤も選べる）。
- ちゃぶ台対局 atlas/games/fanorona.js（9×5、AI／二人対戦、接近・離脱の選択、連続取りは次の点 or 玉をタップで終了）。
- 横向き固定（rotwrap）の外側ページではスキンを読まない（iframe 内で読む）。
- ポータルのカードゲーム（poker / blackjack / baccarat / solitaire）は2D専用：ボードカードに「カードゲームは2Dで遊ぶよ」の案内（atlas/app.js CARD2D、i18n bv.card2d）。

## 対局設定の Pro モード（2026-11-08）
対局設定の「AIの強さ」の PRO ボタン（`shared/proset.js` の `ProSet.ladder()`、addendum「対局設定の Pro モード」）。項目：思考の制限（時間／深さ／局面数）、定跡（ファノロナ本来のルールのみ。既定は Lv.15 以上。アルケルケには出さない）、手のばらつき（深さで読むときだけ）。変えた値は fanorona/engine.js `think` の `cfg`（LEVELS と同じキー）で渡す。レート戦では使わない。戦績のキーは `ai:pro<レベル>`、相手名に「PRO」。
