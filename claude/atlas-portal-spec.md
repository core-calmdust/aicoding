# 世界のボドゲ大全 ポータル仕様（atlas/）

URL: https://core-calmdust.github.io/aicoding/atlas/  ／ 詳細: repo の atlas/README.md

## 画面
- ホーム：白背景のタイトル（コンパス紋章＋周りに3Dのデフォルメ駒が浮かぶ）→ 最近のアップデート（横スクロールの大カード）→ ゲームのアイコン一覧（更新順、スマホは1列4個）→ プロフィール＋ログインボーナス
- アイコンをタップ → 3D盤がポップして表示（情報カードと重ならないよう盤の描画領域をカードの外に限定）→ スタートでカメラが寄って3D盤でそのまま対局
- **スマホの3Dビューの盤の大きさ（2026-11-09）**：画面幅700px未満では、盤の大きさに合わせてカメラを寄せる（table3d.js camPose の `pr`）。チェス盤で横幅の約6割。盤の大きさは盤だけで測る（駒台・碁笥・脇に置いた駒は除く：描画の足跡をグリッドに塗り、いちばん大きいつながった塊＝盤。table3d.js boardBox）。従来の固定枠（約11ユニット）より遠くはしない。長い盤（ウル）は長辺が画面端に付かないよう抑える。
- **3D盤のマウスホイール（2026-11-09）**：3Dビューでも3D卓での対局中でも、ホイールで盤に寄る／引く（対局中は 0.6〜1.5倍、table3d.js `pzoom`）。スマホは対局中もピンチで同じく寄る／引く（ピンチの指で駒は動かない）。PCではマウスの左右ドラッグで3Dビューのゲームは切り替わらない（盤が回るだけ。切り替えは矢印・キー）。スマホの指のフリックは従来どおり切り替わる。フル機能のゲーム画面の3D盤は2D盤の位置に合わせて描いているので対象外。
- **3D卓のパズル（2026-11-10）**：将棋（詰将棋）とチェス（詰めチェス・戦術）のパズルを、フル機能へ飛ばずにポータルの3D卓でそのまま解ける（`atlas/puzzles.js`）。あそぶシートの「パズル」から開始。ルール説明と同じガイドキャラ（ナイトン＝「ぼく」の元気な騎士、ショウギツネ＝「わたし」の明るいキツネで語尾にときどき「コン」）が出題・相手の受け・正解・連続正解・届かなかった時・ヒント・やり直しに、それぞれの口調の台詞で反応（`atlas/puzzle-lines.js`、場面ごとに複数パターンからランダム・同じ台詞は連続しない。日本語・英語は3〜5種、他言語は2〜3種）。途中の台詞は手の良し悪しに触れない。問題はフル版と同じデータ（`chess/puzzles.json`・`shogi/tsume.json`）、進み具合もフル版と同じ localStorage キーで共有（★3＝ヒントなし初回正解、★2＝ヒントか失敗あり）。出題は続きから（フル版の「続き」と同じ順・ステージ解放ルール）。判定：詰め問題（詰めチェス・詰将棋）は途中の手を一切ミス扱いにしない（絶対条件、2026-11-10）。どの手を指しても相手が受け（詰将棋は記録の手順かエンジンの tsumeDefend、チェスはエンジン最善手）、基準手数以内に詰めばクリア、使い切ったら「詰ませられなかった」で終了。キャラも「ミス」とは言わない（途中は「あと◯手」だけ）。戦術問題は記録の手順どおり（途中で詰めばクリア）。詰将棋のスマホでは、自分の持ち駒を画面上部にチップで表示（タップで打てる）。創作詰将棋は相手が残りの駒をすべて持つ約束なので相手の持ち駒は出さず、実戦の詰み（攻め方の玉が盤上にある問題）だけ相手の持ち駒も出す。盤の一部だけを使う詰将棋は、問題の駒と正解手順のマス（＋周り1マス、最低5×5）を拡大して映し、拡大は一瞬で切り替えず短時間（約0.4秒）でズームする。フル機能版の詰将棋（2D盤と3Dスキン、shogi/index.html の tzSync／atlas/skin/common.js が window.__boardZoom に追従）にも同じ拡大・切替ボタン・スライドを入れた（2026-11-10）。丸いアイコンボタン（文字なし、盤に重ねない：3D卓はガイドキャラのアイコンの真上、フル版は盤の右下の角。拡大は周りに少し余白を残し、下側のボタンの帯をあけて合わせる）で全体／拡大を切り替え、拡大中は指（マウス）でスライドすると盤を動かせる（2026-11-11 ユーザー指定で滑らかに：スライド中は9×9の盤全体を拡大の倍率のまま CSS transform で指に付けて動かし、3D盤は window.__boardZoom で追従、盤の場所で切り抜き。上と右の数字の帯も9つ全部を盤と同じ長さで一緒にスクロール（消さない）。離すといちばん近いマスの位置に収まって拡大表示に戻る。それまではマス単位で飛んでいた）。全888問は記録手順が正しく詰むことを確認済み（9手以内の683問はソルバーで「相手が残り全部の駒を自由に打てる」前提でも手数内に詰むことを確認、2026-11-10）。パズル中の駒の移動は対局より速い（約半分の時間）、3Dの持ち駒列は隠す。レッスンは今のところフル機能へ。
- **フル版の詰め問題カード（将棋の詰将棋・チェスのパズル共通、2026-11-10）**：見出し行の右端にやめる（アイコン＋文字の小さな丸ボタン。カードの縁からの上・右の空きは、下の列のボタンの下・横の空きと同じ）、タイトルの横に「n/N問目」。目標は枠なしの文。ボタンは両ゲームで統一：アイコン＋小さな文字の「ヒント・やり直し・答え・一覧」（この順）と横長の「次の問題」（解けたら金色。未解答でも次が解放済みなら進める）。再生ボタンは置かない（答えは解いた後に押すと再生）。将棋のやり直しは解く前ならいつでも初期局面へ戻す。パズル中はコーチのパネルを出さない（将棋・チェスとも）。チェスのパズル中は駒の点数のカード（あなた／守り手）も出さない。ページのピンチ拡大は止めない（利便性優先）。
- **トップのプロフィールカードのレア演出（2026-11-10）**：SSR・UR（アイコン・背景・フレームのどれか）を身につけている時は、きせかえのネームカードと同じ縁を走る光・光彩・角のきらめきをトップのプロフィールカードにも出す。
- **ボスを倒した表示（2026-11-10）**：3D卓でボスを倒した時の「〜を倒した！」のお知らせ（npc.js .npc-toast）は、PCでは大きめ（キャラ108px・見出し26px）。
- **戦績ポップアップ（2026-11-10）**：タブ（戦績・あそびの記録・実績）がある時は箱の大きさを固定（高さ min(860px, 画面)）、タブを切り替えても大きさは変わらず中身だけスクロール。
- **スマホの「あそぶ」シート（2026-11-09）**：パズル・レッスンのあるゲーム（まず将棋・チェス）は、スマホのカードを「あそぶ ▶」＋「2Dで遊ぶ」だけにして、対局の設定（モードタブ・AIの強さ・手番・持ち時間）とフル機能／ちゃぶ台ボタンは下から出るシートへ移す。シートは「対局／パズル／レッスン」の3段で、パズル・レッスンは進み具合のバー付き。パズル・レッスンはフル機能の3D盤（`?skin=atlas&mode=puzzle|lesson`）を開き、その一覧から始まる（将棋は詰将棋、チェスはパズル）。解析などマニアックな機能はフル機能だけ。ヒストリアと戦績は左上のまま（カード内に置く案は試したが一旦見送り、2026-11-10）。PCのカードは保留中のため従来どおり。
- **やめるボタンの高さ（2026-11-09）**：スマホの3D卓では、ルール説明中のやめるもゲーム中と同じ高さ（HUDの高さ、HUDがない時は45px）。
- **3D卓→やめる→3Dビューの戻り（2026-11-09）**：バウンドさせずに滑らかに。盤は落下＆弾みではなく少し上から静かに着地（show opts.soft、0.34秒）。カメラの戻りは0.4秒。カメラの戻り（glide）の間は対局の画角（fit）と上帯（insetT）・レンズシフト（vsh）も同じカーブで戻す（以前は上帯が先に消えて盤が跳ねて見えた）。
- **3Dビューの駒の選択（2026-11-11）**：3D駒のセットが複数あるゲーム（`atlas/tables3d.js` の `Table3D.PIECES`：今はアマゾンズの6種）は、3Dビューの場所パネルの「盤」の行の下に「駒」の行を出す（`atlas/app.js` pieceRowHtml）。保存キーはフル機能と共有（アマゾンズは atlas-amazons-pc3）、選ぶとその場で卓の盤を作り直し、3D卓で対局中ならゲーム側が `atlas-pieces` イベントで盤上の駒を入れ替える。絵はフル機能の駒の絵を暗い台の上に表示。
- **3D駒のポリゴン（2026-11-09・チェス）**：ろくろ駒は輪郭点を Douglas–Peucker で間引く（直線上の点を落とす：フル機能 0.0022・大百科 0.0035・映り込み 0.008）、フル機能の周方向は36→24分割、輪郭の許容 0.003。チェス駒32個でフル機能 約22万→約9万、大百科の3Dビュー 約10.7万→約6万三角形（周方向 フル24・大百科12、ナイトの頭は輪郭・面取りを粗く）。見た目は並べて比較してほぼ同じ。新しい3D駒もこの方式で作る（atlas/models/chess.js simplify、他のモデルは Table3D.lp）。2026-11-09 フル機能の3D盤も同様に削減：コナネ7.1万→3.6万、チェッカー6.6万→4.7万、アルケルケ6.4万→3.8万、モリス6.0万→3.8万、ファノロナ5.9万→3.7万、アゴン5.2万→2.6万、ウゴルキ4.4万→1.9万、セネト2.3万→1.5万、マンカラ2.6万→2.3万。
- **バックギャモンの3D盤6種と駒の色（2026-11-11）**：`atlas/models/backgammon.js` の `LOOKS`＝寄木細工 marq・レザー scarlet・スモークオーク oak・バタフライ butterfly・大理石と真鍮 marble・クロコダイル croc（新4種は `LUX` に盤面・枠の絵と素材。**盤面に対局の邪魔になる模様・柄は入れない**（2026-11-12、螺鈿・孔雀石・シャグリーンは不採用で差し替え）。oak＝スモークオークの箱にクリームの盤面と赤・グレーのポイント、butterfly＝明るいオークの箱・紺の盤面に白い蝶6匹と青緑のシェブロンのポイント、croc＝グレーのクロコ型押しの箱（腹側の四角い鱗が列にそろう・丸く盛り上がった鱗と細い溝、カーネル croc）・チャコールの革の盤面に白黒のポイント。butterfly の蝶は頭を盤の中央に向け、上下の列で向かい合う。大理石は1枚絵で描き、真鍮の象嵌は粗さ／金属マップにも描いて金属として光らせる）。保存は `atlas-bg-look`、2Dページの下地スキンは classic／midnight／marble／classic に連動（`Table3D.BOARDS.backgammon`）。フル機能版はデザインタブの2D盤の下に「3D盤」の小箱（3×2、`atlas/img/boardic-backgammon-<look>.webp`）。**駒の色は他のゲームと違いプレイヤーごとに選ぶ**：8色＝金（象牙）・黒・赤・白・緑（孔雀石）・青（ラピスラズリ）・パール（白蝶貝）・茶（コニャック革）。2Dも同じ8色（`backgammon/themes.js` CK_IDS、4×2）、3Dの対局設定ではスウォッチが3D駒の絵になる。ポータルの盤の設定パネルには「駒の色」の行（あなた／相手、`Table3D.CKCOL.backgammon`、保存は `settings.ck`）。
- **戦績ページ（2026-11-09）**：全ゲームのカードに「🏆 戦績」ボタン（ルールの隣）。開くと大百科スタイルのシートで：勝・負・分と勝率リング、連勝中／最多連勝、最近15局の○×、相手別（AIレベル順→レート→オンライン）の勝敗バー、最近20局、あそびの記録（パズル・レッスン・レート・今日の一問・3D卓など）、このゲームの実績。データは各ゲームの GameRecord（localStorage `atlas-rec-<id>`、shared/record.js）を共用し、大百科の3D卓の対局も同じリストに `via:'3d'` で追加する（二人対戦は記録しない）。`atlas-rec-` はアカウント同期の対象。モードの絞り込みはプルダウン（すべて／AI戦／レート戦／オンライン／3D卓、記録のあるものだけ）。シート下部のタブで「戦績／あそびの記録／実績」を切り替える（中身のあるタブだけ）。戦績ボタンはカップのアイコンだけで、スマホは3Dビュー左上のヒストリアの下（左寄せ）に置く（PCは右上の背景選択の右＝閉じるの左。PCレイアウトは保留中）。ヒストリアと同じ作りで、金色の丸に白い線画のカップ（カードには置かない：タイトルが詰まる）。スマホのカードの進捗リングは、進捗バーのないゲーム（ウル等）も含めて、カードを広げた時だけ出す。スマホのカードではAIの強さは「Lv.N＋キャラ」だけを表示（PCは保留）。パズルなど対戦のないゲームは「対局の記録なし」の箱を出さない。 置き場所（2026-11-17）：見えている3Dビューの右下（カードのすぐ上）に固定、カードの大きさに追従（addendum）。
- **カードの「AIの強さ」と「手番」は1行（2026-11-09）**：レベル名やキャラの長さに関係なく、手番が2択のゲームは同じ行に並べる（index.html `#bvOpts` の nowrap）。バックギャモンも手番を選べる：先手＝自分が最初のサイコロで勝つ（3D卓は振り出しの目を入れ替え、フル機能は振り出しがそうなるシードを選ぶ。色は変えない）。
- **ゲーム画面の上部バーのコインは常にポータルと同じ数字**：実績の計算に使うポータル専用の数（3D卓の各ゲームのレベル数・ガチャの景品数）は localStorage `atlas-ach-meta` に覚えて同期し、ゲームページも同じ実績＝同じコインを出す（shared/atlas.js achMeta）。共有アカウントの同期が終わった時・他タブで変わった時・画面に戻った時に読み直す（skin/common.js）。ゲームページは必ず shared/atlas-account.js を読み込む（ルドーに不足していた）。
- 3D専用のタイトル（`only3d`、例：キャロム・クロキノール・テーブルホッケー）はボードカードに「2Dで遊ぶ」を出さない。トップページからは `atlas/#games/<id>` で3Dビューを直接開く
- **きせかえ（2026-11-09）**：レアリティの絞り込みは自前のポップアップ（`#drar` ボタン＋`#drarPop`、レアリティ色のバッジ）。SSR・URのセルの演出は軽量化：枠を回る光は輪にマスクした子要素（`.rfx`）の transform 回転、光彩は静止、画面外のセルは一時停止（IntersectionObserver で `.vis`）、未所持は演出なし。SSR・URを身につけている（アイコン・背景・フレームの最高レア）ときはネームカードにも同じ光（`.dprev.nr3/.nr4`）。
- **3Dビューと対局中の表示は文字選択なし（2026-11-09）**：`#bv` の中と、body に出すトースト・やることの帯・力の表示・操作カード・反転ボタン・キャラ会話（`.cr*`／`.ck*`／`npc-*`）は user-select:none と長押しメニューなし（入力欄は除く）。スマホで狙っている長押しでHUDの文字が選択されないように。
- 3D対局はリバーシのみ実装（../reversi/engine.js のAIをそのまま使用）。未対応のゲームは「いつもの画面で遊ぶ」
- タブ：ホーム／ゲーム／**博物館**／実績／ガチャ／きせかえ（スマホは下部タブバー）。地図は博物館の展示室の1つ（2026-11-21、詳細は `claude/museum-spec.md`）。**PCの上部は横幅いっぱいの1行（2026-11-20）**：ロゴ｜タブ（中央）｜コイン・設定・ホーム。タブが詰まるときはロゴの英字サブタイトル→タイトル文字の順に省き（ロゴマークだけ）、それでも入らない狭い画面だけ従来の2段（app.js fitHeader）。**ショップはガチャのページの下段**（2026-11-06、上＝ガチャ・下＝ショップ、タブ名は「ガチャ」。`#shop` はガチャのページのショップ位置へ）。**スマホは画面下（下部タブバーのすぐ上）の「ガチャ｜ショップ」タブで切り替え**（きせかえと同じ。NEWSバーはガチャ・ショップとも出さない）、ショップ表示中は下のNEWSバーを出さない
- **3Dのゲーム画面（ポータル版 `?skin=atlas`）の上部バー（PC）**：世界のボドゲ大全のロゴ（サブタイトル込み・ロゴ側の表示は変えない）の右に、区切り線のあと、ロゴの文字と同じくらいの大きさでゲーム名だけを出す。手番・石数・形勢などのゲーム情報はここには出さない。その右にメニュー（対局＞待った＞ヒント＞ルール＞レッスン＞パズル）・コイン・アイコン。実装は `shared/headerbar.js` のポータルモード。スマホはスペースがないのでゲーム名は出さない。

## デザイン方針（確定）
- **ゲームアイコン（今後もこの路線で統一）**：そのゲームを象徴するコマを大きくデフォルメし、盤は2〜4路の切れ端だけ。厚みのある正方形の土台を45°の角から等角（アイソメトリック）で見せ、ダイヤ形に見える。おもちゃのような丸みのある質感。atlas/icons3d.js の ICONS に1シーン追加 → atlas/tools/icons.html で images/atlas/<id>.webp に書き出す
