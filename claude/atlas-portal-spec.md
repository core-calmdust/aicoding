# 世界のボドゲ大全 ポータル仕様（atlas/）

URL: https://core-calmdust.github.io/aicoding/atlas/  ／ 詳細: repo の atlas/README.md

## 画面
- ホーム：白背景のタイトル（コンパス紋章＋周りに3Dのデフォルメ駒が浮かぶ）→ 最近のアップデート（横スクロールの大カード）→ ゲームのアイコン一覧（更新順、スマホは1列4個）→ プロフィール＋ログインボーナス
- アイコンをタップ → 3D盤がポップして表示（情報カードと重ならないよう盤の描画領域をカードの外に限定）→ スタートでカメラが寄って3D盤でそのまま対局
- **スマホの3Dビューの盤の大きさ（2026-11-09）**：画面幅700px未満では、盤の大きさに合わせてカメラを寄せる（table3d.js camPose の `pr`）。チェス盤で横幅の約6割。盤の大きさは盤だけで測る（駒台・碁笥・脇に置いた駒は除く：描画の足跡をグリッドに塗り、いちばん大きいつながった塊＝盤。table3d.js boardBox）。従来の固定枠（約11ユニット）より遠くはしない。長い盤（ウル）は長辺が画面端に付かないよう抑える。
- **3D盤のマウスホイール（2026-11-09）**：3Dビューでも3D卓での対局中でも、ホイールで盤に寄る／引く（対局中は 0.6〜1.5倍、table3d.js `pzoom`）。スマホは対局中もピンチで同じく寄る／引く（ピンチの指で駒は動かない）。PCではマウスの左右ドラッグで3Dビューのゲームは切り替わらない（盤が回るだけ。切り替えは矢印・キー）。スマホの指のフリックは従来どおり切り替わる。フル機能のゲーム画面の3D盤は2D盤の位置に合わせて描いているので対象外。
- **3D卓のパズル（2026-11-10）**：将棋（詰将棋）とチェス（詰めチェス・戦術）のパズルを、フル機能へ飛ばずにポータルの3D卓でそのまま解ける（`atlas/puzzles.js`）。あそぶシートの「パズル」から開始。ルール説明と同じガイドキャラ（ナイトン＝「ぼく」の元気な騎士、ショウギツネ＝「わたし」の明るいキツネで語尾にときどき「コン」）が出題・相手の受け・正解・連続正解・届かなかった時・ヒント・やり直しに、それぞれの口調の台詞で反応（`atlas/puzzle-lines.js`、場面ごとに複数パターンからランダム・同じ台詞は連続しない。日本語・英語は3〜5種、他言語は2〜3種）。途中の台詞は手の良し悪しに触れない。問題はフル版と同じデータ（`chess/puzzles.json`・`shogi/tsume.json`）、進み具合もフル版と同じ localStorage キーで共有（★3＝ヒントなし初回正解、★2＝ヒントか失敗あり）。出題は続きから（フル版の「続き」と同じ順・ステージ解放ルール）。判定：詰め問題（詰めチェス・詰将棋）は途中の手を一切ミス扱いにしない（絶対条件、2026-11-10）。どの手を指しても相手が受け（詰将棋は記録の手順かエンジンの tsumeDefend、チェスはエンジン最善手）、基準手数以内に詰めばクリア、使い切ったら「詰ませられなかった」で終了。キャラも「ミス」とは言わない（途中は「あと◯手」だけ）。戦術問題は記録の手順どおり（途中で詰めばクリア）。詰将棋のスマホでは、自分の持ち駒を画面上部にチップで表示（タップで打てる）。創作詰将棋は相手が残りの駒をすべて持つ約束なので相手の持ち駒は出さず、実戦の詰み（攻め方の玉が盤上にある問題）だけ相手の持ち駒も出す。盤の一部だけを使う詰将棋は、問題の駒と正解手順のマス（＋周り1マス、最低5×5）を拡大して映し、拡大は一瞬で切り替えず短時間（約0.4秒）でズームする。フル機能版の詰将棋（2D盤と3Dスキン、shogi/index.html の tzSync／atlas/skin/common.js が window.__boardZoom に追従）にも同じ拡大・切替ボタン・スライドを入れた（2026-11-10）。丸いアイコンボタン（文字なし、盤に重ねない：3D卓は「やめる」の左、フル版は詰将棋カードの「詰将棋をやめる」の左にカードのアイコンボタンとして）で全体／拡大を切り替え、拡大中は指（マウス）でスライドすると盤を動かせる。全888問は記録手順が正しく詰むことを確認済み（9手以内の683問はソルバーで「相手が残り全部の駒を自由に打てる」前提でも手数内に詰むことを確認、2026-11-10）。パズル中の駒の移動は対局より速い（約半分の時間）、3Dの持ち駒列は隠す。レッスンは今のところフル機能へ。
- **スマホの「あそぶ」シート（2026-11-09）**：パズル・レッスンのあるゲーム（まず将棋・チェス）は、スマホのカードを「あそぶ ▶」＋「2Dで遊ぶ」だけにして、対局の設定（モードタブ・AIの強さ・手番・持ち時間）とフル機能／ちゃぶ台ボタンは下から出るシートへ移す。シートは「対局／パズル／レッスン」の3段で、パズル・レッスンは進み具合のバー付き。パズル・レッスンはフル機能の3D盤（`?skin=atlas&mode=puzzle|lesson`）を開き、その一覧から始まる（将棋は詰将棋、チェスはパズル）。解析などマニアックな機能はフル機能だけ。ヒストリアと戦績は左上のまま（カード内に置く案は試したが一旦見送り、2026-11-10）。PCのカードは保留中のため従来どおり。
- **やめるボタンの高さ（2026-11-09）**：スマホの3D卓では、ルール説明中のやめるもゲーム中と同じ高さ（HUDの高さ、HUDがない時は45px）。
- **3D卓→やめる→3Dビューの戻り（2026-11-09）**：バウンドさせずに滑らかに。盤は落下＆弾みではなく少し上から静かに着地（show opts.soft、0.34秒）。カメラの戻りは0.4秒。カメラの戻り（glide）の間は対局の画角（fit）と上帯（insetT）・レンズシフト（vsh）も同じカーブで戻す（以前は上帯が先に消えて盤が跳ねて見えた）。
- **3D駒のポリゴン（2026-11-09・チェス）**：ろくろ駒は輪郭点を Douglas–Peucker で間引く（直線上の点を落とす：フル機能 0.0022・大百科 0.0035・映り込み 0.008）、フル機能の周方向は36→24分割、輪郭の許容 0.003。チェス駒32個でフル機能 約22万→約9万、大百科の3Dビュー 約10.7万→約6万三角形（周方向 フル24・大百科12、ナイトの頭は輪郭・面取りを粗く）。見た目は並べて比較してほぼ同じ。新しい3D駒もこの方式で作る（atlas/models/chess.js simplify、他のモデルは Table3D.lp）。2026-11-09 フル機能の3D盤も同様に削減：コナネ7.1万→3.6万、チェッカー6.6万→4.7万、アルケルケ6.4万→3.8万、モリス6.0万→3.8万、ファノロナ5.9万→3.7万、アゴン5.2万→2.6万、ウゴルキ4.4万→1.9万、セネト2.3万→1.5万、マンカラ2.6万→2.3万。
- **戦績ページ（2026-11-09）**：全ゲームのカードに「🏆 戦績」ボタン（ルールの隣）。開くと大百科スタイルのシートで：勝・負・分と勝率リング、連勝中／最多連勝、最近15局の○×、相手別（AIレベル順→レート→オンライン）の勝敗バー、最近20局、あそびの記録（パズル・レッスン・レート・今日の一問・3D卓など）、このゲームの実績。データは各ゲームの GameRecord（localStorage `atlas-rec-<id>`、shared/record.js）を共用し、大百科の3D卓の対局も同じリストに `via:'3d'` で追加する（二人対戦は記録しない）。`atlas-rec-` はアカウント同期の対象。モードの絞り込みはプルダウン（すべて／AI戦／レート戦／オンライン／3D卓、記録のあるものだけ）。シート下部のタブで「戦績／あそびの記録／実績」を切り替える（中身のあるタブだけ）。戦績ボタンはカップのアイコンだけで、スマホは3Dビュー左上のヒストリアの下（左寄せ）に置く（PCは右上の背景選択の右＝閉じるの左。PCレイアウトは保留中）。ヒストリアと同じ作りで、金色の丸に白い線画のカップ（カードには置かない：タイトルが詰まる）。スマホのカードの進捗リングは、進捗バーのないゲーム（ウル等）も含めて、カードを広げた時だけ出す。スマホのカードではAIの強さは「Lv.N＋キャラ」だけを表示（PCは保留）。パズルなど対戦のないゲームは「対局の記録なし」の箱を出さない。
- **カードの「AIの強さ」と「手番」は1行（2026-11-09）**：レベル名やキャラの長さに関係なく、手番が2択のゲームは同じ行に並べる（index.html `#bvOpts` の nowrap）。バックギャモンも手番を選べる：先手＝自分が最初のサイコロで勝つ（3D卓は振り出しの目を入れ替え、フル機能は振り出しがそうなるシードを選ぶ。色は変えない）。
- **ゲーム画面の上部バーのコインは常にポータルと同じ数字**：実績の計算に使うポータル専用の数（3D卓の各ゲームのレベル数・ガチャの景品数）は localStorage `atlas-ach-meta` に覚えて同期し、ゲームページも同じ実績＝同じコインを出す（shared/atlas.js achMeta）。共有アカウントの同期が終わった時・他タブで変わった時・画面に戻った時に読み直す（skin/common.js）。ゲームページは必ず shared/atlas-account.js を読み込む（ルドーに不足していた）。
- 3D専用のタイトル（`only3d`、例：キャロム・クロキノール・テーブルホッケー）はボードカードに「2Dで遊ぶ」を出さない。トップページからは `atlas/#games/<id>` で3Dビューを直接開く
- **きせかえ（2026-11-09）**：レアリティの絞り込みは自前のポップアップ（`#drar` ボタン＋`#drarPop`、レアリティ色のバッジ）。SSR・URのセルの演出は軽量化：枠を回る光は輪にマスクした子要素（`.rfx`）の transform 回転、光彩は静止、画面外のセルは一時停止（IntersectionObserver で `.vis`）、未所持は演出なし。SSR・URを身につけている（アイコン・背景・フレームの最高レア）ときはネームカードにも同じ光（`.dprev.nr3/.nr4`）。
- **3Dビューと対局中の表示は文字選択なし（2026-11-09）**：`#bv` の中と、body に出すトースト・やることの帯・力の表示・操作カード・反転ボタン・キャラ会話（`.cr*`／`.ck*`／`npc-*`）は user-select:none と長押しメニューなし（入力欄は除く）。スマホで狙っている長押しでHUDの文字が選択されないように。
- 3D対局はリバーシのみ実装（../reversi/engine.js のAIをそのまま使用）。未対応のゲームは「いつもの画面で遊ぶ」
- タブ：ホーム／ゲーム／地図／実績／ガチャ／きせかえ（スマホは下部タブバー）。**ショップはガチャのページの下段**（2026-11-06、上＝ガチャ・下＝ショップ、タブ名は「ガチャ」。`#shop` はガチャのページのショップ位置へ）。**スマホは画面下（下部タブバーのすぐ上）の「ガチャ｜ショップ」タブで切り替え**（きせかえと同じ。NEWSバーはガチャ・ショップとも出さない）、ショップ表示中は下のNEWSバーを出さない
- **3Dのゲーム画面（ポータル版 `?skin=atlas`）の上部バー（PC）**：世界のボドゲ大全のロゴ（サブタイトル込み・ロゴ側の表示は変えない）の右に、区切り線のあと、ロゴの文字と同じくらいの大きさでゲーム名だけを出す。手番・石数・形勢などのゲーム情報はここには出さない。その右にメニュー（対局＞待った＞ヒント＞ルール＞レッスン＞パズル）・コイン・アイコン。実装は `shared/headerbar.js` のポータルモード。スマホはスペースがないのでゲーム名は出さない。

## デザイン方針（確定）
- **ゲームアイコン（今後もこの路線で統一）**：そのゲームを象徴するコマを大きくデフォルメし、盤は2〜4路の切れ端だけ。厚みのある正方形の土台を45°の角から等角（アイソメトリック）で見せ、ダイヤ形に見える。おもちゃのような丸みのある質感。atlas/icons3d.js の ICONS に1シーン追加 → atlas/tools/icons.html で images/atlas/<id>.webp に書き出す
  - **アイコンの位置（2026-11-07 決定・全アイコン共通で守る）**：土台は正確な正方形（`rbox(…, true)`）で、盤面は土台のちょうど中央。土台の左右の角は同じ高さ（左下・右下の外周の厚みが同じ）。画像は 320×320 で、土台の左右の角の行を y=204、土台（床の影を除く）を左右中央に置く。床の影が右端からはみ出す分は最後の14pxで薄く消す。後処理は `atlas/tools/icon-post.py`。ファノロナ（3Dシーンなしの画像）とランダム（icons3d.js の ICONS.random を `?part=base` と `?part=top` の2枚に書き出し、土台＋影の上でサイコロだけが跳ねる。images/atlas/random-base.webp・random-die.webp）も同じ基準（土台の幅・左右の角の高さ・左右中央）にそろえてある。新しいアイコンも既存のアイコンを描き直すときも同じ手順で書き出し、ポータルのアイコン一覧で枠の中心に十字を重ねて左右のずれがないか確かめる
- **キャラクター（確定）**：マットでぷにっとしたぬいぐるみ／マシュマロ質感（ツルツル・モフモフ・フィギュア調は不可）。黒ビーズ目＋光点1つ（または閉じ目）、線の口、丸いほっぺ。目のパーツは顔の表面にぴったり付ける（浮かせない）。ころんとした体＋ボードゲーム／おもちゃのモチーフ。既存キャラに似せない
- タイトル：白黒。コンパス（方位磁針）の紋章、外周に回る英字、燕尾リボンに「ボドゲ大全」（Mochiy Pop One）、黒タグ「世界の」、「N GAMES」。アソビ大全の箱型タイトルとは別物にする
- ロゴ：黒丸の中の方位磁針、4つの先端がポーン・サイコロ・石・将棋の駒
- UI：クリーム地、押せるボタン（下影）、丸ゴシック

## アバター・背景・フレーム・ガチャ（すべて3D）
- アバター：50種族×4段階＝200体。N＝基本色／R＝別色＋小物／SR＝別色＋帽子・マフラー／SSR＝特別仕上げ＋王冠など。UR種族（10種）は4段階目が金色＋王冠＋星のオーラ
- 種族：ゲームの案内役11種（icons3d.js の MONS）＋39種（atlas/avatars/sp-*.js）。仕組みは atlas/avatars3d.js（define・段階・小物・色替え）
- アバター画像は images/atlas/av/<種族>-<段階>.webp（256px）を atlas/tools/icons.html?kind=av&id=<種族>-<段階> で書き出し。ポータルは画像だけ使う（three.js不要）
- 種族の追加：sp-*.js に define → art.js の AV 表に名前（10言語）を1行 → 書き出し
- 背景100種も3D調の画像（atlas/bg3d.js＝タイル、atlas/bg3d-covers.js＝1枚絵の空・草原・海・雪・おもちゃの町・宇宙 → tools/bgs.html → images/atlas/bg/<id>.webp）。IDは追加順（新しいものは末尾に追加し、既存IDは動かさない）。名前は模様×色の組み合わせ（art.js の BG_NAME・BGCOL・NAMES、10言語）
- フレーム50種も3Dのリング画像（atlas/frame3d.js → tools/frames.html → images/atlas/frame/<key>.webp、透過256px、アバター全体に重ねる）
- ガチャは3Dのカプセル機（atlas/gacha3d.js）：コイン投入→ツマミ→滑り台→受け皿→揺れ（カプセルの色でレア度）→開封。10連は10個並べて順に開封。タップでスキップ。描画は必要なときだけ
- きせかえ画面：キャラをタップするとランダムなアニメーション（ジャンプ・回転・ゆらゆら・むぎゅっ・ダンス・宙返り）＋ハート等が飛ぶ。着替え直後もジャンプ。暗い背景では名前を白文字に
- きせかえの並び替え（持ってる順／レア度 高い順／低い順）の**左・同じ列にレア度のプルダウン**（すべて・N・R・SR・SSR・UR）。タグ形式は使わない（場所を取るため）。並び替えと組み合わせて使え、選択は端末に保存（`atlas-drar`）。スマホでも1列に収める。2026-11-09
- 旧2Dアイコン（i001…）は廃止。保存データからは消し、初期キャラ（ダイスン・ポトンウサ・ゴイシペン）を配り直す

## 共通ルール
- 更新情報の並び（2026-11-08）：先頭は公開14日以内のいちばん新しい新作（`news()`）、残りは新しい順。
- バッジ（2026-11-08、最大2・優先順）：**BETA**（`beta: true`、これだけ）→ **NEW**（公開 `released` から14日以内、これだけ）→ **ORIGINAL**（`original: true`、NEWの後）→ **UPDATE**（そのゲームの最新の `UPDATES` の行が公開日より後の日付＝更新で、14日以内）。公開日以前の行は「公開の行」とみなすので、行にラベルは要らない。判定は `shared/atlas.js` の `badges()`（`NEW_DAYS`・`UPDATE_DAYS`）、文字は `badgeText()`（どのバッジも全言語で英語表記）。出る場所：更新情報の列・ゲームのアイコン一覧・ゲーム一覧・ゲームカード、トップページ `index.html` の詳細パネル（同じ `badges()` を読む）。色：NEW＝コーラル、UPDATE＝スカイ、BETA＝グレープ（PREMIUM は廃止）
- タグ：ai / online / rated / netrank / daily / lessons / puzzles / openings / variants / mobile
- 実績はゲームごとの記録（localStorage）から自動計算。銅50・銀120・金300・プラチナ800コイン
- コイン＝実績＋ログインボーナス（毎日30・7日ごと+150）＋ガチャかぶり返金−使用分
- ガチャ 1回100／10回900（10回目SR以上）、N58/R28/SR10/SSR3.5/UR0.5%。アイテム350種（アバター200・背景100・フレーム50）
- **AIのボス**（2026-11-09、`atlas/npc/`）：各ゲームのボスのSSR（最上位はUR）がガチャに入る。ボスのSRはそのボスに勝ったときだけもらえる（ガチャ・ショップには出ない）。詳細は addendum「AI戦のボスと観戦キャラ」
- 「今日のゲーム」カードの本文は `hist.<id>`（i18n.js、14言語）＝そのゲームの歴史・雑学。ルール説明（`about.<id>`）は載せない。ゲーム追加時は `hist.<id>` を必ず書く（無い言語は英語、英語も無ければ空）。
- ショップ：毎日6品（アイコン3・背景2・フレーム1。PCは横1列で幅いっぱい、スマホは3×2。ガチャのページの下段）

## 共通アカウント
- Firebaseプロジェクト1つ（例: board-game-atlas、Google認証＋Realtime Database）。設定は shared/atlas-firebase-config.js（未設定の間は「準備中」）
- 全ゲームページに shared/atlas.js・atlas-firebase-config.js・atlas-account.js を読み込み済み
- 同期対象は GAMES[].store の接頭辞で決まる → ゲーム追加時は台帳に1行
- 進捗系のキーは合算マージ、対局中データや設定は新しい方を採用

## ゲーム追加の手順
GAMES に追加（store 含む）→ i18n.js に hist.<id>（歴史・雑学、14言語）→ READ に進捗読み取り → UPDATES に1行 → icons3d.js にアイコンシーン＋書き出し（書き出したら `atlas/app.js` の `R3` に id を足す。足さないとポータルに3Dアイコンが出ない）→ table3d.js に盤モデル → 3D対局は games/<id>.js → ゲームページに `HeaderBar.init` を入れておけば、ポータル版でもロゴ横のゲーム名・メニューが自動で出る
