# 世界のボドゲ大全 ポータル仕様（atlas/）

URL: https://core-calmdust.github.io/aicoding/atlas/  ／ 詳細: repo の atlas/README.md

## 画面
- ホーム：白背景のタイトル（コンパス紋章＋周りに3Dのデフォルメ駒が浮かぶ）→ 最近のアップデート（横スクロールの大カード）→ ゲームのアイコン一覧（更新順、スマホは1列4個）→ プロフィール＋ログインボーナス
- アイコンをタップ → 3D盤がポップして表示（情報カードと重ならないよう盤の描画領域をカードの外に限定）→ スタートでカメラが寄って3D盤でそのまま対局
- 3D対局はリバーシのみ実装（../reversi/engine.js のAIをそのまま使用）。未対応のゲームは「いつもの画面で遊ぶ」
- タブ：ホーム／ゲーム／地図／実績／ガチャ／きせかえ（スマホは下部タブバー）。**ショップはガチャのページの下段**（2026-11-06、上＝ガチャ・下＝ショップ、タブ名は「ガチャ」。`#shop` はガチャのページのショップ位置へ）。**スマホは画面下（下部タブバーのすぐ上）の「ガチャ｜ショップ」タブで切り替え**（きせかえと同じ。NEWSバーはガチャ・ショップとも出さない）、ショップ表示中は下のNEWSバーを出さない
- **3Dのゲーム画面（ポータル版 `?skin=atlas`）の上部バー（PC）**：世界のボドゲ大全のロゴ（サブタイトル込み・ロゴ側の表示は変えない）の右に、区切り線のあと、ロゴの文字と同じくらいの大きさでゲーム名だけを出す。手番・石数・形勢などのゲーム情報はここには出さない。その右にメニュー（対局＞待った＞ヒント＞ルール＞レッスン＞パズル）・コイン・アイコン。実装は `shared/headerbar.js` のポータルモード。スマホはスペースがないのでゲーム名は出さない。

## デザイン方針（確定）
- **ゲームアイコン（今後もこの路線で統一）**：そのゲームを象徴するコマを大きくデフォルメし、盤は2〜4路の切れ端だけ。厚みのある正方形の土台を45°の角から等角（アイソメトリック）で見せ、ダイヤ形に見える。おもちゃのような丸みのある質感。atlas/icons3d.js の ICONS に1シーン追加 → atlas/tools/icons.html で images/atlas/<id>.webp に書き出す
  - **アイコンの位置（2026-11-07 決定・全アイコン共通で守る）**：土台は正確な正方形（`rbox(…, true)`）で、盤面は土台のちょうど中央。土台の左右の角は同じ高さ（左下・右下の外周の厚みが同じ）。画像は 320×320 で、土台の左右の角の行を y=204、土台（床の影を除く）を左右中央に置く。床の影が右端からはみ出す分は最後の14pxで薄く消す。後処理は `atlas/tools/icon-post.py`。ファノロナ（3Dシーンなしの画像）とランダム（icons3d.js の ICONS.random を `?part=base` と `?part=top` の2枚に書き出し、土台＋影の上でサイコロだけが跳ねる。images/atlas/random-base.webp・random-die.webp）も同じ基準（土台の幅・左右の角の高さ・左右中央）にそろえてある。新しいアイコンも既存のアイコンを描き直すときも同じ手順で書き出し、ポータルのアイコン一覧で枠の中心に十字を重ねて左右のずれがないか確かめる
- **キャラクター（確定）**：マットでぷにっとしたぬいぐるみ／マシュマロ質感（ツルツル・モフモフ・フィギュア調は不可）。黒ビーズ目＋光点1つ（または閉じ目）、線の口、丸いほっぺ。目のパーツは顔の表面にぴったり付ける（浮かせない）。ころんとした体＋ボードゲーム／おもちゃのモチーフ。既存キャラに似せない
- タイトル：白黒。コンパス（方位磁針）の紋章、外周に回る英字、燕尾リボンに「ボドゲ大全」（Mochiy Pop One）、黒タグ「世界の」、「N GAMES」。アソビ大全の箱型タイトルとは別物にする
- ロゴ：黒丸の中の方位磁針、4つの先端がポーン・サイコロ・石・将棋の駒
- UI：クリーム地、押せるボタン（下影）、丸ゴシック

## アバター・背景・フレーム・ガチャ（すべて3D）
- アバター：50種族×4段階＝200体。N＝基本色／R＝別色＋小物／SR＝別色＋帽子・マフラー／SSR＝特別仕上げ＋王冠など。UR種族（10種）は4段階目が金色＋王冠＋星のオーラ
- 種族：ゲームの案内役11種（icons3d.js の MONS）＋39種（atlas/avatars/sp-*.js）。仕組みは atlas/avatars3d.js（define・段階・小物・色替え）
- アバター画像は images/atlas/av/<種族>-<段階>.webp（256px）を atlas/tools/icons.html?kind=av&id=<種族>-<段階> で書き出し。ポータルは画像だけ使う（three.js不要）
- 種族の追加：sp-*.js に define → art.js の AV 表に名前（10言語）を1行 → 書き出し
- 背景100種も3D調の画像（atlas/bg3d.js＝タイル、atlas/bg3d-covers.js＝1枚絵の空・草原・海・雪・おもちゃの町・宇宙 → tools/bgs.html → images/atlas/bg/<id>.webp）。IDは追加順（新しいものは末尾に追加し、既存IDは動かさない）。名前は模様×色の組み合わせ（art.js の BG_NAME・BGCOL・NAMES、10言語）
- フレーム50種も3Dのリング画像（atlas/frame3d.js → tools/frames.html → images/atlas/frame/<key>.webp、透過256px、アバター全体に重ねる）
- ガチャは3Dのカプセル機（atlas/gacha3d.js）：コイン投入→ツマミ→滑り台→受け皿→揺れ（カプセルの色でレア度）→開封。10連は10個並べて順に開封。タップでスキップ。描画は必要なときだけ
- きせかえ画面：キャラをタップするとランダムなアニメーション（ジャンプ・回転・ゆらゆら・むぎゅっ・ダンス・宙返り）＋ハート等が飛ぶ。着替え直後もジャンプ。暗い背景では名前を白文字に
- 旧2Dアイコン（i001…）は廃止。保存データからは消し、初期キャラ（ダイスン・ポトンウサ・ゴイシペン）を配り直す

## 共通ルール
- バッジ（2026-11-08、1つだけ・優先順）：**BETA**（`beta: true`）→ **NEW**（公開 `released` から14日以内）→ **UPDATE**（そのゲームの最新の `UPDATES` の行が公開日より後の日付＝更新で、14日以内）。公開日以前の行は「公開の行」とみなすので、行にラベルは要らない。判定は `shared/atlas.js` の `badges()`（`NEW_DAYS`・`UPDATE_DAYS`）、文字は `badgeText()`（NEW・BETA は全言語そのまま、UPDATE は14言語）。出る場所：更新情報の列・ゲームのアイコン一覧・ゲーム一覧・ゲームカード、トップページ `index.html` の詳細パネル（同じ `badges()` を読む）。色：NEW＝コーラル、UPDATE＝スカイ、BETA＝グレープ（PREMIUM は廃止）
- タグ：ai / online / rated / netrank / daily / lessons / puzzles / openings / variants / mobile
- 実績はゲームごとの記録（localStorage）から自動計算。銅50・銀120・金300・プラチナ800コイン
- コイン＝実績＋ログインボーナス（毎日30・7日ごと+150）＋ガチャかぶり返金−使用分
- ガチャ 1回100／10回900（10回目SR以上）、N58/R28/SR10/SSR3.5/UR0.5%。アイテム350種（アバター200・背景100・フレーム50）
- 「今日のゲーム」カードの本文は `hist.<id>`（i18n.js、14言語）＝そのゲームの歴史・雑学。ルール説明（`about.<id>`）は載せない。ゲーム追加時は `hist.<id>` を必ず書く（無い言語は英語、英語も無ければ空）。
- ショップ：毎日6品（アイコン3・背景2・フレーム1。PCは横1列で幅いっぱい、スマホは3×2。ガチャのページの下段）

## 共通アカウント
- Firebaseプロジェクト1つ（例: board-game-atlas、Google認証＋Realtime Database）。設定は shared/atlas-firebase-config.js（未設定の間は「準備中」）
- 全ゲームページに shared/atlas.js・atlas-firebase-config.js・atlas-account.js を読み込み済み
- 同期対象は GAMES[].store の接頭辞で決まる → ゲーム追加時は台帳に1行
- 進捗系のキーは合算マージ、対局中データや設定は新しい方を採用

## ゲーム追加の手順
GAMES に追加（store 含む）→ i18n.js に hist.<id>（歴史・雑学、14言語）→ READ に進捗読み取り → UPDATES に1行 → icons3d.js にアイコンシーン＋書き出し → table3d.js に盤モデル → 3D対局は games/<id>.js → ゲームページに `HeaderBar.init` を入れておけば、ポータル版でもロゴ横のゲーム名・メニューが自動で出る
