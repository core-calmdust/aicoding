# ライアーダイス（liarsdice/）仕様

- 公開：2026-11-28（ALPHA）。2D専用のダイスゲーム（大百科の3D卓は今回は作らない）。トップページ `index.html` の GAMES に `alpha:true`（cat `card`、kind `DICE GAME`、key `lr`）。
- 画面の土台はポーカー／掼蛋と同じ（`app.css` の前半はその共通部分。後半の `ld-*` がこのゲームの卓）。

## ルール（実装：`engine.js`、テスト：`tools/test.js`）
出典：Wikipedia「Dudo」「Liar's dice」、gamerules.com の Perudo、rulespal.com の Perudo ルールブック（1jour-1jeu 版）、Opinionated Gamers「SdJ Re-Reviews #15: Bluff」（2026-11-28 参照）。
- 2〜6人、各5個のダイスとカップ。全員が振って自分のダイスだけを見る。手番は時計回り（画面では あなた → 左 → 上 → 右）。
- 宣言＝「全員のダイスの中に、この目が少なくとも q 個ある」。次の人は上げるか、ダウト（Dudo）。
- ダウト：全員が開けて数える。宣言どおり（以上）なら疑った人、足りなければ宣言した人がダイスを1個失う。失った人が次のラウンドの最初に宣言（脱落したらその左隣）。
- 0個で脱落、最後に残った1人が勝ち。
- **変種（ルールタブ・ゲームタブ）**
  - **1はワイルド**（既定オン）：1はどの目としても数える。1へ切り替えるときは個数を半分（切り上げ）、1から戻すときは2倍＋1（rulespal / gamerules）。ワイルドの間は最初の宣言で1を言えない。オフなら1は普通の目（いちばん小さい目）。
  - **パラフィコ**（既定オン）：ダイスが1個になった人の次のラウンド（1人1回）。その人から始め、1はワイルドでなく、最初の目から変えられない（ダイス1個の人だけは目を変えてよい）。カルサもなし。最初の宣言で1を言ってよい。
  - **カルサ**（既定オン）：自分の番に「ぴったり」と言える。ぴったりなら1個戻る（5個まで、5個なら増えない）、外れたら1個失う。宣言した人は失わない。次のラウンドはカルサした人から。パラフィコ中・残り2人のときは不可（gamerules / rulespal）。※rulespal は「次の手番の人以外いつでも」だが、ここでは自分の番に行う。Wikipedia の「元のダイスの半分以上が残っている間だけ」は採らない。
  - **せり上げ方**：個数か目（Perudo：個数を増やす、または同じ個数で大きい目）／同じ目か同じ個数（Wikipedia の3つ目の型：同じ目で個数を増やす、または同じ個数で大きい目）。1への切り替え・戻しは両方で同じ。
- ゲームタブの3種：ペルード（全部オン）／ドゥド（ワイルドのみ）／クラシック（ワイルドなし）。ルールタブで個別に変えるとカスタム。
- 歴史（ルール説明の1ページ目）：南米で「ドゥド（スペイン語で『疑う』）」「ペルード」などの名で遊ばれ、インカの遊びという言い伝えがある（Wikipedia／Opinionated Gamers は伝説として紹介）。1993年にリチャード・ボーグの『Bluff』（F.X. Schmid）がドイツ年間ゲーム大賞。

## AI（`ai.js`、自作）
- **ベイズ推定**：各相手の手を5個のダイスの多重集合（252通り）で持ち、事前確率は目の確率。相手が宣言するたびに、その手から「その目を言う確率」P(f|手) = exp(γ·s_f) / Σ exp(γ·s_g) を掛ける（s_f＝その手で f に数えるダイス）。γ＝宣言をどれだけ信じるか。
- 宣言が成立する確率＝自分の手の数＋相手の事後分布の畳み込み。
- 選択肢の価値（ダイス単位）：ダウト＝−T＋(1−T)·w（T＝前の宣言が本当の確率、w＝1/(人数−1)＝他人が失う価値）。宣言＝次の人がダウトする確率 d と成立確率から −d(1−T)＋d·T·w。d は「卓から見た成立確率」（自分の手を自分の宣言から読んだ分布＋他人の事後分布）から。（次の人の手ごとに「疑うか」を計算する nextModel も作ったが、計測で伸びなかったので使っていない。）カルサはぴったりの確率で。
- **ブラフ**：Lv.9 以上、一定の割合で「卓からは本当らしく見える（Tt>0.6）が自分は1個以下」の宣言を混ぜる。
- **ロールアウト**（Lv.17〜20）：相手の手を事後分布から引き、上位6つの宣言についてラウンドの残りを速い方策（Lv.6〜9 相当）で 30〜160 回打ち切って、誰がダイスを失うかを数える。
- レベル：Lv.1〜3 は自分のダイスを見落とす・最小の上げ方が多い、Lv.4 まで宣言を読まない、Lv.5〜 読む（γ 0.2→0.85）、Lv.6〜 卓から見た確率、Lv.10〜 次の人のモデル、Lv.9〜 ブラフ、Lv.17〜 ロールアウト。選択のぶれ（softmax の温度）は Lv.1＝1.0 → Lv.20＝0.004。
- **段差の計測**（`tools/arena.js`：4人卓、隣接±3レベルの混合卓で対局し、順位から2人ずつの勝敗を作って Bradley–Terry で Elo を推定）。結果と目盛りは下の表。運の要素が大きいゲームなので、天上なし・幅 400→1900（バックギャモン・ヒット＆ブローと同じ扱い）。計測の形を保って両端を合わせ、逆転は隣と平均して単調にした値を `rated.js` の RT_LV に入れる。
- 天上（ベンチ用）は作らない（Lv.20 でも1手 平均 0.03 秒・最大 0.2 秒程度。コーチの計算は1回 0.07 秒程度）。

## 画面
- ヘッダー：新規＞投了＞ヒント＞ルール＞レッスン＞確率＞統計（＋戦績・オプションは headerbar.js が自動）。
- 卓：ウォールナットの縁＋ラシャ／革の天板。席は楕円上（あなたが下、時計回り）。各席に革のカップ・名札（ダイスの残りの粒）・吹き出し（そのラウンドの最後の宣言／ダウト／カルサ）。中央の札に今の宣言・ラウンド・ワイルド／パラフィコ・宣言の履歴。
- 演出：ラウンドの初めに全員のカップが揺れて（ガラガラ音）伏せ、自分のカップが横に持ち上がってダイスが落ちる。ダウト／カルサで全員のカップが持ち上がり、該当するダイスが1個ずつ光って数が数え上がり、判定の文と、失ったダイスが飛んで消える。
- 操作バー：個数（−／＋）×目（ダイス6つ。押せない目は暗く、最小の個数を下に）、ダウト・カルサ・宣言。キー：1〜6 で目、↑↓ で個数、←→ で目、Space 宣言、D ダウト、C カルサ、H ヒント。PCでは成立確率のチップ（設定でオフ可）。
- 右欄（スマホは下タブ コーチ｜確率｜ログ｜戦績｜レート）：卓（順番・残り）、コーチ、目ごとの見込み（自分の手＋見えないダイス×1/6 or 1/3）、ログ、レート戦。
- コーチ：要約チップ、今の宣言が成立する確率（ベイズとただの確率の両方）、おすすめと理由、選択肢（成立・失う見込み・期待値、押すとその手を選ぶ）、宣言からの読み、考え方のヒント、あなたの前の判断（◎○△✕）。レート戦・終局後はお休み。
- 確率計算機（`tools.js`）：計算タブ（見えない個数・自分の該当数・個数・目・ワイルド → 以上の確率・ぴったりの確率・見込み・分布）、いまの局面タブ（目の確率だけ／宣言の読みを入れた確率、全選択肢の期待値の表）。
- 振り返り：対局後、ラウンドごとに全員のダイス・宣言・あなたの判断の評価（コーチとの期待値の差：<0.03 最善、<0.1 良い、<0.22 疑問、それ以上 悪い）。分かれ目のラウンドへ飛べる。←→ でラウンド送り。直近20局を保存。
- 統計：対局数・優勝率・平均順位・好判断の割合・ダウト／カルサの成功率・見破られた率・ブラフの割合・ダイスを失った理由・AIの強さ別。
- 戦績（shared/record.js）：1局ごと（1位＝勝ち、それ以外＝負け、key は人数）。途中で新規・投了は最下位。
- レート戦（`rated.js`）：4人卓、相手3人は同じレベル（レートに合わせて選ぶ）。点は順位（1位1、2位2/3、3位1/3、4位0）、Elo、K は10局まで48。最初の3局は予備選（shared/placement.js）。
- オンラインは「準備中」（対局設定の対戦形式にタブだけ）。
- 保存：`aicoding-liarsdice`（設定・統計・続き・振り返り用の履歴）、`aicoding-liarsdice-lessons`、`liarsdice-rated-v1`。ページを開くと続きから（公開中のラウンドはその結果から）。

## 学習
- ルール（`rules.js`、RuleTour 11ページ）：紹介＋カップを開ける／宣言する（個数×目を選ぶ）／正しいせり上げを選ぶ／ダウトの判定（4を数えて負けた人）／1のワイルドを数える／1への切り替え（半分切り上げ）／1から戻す（2倍＋1）／脱落と勝ち／パラフィコ／カルサ。答えは engine.js で判定。
- レッスン（`lessons.js`、4本「確率で考える」）：見えないダイスの見込み／自分の手を足す／ダウトか、せり上げか／1への切り替えとカルサ。各レッスン＝準備（考え方3ページ、図つき）→例題（採点なし）→問題5問（毎回生成、4問正解で合格）。問題の答えは engine.js の二項分布で計算し、`tools/check_lessons.js` が各生成器を3000回ずつ回して「正解が1つ・選択肢の重複なし・独立に計算し直した値と一致・確率の問題は最も近い選択肢が16ポイント以上離れて唯一」を確かめる。
- パズル：作らない（ユーザー了承済み）。
- 実戦チュートリアル（`tutorial.js`、2026-11-28）：掼蛋・ポーカー・ブラックジャックのチュートリアルと同じ方式（暗幕に穴＋光の枠、吹き出しは枠を隠さない位置に自動で置く、戻る／たたむ／やめる、上部に章・手順番号と進み具合の線）。全21手順・3章。
  - 1章「どんなゲーム？」（読むだけ・卓の各部を光の枠で指す）：カップ／自分だけ見えるダイス／相手のダイスは見えない／宣言の意味／せり上げ／ダウトで誰が失うか／脱落と勝ち。
  - 2章：3人卓・ペルードの規則・固定の出目で1ラウンドを実際に進める。あなた 1 3 3 3 6、ルカ 2 4 4 5 6、ミナ 2 2 5 6 6。ルカ「3個の4」→ミナ「4個の4」→あなた（課題）→ルカ「6個の4」→ミナ「8個の4」→あなた（課題：ダウト）→4と1は3個でミナが1個失う。CPUの宣言ごとに止めて説明（1のワイルド・同じ目の上げ方・相手の宣言からの読み・個数の見積もり）。
  - 課題は2つ：①3の目で5個か6個を宣言（小さい目へ移るときは個数＋1）、②ダウト。どちらも吹き出しに目安メーター（①組み立て中の宣言が成立する見込み、②ダウトが当たる見込み、コーチと同じ読み込みの確率）。正解すると自動で次へ、違う操作は理由を出して吹き出しを揺らす。ヒントボタンは課題の答えを入れる。
  - 3章：はったりだったミナの手／パラフィコ／カルサ／ヒント・コーチ・確率・レッスン・ルールの案内。終わる（またはやめる）と元の対局に戻る（チュートリアル中は保存・戦績・統計に触れない）。新しい対局を始めるとチュートリアルは止まる。
  - 入口：初回から毎回、案内ボックス（「次から表示しない」をつけるか最後まで終えると出ない、`aicoding-liarsdice-tut-hide`／`-done`）、ルール画面の上部タブ、レッスン一覧の先頭。
  - `tools/test.js` が台本を検査（2つの正解どちらでも全宣言が合法・課題の宣言の成立見込み80%以上・ダウトが当たる見込み70%以上でコーチの第1候補・結果はミナが1個失う）。
  - 吹き出しが隠してはいけない物＝光の枠＋説明文が言及する物（手順ごとの `see`：相手の席と宣言、中央の現在の宣言、自分のダイスなど）。PCは枠の上下左右・四隅から重ならない位置を選ぶ。スマホは画面幅いっぱいで、上端・下端・物と物の間の空いた帯から選ぶ。入らなければ字を詰めた小さい吹き出しにし、それでも入らない背の低い画面（360×640 の手順15）では題・メーター・やることだけにたたむ（「開く」で本文。開いたらその手順の間は開いたまま）。説明文は です・ます の地の文で、キャラの台詞は使わない。
  - 違う操作をしたときの理由は、画面下のトースト（ボタンを覆う）ではなく吹き出しの中に赤い行で出す。
  - スマホの3人卓では、相手2人の宣言の吹き出しを名札の下に出す（横に出すと中央で2つがぶつかって隠れた）。
