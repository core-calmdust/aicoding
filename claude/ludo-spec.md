# ルード・パチーシ（ludo/）設計仕様

世界のボドゲ大百科のタイトル（制作中）。1つのゲームに2つのルール（ゲームタブで切り替え）：
- **ルード**：世界中で遊ばれる現代版（15×15の正方形盤・サイコロ1個）。
- **パチーシ**：インドの伝統版（十字の布の盤・タカラガイ6個・2人組のチーム戦）。
人数は2〜4人（パチーシは2人か4人）。AI対戦（Lv.1–20）、同じ端末でみんなで、AIどうし。

## 1. ルール（`ludo/engine.js` → `window.LudoEngine`、Node でも require 可）
共通：各色4つの駒。駒の進み p：−1＝未出発（陣地・チャルコーニ）、0..LAST−1＝道の上、LAST＝上がり。席 0 が下、以降は盤を回る順。

### ルード（Ludo King に近い既定）
- 共通の道52マス。席 s の出発マスは 13·s。p 0..50 が共通の道、51..55 が自分のホーム列、56 が上がり（LAST=56）。
- 6で駒を出す（出発マスへ）。6はもう一度振る。6が3回続くと手番終了（オプション、既定オン）。
- 相手の駒1つに止まると陣地へ戻し、もう一度振れる。駒を上がらせたときももう一度。
- 安全マス：4つの出発マスと4つの星（出発から8つ先）。そこでは取られない（共存）。
- 同じ色2つが並んだマスには止まれない（ペアは取られない）。オプション「ブロック」（既定オフ）：同じ色2つの駒は誰も通れない。
- 上がりはちょうどの目。動かせる手があれば必ず動かす。
- 人数：2人＝席0と2（向かい合う）、3人＝0,1,2、4人＝全部。最初に全部上がった人の勝ち。

### パチーシ（出典：Wikipedia「Pachisi」、Masters of Games のルール。決まった公式ルールはないので代表的なもの）
- 十字の盤：4本の腕 × 3列 × 8マス、中央がチャルコーニ。駒は自分の腕の中央列を下り、盤の外周を反時計回りに一周し、自分の中央列を上ってチャルコーニへ。84歩（p 0..82 が盤上、83 が上がり）。3つ目の腕の端の城は上がりのちょうど25手前。
- 城（×）12マス：各腕の中央列の端、両外側の列の端から4つ目。城では取られず、相手側の駒がいる城には止まれない。
- タカラガイ6個：口が上の数 0→25、1→10、2〜6→2〜6。25・10・6 は「恵み（grace）」：もう一度投げられ、駒をチャルコーニから出せる（各色の最初の1つはどの目でも出せる）。
- 恵みの目は、かわりに駒1つを1マスだけ進めることもできる（1の目がないので、上がりの1手前の駒のため。資料にある変種）。
- 相手の駒に止まると（城以外）その駒すべてをチャルコーニに戻し、もう一度投げる。味方（パートナー）の駒とは同じマスに並べる。
- 上がりはちょうどの目。動かすのは任意（パスできる）。
- チーム：黄＋黒（席0+2）対 赤＋緑（席1+3）。2人なら1人が2色を持つ。チームの8つの駒が全部上がったら勝ち。
- 投げる→動かすを1回ずつ（伝統の「全部投げてから振り分ける」は採らない）。

### AI
- 評価：進んだマス数 − 取られる危険（次の相手の1投で当たる確率 × 失う量）＋上がり・安全マスのボーナス。ルードは一番強い相手と平均の混ぜ、パチーシは相手チーム。
- レベル1〜20：ランダム手の割合（L1 約58% → L15以上 0%）と評価のノイズ。L9以上は「もう一度振れる手」の次の1投まで期待値で読む。
- 確認：`node ludo/tools/test_engine.js [局数]`（道の形・確率・自己対局。L20 は L1・L5 に大きく勝ち越す）。

## 2. 画面（`ludo/index.html`・`app.js`・`board2d.js`）
- テーマ：藍の夜（#130f22）にマリーゴールド（#f4b042）と朱。PCは盤左・情報右（360px）、HeaderBar。スマホはタイトル・メニュー → 盤 → 投げる → 対局者 → 記録。
- 盤：SVG（1マス＝1単位）。ルード 15×15（色：赤・緑・黄・青）、パチーシ 19×19 の十字（色：黄・赤・黒・緑、布は朱に金糸）。デザイン：クラシック／木目（対局設定のデザインタブ、押した瞬間に反映）。
- 駒は1マスずつ跳ねて進む。取られた駒は回りながら陣地へ。同じマスの駒は小さく並べる。
- 操作：「振る／投げる」（スペースキーでも）→ 光る駒をタップ。パチーシの恵みで2通りあるときは行き先の丸をタップ。パチーシはパスボタンあり。
- オプション：自動で振る、1手しかないときは自動で動かす、速さ（ゆっくり／ふつう／速い）。
- 待った（AI戦のみ）：自分の最後の選択の前に戻る（同じ目のまま）。ヒント：Lv.20 の手の駒を光らせる。投了：Resign.confirm。
- 14言語：`ludo/i18n.js` は `ludo/tools/build_i18n.py` で生成。
- localStorage：`aicoding-ludo`（settings と対局）。

## 3. 学ぶ（`ludo/tour.js`・`app-learn.js`・`learn.json`）
- ルール説明：盤上で動かすチュートリアル（RuleTour、ルード／パチーシ 各8ページ・14言語）。既読は `aicoding-ludo-rules-<rule>`。最初のページの絵は `images/atlas/ludo.webp`。
- レッスン：10ステップ（ルード5・パチーシ5：出す・取る・上がる・安全マス／城・逃げる）、各5問、20点×5、75点で合格。`aicoding-ludo-lessons`（id → 最高点）。
- 次の一手パズル：120問（各ルール60、★1〜3 は最善手と次善手の差）。`aicoding-ludo-puzzles`（`rule:番号` → 1）。
- 問題は `node ludo/tools/gen_learn.js [局数]` で AI 自己対局から作る（Lv.20 評価で最善手が次善手より 4 以上良く、教える種類に当てはまる局面。手番の色を席0へ回して、いつも赤／黄の番にする）。

## 4. 3D・ポータル
- 3D モデル：`atlas/models/ludo.js`（`Table3D.MODELS.ludo(live, rule)`／`MODELS.pachisi`）。ルードは2D盤の絵を貼った木枠の盤と挽き物の駒、パチーシは十字の布と蜂の巣形の駒。サイコロ、タカラガイ。
- ちゃぶ台で遊ぶ：`atlas/games/ludo.js`。カードの「ルールと人数」でルード 4/3/2人・パチーシ 4人（2対2）/2人（1人2色）。AI 戦（あなたは赤／黄、ほかは全部 AI。4人パチーシの味方の黒も AI）と二人以上で対戦（全色を順にタップ）。待った（自分の番の初めへ）・ヒント（Lv.20 の手）・投了。時計なし。テキストは `ludo/i18n.js` を読み込んで使う。
- ポータル登録：`shared/atlas.js`（GAMES・更新情報・進み具合）、`atlas/i18n.js`（about／hist）、3Dアイコン `atlas/icons3d.js` → `images/atlas/ludo.webp`、一覧の絵 `atlas/shots/ludo.webp`（`tools/shots.js`）、地図 `atlas/mapdata.js`、ヒストリア `atlas/historia/<言語>/ludo.json`・`s/ludo.json`（`python3 ludo/tools/gen_historia.py` で生成。盤の図は historia.js の `t:'ludo'`）。
- トップページ：`index.html` のカード（key `ld`）・JSON-LD、アイコン `images/icons/ludo.svg`、サムネイル `images/ludo.webp`。
