# ルドー・パチーシ（ludo/）設計仕様

- 日本語表記は「ルドー」で統一（日本での一般的な呼び名。「ルドー」は使わない）。

世界のボドゲ大百科のタイトル（制作中）。1つのゲームに2つのルール（ゲームタブで切り替え）：
- **ルドー**：世界中で遊ばれる現代版（15×15の正方形盤・サイコロ1個）。
- **パチーシ**：インドの伝統版（十字の布の盤・タカラガイ6個・2人組のチーム戦）。
人数は2〜4人（パチーシは2人か4人）。AI対戦（Lv.1–20）、同じ端末でみんなで、AIどうし。

## 1. ルール（`ludo/engine.js` → `window.LudoEngine`、Node でも require 可）
共通：各色4つの駒。駒の進み p：−1＝未出発（陣地・チャルコーニ）、0..LAST−1＝道の上、LAST＝上がり。席 0 が下、以降は盤を回る順。

### ルドー（Ludo King に近い既定）
- 共通の道52マス。席 s の出発マスは 13·s。p 0..50 が共通の道、51..55 が自分のホーム列、56 が上がり（LAST=56）。
- 6で駒を出す（出発マスへ）。6はもう一度振る。6が3回続くと手番終了（オプション、既定オン）。
- 相手の駒1つに止まると陣地へ戻し、もう一度振れる。駒を上がらせたときももう一度。
- 安全マス：4つの出発マスと4つの星（出発から8つ先）。そこでは取られない（共存）。
- 同じ色2つが並んだマスには止まれない（ペアは取られない）。ほかの遊び方は 4c のハウスルール。
- 上がりはちょうどの目。動かせる手があれば必ず動かす。
- 人数：2人＝席0と2（向かい合う）、3人＝0,1,2、4人＝全部。最初に全部上がった人の勝ち。

### パチーシ（出典：Wikipedia「Pachisi」、Masters of Games のルール。決まった公式ルールはないので代表的なもの）
- 十字の盤：4本の腕 × 3列 × 8マス、中央がチャルコーニ。駒は自分の腕の中央列を下り、盤の外周を反時計回りに一周し、自分の中央列を上ってチャルコーニへ。84歩（p 0..82 が盤上、83 が上がり）。3つ目の腕の端の城は上がりのちょうど25手前。
- 城（×）12マス：各腕の中央列の端、両外側の列の端から4つ目。城では取られず、相手側の駒がいる城には止まれない。
- タカラガイ6個：口が上の数 0→25、1→10、2〜6→2〜6。25・10・6 は「恵み（grace）」：もう一度投げられ、駒をチャルコーニから出せる（各色の最初の1つはどの目でも出せる）。
- 恵みの目は、かわりに駒1つを1マスだけ進めることもできる（1の目がないので、上がりの1手前の駒のため。資料にある変種）。
- 相手の駒に止まると（城以外）その駒すべてをチャルコーニに戻し、もう一度投げる。味方（パートナー）の駒とは同じマスに並べる。
- 上がりはちょうどの目。動かすのは任意（パスできる）。
- チーム：黄＋黒（席0+2）対 赤＋緑（席1+3）。2人なら1人が2色を持つ。チームの8つの駒が全部上がったら勝ち。
- 投げる→動かすを1回ずつ（伝統の「全部投げてから振り分ける」は採らない）。

### AI
- 評価：進んだマス数 − 取られる危険（次の相手の1投で当たる確率 × 失う量）＋上がり・安全マスのボーナス。ルドーは一番強い相手と平均の混ぜ、パチーシは相手チーム。
- レベル1〜20：ランダム手の割合（L1 約58% → L15以上 0%）と評価のノイズ。L9以上は「もう一度振れる手」の次の1投まで期待値で読む。
- マルチスレッド（2026-11-08、`shared/mtworkers.js`・`ludo/mt.js`・`ludo/worker.js`）：形勢カード（バーとグラフ）の勝率を、各局面から Lv.20 同士で最後まで 128 局打ったロールアウト（`E.playout`／`E.wpTask`、投げは局面ごとに同じシード＝隣の局面と同じ目なのでグラフが滑らか、1局面 約±4%）に順に置き換える（最新の局面から、一度に「スレッド数×2」局面ずつ）。スレッドがないときは今までどおり `winProb`（当てはめの式）。AI の手・ヒント・コーチは Lv.20 の1投先の読みのまま：1手に使える時間でのロールアウト（1手16局・60投で打ち切り）は Lv.20 に 25/100 しか勝てず（2人ルドー）、手の選択には使わない。最上位レベルも足さない。計測：`ludo/bench.html`。
  - ユーザーの Mac（M4 Pro 14コア＝高性能10＋高効率4、Chrome、2026-11-09）の実測（128局、4局ずつの仕事）：×1.90／×3.46／×5.91／×6.35（2・4・8・14スレッド）。1局のロールアウトの長さのばらつきが大きく（作業機で変動係数 約2.5）、1局面の 32 仕事ではいちばん長い仕事を待つ。さらに見落とし：対局中は新しい局面が1つずつ増えるので、1局面＝1仕事（128局）では**最新の局面（バーに出る値）が1スレッドで読まれていた**。
  - 2026-11-09：1局面をスレッド数×4 の仕事くらいに分け（`ludo/mt.js`、`worker.js` の `each: true` で1局ごとの値を返し、ページで順に足す＝1つの仕事と同じ和・同じ勝率）、Worker は PC の全論理コア（最大16）。ベンチの仕事の分け方も同じにした。見積もり（作業機で1局ごとの時間を測ったシミュレーション）：最新の1局面だけのとき 8スレッドで約4倍速く（1局の長さの上限があるので頭打ち。今までは1倍）。Mac で測り直すページ：`ludo/bench.html`。
- 確認：`node ludo/tools/test_engine.js [局数]`（道の形・確率・自己対局。L20 は L1・L5 に大きく勝ち越す）。

## 2. 画面（`ludo/index.html`・`app.js`・`board2d.js`）
- テーマ：藍の夜（#130f22）にマリーゴールド（#f4b042）と朱。PCは盤左・情報右（360px）、HeaderBar。スマホはタイトル・メニュー → 盤 → 投げる → 対局者 → 記録。
- 盤：SVG（1マス＝1単位）。ルドー 15×15（色：赤・緑・黄・青）、パチーシ 19×19 の十字（色：黄・赤・黒・緑、布は朱に金糸）。デザイン：クラシック／木目（対局設定のデザインタブ、押した瞬間に反映）。
- 駒は1マスずつ跳ねて進む。取られた駒は回りながら陣地へ。同じマスの駒は小さく並べる。
- 操作：「振る／投げる」（スペースキーでも）→ 光る駒をタップ。パチーシの恵みで2通りあるときは行き先の丸をタップ。パチーシはパスボタンあり。
- 手番フォーカス（スマホ、2026-11-08）：盤が小さいので、手番の色に寄せて表示する（桃鉄の手番のような感じ）。振る前はその色の陣地、振った後は動かせる駒と行き先、動いている間は出発点と行き先を枠に入れ、次の手番へは viewBox をなめらかにパン・ズームしてつなぐ（カットしない）。範囲は最小9.5マス、盤の外は見せない。盤の右上のボタンで「盤全体」と切り替え（`aicoding-ludo-zoom`）。レッスン・パズル・振り返り中は全体表示。
- オプション：自動で振る、1手しかないときは自動で動かす、速さ（ゆっくり／ふつう／速い）。
- 待った（AI戦のみ）：自分の最後の選択の前に戻る（同じ目のまま）。ヒント：Lv.20 の手の駒を光らせる。投了：Resign.confirm。
- 14言語：`ludo/i18n.js` は `ludo/tools/build_i18n.py` で生成。
- localStorage：`aicoding-ludo`（settings と対局）。

## 3. 学ぶ（`ludo/tour.js`・`app-learn.js`・`lessons.json`・`puzzles.json`）
- 共通ルール（`claude/puzzle-collection-spec.md`・`game-conventions*.md`）どおり：ルール／レッスン／パズルは1つのオーバーレイのタブ（`ls-tabs`）、一覧は `shared/pzbook.js`、カード操作は `shared/cardbar.js`。
- ルール説明：盤上で動かすチュートリアル（RuleTour、ルドー／パチーシ 各8ページ・14言語）。既読は `aicoding-ludo-rules-<rule>` と `aicoding-ludo-rules-seen`。最初のページの絵は `images/atlas/ludo.webp`。
- ルールとレッスンの上タブ：「ルール（ルドー）｜ルール（パチーシ）｜レッスン」（選んだタブはアクセント色）。対局設定のゲームカードの「ルール」ボタンからもそのルールの説明へ。
- レッスン：4カテゴリ（ルドーの基本・ルドーの作戦・パチーシの基本・パチーシの作戦）×計10ステップ（出す・取る・上がる・安全マス／城・逃げる）。2026-11-09〜：基本は「ルールの説明 → 1問」、作戦は「説明 → 例題 → 3問」（lessons.json の5問から読み込み時に絞る）。点数は問題数によらず100点満点（1問20点の割合）、75点で合格。`aicoding-ludo-lessons`（id → {best, pass}）、カテゴリの記憶 `aicoding-ludo-ls-cat`。
- パズル（次の一手500問・デイリー）は 2026-11-09 に廃止（つまらないため）。
- レッスンの問題は `node ludo/tools/gen_learn.js [局数=300]` で AI 自己対局から作る（Lv.20 評価で最善手が次善手より 4 以上良く、教える種類に当てはまる局面。手番の色を席0へ回して、いつも赤／黄の番にする）。文言は `ludo/i18n.js`（ls.* / lsc.* / lb.* / lh.*）。

## 4. コーチ・振り返り・戦績・レート戦
- コーチ（`ludo/coach.js`・`coach-i18n.js`、`shared/coachkit.js`）：AI戦・対人戦で、自分の手を Lv.20 の評価（`LudoEngine.rank`）で採点し、最善手との勝率差で判定。候補手と理由（取る・出す・安全・逃げる・上がる）を表示。レート戦・レッスン中は出さない。
- 勝率：`LudoEngine.winProb`（ルール×人数ごとのロジスティック近似 `WP`、`node ludo/tools/fit_wp.js` で自己対局から当てはめ）。
- 振り返り（`ludo/review.js`）：対局後に全手を評価し、形勢グラフ・手の質（好手〜悪手）・正確さ（100 − 平均損失×400）。←→↑↓で移動。PCは盤の高さに右欄を合わせる。
- 戦績：`shared/record.js`（ルール×人数ごとの勝敗）。レート戦（`ludo/rated.js`）：Lv.1〜20 の AI 相手の段位戦、`RT_LV` の Elo 表、`aicoding-ludo-rated`。待った・ヒント・コーチなし、途中で離れると負け。
- 情報タブ（`shared/infotabs.js`）：スマホは「コーチ・形勢・記録・戦績・オンライン」。

## 5. 3D・ポータル
- 3D モデル（陳列用のサイコロは青の陣地の真ん中に平らに置く）：`atlas/models/ludo.js`（`Table3D.MODELS.ludo(live, rule)`／`MODELS.pachisi`）。ルドーは2D盤の絵を貼った木枠の盤と挽き物の駒、パチーシは十字の布と蜂の巣形の駒。サイコロ、タカラガイ。
- 駒のポリゴン：ろくろ駒は周方向24分割（軽量16）、ルドーの頭の球は縦8段。ルドー駒864・パチーシ駒672三角形（30分割の頃と見た目はほぼ同じ）。子安貝は16×10。
- ちゃぶ台で遊ぶ：`atlas/games/ludo.js`。カードの「ルールと人数」でルドー 4/3/2人・パチーシ 4人（2対2）/2人（1人2色）。AI 戦（あなたは赤／黄、ほかは全部 AI。4人パチーシの味方の黒も AI）と二人以上で対戦（全色を順にタップ）。待った（自分の番の初めへ）・ヒント（Lv.20 の手）・投了。時計なし。スマホでは2D版と同じ手番フォーカス：カメラが手番の色の陣地・動かせる駒・動く駒へ寄り、次の手番へなめらかにパン・ズーム（`Table3D.fit({cx, cz, ease:true})`、`atlas/table3d.js` に追加した中心指定となめらか移動）。画面右端のボタンで全体表示に切り替え（`atlas-ludo-zoom`）。テキストは `ludo/i18n.js` を読み込んで使う。
- 3Dルールコース：`atlas/rules/ludo.js`。案内役はヨーヨーの得意なサルの「ルディ」（`images/atlas/av/monkey-1.webp`）。ルドーの8ページ（あいさつ・盤と出発マス・6で出発・目の数だけ進む・捕まえる・安全なマス・ゴール・勝ち）。各ページで3Dのサイコロを振って（目は仕込み）駒を動かす。台詞は全ページ・14言語ともルディの口調（ヨーヨーやバナナのひと言ボケ）。文字送りの声・黄色の課題札・正解後の自動送り（1.6秒＋文字数×45ms）・駒の差分配置は共通ルールどおり。
- ポータル登録：`shared/atlas.js`（GAMES・更新情報・進み具合）、`atlas/i18n.js`（about／hist）、3Dアイコン `atlas/icons3d.js` → `images/atlas/ludo.webp`、一覧の絵 `atlas/shots/ludo.webp`（`tools/shots.js`）、地図 `atlas/mapdata.js`、ヒストリア `atlas/historia/<言語>/ludo.json`・`s/ludo.json`（`python3 ludo/tools/gen_historia.py` で生成。盤の図は historia.js の `t:'ludo'`）。
- トップページ：`index.html` のカード（key `ld`）・JSON-LD、アイコン `images/icons/ludo.svg`、サムネイル `images/ludo.webp`。

## 4b. 設定・表示（2026-11-09）
- 対局設定（スマホ縦）：ゲームタブにルールのカードとハウスルールのボタン。閉じる・対局開始は横一列に同じ幅で（短い閉じるは横画面用）。ルール説明のタブはスマホでは2段（小さく「ルール」、その下に「ルドー」「パチーシ」）。
- 駒の速さは歯車（オプション）の「速さ」の行のプルダウン（言語の行と同じ形。ゆっくり／ふつう／はやい、2026-11-09。以前は押すたびに切り替え。共通部品 `HeaderBar.addOption({ type: 'select', options, get, set })`）。対局設定からは外した。旧「ふつう」が今の「はやい」、旧「ゆっくり」が今の「ふつう」、さらに遅い「ゆっくり」を追加（動きの時間 ×2.4 / ×1.6 / ×1）。
- 動かせる駒がないときは短く表示してすぐ次へ（2D 約0.4〜0.6秒、3D 0.56秒）。
- 形勢カードの手のナビゲーション（⏮◀▶▶⏭）は振り返り中だけ表示。
- タイトルは選んでいるルールの名前だけ（「ルドー」または「パチーシ」）。日本語表記は「ルドー」に統一。
- 対局設定ダイアログはPCで他ゲームと同じ幅（980px）。
- 3D卓の下のバーは短い状態だけ（🎲 5・考え中…）。長い文は上のトーストへ。

## 4c. ハウスルール（2026-11-09・ルドーのみ。パチーシは伝統ルールのまま）
- ボタンは「ハウスルール ⚙」だけ（★の説明は出さない。変えた項目があるときだけ「変更 n」の印。大百科のカードでは数字だけの丸い印で、レベルのプルダウンの幅を残す）。大百科のカードでは PC・スマホとも AIの強さ の行の右端（カードの共通の型どおり：ラベルは各行の自然な幅、行と行・最後の行とボタンは14pxの間隔。「ルールと人数」はモードの箱の下の別の行（#bvSzRow。二人で対戦でも選べる））。パチーシを選んだときもボタンは消さず、押せない表示（薄く）にして行の形を保つ。
- 設定は `ludo/house.js`（`window.LudoHouse`、保存 `aicoding-ludo-house`、14言語）。2D の対局設定の「ハウスルール」ボタン、3D 卓のカード（アダプタの `house` → `atlas/app.js` が「ハウスルール」行を出す）から同じポップアップを開く。★が既定、プルダウン（クイック・安心地帯だけスイッチ）、「すべて★に戻す」。全ルール重ねがけ可。レート戦は常に★の既定。
- 項目と既定（`LudoEngine.HOUSE`）：クイック ON（開始時に1個スタートへ／盤上に駒がなければどの目でも出せる）、安心地帯 ON、スタート＝クラシック（6）／1か6／5か6／制限なし（追加で振れるのは6だけ）、ブロック＝着地不可／通行止め／なし、アタック＝スタートへ／5マス戻す／10マス戻す、6＝3回連続で無効／2回連続／なし（6で追加なし）、ゴール＝ピッタリ／バック（余りは戻る）／なんでも。上級（既定すべてなし）：ダブル＝スタンダード（同じ色2個を1塊で進める。1個に踏まれても取られず、ダブル同士で両方待機へ）／スプリット（1個だけ進めても良い）、ダブルダイス＝スプリット（2つの目を別々に）／フリーダム（別々か合計）／666（基本スプリット、6ゾロは6を3つ自由に・追加なし）。6ゾロで追加ターン。バックステップ＝いつでも／取れるときだけ／1の目だけ。
- ポップアップの形（2026-11-09 改）：★はどこでも同じ黄色（見出し・説明・プルダウンの中・ボタン）。各項目の名前の前に線のアイコン（基本は青、上級は赤。クイック＝稲妻、安心地帯＝盾、スタート＝旗、ブロック＝レンガ、アタック＝剣、6＝サイコロ、ゴール＝的、ダブル＝重なった駒、ダブルダイス＝サイコロ2つ、バックステップ＝戻る矢印）。見出しの説明は文ごとに改行（「★がふだんのルール。」／「どれも組み合わせて使えます。」）。各項目は1行目に名前と操作（スイッチ／プルダウン、幅は最大260pxか60%）、2行目に説明（全幅で折り返し）。プルダウンの一覧は画面に固定配置で、下に入りきらなければ上に開く（スクロール部分の外に出ない）。変更してもスクロール位置はそのまま。大百科から開くときは `theme:'atlas'`（クリーム地・コーラルのボタン、大百科のカードと同じ見た目）。表記：ダブルダイスの説明に「（666以外）」、バックアタックは「コマを取れるときだけ」。
- 大百科のカードは共通の型（チェスなどと同じ。行の間隔14px）。「ルールと人数」（5択）は PC・スマホとも、トグルではなく AIの強さ と同じプルダウン（ボタン＋一覧シート。`atlas/app.js`：選択肢が4つ以上の bvSize は、ハウスルールのあるゲームでは画面幅によらず、ほかのゲームはスマホだけ）。
- エンジン：`s.opt.h` があれば新しい手生成 `ludoMoves/ludoApply`、無ければ従来（パチーシ・以前の保存データ）。2つのダイスは1回の振りで `s.left`（残りの目）を使い切るまで `apply` が `cont:true` を返し、新しく振らずに続ける。AI（think・playout）も同じ。

## 4d. ダイスカップ（2026-11-09 v2・ルドー）
- 流れ（2D・3D共通）：カップは手番の色の陣地の真ん中に**口を上に**して立つ → 振ると口を上にしたまま揺れる（中でサイコロが鳴る）→ ひっくり返して**口を下に**盤へ伏せる（コトッという音）→ カップを持ち上げてどけると、その場にサイコロ。次の手番ではカップが次の色の陣地へ移り、また口を上に。
- カップの見た目（2026-11-09 v3、2D・3D とも）：黒い革の筒、内側は赤いフェルト、口は丸く巻いた縁＋ステッチ1本、底に一段太い帯＋ステッチ。金具・色の帯はなし。
- 2D：`app.js` の `cupDraw`（口が上 `cupUp`／下 `cupBody`、モード ready・idle・shake・flip・down・lift）、時間は速さ設定の √ 倍（`--k`）。自分の番はカップが光って弾み、タップで振る（カップの近く＝陣地の真ん中から1.35マス以内のタップでも振る。3Dのカップは SVG の位置より上に立って見えるため）。
- 次の手番の始め（3D・フル機能版とも）：伏せて脇（陣地の角）に置いたカップがその場で口を上に向け、サイコロが跳ねてカップに入る（すくい上げ。カップをサイコロの横へ寄せると陣地の駒に重なるのでその場で）。それから次の色の陣地へ運ぶ。サイコロが急に消えないように。カップの動きは順番待ち（振る前にすくい上げと移動を終える）。
- 3D 卓：`atlas/games/ludo.js` の `cupThrow`（大きめのカップ：半径0.58、高さ0.72。サイコロは伏せたカップの下に置き、持ち上げると見える。2つのダイスは横に並べてカップの中に収まる）。口が上のときはカップの中にサイコロが見え（ダブルダイスなら2個）、振ると中で跳ねて転がる（上の面が次々に変わる）。カップは持ち上げた後、陣地の奥の外側の角へ口を下にして置く（駒の手前を隠さない）。**カップは駒に重ならない**（2026-11-09）：カップ（直径1.16）は陣地の駒の間（2マス）より大きいので、盤の上を動くときは1つの弧で動かす（`hop()`、3D 卓・フル機能版とも。横はなめらかに加減速、高さは最初に素早く上がって駒の上では駒より高く（最大0.92、駒は0.57）、最後に降りる。上がる→横へ→降りるの段に分けると2ステップに見えたので1つの動きに、2026-11-09）。止まる場所は陣地の真ん中（4つの駒から0.93）と陣地の奥の角（0.98）だけで、どちらも駒（半径0.26）＋カップ（0.58）より離れている。

- サイコロ（3D、2026-11-09 v2）：角と辺を少し丸めた立方体（`atlas/models/ludo.js` の `roundDieGeo`：半径0.07、面ごとの材質はそのまま）。目は彫った穴：面の材質に穴の alphaMap（alphaTest）を付け、穴の下に球の一部を内側から見たお椀（黒、1の目は赤）を置く。光の向きに合わせて穴の中に陰ができる（どの向きに転がっても正しい）。

- 3D卓のテンポ（2026-11-09）：2D版の「ふつう」に合わせる。駒の1マス（160ms、長い移動は104ms）とカップの揺れ（531ms）・伏せ（329ms）は2D版のふつうと同じ時間（`D2`）、ほかのアニメーションと間（`anim`・`later`）は ×0.85（`PACE`）。手番フォーカスのカメラは `T3.fit` の `ek: .12`（既定 .06 の倍の速さで寄る）。

- 音（2026-11-09）：3D卓のサイコロの音（`SND.shake`）はカップが揺れ始めるときに鳴らす（AIの番も同じ。以前は振る操作の時点で鳴り、前のサイコロのすくい上げと重なっていた）。すくい上げではサイコロがカップに落ちるたびに「コトッ」（`SND.collect`、フル機能版は2D版の `tone()`）。

## 4e. フル機能版（`ludo/?skin=atlas`・2026-11-09）
- 大百科のカードの「フル機能版」（`atlas/app.js` の FULL_SKIN に ludo）。2D版の全機能（AI・レート戦・レッスン・コーチ・振り返り・ハウスルール）をそのまま、盤だけ3D。
- 読み込み：`ludo/index.html` の末尾（three.js → table3d → tables3d → skin/common.js → models/ludo.js → `atlas/skin/ludo.js`）。失敗したら2D版のまま。
- `atlas/skin/ludo.js`：3D卓と同じ盤のモデルを SVG 盤（`#frame`）の下に合わせる（`AtlasSkin.alignTo((n+0.8)·u)`）。SVG は透明で上に残り、タップ・行き先の印・矢印はそのまま。SVG の駒の動き（`transform`、ホップの高さは `data-hy`）を 3D の駒に写し、動かせる駒はオレンジ、ヒントはピンクの輪。カップは `cupDraw` を包んで 3D のカップを動かす（口を上で中にサイコロ→揺れる→伏せる→持ち上げる）。スマホの手番フォーカス（2D版の SVG の viewBox の寄り）にカメラが付いていく（盤全体の仮想の箱に合わせて align、寄っている間はキャンバスを枠で切る）。カップの動きは2D版の速さ設定に合わせ、2D版が先に進んでいるときは急いで追いつく。（2026-11-09 修正：アニメーションの関数が未定義の変数で毎回止まり、カップが手番の陣地へ移らず・すくい上げず・伏せたまま残っていた）パチーシは布の盤と駒、タカラガイは右欄のまま。
- 大百科から開くと「ルール」（size=4/3/2/14/12）と AI の強さで対局を始める。PC の配置は2D版の規定（ヘッダー64px、盤の枠のぶん少し小さく）。
