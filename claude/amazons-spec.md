# アマゾンズ（amazons/）仕様

URL: https://core-calmdust.github.io/aicoding/amazons/ ／ トップは「囲碁」の前（cat: line、also: chess、定番タグ、BETA）。テーマ色 #3f8a5c（ジャングルグリーン、アクセント #d6ec86）。

## ルール（10×10、標準ルールのみ）
- 白のアマゾン a4・d1・g1・j4、黒 a7・d10・g10・j7。白が先手。
- 1手＝アマゾン1体をクイーンのように動かす（縦横斜め・何マスでも・何も飛び越えない）＋着いたマスから同じ動きで矢を放つ（元いたマスにも撃てる）。矢のマスは最後まで使えない。
- 自分の番にどのアマゾンも動けない側の負け。引き分けはない（引分提案なし）。
- 出典（2026-11 確認）：Wikipedia「Game of the Amazons」（考案 Walter Zamkauskas、アルゼンチン 1988年、初出はアルゼンチンのパズル雑誌 El Acertijo 1992年12月、英訳 1994年、コンピューター・オリンピアードの種目、簡単な終盤でもNP困難）。
- 名称：スペイン語の「El Juego de las Amazonas」は Ediciones de Mente の商標なので使わない（各言語の表記は「Amazons／アマゾンズ」と各言語の一般名）。ルール自体の実装は自由。

## エンジン（engine.js、純JS、Web Worker）
- 手 m = from + 128×to + 16384×arrow。表記「d1-d7/g7」。Pos は play / unplay（探索は複製しない）。
- 評価（約100＝陣地1マス）：Lieberum の項（クイーン距離・キング距離の陣地 t1/t2、位置項 c1/c2、盤の開き具合 w で重み付け）＋各アマゾンの自由度（動けるマスが少ないほど減点）。
- 候補手は2段階：全クイーン移動を評価 → 上位だけ全ての矢を評価（`cands`）。αβ（PVS・置換表）で残り深さごとに上位 K 手だけ読む（K=8〜10）。
- 20段階（Lv. 表記）：Lv.1〜8 は1手読み＋ノイズ（弱い段ほど見るクイーン移動も少ない）、Lv.9〜18 は評価回数の予算（2千〜7.5万回）、Lv.19・20 は 1.5秒／3秒。RT_LV（レート戦の基準値）は作業機での短い対戦からの仮の値（ユーザーの Mac で測り直す）。
- 振り返りの分析は実際に指した手を `extra` で必ず評価に含める（候補に入らない手も判定できるように）。
- 1スレッド（本編のマルチスレッド・PRO は未対応）。

## 画面（konane/ から派生、共通部品はそのまま）
- 入力は3タップ：自分のアマゾン → 行き先（黄緑の点）→ 矢のマス（オレンジのひし形）。2段階目はアマゾンを行き先に半透明で表示、元のマスは薄く。行き先のアマゾンをもう一度タップで行き先を選び直し、別のアマゾンで最初から。盤下に「アマゾンを動かすマスを選ぼう／矢を放つマスを選ぼう」。
- アニメ：アマゾンが滑る → 矢が飛んで刺さる（効果音：滑る音・ヒュッ・トン）。
- 盤の上下と対局者カード：陣地（クイーン距離で先に届く空きマスの数）と動けるマスの数。ヘッダー中央：手番・両者の陣地／動けるマス・矢の本数・形勢・手数。
- 盤（tools/gen_art.py で生成するテクスチャ）6種：ジャングル（既定）・メープルとウォルナット・大理石・セレステ・モダン・グレー・ミッドナイト。駒（tools/gen_pieces.js の SVG）4種：アイボリーと黒檀（既定）・シルバーとブロンズ・ガラス・フラット。矢のマスは盤ごとの色の焼き印のタイル＋刺さった矢。
- ルール（RuleTour、実際の盤）：紹介 → 盤とアマゾン → クイーンのように動く（課題）→ 矢を放つ（課題）→ 飛び越えられない（課題）→ 動けなくしたら勝ち（課題）→ 陣地（読むだけ）。
- 振り返り解説：最善／悪くない／疑問手／悪手と、陣地の損・自分のアマゾンが囲まれかけた・相手を閉じ込めるチャンス。PC振り返りボックス（候補手・読み筋・検討モード）。
- 対局設定：ルールが1つなので「ゲーム」タブなし（ルール｜デザイン）。
- コーチ（coach.js ＋ coach-i18n.js、14言語）：要約チップ（形勢・陣地・動けるマス）、推奨方針、分かれ道（方針：勝ち筋／動けなくする／閉じ込める／逃げる／道をふさぐ／壁を作る／中央へ／陣地を広げる、各候補の手のあとの陣地）、考え方のヒント（閉じ込めのチャンス・囲まれそうなアマゾン・部屋の分かれ方・中央・元のマスへの矢…）、前の手の評価。出典は coach.js の冒頭。
- スマホ下タブ：コーチ｜形勢｜棋譜｜戦績（オンラインなし。#mtabs を index.html に置く）。
