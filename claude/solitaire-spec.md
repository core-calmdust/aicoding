# ソリティア（solitaire/）

クロンダイク・スパイダー・フリーセル・ゴルフ・トライピークス・ピラミッドの6種を1つにまとめたカードゲーム。ゲームの種類（バリアント）は後から追加できる作り。

## ファイル
| ファイル | 役割 |
|---|---|
| `variants.js` | ルールエンジンとバリアント登録（DOMなし、Workerでも動く） |
| `solver.js` | 汎用ソルバー（最良優先探索。`search: 'dfs'` のバリアントは深さ優先）。勝てる配り・今日の配り・ヒントに使用。Web Workerとして起動 |
| `table.js` | カードの描画・ドラッグ／タップ／ダブルクリック・アニメーション（本盤とルール説明の小盤で共用） |
| `app.js` | 進行（元に戻す・自動移動・自動で完成・勝敗・統計・今日の配り・各ダイアログ・効果音・勝利演出） |
| `rules.js` | チュートリアル式ルール説明（`shared/ruletour.js`、ゲーム種類ごとのタブ） |
| `i18n.js` | 画面の文言（10言語） |

## ゲーム種類の追加手順
1. `variants.js` で `register({...})`：`layout`・`deal`・`canPick`・`canDrop`・`won` は必須。山札があれば `canStock`/`stock`、得点は `score0`/`score`、ヒントの並べ替えは `rank`、自動移動は `safe`。札の山の種類は `stock / waste / found / tab / cell`（独自の種類・手は `custom`/`applyCustom` で追加可）。
2. 難易度は `presets: { easy, normal, hard, expert }`、ルールの選択肢は `opts: [{ k, vals, def }]`。新しいゲームダイアログ・ルール要約・統計・今日の配りは自動で対応。
3. ソルバーで解けるゲームは `solver: true`（「勝てる配り」が選べるようになる）。
4. `i18n.js` に `v.<id>`・`vd.<id>`・`dd.<id>.<難易度>`・`o.<キー>`・`ov.<キー>.<値>`・`os.<キー>.<値>` を10言語で追加。
5. `rules.js` の `RULES[<id>]`（小盤の配置と合格条件）と `RT[言語][<id>]`（紹介・各ページの文言）を追加。
6. `app.js` の `GICON`（小アイコン）と `GART`（新しいゲームのカード絵）を追加。

### ピラミッド型のゲーム（トライピークス・ピラミッド）
- 場の1枚ずつが種類 `pk` の山（1枚）。上に重なる `pk` は配置（1段下で横にずれが0.9未満）から自動計算（`coverOf`）。重なりが全部なくなると表になる（`uncover`）。描画順は `L[i].z`。
- 局面の同一判定はバリアントの `key(st)`（場の残り・山札・捨て札だけ）で行い、ソルバーを速くしている。評価関数は `eval(st)`。
- ピラミッドは、相手のカードに重ねる手（`{f,i,t}`）のあと `after` で合計13の2枚を捨て場（`found`、`discard:1`）へ。Kは捨て場へ直接（自動移動「安全」でも取る）。
- トライピークスの連続得点は `st.runs` を連続数として使う（元に戻すで巻き戻るため）。

## 保存
- `localStorage['aicoding-solitaire']`：設定・遊び途中のゲーム（元に戻す履歴つき）・統計（種類×難易度）・今日の配りの記録・勝てる配りの先読み
- ルール説明の進み具合：`aicoding-solitaire-rules-<種類>`、ルールを見たか：`aicoding-solitaire-rules-seen`

## 画像のクレジット
- 絵札（J・Q・K）とカード裏面「クラシック赤・青」："Classic Playing Cards"（Alborz Heydaryan、Figma Community）CC BY 4.0。`img/CREDITS.txt` 参照。ゲーム内の設定ダイアログにも表記。
- 絵札「アンティーク」「フラット」と裏面「アラベスク」「アラベスク黒」「フローラル」「アズール」（各黒）「ラッキースカル」（白・黒）、カード・裏面「ギャングスタ」：Designed by Freepik（magnific.com の7素材、出典明記で使用可）。`img/CREDITS.txt` 参照。
- カードのデザインは `set.court`（classic / antique / flat / gangsta）。classic・antique は絵札だけ画像（`img/`・`img/antique/`）、flat・gangsta は52枚すべてを画像で表示（`img/<deck>/<A23456789TJQK><shdc>.webp`、`Table.FULL_DECKS`、とても小さいカードでは描画のカードに切り替え）。裏面の既定はアラベスク。
- 新しいゲームのダイアログは「ゲーム」「ルール」「デザイン」のタブ。今日の配りはメイン画面の「今日のソリティア」から。

## 画面構成（ユーザー指定・共通仕様の右欄2列の例外）
- ページを開いたら新しいゲームのダイアログを表示する（本作のみ・共通仕様「読み込み直後に対局設定を出さない」の例外。遊び途中の配りはその裏に残る）。
- 既定：カードはギャングスタ、テーブルはティール、裏面はラッキースカル黒。カラーテーマはダークグレー。
- 新しいゲームのゲームタブは6種を3列×2段のカードで表示。デザインタブは左に裏面、右にカードのデザイン、テーブルは下に1列。
- クリアの効果音は `snd/win.mp3`（Universfield / Pixabay「Game Bonus」）。勝利演出で跳ねるカードは選択中のカードのデザインで描く。
- PC：ゲームボードを画面横幅いっぱい（横長）。ゲーム名・難易度はタイトル横にサブタイトル程度の大きさ、時間・手数・得点は大きめの文字でヘッダーバーに。ボードの下に3列で「今日のソリティア」「成績（配り番号・最初からを含む）」「ショートカット」を、スクロールなしで画面内に収める。
- スマホ：ボードの下にゲーム名・時間・手数・得点、その下に成績・今日のソリティア。
- テーブル：革張りのレール＋金の縁取り、カジノ風のフェルト（織り目・スポットライト・SOLITAIRE の刷り込み）。
