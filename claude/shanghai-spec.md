# 上海（麻雀牌のひとり遊び）仕様 — 大百科の3D専用（atlas/#games/shanghai）

2026-11-13 BETA公開。2Dページなし（ペグソリテールと同じ3D専用フォーマット、`only3d`）。大百科のカテゴリはパズル（cat: puzzle、定番タグ）。テーマ色 #1f6a4c（翡翠）。

## ルール（atlas/games/shanghai-core.js、DOMなし・node でも動く）
- 取れる牌：上に何も載っておらず、左か右の少なくとも片方が空いている牌。同じ絵柄の2枚を取る。花（梅蘭菊竹）は花どうし、季節（春夏秋冬）は季節どうしなら絵柄が違っても組になる。
- 位置は半牌単位 `[x2, y2, z]`。上に載る＝1段上で |dx|<2 かつ |dy|<2、左右＝同じ段で dx=±2 かつ |dy|<2。
- 配牌は必ず解ける：配置を「同時に自由な2か所」ずつ空にしていき、その順の逆に同じ組を置く（`deal`）。シャッフルも残りの牌で同じ方法（`reshuffle`）。
- ヒント：配牌時の手順（プラン）を持ち、取るたびに補修（`patch`：組の相方どうしを組み直す）→ 一発で検証（`planOK`、牌は取るほど自由になるので順に1回たどれば判定できる）→ だめなら時間制限つき探索（`solve`、400ms）。見つからなければ「このままだと全部は取れなさそう」と出す。
- 配置10種（`FREE`、カードのサイズ行 1〜10）：はじめの一歩24・ピラミッド40・ふたご島32・十字路60・塔48・城塞108・石橋84・蝶118・竜146・亀（定番）144。

## 3D（atlas/models/shanghai.js）
- 牌はすべて1つの InstancedMesh（配置全体で描画1回）。角を丸めたブロック（上面の縁も丸い）、象牙色と背の色の2トーン（境目はくっきり）。底面なし。三角形は PC 約150・スマホ約100／枚（亀144枚で PC 約2.2万、規定8万に十分な余裕）。
- 絵柄は1枚のキャンバスのアトラス（PC 256px・スマホ 160px幅のセル）に一度だけ描き、インスタンスごとにセルをずらす（onBeforeCompile、側面はアトラスの白いセル）。
- 牌は白く磨いた現代の牌（2026-11-13 ユーザー：象牙色は古めかしい）。地は平らな白 #fafaf6、側面 #f7f7f3、背は明るめの色（側面は陰になるため）。
- 文字（萬子・東南西北・發・中・花／季節の漢字）は日本式の実物の牌の写真からなぞった字形（ユーザー指定：1枚目の日本式の書体、赤ははっきり）。`atlas/tools/shanghai-glyphs.py` で参考画像から `atlas/img/shanghai-glyphs.png`（8×3セル、R＝黒・G＝赤・B＝緑のインク濃度）を作り、読み込んで色を付けて描く。読めないときは Yuji Syuku（Google Fonts）で代用。筒子・索子・一索の鳥・花／季節の絵（2026-11-14）も同じ日本式の写真から色つきで抜き出す（`shanghai-glyphs.py art` → `atlas/img/shanghai-art.png`、RGBA 8×4セル、色は牌の塗り5色に寄せ、索子と花の葉は緑）。色は画素ごとでなく線（つながった塗り）ごとに決める：はっきり色のついた画素だけが投票→多数決で斑を消す→暗い縁などは近い色に→一つの線は一色に。花／季節の漢字は赤だけ、数字は紺だけ、絵は赤か緑、筒子は紺と赤、索子は緑と赤（2026-11-14 ユーザー指摘：赤に緑が混ざる）。白は何も描かない（日本式）。コードの絵は読み込めないときの代用。
- 彫り（ユーザー：実物は数字や文字を掘っている、深く）：描いたインクの濃さを深さとし、ぼかしてから法線マップ（normalMap、アトラスと同じUV）を作る。毎フレームの負担なし（アトラスを描くとき1回）。2026-11-14 さらに深く（ユーザー指示）：溝の壁を広く・急に。文字の縁に暗い線（陰の塗り）は入れない（ユーザー指示）。彫った溝はそのまま着色（墨入れなし）＝塗りは平らで自分の色のまま、斜面は文字のすぐ外の白い縁にだけ付ける（象牙を彫っても黒い線は出ない、ユーザー指示）。
- インスタンスの色＝取れない牌は少し暗く（0.6）、選んだ牌は暖色、金の牌は金色、ヒントは橙。
- 牌どうしの影は上の段の牌ごとの柔らかい影の板（InstancedMesh、2三角形／枚）。牌は影を落とすが受けない（側面の縞状の自己影を避ける）。
- 背の色4種（翡翠＝既定・瑠璃・黒檀・珊瑚、'aicoding-shanghai' settings.back。選択UIはまだ）。下に緑のフェルト＋金の縁のマット。

## 遊び方（atlas/games/shanghai.js）
- 牌をタップ → 同じ絵柄の自由な牌をタップで2枚が浮いて消える。取れない牌をタップすると小さく揺れて「その牌はまだ取れません」。
- 下のバー：待った（何手でも）とヒント。投了ボタンなし（noResign）。取れる組がなくなると「手詰まり — シャッフルしますか？」のシート。
- HUD：残り枚数・取れる組の数（ステージではミッション）・タイム（時間制限のあるステージは残り時間）。

## ステージ（12星座×10＝120、`stage(s)`）
- カードのタブ「フリー｜ステージ」（app.js の adapter.stages：stagePanel／stageBind／freeBind、STX）。ステージタブのスタート＝次の未クリア、「星座マップ」で全画面の星図（星座ごとのタブ、スワイプ／←→で切り替え、縦長画面は星座を90度回す）。
- 各星座10ステージのミッション：すべて取る／○組を時間内／金の牌（深い所の組に金色）／時間内にすべて／ヒント・シャッフルなし。配置は星座が進むほど大きく、時間は厳しく。配牌はステージごとに固定（seed）。
- 星：★クリア、★★基準タイム以内（時間制限ありは制限の75%）、★★★さらにヒント・シャッフルなし。シャッフルは1ステージ3回まで（ヒントなしミッションは0回）。手詰まりでシャッフルが残っていなければ失敗。
- 解放は1つずつ（前のステージをクリア）。終わりのカードに「次のステージ」（res.next、app.js の eNext）。
- 保存：'aicoding-shanghai' { settings, free: { 配置: { best, n, date } }, st: { s: 星 }, bt: { s: 秒 } }。大百科の進み具合は st の数（total pz 120）。
