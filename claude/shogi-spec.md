# 将棋（shogi/）仕様メモ

AI・評価関数・定跡などは `shogi/MODEL_CARD.md` を参照。ここにはレッスン・詰将棋の画面まわりの決定事項を書く。

## 段級位別レッスンの「次の一手」問題 = 3手の実践（2026-11-10）

- 対象：段級位別レッスンの次の一手型の問題（駒の動きと価値・タダの駒・王手をかわす・両取り・詰めろを受ける・中盤の次の一手・難問の一手）。ステップ（分類）・1問20点・75点以上で合格はそのまま。詰将棋型・ルール・駒落ち・棋力認定テスト・自分の対局の復習は従来どおり1手。
- 1問で自分は3手指す。相手の手はAIが返す（0.7秒の思考）。
- 1手ごとに、コーチの箱に評価（最善手・好手・疑問手・悪手と点数）、いちばん良い手、その理由を出す（新しい手が上）。カードには最新の評価だけを短く出す。
  - 1手目（テーマの手）：問題の採点（accept / cand）と、問題ごとの解説（expl・理由・罠の注意）。
  - 2・3手目：指す前の局面の全候補の解析（1.5秒）から、勝率の落ち幅で採点（最善手＝20点）。理由はコーチの方針分類（`ShogiCoach.classify` と `x.*` の文）。
- 点数：1手目×0.5＋2手目×0.25＋3手目×0.25。途中で詰ませたら残りは満点、詰まされたら残りは0点。
- ボタンは詰将棋と同じ：ヒント（その手の動かす駒を光らせる、その手は−4点）・やり直し（初期局面から）・答え（その手の最善手を代わりに指して解説、その手は0点）・一覧・次の問題（最後の問題では「結果を見る」）。
- 問題は易しいものから選ぶ：`shogi/tools/lesson_easy.js` が各問題に `fd`（正解をエンジンが見つける最小の探索深さ）を付け、各ステップは易しい方の6割（最低7問）から5問を選び、易しい順に出す。

## 詰将棋（2026-11-10）

- 途中の手に正誤を出さない（「あと◯手」だけ）。正誤はクリアした時か手数を使い切った時だけ。失敗しても正解手順は出さず、「答え」で見られる。
- カード：見出し行の右上に「やめる」、タイトルの直後に「n/N問目」、ボタンはヒント・やり直し・答え・一覧＋横長の次の問題（再生ボタンはなし）。
- 詰将棋中はコーチのパネルを出さない。創作詰将棋だけ相手の駒台を隠す（相手は残りの駒をすべて持つ約束）。
