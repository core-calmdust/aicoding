# 将棋（shogi/）仕様メモ

AI・評価関数・定跡などは `shogi/MODEL_CARD.md` を参照。ここにはレッスン・詰将棋の画面まわりの決定事項を書く。

## 定跡の実戦練習 = 3手の実践（2026-11-10）

- 対象：定跡 → 戦型 → 実戦練習（Floodgate の強い対局の局面から出題）。段級位別レッスン（入門〜）は従来どおり1手の問題（変更しない）。
- 1問で自分は3手指す。相手は定跡（book.json）でいちばん多く指された手を返す。定跡を外れた局面ではAI（0.7秒）。
- 1手ごとに、コーチの箱に評価（最善手・好手・疑問手・悪手と点数）、実戦での採用率、定跡の本命の手、その手の方針の解説を出す（新しい手が上）。カードには最新の評価だけを短く出す。
- 点数（1手20点、3手の平均が1問の点数。合格は従来どおり75%）：本命（いちばん多い手）20点・採用率15%以上18点・3%以上16点・それ未満12点。定跡にない手はAIの解析（1.5秒）で勝率の落ち幅から最大12点。定跡の外の局面はAIの最善手との比較。
- 3手を指し終えたら振り返り：コーチの箱に「振り返り：定跡の正しい進行」として、問題の局面からの定跡の正しい進行（その戦型の解説手順の上ならその手、なければ定跡でいちばん多い手。定跡が途切れた先だけAIの手で「(AI)」と表示。自分3手＋相手2手）を出す。自分の手が一致した手は緑、違った手は黄、相手の手は灰色。「盤で再生」で手順を盤に並べ直す。
- ボタンは詰将棋と同じ：ヒント（本命の手の動かす駒を光らせる、その手は−4点）・やり直し・答え（本命の手を代わりに指して解説、その手は0点）・一覧・次の問題（最後は「結果を見る」）。

## 詰将棋（2026-11-10）

- 途中の手に正誤を出さない（「あと◯手」だけ）。正誤はクリアした時か手数を使い切った時だけ。失敗しても正解手順は出さず、「答え」で見られる。
- カード：見出し行の右上に「やめる」、タイトルの直後に「n/N問目」、ボタンはヒント・やり直し・答え・一覧＋横長の次の問題（再生ボタンはなし）。
- 詰将棋中はコーチのパネルを出さない。創作詰将棋だけ相手の駒台を隠す（相手は残りの駒をすべて持つ約束）。

## 盤・駒の追加（2026-11-10）

- 盤「本榧」（天地柾、**既定の盤**。以前の保存で標準のままの人も一度だけ本榧に切り替える）：黄金色の榧、上から下へ走る年輪の線が本物の木のように揺らぎ・枝分かれする木目（控えめ、multiply .22）、照り返しはごく控えめ。デザインタブでは木目の次。
- 駒「菱湖」「錦旗」「水無瀬」：LuffyKudo さんの SVG（CC BY-SA 4.0、github.com/LuffyKudo/Shogi-Themes の 2-Kanji、成駒は赤）。大きさは本格（立体）に合わせる（viewBox を元の1.08倍）。菱湖は字の右上がりが強すぎたので、文字だけを自身の中心で時計回りに3°戻す。`shogi/pieces/{ryoko,kinki,minase}/`、クレジットは pieces/README.md とデザインタブ下の1行。既存の「本格（一文字）」（1kanji_3d）とは別物。
- 画像の駒（本格・菱湖・錦旗・水無瀬など）の表面にうっすら木目：駒の絵そのものをマスクにして、本物の駒（黄楊）のように細くまっすぐな繊細な木目を重ねる（multiply .26）。木目の位置・大きさは駒の種類と向きごとに変え、同じ種類どうしは同じ木目。メタル・漆黒の盤では出さない。
- どうぶつしょうぎ（LuffyKudo の Dobutsu Chess）は保留：元の絵柄（藤田麻衣子さん）は著作権が保護されており、lishogi も許可を得て使っているため。

- **3D駒は6種（2026-11-11、ユーザー指定「盛り上げ駒のフォント違いで計6種」）**：菱湖（既定、2026-11-12〜）・盛り上げ（2kanji_3d、以前の既定）・一字書き（1kanji_3d）・錦旗・水無瀬・菱湖（LuffyKudo）・浮木（うきき。sunfish-shogi の二文字駒、CC0、`shogi/pieces/futamoji/piece.svg` → `atlas/tools/shogi-glyphs-futamoji.py`。2026-11-11。6枠目は楷書〔盛り上げと同じ字〕→隷書〔フリーフォントでは実物の隷書駒にならず不採用〕→浮木（名前はユーザー命名：Sunfish＝マンボウ＝方言で浮木）。保存値 kaisho・reisho は futofude に読み替え）。浮木は元の字をそのまま同じ位置・大きさで再現し、高さは盛り上げの丸い漆の盛り（線の中心が高く、太い線ほど高い）。成り駒の裏は実物どおり草書（水無瀬の成り駒の字を流用）。同じ柘植の3D駒に、2Dの各駒セットのSVGから切り出した文字を盛り上げの漆で載せる（`atlas/tools/shogi-glyphs-faithful.py` → `images/atlas/shogi-glyphs-<set>.png`、ページの駒の絵は `atlas/tools/shogi-pieces.html` → `images/atlas/shogi-pieces-<set>.png`、タイル `atlas/img/pc3-shogi-<set>.webp`）。保存キー `atlas-shogi-pc3`＝`Table3D.PIECES.shogi`（大百科の「駒」の行と共通）。フル機能版は「3D盤」の箱の下に「3D駒」の行。ライセンスは `shogi/pieces/README.md`。
  - 文字は**元の2D駒の書き方をそのまま再現**（2026-11-11 第2版。ユーザー：「オリジナルの駒と比べてバランスがイマイチ・角度が曲がっている」）。文字の線だけを元のSVGの変形ごと描き（菱湖の3°補正も含む）、駒の上面（帯は除く）に対する位置・大きさを2Dと同じにする。文字ごとの中央寄せや盛り上げの枠への当てはめはしない。一字書きだけは3D駒の屋根が2Dより急なので、肩から下の胴に対して中心を合わせる。高さは一字書きの赤駒は元の重ねた層の濃淡、それ以外は線をぼかして作る。比べる絵は 3D の真上の絵と元のSVGを並べて目で確かめる。
  - 菱湖・水無瀬・錦旗の微修正（2026-11-11、実物の写真と比べて）：2字の駒は上下の字を線のまとまりごとに切り分け（横に切ると飛の払いなどが下の字に混ざって傾いて見える）、それぞれ縦画が垂直になるようにわずかにずらして起こし、字の本体の中央（墨の6〜94%）で駒の中心線にそろえる。大きさはどの駒も同じ枠（高さ78%・幅80%まで）に。位置は駒師の作法どおり、字の一番下をどの駒も同じ線（上から92.5%）にそろえる（枠の中央ではない）。菱湖の飛車は右へ、王将・玉将は1.1倍（金は大きくしない：駒の字は上が小さく下が大きいのが基本）。錦旗の王將が手本。王・玉の上の字は水無瀬は下の字の0.52倍（太く大きく見えるので小さく）、錦旗は0.78倍（桂は0.86倍）。水無瀬の金は上の字を3°右回し・左へ寄せ、歩・香・桂は上の字を小さく（下の字の約0.8倍）、王将・玉将は全体を1.12倍、歩兵は線を細く・2字の間を空ける（元の絵で2字の線がつながっているのは切り分け線で分ける）。菱湖・錦旗の馬は右へ5%（4つの点で字の軸が左に寄って見える）。設定は `shogi-glyphs-faithful.py` の TUNE・FILL。
  - 駒の置き方（2026-11-11、ユーザー指定「将棋の作法」）：駒はマスの中央ではなく、駒の底をマスの手前の線（持ち主側）にそろえて置く。相手の駒は向こう側の線。3Dモデル自体をずらしてあり、ページの駒の絵も同じ。菱湖の飛車は線を細く。横画が右上がりで傾いて見える下の字（菱湖の車・將、水無瀬の兵・馬・將・車）は1.2〜1.5°時計回りに（ユーザーが自分で直した絵に合わせて、2026-11-12）。
  - **水無瀬は実物の写真から字を起こす（2026-11-12、ユーザー指定）**：LuffyKudo の字を調整する方式（上の TUNE の水無瀬の項）では実物の水無瀬書にならなかったため、表の字（歩・香・桂・銀・金・角・飛・王將・玉將）はユーザー提供の盛り上げ駒の写真（リポジトリには置かない）から輪郭を起こす。`atlas/tools/shogi-glyphs-photo.py <写真> minase`：木地の色で駒を切り分け → 墨（暗さ＋漆の照りの無彩色）を抜く → 同じ駒の写し（金4枚・歩18枚など）を位置合わせして中央値で平均 → 駒の中での位置・大きさは写真のまま（中央寄せ・枠への当てはめ・傾きの補正はしない）、横だけ写真の駒と3D駒の縦横比の差を補正して字形を保つ。王將は写真が白飛びしているので玉將から点を除いたもの、王・玉の「將」は金將の將（4枚平均）を王の將に重ねたもの。成り駒（裏）は写真にないので LuffyKudo のまま。2Dの駒（`shogi/pieces/minase/*.svg`）も同じ字に差し替え（`atlas/tools/shogi-traced-svg.py <set>`、元データ `shogi/pieces/minase/traced.png`）。作り直す順：`shogi-glyphs-faithful.py minase`（裏）→ `shogi-glyphs-photo.py`（表）→ `shogi-traced-svg.py`（2D）→ `shogi-pieces.py minase`（ページの駒の絵・タイル）。
  - **菱湖も実物の写真から（2026-11-12、ユーザー指摘「レイアウトにばらつき」）**：LuffyKudo の字は実物より横に広く、駒ごとに大きさ・位置がそろわなかったため、水無瀬・錦旗と同じく表の字と配置を写真から起こす（`shogi-glyphs-photo.py <写真> ryoko 8`、細い線の書体なので輪郭をやや内側に取る thr=.58）。2Dも同じ（`shogi-traced-svg.py ryoko`）。これで菱湖・水無瀬・錦旗の TUNE（字ごとの手調整）は表の字には使われない。菱湖の玉將は、写真の駒の先端の照りが字の上に点として拾われるので取り除く（ユーザー指摘、`LAY.ryoko.drop`）。
  - **錦旗も実物の写真から（2026-11-12、ユーザー指定）**：水無瀬と同じ手順（`shogi-glyphs-photo.py <写真> kinki 8`。8 は木地の色のしきい値＝淡い木地の写真用。写真の並びは LAY に書く）。王將・玉將はそれぞれの駒から起こす。成り駒は LuffyKudo のまま。2Dも同じ字（`shogi-traced-svg.py kinki`）。

## 詰将棋のズームとレイアウト（2026-11-10）
- 玉方の駒台を隠すとき（`body.ts-noopp`）、PCでは駒台の列ごと外す。
- PC（右に列があるとき）は、攻め方の駒台を右の列の下に置く。駒台の左端は列の左端に、下端は盤枠の下端にそろえる。空いた幅の分だけ盤を大きくする。
  - 2D版：CSS（`.board-area{display:contents}`、駒台は grid-area side）。
  - フル機能版：atlas/skin/shogi.js `extraOff` / `afterSide`。
- 詰将棋の拡大は「盤の作り直し」：問題の範囲を n×n 升（5〜8）の窓として、その升だけを大きくした盤を描く（`tzWindow` / `tzStyle`、`.board.tzc`）。
  - 盤の箱の大きさは変えない。
  - 盤の縁・外周線・窓の中に入る星・窓の筋と段の数字はそのまま。
  - 3D（フル機能版）は n×n の榧の盤を作る（atlas/models/shogi.js `o.crop {c0,r0}`）。木目は9×9の盤の該当部分を使い、厚みと脚は n/9。
  - スライドで窓を1升ずつ動かす。右下のボタンで全体の盤と切り替える。
  - 座標の変換は `bgeom()`（拡大の窓 → 変則将棋の盤 → 9×9 の順）。
