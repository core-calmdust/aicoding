# 将棋（shogi/）仕様メモ

AI・評価関数・定跡などは `shogi/MODEL_CARD.md` を参照。ここにはレッスン・詰将棋の画面まわりの決定事項を書く。

## 定跡の実戦練習 = 3手の実践（2026-11-10）

- 対象：定跡 → 戦型 → 実戦練習（Floodgate の強い対局の局面から出題）。段級位別レッスン（入門〜）は従来どおり1手の問題（変更しない）。
- 1問で自分は3手指す。相手は定跡（book.json）でいちばん多く指された手を返す。定跡を外れた局面ではAI（0.7秒）。
- 1手ごとに、コーチの箱に評価（最善手・好手・疑問手・悪手と点数）、実戦での採用率、定跡の本命の手、その手の方針の解説を出す（新しい手が上）。カードには最新の評価だけを短く出す。
- 点数（1手20点、3手の平均が1問の点数。合格は従来どおり75%）：本命（いちばん多い手）20点・採用率15%以上18点・3%以上16点・それ未満12点。定跡にない手はAIの解析（1.5秒）で勝率の落ち幅から最大12点。定跡の外の局面はAIの最善手との比較。
- 3手を指し終えたら振り返り：コーチの箱に「振り返り：定跡の正しい進行」として、問題の局面からの定跡の正しい進行（その戦型の解説手順の上ならその手、なければ定跡でいちばん多い手。定跡が途切れた先だけAIの手で「(AI)」と表示。自分3手＋相手2手）を出す。自分の手が一致した手は緑、違った手は黄、相手の手は灰色。「盤で再生」で手順を盤に並べ直す。
- ボタンは詰将棋と同じ：ヒント（本命の手の動かす駒を光らせる、その手は−4点）・やり直し・答え（本命の手を代わりに指して解説、その手は0点）・一覧・次の問題（最後は「結果を見る」）。

## 詰将棋（2026-11-10）

- 途中の手に正誤を出さない（「あと◯手」だけ）。正誤はクリアした時か手数を使い切った時だけ。失敗しても正解手順は出さず、「答え」で見られる。
- カード：見出し行の右上に「やめる」、タイトルの直後に「n/N問目」、ボタンはヒント・やり直し・答え・一覧＋横長の次の問題（再生ボタンはなし）。
- 詰将棋中はコーチのパネルを出さない。創作詰将棋だけ相手の駒台を隠す（相手は残りの駒をすべて持つ約束）。

## 盤のデザイン（2026-11-10）

- 木目：落ち着いた榧の色（#e4c48e→#c9a066。明るすぎず濃すぎず、駒との差で視認性重視）に、少し揺らぐ柾目の年輪と細かい繊維をSVGフィルター（feTurbulence＋feDisplacementMap）で1枚に描く（盤いっぱい・繰り返しなし）。
- 漆黒：色味は最初のもの（#2b2622→#1f1b18）。木目は縦方向に走る細くくっきりした年輪の線（引き伸ばしたノイズの等高線）と細かい繊維で、本物の木のように不揃い。ぼかしに見えないよう線は細く、濃さは控えめで目立たない程度（screen .09）で視認性を優先。盤いっぱいの1枚で継ぎ目なし。罫線と星は金。

## 盤・駒の追加（2026-11-10）

- 盤「本榧」（天地柾、**既定の盤**。以前の保存で標準のままの人も一度だけ本榧に切り替える）：黄金色の榧、上から下へ走る年輪の線が本物の木のように揺らぎ・枝分かれする木目（控えめ、multiply .22）、照り返しはごく控えめ。デザインタブでは木目の次。
- 駒「菱湖」「錦旗」「水無瀬」：LuffyKudo さんの SVG（CC BY-SA 4.0、github.com/LuffyKudo/Shogi-Themes の 2-Kanji、成駒は赤）。大きさは本格（立体）に合わせる（viewBox を元の1.08倍）。菱湖は字の右上がりが強すぎたので、文字だけを自身の中心で時計回りに3°戻す。`shogi/pieces/{ryoko,kinki,minase}/`、クレジットは pieces/README.md とデザインタブ下の1行。既存の「本格（一文字）」（1kanji_3d）とは別物。
- 画像の駒（本格・菱湖・錦旗・水無瀬など）の表面にうっすら木目：駒の絵そのものをマスクにして、本物の駒（黄楊）のように細くまっすぐな繊細な木目を重ねる（multiply .26）。木目の位置・大きさは駒の種類と向きごとに変え、同じ種類どうしは同じ木目。メタル・漆黒の盤では出さない。
- どうぶつしょうぎ（LuffyKudo の Dobutsu Chess）は保留：元の絵柄（藤田麻衣子さん）は著作権が保護されており、lishogi も許可を得て使っているため。

## フル機能版（?skin=atlas）の盤・駒（2026-11-10）

- ~~デザインタブの「盤と駒の見た目」の先頭に「3D」タイル~~ → 2026-11-11 から共通規定どおり、2D盤の下に「3D盤」の小箱（6種のタイル）。2Dの盤を選ぶと2D表示、3D盤のタイルを選ぶとその3D盤（表示の保存キー atlas-shogi-view、盤の保存キー atlas-shogi-look＝ポータルの「盤」と共通 `Table3D.BOARDS.shogi`）。
- **3D盤は6種（2026-11-11、ユーザー指定）**：本榧（既定・従来のまま）／蒔絵（盤面は本榧、側面・脚・駒台が黒の呂色漆に蒔絵：長い面＝山水楼閣図〔楼閣・五重塔・松・波・霞・鳥〕、短い面＝扇流し、駒台＝唐草に梅の丸。ユーザーの参考写真のような実物の蒔絵盤の密度が基準）／新榧（2Dの「木目」の盤面、側面は淡いスプルースの木口）／漆黒（2Dの「漆黒」の盤面に金の線・星、側面は縞黒檀の艶）／寄木細工（淡い盤面の縁に矢羽根・四隅に市松、側面は桂の板に大きめの矢羽根の帯を1本だけ＝細かすぎる模様は不可とユーザー指摘）／山桜（山桜の盤面、縁の四隅に螺鈿の桜。側面・駒台は朱溜の漆に**螺鈿の桜と鶯**、金の平蒔絵の線＝ユーザーの参考写真の発展形。満開にしすぎない・余白を残す）。蒔絵の金は明るく（金属感をやや下げて地の金色が光で見えるように）。新榧は落ち着いたトーン、漆黒の駒台は木目ごく控えめ、寄木の盤面・駒台は桂の色で複雑な板目。
  - 絵は `images/atlas/shogi3d/`（`atlas/tools/shogi-tex.html` で描いて `atlas/tools/shogi-tex.py` で書き出す）。蒔絵は色＋（R=高さ・G=粗さ・B=金属）の2枚。盤のモデルは `atlas/models/shogi.js` の `LOOK`。
  - フル機能版のページの駒台（DOM）も盤の素材の絵（`--shstand`、`html.atlas-shbd-<look>`）。暗い盤（蒔絵・漆黒・山桜）は駒台の名前を明るい色に。
- **3D駒は6種（2026-11-11、ユーザー指定「盛り上げ駒のフォント違いで計6種」）**：盛り上げ（既定、2kanji_3d）・一字書き（1kanji_3d）・錦旗・水無瀬・菱湖（LuffyKudo）・隷書（フリーフォント「青柳隷書しも」、`atlas/tools/shogi-glyphs-font.py`。2026-11-11、楷書〔orangain〕は盛り上げと同じ字だったのでユーザー指定で隷書に入れ替え。保存値 kaisho は reisho に読み替え）。隷書は実物（ユーザーの写真）に合わせて、横に平たく太い字を面いっぱいに2字詰めて置き（下の字が大きい）、かすれの点は除く。成り駒の裏は実物どおり草書（水無瀬の成り駒の字を流用）。同じ柘植の3D駒に、2Dの各駒セットのSVGから切り出した文字を盛り上げの漆で載せる（`atlas/tools/shogi-glyphs-faithful.py` → `images/atlas/shogi-glyphs-<set>.png`、ページの駒の絵は `atlas/tools/shogi-pieces.html` → `images/atlas/shogi-pieces-<set>.png`、タイル `atlas/img/pc3-shogi-<set>.webp`）。保存キー `atlas-shogi-pc3`＝`Table3D.PIECES.shogi`（大百科の「駒」の行と共通）。フル機能版は「3D盤」の箱の下に「3D駒」の行。ライセンスは `shogi/pieces/README.md`。
  - 文字は**元の2D駒の書き方をそのまま再現**（2026-11-11 第2版。ユーザー：「オリジナルの駒と比べてバランスがイマイチ・角度が曲がっている」）。文字の線だけを元のSVGの変形ごと描き（菱湖の3°補正も含む）、駒の上面（帯は除く）に対する位置・大きさを2Dと同じにする。文字ごとの中央寄せや盛り上げの枠への当てはめはしない。一字書きだけは3D駒の屋根が2Dより急なので、肩から下の胴に対して中心を合わせる。高さは一字書きの赤駒は元の重ねた層の濃淡、それ以外は線をぼかして作る。比べる絵は 3D の真上の絵と元のSVGを並べて目で確かめる。
  - 3D盤タイルの絵（`atlas/img/boardic-shogi-<look>.webp`）は、真上からだと側面の違い（蒔絵など）が見えないので、将棋だけ斜め上（el=48）から撮る。
- 3D盤の盤面は2Dの本榧と同じ木目（images/atlas/shogi-kaya.webp：2Dの本榧の地色＋木目SVGを書き出した絵。SVGフィルターを直接canvasに描くとWebGLで使えないため）。色合いは大百科の3Dビュー（ちゃぶ台）と同じ（フル機能版も TONES の classic を使う）。
- 2Dの盤の並び：本榧＞木目＞標準＞メタル＞漆黒。
- 盛り上げ（立体）駒の絵にも、画像の駒と同じ細かい木目を重ねる（後手は回転して合わせる）。
- 駒台：フル機能版のページの駒台は本榧（shogi-kaya.webp を薄めて使う）。3D卓の駒台は元の色味のまま、木目の濃淡差を小さくしてうっすら（#d9a764／#c18a48）。
- フル機能版の床の畳（table3d.js tatamiTex、ページ背景にも使う）は実物の写真（images/atlas/tatami.webp）を縁（へり）の間に敷き、色味は淡い灰がかった黄緑（い草色）にし、濃くしない（color＋screen ブレンド）。ちゃぶ台の部屋の3Dビューの畳は以前のまま。
- フル機能版で2D盤を選んだとき（html.atlas-2d）は、3D盤とまったく同じ配置にする（atlas/skin/common.js pcFit の fit2d：3D盤で測った枠の余白 K を localStorage atlas-k2d に保存し、2Dでも同じ K で盤・駒台・右の列を配置。未測定なら shogi.js の k2d）。2Dの板は盤の ::before（地）・::after（木目）を --k2l/t/r/b だけ外に広げて描き、選んだ盤（本榧・木目・標準・メタル・漆黒）の色と木目そのまま、継ぎ目なし。駒台も同じ板。
- フル機能版3Dの駒台は3D盤の色味（ちゃぶ台と同じ TONES classic）に合わせる（本榧の絵に rgba(191,152,92,.5) を重ねる）。
- フル機能版の駒台の「先手／後手」は明朝体。
- 3Dの駒の厚みは実物に近く少し薄め（底 .26・先端に向けて −.085、×駒の大きさ）。フル機能版の駒の絵 images/atlas/shogi-pieces.png も同じ形で描き直した。
- 定跡の解説（手順を見る）のカードもパズルと同じコンパクト型（2026-11-10）：やめるは右上のピル、一覧・再生は文字付きのアイコンボタン、戻る・次へは横並び。解説中はコーチを隠し、抜けると戻す。「この局面からAIと対局」「定跡の説明に戻る」とボタン列の間隔は同じ 8px。
- 定跡の3手練習を終えたら、コーチ欄の一番上（見出しのすぐ下）に「振り返り」のボックス（見出し・合計点・定跡の手順・凡例・明るい「盤で再生」ボタン）を出し、各手の判定はその下に置く。
- フル機能版で3D盤を選んでいる間は、2Dで選んだ盤（メタル・漆黒など）の駒の色・フィルター（body.skin-*）を外し、本榧の駒で表示する。2Dに戻すと選んだ盤に戻る。

## 詰将棋のズームとレイアウト（2026-11-10）
- 玉方の駒台を隠すとき（`body.ts-noopp`）、PCでは駒台の列ごと外す。
- PC（右に列があるとき）は、攻め方の駒台を右の列の下に置く。駒台の左端は列の左端に、下端は盤枠の下端にそろえる。空いた幅の分だけ盤を大きくする。
  - 2D版：CSS（`.board-area{display:contents}`、駒台は grid-area side）。
  - フル機能版：atlas/skin/shogi.js `extraOff` / `afterSide`。
- 詰将棋の拡大は「盤の作り直し」：問題の範囲を n×n 升（5〜8）の窓として、その升だけを大きくした盤を描く（`tzWindow` / `tzStyle`、`.board.tzc`）。
  - 盤の箱の大きさは変えない。
  - 盤の縁・外周線・窓の中に入る星・窓の筋と段の数字はそのまま。
  - 3D（フル機能版）は n×n の榧の盤を作る（atlas/models/shogi.js `o.crop {c0,r0}`）。木目は9×9の盤の該当部分を使い、厚みと脚は n/9。
  - スライドで窓を1升ずつ動かす。右下のボタンで全体の盤と切り替える。
  - 座標の変換は `bgeom()`（拡大の窓 → 変則将棋の盤 → 9×9 の順）。
