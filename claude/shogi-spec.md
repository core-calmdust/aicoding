# 将棋（shogi/）仕様メモ

AI・評価関数・定跡などは `shogi/MODEL_CARD.md` を参照。ここにはレッスン・詰将棋の画面まわりの決定事項を書く。

## 定跡の実戦練習 = 3手の実践（2026-11-10）

- 対象：定跡 → 戦型 → 実戦練習（Floodgate の強い対局の局面から出題）。段級位別レッスン（入門〜）は従来どおり1手の問題（変更しない）。
- 1問で自分は3手指す。相手は定跡（book.json）でいちばん多く指された手を返す。定跡を外れた局面ではAI（0.7秒）。
- 1手ごとに、コーチの箱に評価（最善手・好手・疑問手・悪手と点数）、実戦での採用率、定跡の本命の手、その手の方針の解説を出す（新しい手が上）。カードには最新の評価だけを短く出す。
- 点数（1手20点、3手の平均が1問の点数。合格は従来どおり75%）：本命（いちばん多い手）20点・採用率15%以上18点・3%以上16点・それ未満12点。定跡にない手はAIの解析（1.5秒）で勝率の落ち幅から最大12点。定跡の外の局面はAIの最善手との比較。
- ボタンは詰将棋と同じ：ヒント（本命の手の動かす駒を光らせる、その手は−4点）・やり直し・答え（本命の手を代わりに指して解説、その手は0点）・一覧・次の問題（最後は「結果を見る」）。

## 詰将棋（2026-11-10）

- 途中の手に正誤を出さない（「あと◯手」だけ）。正誤はクリアした時か手数を使い切った時だけ。失敗しても正解手順は出さず、「答え」で見られる。
- カード：見出し行の右上に「やめる」、タイトルの直後に「n/N問目」、ボタンはヒント・やり直し・答え・一覧＋横長の次の問題（再生ボタンはなし）。
- 詰将棋中はコーチのパネルを出さない。創作詰将棋だけ相手の駒台を隠す（相手は残りの駒をすべて持つ約束）。

## レッスンの導入ページ（2026-11-10）

- ルールの箱と同じ枠：高さ固定で本文だけスクロール、下のボタンはルールの箱と同じ大きさ・位置（「一覧へ」＝閉じるの中央の枠、「はじめる」＝次への右の枠。PCは幅220px・中央寄せ）。
- 本文：問題の一例の盤面図（印なし）と、目安・問題数・合格点・形式のチップ。続いてアイコン付きのカードで「このレッスンの目標」（short）・「考え方」（intro）・「クリアの目安」（note）・「進め方」（点数・合格・ヒントの減点、準備問題がある時はその説明）。14言語（LI_TX）。

## 盤のデザイン（2026-11-10）

- 木目：落ち着いた榧の色（#e4c48e→#c9a066。明るすぎず濃すぎず、駒との差で視認性重視）に、少し揺らぐ柾目の年輪と細かい繊維をSVGフィルター（feTurbulence＋feDisplacementMap）で1枚に描く（盤いっぱい・繰り返しなし）。
- 漆黒：色味は最初のもの（#2b2622→#1f1b18）。木目は縦方向に走る細くくっきりした年輪の線（引き伸ばしたノイズの等高線）と細かい繊維で、本物の木のように不揃い。ぼかしに見えないよう線は細く、濃さは控えめで目立たない程度（screen .09）で視認性を優先。盤いっぱいの1枚で継ぎ目なし。罫線と星は金。

## 盤・駒の追加（2026-11-10）

- 盤「本榧」（天地柾）：黄金色の榧、上から下へ細く詰まったまっすぐな木目、左上にやわらかい艶。デザインタブでは木目の次。
- 駒「菱湖」「錦旗」「水無瀬」：LuffyKudo さんの SVG（CC BY-SA 4.0、github.com/LuffyKudo/Shogi-Themes の 2-Kanji、成駒は赤）。`shogi/pieces/{ryoko,kinki,minase}/`、クレジットは pieces/README.md とデザインタブ下の1行。既存の「本格（一文字）」（1kanji_3d）とは別物。
- 画像の駒（本格・菱湖・錦旗・水無瀬など）の表面にうっすら木目：駒の絵そのものをマスクにして木目を重ねる（multiply .42）。木目の位置・大きさは駒の種類と向きごとに変え、同じ種類どうしは同じ木目。メタル・漆黒の盤では出さない。
- どうぶつしょうぎ（LuffyKudo の Dobutsu Chess）は保留：元の絵柄（藤田麻衣子さん）は著作権が保護されており、lishogi も許可を得て使っているため。
