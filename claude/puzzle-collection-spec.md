# 詰めパズル共通仕様 v2（PZBook）

世界のボドゲ大全で、詰めパズルがあるゲーム（モリス・チェス・将棋・リバーシなど）すべてに使う共通の仕様です。最初の実装はナイン・メンズ・モリスです（参考実装：`morris/index.html` の puzzles セクション）。

- 実装：`shared/pzbook.js`（CSS込みの1ファイル・10言語の文言内蔵）。ゲームは `../shared/pzbook.js?v=N` を読み込みます。
- 記録はゲーム側で持ちます。問題ごとの獲得★を 0〜3 で保存します（旧形式の `true` は★3として読む）。

## 解き方（v2：規定手数まで指せる）
- 正解以外の手を指しても、その場で「失敗」にしない。相手は最善の応手を返し、**基準の手数（問題の手数）に達するまで続けて指せる**。ステータスに「あと n 手」を出す。
- 基準の手数に達して目標（詰み・ミル・箱の獲得数など）を果たせていなければ「失敗」（`PZBook.t('outOfMoves')`）。最初に外れた手と正解手を見せる。
- 手数内に目標を達成すれば別解でも正解。ただし外れた手を指したあとの正解は★★（やり直し相当）。
- **明らかなミス**の手は、その場でミスを知らせて失敗にする（`PZBook.t('blunder')`）。定義はゲームごと（例）：
  - 将棋：王手でない手／応手のあと王手が一つもなくなる手
  - チェス：1手で詰まされる手・ステイルメイト・詰ます駒がなくなる手
  - 連珠：禁手／相手の四を止めない／VCFで四でない手
  - ドット＆ボックス：取るべき箱を取らない／安全な線があるのに箱を渡す
  - 共通：相手が協力しても残り手数で目標に届かないと読み切れる手
- 基準1手の問題は従来どおり即判定。

## 構成
- **テーマ**：問題はテーマ別。目安は1テーマ50問（最低でも20問）。
  - テーマ一覧はカード形式。色（テーマの難しさ）、進捗バー、★合計（最大は問題数×3）、ステージごとのメダル、全問クリアで王冠と「コンプリート」。
  - テーマはカテゴリ（例：N手で勝て／テーマ別／ユニーク）にまとめ、カテゴリはタブで切り替える（下の「一覧ホーム」）。
- **ステージ**：各テーマを10問ずつのステージに分ける。
  - 名前は STAGE 1〜。段階名は 入門・初級・中級・上級・達人・名人。
  - 段階ごとに色が変わり、難しくなるほど暖色に（緑→水色→青→紫→ピンク→金）。
  - 問題はテーマ内で易しい順に並べる。
- **解放**：前のステージを6問クリアすると次のステージが解放される。ロック中は「STAGE n をあと○問クリアで解放」と表示。
- **★評価**：★★★＝ヒントなし・一度もまちがえずに解いた／★★＝ヒントを使った、またはやり直した（外れた手のあとの正解を含む）／★＝答えを見たあとで解いた。記録は最高値だけ残す。
- **ステージメダル**：全問クリアで銅、全問★★以上で銀、全問★★★で金。
- **問題一覧（グリッド）**：上部に進捗リング（解いた数/全数）、★合計、「続きから ▶ n」。タイルはクリア済みをステージ色で塗り★表示、次に解く問題は「NEXT」で光らせ、プレイ中の問題は白枠。
- **正解時の演出**：★が1つずつ飛び出す＋ステージ進捗バー。ステージクリア（メダル獲得）・メダルの格上げ・次ステージ解放・テーマのコンプリートが起きたら追加表示し、紙吹雪を2回。正解音はリバーシの「ピ〜ンポ〜ン」（鐘のような2音）に揃える。
- 「次の問題」は解放済みの範囲でだけ進める（テーマの最後で止まる）。
- **今日の一問**：一覧ホームの上部。連続日数を表示。

## 一覧ホーム（規定：詰めオセロと同じ構成）
全ゲームで詰めオセロ（リバーシ）と同じ構成にし、`shared/pzbook.js` の `PZBook.home()`（`bindHome / ghead / resume / icon`）で組み立てる。参考実装：将棋・チェス・五目並べ・ドット＆ボックス・モリス（リバーシは独自実装 .pzx で同じ見た目）。上から次の順：
1. **ヒーローカード**：全体の進捗リング（解いた数／総数）、タイトルと「N問」バッジ、2〜3行の説明、★合計と金・銀・銅メダル数、「続きから ▶ No.N」ボタン（最後に遊んだテーマ名付き。そのテーマを解き終えていれば同じカテゴリの未完テーマへ進む）。
2. **今日の一問カード**：ミニ盤面、日付、テーマ、連続日数、挑戦ボタン。
3. **カテゴリタブ**：SVG アイコン、名前、解いた数／総数。その下に1行のカテゴリ説明。
4. **テーマカードのグリッド**（PC は3列、スマホは1〜2列）：「次に解く問題」の局面を各ゲームの SVG ミニ盤で大きく表示し、手番マークと番号またはアイコンのバッジを付ける。テーマ名、5段階の難易度ピップ、2行の説明、n/N の進捗バー、ステージメダル、★数。カードの色は難易度ティアで決める。

カードを開くとテーマ見出し（バッジ、名前、説明、カテゴリ・問題数のチップ、難易度）の下に `PZBook.grid` のステージ画面を出す。ルール切り替えなどゲーム固有のタブはホームより上に置く。ダイアログの大きさはタブを切り替えても変えない。新しい文言は10言語、アラビア語は右から左（盤面と数字は左から右）。

## ルール違いがあるゲーム
- ルールの違いはタブで切り替える（例：モリスのナイン／トゥエルブ／シックス）。レッスンも同じタブで切り替える。
- データはルール別ファイル（例：`puzzles.json` / `puzzles-twelve.json` / `puzzles-six.json`）。
- 記録はルール別に保存し、保存キーに接頭辞を付ける（例：`twelve:win1-3`）。標準ルールは接頭辞なし。
- 今日の一問は標準ルールから出す。

## 組み込み方（PZBook API）
- `PZBook.setLang(lang)` … 表示言語。
- `PZBook.home(...)` / `PZBook.bindHome(...)` / `PZBook.ghead(...)` / `PZBook.resume(...)` / `PZBook.icon(...)` … 一覧ホーム（上記）の組み立て。
- `PZBook.card({ i, no, name, sub, recs, tier })` … テーマカードのHTML（`recs` は★配列、`tier` 0〜5 はテーマの難しさ）。クリックは `.pb-card[data-i]`。
- `PZBook.grid({ recs, cur })` … 問題一覧のHTML。タイルは `button[data-j]`、ロック中は `aria-disabled`（クリック時は `PZBook.t('locked')` をトースト）。
- `PZBook.isOpen(recs, j)` … その問題が解放済みか（「次の問題」ボタンの可否に使う）。
- `PZBook.starsFor({ hinted, failed, answered })` … 今回の★数。
- `PZBook.events(before, after, j)` … 正解で起きたイベント（ステージクリア等）。
- `PZBook.solved({ stars, recs, j, events })` … 正解時の演出HTML（ステータス欄に追加）。events があれば紙吹雪をもう1回。
- `PZBook.t('movesLeft', {n})` / `PZBook.t('blunder')` / `PZBook.t('outOfMoves', {n})` / `PZBook.t('retry')` … v2 の解き方の文言（10言語）。
- `PZBook.STAGE`（10）、`PZBook.t(key, vars)`。
