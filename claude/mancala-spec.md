# マンカラ（mancala/）仕様メモ

コード（`mancala/engine.js`・`app.js`・`coach.js`・`rvcoach.js`）が実質の仕様。ここではルールの種類と、2026-11-06〜07 に追加した世界の伝統ルール（オワレ・マンガラ・ボーネンシュピール・アヨアヨ）まわりの決定事項をまとめる。

## ルール（8種）
| id | 名前 | 内容 |
|---|---|---|
| basic | ノーマル（初級） | 横取りは相手の種だけ（最後の1粒は残る） |
| easy | イージー（入門） | 横取りなし。まき方と「もう一回」だけ |
| kalah | カラハ（中級・標準） | 相手の種と最後の1粒をまとめて横取り |
| sunka | スンカ（上級） | リレーまき＋カラハの横取り |
| oware | オワレ（上級） | ガーナの伝統ルール。下記 |
| mangala | マンガラ（中級） | トルコの伝統ルール。下記 |
| bohnen | ボーネンシュピール（中級） | ドイツ・バルト地方の豆遊び。下記 |
| ayo | アヨアヨ（上級） | ナイジェリア（ヨルバ）の遊び。下記 |

- 1穴の種は 4 / 6 粒（全ルール共通の設定）。ボーネンシュピールのカードを選ぶと 6 粒に切り替わる（原典が6粒）。

### オワレ（Abapa 準拠。出典：Wikipedia「Oware」）
- 反時計回りに1粒ずつまく。**ストアには入れない**（自分・相手とも飛ばす）。「もう一回」はない。ストアは取った種の置き場。
- 12粒以上の穴をまくと、**まき始めた穴を飛ばす**（1周しても空のまま）。
- 最後の1粒が相手の穴に入り、その穴が**ちょうど2か3**になったら取る。手前（さかのぼる方向）の相手の穴も2か3なら続けて取る（相手の列の中だけ）。
- **グランドスラム**（相手の列の種を全部取る形）：指せるが**1粒も取らない**（国際大会でよく使われる扱い）。
- 相手の列が空のときは、**相手に種が届く手**しか指せない。届く手がなければ終局し、盤に残った種はそれぞれの側の持ち主のもの。
- 全体の半分を超えたら勝ち（4粒：25 / 48、6粒：37 / 72）。半分ずつは引き分け。
- **千日手**：同じ局面（盤＋手番）が3回目になったら終局し、それぞれ自分の列の種を取る（`engine.replay` が判定し `mv.cycle`）。探索は千日手を考えない。

### マンガラ（トルコの大会ルール。出典：World Ethnosport Confederation「Mangala」ほか）
- ストアにまく（相手のストアは飛ばす）。ぴったり自分のストアで「もう一回」。
- 2粒以上の穴は**最初の1粒を元の穴に戻して**からまく。1粒だけの穴は隣へ動かす。
- 最後の1粒が相手の穴に入り**偶数**になったらその穴を全部取る。自分の空き穴に止まり向かいに種があれば、向かい＋その1粒を取る。
- どちらかの列が空になったら終局。**列が空になった人が反対側の残りを全部取る**（資料により「最初に空にした人が取る」と記述）。

### ボーネンシュピール（出典：Wikipedia「Das Bohnenspiel」、iggamecenter）
- 1穴6粒（72粒）。ストアにはまかない。12粒以上でも起点は飛ばさない（原典に記述なし）。
- 最後の1粒で**どちらの列でも**穴が2・4・6粒になったら取る。手前（さかのぼる方向）の穴も2・4・6なら続けて取る（列をまたいでよい、最大12穴）。
- 手番の人に種がなければ終局し、残りの種はもう一方の人のもの（実装上は、手を指した直後に相手の列が空なら、指した人が自分の列を取る）。

### アヨアヨ（出典：Wikipedia「Ayoayo」、J. P. Pratt）
- 1穴4粒。ストアにはまかない。リレーまき：最後の1粒が種のある穴に入ったら全部拾ってまき続ける。**各回のまき始めの穴は飛ばす**。空の穴に止まったら終わり。
- 自分の列の空き穴に止まり、向かいに種があれば**向かいの種だけ**を取る（最後の1粒は残る）。
- 相手の列が空なら種を渡す手しか指せない（シミュレーションで判定）。動けない人が出たら終局し、もう一方が残りを取る。渡せずに終局した場合は渡せなかった側が自分の列を取る。
- 原典の「渡せる手があったのに渡さなかった場合の罰則」は、渡さない手を合法手から外すことで不要にした。

### 千日手（オワレ・ボーネンシュピール・アヨアヨ）
- 同じ局面が3回目になったら、それぞれ自分の列の種を取って終局（`RULES[r].cyc`）。

### エンジン
- `RULES.oware`（`oware:true`）。`legal(b, side, rules)` は種を渡す義務を反映（rules を省くと従来どおり＝空でない穴）。`isLegal` / `canFeed` / `stuck` を追加。
- trace のイベント：`cap`（取った穴ごとに1つ、`chain` は何番目か）、`slam`（グランドスラム）、`sweep`（渡せず終局）。trace に `caps`（取った穴の数）・`slam`・`fed`。
- 評価（`evalOware`）：取った数の差＋自陣の種・相手の1〜2粒の穴（的）・今すぐ取れる量（`owareCap`、グランドスラムは0）。重みは `WO`。固定深さ6で「評価なし（取った数の差だけ）」に 26勝11敗3分。レベルは Lv.3<Lv.5<Lv.7<Lv.9 の順に強いことを対戦で確認。
- カラハ系4ルールの手・AIの選択は変更前と一致（ランダム局面で照合）。

## 対局設定「ゲーム」タブ（2026-11-06）
- 4×2：上段「ストアにまくルール（ぴったりストアで“もう一回”）」ノーマル・イージー・カラハ・スンカ、下段「世界の伝統ルール（国や地域ごとの取り方）」オワレ・マンガラ・ボーネンシュピール・アヨアヨ。
- 入門・中級などのタグは**名前の横**（カラハは「標準」も）。説明文はカードで2〜3行に収まる短さにする。
- PC：1280×720〜1920×1080・1100×1300 でスクロールなし（10言語で計測。独仏西葡は説明文を少し小さく）。高さ780px以下では「ルール」ボタンを絵の右下に重ね、絵は左寄せ。
- スマホ縦：各段 2×2（シートはスクロール）。スマホ横：各段を横1列。
- 各カードの「ルール」ボタンは、そのルールのページを開く（オワレは `owSow` から）。

## ルール説明（`shared/ruletour.js`）（2026-11-07 ルール別に分割）
- ルールごとに別のコース（RuleTour をルールごとに1つ、`RT_COURSES`）。上に8ルールの切り替え行（PCは1列、スマホは4×2。名前は短縮名 `rule.<id>.s` があればそれ）。全ステップを終えたルールに ✓。
  - ノーマル：紹介・まき方・もう一回・横取り（ノーマル）・終局・ルールの違い／イージー：紹介・まき方・もう一回・終局・ルールの違い
  - カラハ：紹介・まき方・もう一回・横取り・終局・ルールの違い／スンカ：＋リレーまき
  - オワレ：紹介・まき方・取り方・まとめ取り・12粒以上・種を渡す・グランドスラム・勝ち負け・ルールの違い
  - マンガラ：紹介・まき方・取り方・終わり方・ルールの違い／ボーネンシュピール：紹介・取り方・終わり方・ルールの違い／アヨアヨ：紹介・リレーまき・取り方・ルールの違い
- 進み具合（クリア済みのステップ）は全コース共通の `mancala-rules-v2`（同じページは一度クリアすればどのコースでも ✓）。最後に見たコースは記憶。
- メニュー・初回案内から開くと、いま遊んでいるルールのコース（レッスン・パズル中は最後に見たコース）。対局設定のカードの「ルール」からはそのルールのコースを紹介の次のページから。最後のページの「対局してみる」はそのルールを選んだ状態で対局設定を開く。
- どのページも実際にまいて確かめる課題つき。ストアにまかないルールのページは盤の下に「右があなたの取り分」と表示。

## 対局中の表示（オワレ）
- 種が届かない穴は選べない（光らせない・押すと「相手に種が届く穴を選んでね」）。
- 取りは取った穴をすべて光らせ、バナーは合計数。グランドスラムは「グランドスラム／全部は取れません」。
- 終局ダイアログに終わり方（25粒以上・渡せず終局・千日手・引き分け）。
- コーチ・振り返り解説はルール別の文言（オワレ：`i18n-oware.js`、他3ルール：`i18n-world.js` の RULE ＋共通 WCOACH / WRV。`MANCALA_RULE_TX[rule]` を上から順に引き、無ければカラハの文言）。

## 対局設定の Pro モード（2026-11-08）
対局設定の「AIの強さ」の PRO ボタン（`shared/proset.js`、addendum「対局設定の Pro モード」）。項目：思考の制限（時間 0.1〜30 秒／深さ 1〜30）、手のばらつき（深さのときだけ。変えると 小 30／大 140）。Lv.1〜3（でたらめ・欲ばり）は変えると深さで読む AI になる。engine.js `chooseMove` の `cfg`（`{ kind: 'depth', depth, noise }` か `{ kind: 'time', ms }`）。レート戦では使わない。戦績のキーは `ai:pro…`、相手名に「PRO」。

## 本編のマルチスレッド（2026-11-08、`shared/mtsplit.js`）
- ウゴルキ等と同じ**ふつうの Worker の組**（共有メモリなし・分離なし・再読み込みなし。ログイン・オンラインはそのまま）。オプション（歯車）の「マルチスレッド」は他のゲームと同じ選択（PC は自動でオン、スマホ・タブレットは1スレッド）。
- 方式：ルートの手と本筋の分担（Young Brothers Wait、残り深さ6以上の節点を分ける。もう一回の手番（自分の倉で終わる手）は符号を変えずに子の値を使う。`mtKids` が search() と同じ手・同じ順を返す）。解析は全部の手を深さごとに全幅で分け合い、全部が読み切り（`exact`）になったら止める。
- 使う所：分析・ヒント・コーチ・振り返りボックス（`bxAnalyze`、読み筋8手も手ごとに並列）・時間で考える Lv.8〜10。Lv.1〜7（手筋・深さ固定）は1スレッド。PRO の「スレッド数」：時間でも深さでも（深さは全部の手の値を並列に出してから手のばらつき）。情報行の末尾に全スレッド合計の nps。
- 確認：深さ固定（9）の値と手が1スレッドと全ルール一致（カラハ・オワレ・マンガラ・アヨアヨ・ボーネンシュピール、置換表を空にして比較）。計測ページ `mancala/bench.html`（深さ固定の時間比、解析・AIの手の読めた深さ）。
- カラハ（6穴4粒）は完全解析済み（先手勝ち）。Lv.10 は1.8秒で終盤を読み切る深さに届くので、最上位レベルは足さない（速さのためだけに対応）。
