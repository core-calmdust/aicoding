# マンカラ（mancala/）仕様メモ

コード（`mancala/engine.js`・`app.js`・`coach.js`・`rvcoach.js`）が実質の仕様。ここではルールの種類と、2026-11-06 に追加したオワレ（Oware）まわりの決定事項をまとめる。

## ルール（5種）
| id | 名前 | 内容 |
|---|---|---|
| basic | ノーマル（初級） | 横取りは相手の種だけ（最後の1粒は残る） |
| easy | イージー（入門） | 横取りなし。まき方と「もう一回」だけ |
| kalah | カラハ（中級・標準） | 相手の種と最後の1粒をまとめて横取り |
| sunka | スンカ（上級） | リレーまき＋カラハの横取り |
| oware | オワレ（上級） | アフリカ（ガーナ）の伝統ルール。下記 |

- 1穴の種は 4 / 6 粒（全ルール共通の設定）。

### オワレ（Abapa 準拠。出典：Wikipedia「Oware」）
- 反時計回りに1粒ずつまく。**ストアには入れない**（自分・相手とも飛ばす）。「もう一回」はない。ストアは取った種の置き場。
- 12粒以上の穴をまくと、**まき始めた穴を飛ばす**（1周しても空のまま）。
- 最後の1粒が相手の穴に入り、その穴が**ちょうど2か3**になったら取る。手前（さかのぼる方向）の相手の穴も2か3なら続けて取る（相手の列の中だけ）。
- **グランドスラム**（相手の列の種を全部取る形）：指せるが**1粒も取らない**（国際大会でよく使われる扱い）。
- 相手の列が空のときは、**相手に種が届く手**しか指せない。届く手がなければ終局し、盤に残った種はそれぞれの側の持ち主のもの。
- 全体の半分を超えたら勝ち（4粒：25 / 48、6粒：37 / 72）。半分ずつは引き分け。
- **千日手**：同じ局面（盤＋手番）が3回目になったら終局し、それぞれ自分の列の種を取る（`engine.replay` が判定し `mv.cycle`）。探索は千日手を考えない。

### エンジン
- `RULES.oware`（`oware:true`）。`legal(b, side, rules)` は種を渡す義務を反映（rules を省くと従来どおり＝空でない穴）。`isLegal` / `canFeed` / `stuck` を追加。
- trace のイベント：`cap`（取った穴ごとに1つ、`chain` は何番目か）、`slam`（グランドスラム）、`sweep`（渡せず終局）。trace に `caps`（取った穴の数）・`slam`・`fed`。
- 評価（`evalOware`）：取った数の差＋自陣の種・相手の1〜2粒の穴（的）・今すぐ取れる量（`owareCap`、グランドスラムは0）。重みは `WO`。固定深さ6で「評価なし（取った数の差だけ）」に 26勝11敗3分。レベルは Lv.3<Lv.5<Lv.7<Lv.9 の順に強いことを対戦で確認。
- カラハ系4ルールの手・AIの選択は変更前と一致（ランダム局面で照合）。

## 対局設定「ゲーム」タブ（2026-11-06）
- 2つの見出しで分ける：「ストアにまくルール（ぴったりストアで“もう一回”）」に 4 枚、「アフリカの伝統ルール（ストアは取った種の置き場）」にオワレ 1 枚。
- PC：4 枚を横1列、オワレは横長カード（左に絵、右に説明）。1280×720 でスクロールなしに収まる高さ（絵の高さは画面の高さから計算）。
- スマホ縦：4 枚は 2×2、オワレは横長（絵が左）。スマホ横：4 枚を横1列。
- 各カードの「ルール」ボタンは、そのルールのページを開く（オワレは `owSow` から）。

## ルール説明（`shared/ruletour.js`）
- 共通 → ルールの違い → ノーマル → スンカ → **オワレ 7 ページ**（まき方／取り方／まとめ取り／12粒以上／種を渡す／グランドスラム／勝ち負け）。どれも実際にまいて確かめる課題つき。オワレのページは盤の下に「右があなたの取り分」と表示。

## 対局中の表示（オワレ）
- 種が届かない穴は選べない（光らせない・押すと「相手に種が届く穴を選んでね」）。
- 取りは取った穴をすべて光らせ、バナーは合計数。グランドスラムは「グランドスラム／全部は取れません」。
- 終局ダイアログに終わり方（25粒以上・渡せず終局・千日手・引き分け）。
- コーチ・振り返り解説はオワレ用の文言（`i18n-oware.js` の COACH / RV。カラハ専用の「もう一回」「空き穴の横取り」の話をしない）。
