# さめが〜め POP! 仕様 v5.1

さめがめ（同じ色のブロックをまとめて消す）を、まいにち数独と同じポータル型に作り直したもの。`samegame/`。
経済圏（コイン・アイコン・スタンプ・背景）は独自。

## デザイン（確定）
- **既定はヴィンテージ（skin `vintage`）**。設定の並びはヴィンテージ→ミッドセンチュリー→クラシックPOP→リソグラフ→ナイトPOP→スイス・ミニマル→和モダン→ドット絵。`?skin=` でも指定可。保存済みの配色がある人はそのまま
- ミッドセンチュリー（`mid`）：マスタード #E8B83A・ティール #2E6F8E・バーントオレンジ #D9622B・オリーブ #7A8B3A・サーモン #D98C7A・プラム #5E4B6B、クリーム地 #F2EADB。キャラ等はフラット描画（`art.js` の `setStyle('mid')`→`midify`）
- フォント：見出し Kaisei Decol＋Jost、本文 Murecho。文字は大きめ

## PCレイアウト
- ホーム：左上にプロフィール（キャラ＋スタンプ、名前は中央・直接編集可、LVとコイン横並び、成績、ガチャ等のショートカット）、右に1列タブ（デイリー／ステージ／アクション）
- デイリー：デイリーパズル（3難易度）とカレンダー＋ログインボーナス進行を1ボックスに統合／デイリーアクション（BLITZ・ORDER・FUSE・DIVE）＋フリープレイ（設定はボックス高さに合わせて均等配置）
- ゲーム画面：左パネル330px（スコア、進捗、ルール・しかけ説明、ベスト、待った／やりなおし／ヒント）、右は盤エリア
- 戻るときはゲーム内の確認UI（つづける／ホームにもどる）
- スマホのアクションタブは1モード1行のリスト（ミニアイコン・名前・ベスト・あそぶ・?）

## チュートリアル・ルール説明
- 「あそびかた」「ルール説明」のタイトルロゴと幾何学の背景（ページ送りと紛らわしい丸・×の飾りは撤去）。左にさめ＋吹き出し、右にデモ盤
- しかけテーマは初回にルール説明（`DEMOS.th_*`）。ホームの「?」からいつでも見られる

## ルール（変則）
- セル＝色|種類<<4。種類：N0 ROCK1 ICE2 BOMB3 WILD4 PAINT5 PEARL6 ICE2(かたいこおり)7 ROW8 COL9 PRISM10 HID11 CHAM12
- かたいこおり：となり消去2回で通常に／ライン：横一列・縦一列を消去／プリズム：同じ色を全消去／なぞ：となりを消すと正体が出る／カメレオン：1手ごとに次の色へ
- 爆発系（ボム・ライン・プリズム）は連鎖。真珠は爆発で壊れない
- 点数（パズル系）：(n−2)²、全消し+1000

## ステージ
- 15テーマ×50問＝750問。10問ずつSTAGE 1〜5、前のSTAGE 6問で解放、★3/★2/★1（待った・やりなおしで★2、ヒントで★1）
- 生成：`tools/gen-stages.js`＋`tools/gen-stages-ex.js`。全問全消し確認済み・解答手順つき

## デイリー
- パズル3難易度（8×10・3色／10×14・4色／12×16・5色）。2026-10-22 以降は新ブロックもしかけ抽選対象
- **スコア補正（2026-10-23 の盤から）**：最終スコア＝基本スコア（全消し+1000込み）＋補正
  - 待った1回ごとに −5%（最大 −50%）
  - 待ったなしでクリアすると +10%
  - タイムボーナス 最大+30%：基準時間 かんたん60秒／ふつう150秒／むずかしい300秒。0秒で+30%、基準時間で+15%、基準の2倍以上で0（直線）
  - 計測は盤を開いた時点から。やりなおしで時間と待った回数はリセット
  - ゲーム中は左パネルに経過タイムと待った回数、結果画面に内訳を表示。ランキング・ベスト・コインは補正後のスコア
- デイリーアクション BLITZ・ORDER・FUSE・DIVE：全員同じ盤、各1日3回

## アクションモード
- 共通：コンボ、FEVER、詰まったらシャッフル（ORDERだけは詰み＝即ゲームオーバー「NO MOVES!」）
- BLITZ 60／RISE／ORDER（60秒、注文の色を3個以上で +300×連続・+2秒）／FUSE（導火線、燃え尽きで爆発演出）／DIVE（真珠回収、落とせなくなったら打ち切り）
- アクション用しかけ：ヒーロー、インク、ボム、いわ、こおり、にじ、ライン、プリズム、かたいこおり、なぞ、カメレオン
- ミッション30：ROOKIE/HERO/LEGEND 各10、BLITZ・ORDER・FUSE・DIVE・RISE 各6問。目標は点数・大消し・コンボ・FEVER・ヒーロー・生存秒・注文回数・真珠回収

## 経済圏
- コイン：ステージ★、デイリー、フリー、アクション、ミッション★、実績、ログインボーナス（7日周期 30〜300）
- **ガチャ 1回300／10回2,700**（10個目SR以上）、N55/R28/SR12/SSR4/UR1%。かぶり返却 N10・R25・SR60・SSR150・UR500
- ガチャの中身はアイコン・スタンプ・背景の共通プール（レア度を引いてから同レア度の全アイテムから抽選）
  - アイコン（キャラ）240：12種×8バリエ＝96、UR4、12種×アクセサリ11（王冠・リボン・シルクハット・ヘッドホン・花・パーティ帽・天使の輪・キャップ・音符・新芽・ツノ）＝132、UR8（金色＋王冠）
  - スタンプ120：24モチーフ（形15・文字9）×5色。金色はレア度+1。プロフィールのキャラのまわりに3つまで貼れる（左上・左下・右下）
  - 背景50：初期8種＋10柄×4配色（ミント・ピーチ・レモン・ナイト）＋UR2（ゴールド・ギャラクシー）
- ショップは廃止（購入済み背景はそのまま）。着せかえはプロフィール編集のタブ（アイコン／スタンプ／背景）
- 図鑑はタブ（アイコン／スタンプ／背景）、合計410種。実績：コレクション50・200・全種
- 保存：`own`（キャラ）、`stamps`、`stEq`（装着スタンプ）、`bgOwn`、`bg`。クラウド同期でマージ

## アカウント・ファイル
- 匿名認証 → Google連携、`same/sync/{uid}` にクラウド同期
- `engine.js` ルール・ソルバ／`art.js` 絵（キャラ・スタンプ・背景）／`app.js` 本体（`window.SameApp` にテスト用フック）／`app.css`／`i18n.js`・`i18n-more.js`（10言語）／`online.js` ランキング（`same/` 以下）
- 保存キー `samegame-pop-v1`
- ランキング：same/d/{日付}/pe・p・ph・b・o・f・v、same/m/{年月}、same/t
