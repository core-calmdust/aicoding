# ブラックジャック（blackjack/）仕様メモ

- 用語：日本語は「バースト」（「バスト」は使わない）。卓上の英字ラベルは BUST。
- 土台：バカラ／ポーカーのテンプレ（同じCSS・ヘッダー・新規ダイアログ・研究／統計／レッスン／ルールの枠、チップ・$表記、持ち金 D.chips 引き継ぎ・START 10,000）。
- ルール（新しいゲーム→ゲームタブ）：ベガス・ストリップ／ヨーロピアン（ノーホールカード、ダブル9〜11、スプリット2手、サレンダーなし）／スパニッシュ21（10抜き48枚、21は必ず勝ち、ボーナス21、何枚目でもダブル、Aスプリット後も引ける）／フリーベット（ハード9〜11のダブルと10以外のスプリットが無料、ディーラー22は引き分け）。難易度（レベル）選択は入れない（ユーザー判断で現状維持）。
- 特別ルール（ゲームタブのトグル、ルールごとに対象が違う）：ディーラーS17/H17、サレンダー、BJ配当3:2/6:5、スプリット後のダブル、サイドベット（パーフェクトペア・21+3、スパニッシュは21+3のみ）。ルールタブ：デッキ数（1/2/6/8）、カウント表示。
- 卓：5席（表示は左から 5 4 3 2 1、プレイ順は1→5）。自分は中央3番。SVGの卓印字＋カードは絶対配置。自分のカードはディーラーのカードと重ならない高さに収まるよう自動で縮小。スプリットした手は席の幅に収まるよう縮小して横並び。BOTの勝敗は合計の札の色（勝ち＝黒地に金、負け＝薄く）。
- サイドベット：自分のPP/21+3はボタン大のスポットをメインの円の斜め前に（透明のタップ範囲はメインの円の下に描いてメインを優先）。スマホではBOTの空のサイドスポットは描かない。
- BOT：Sam（ハイローのカウンター）、Aiko（バーストしない打ち方・サイドベット好き）、Marco（マーチンゲール、インシュランスを必ず取る）、Lin（基本戦略・一定額）。
- エンジン（engine.js）：残りの組成から各手の期待値を計算（無限デッキ近似、再スプリットなし、デッキ数補正・スパニッシュのボーナスは概算）。基本戦略表はこの計算から自動生成（cellEVs で1マスの各手の期待値）。ハウスエッジ：6D S17 DAS LS 3:2 ≈0.48%。
- 学習：シュー（見出し1行目＝タイトルとカウント表示ボタン、2行目＝残り枚数）、基本戦略表、コーチ（右上にON/OFFスイッチ。各手の期待値・理由・採点・🔎逸脱・インシュランス・資金プラン。ヒット／スプリット後は「状況が変わりました」ブロック：引いたカードと新しい合計、次の1枚でバーストする確率と期待値の変化（前→今）、新しい局面の考え方）、統計、研究、16レッスン、ルールチュートリアル、盤上チュートリアル（初回ポップアップ、Space/Enterで進む）。
- 研究：大きめのダイアログ（PC 最大1280×960）、文字は大きめ。配色・フォントは通常のテーマのまま（黒×金・明朝の装飾はユーザー判断でやめた）。
  - 基本戦略表：大きな表1枚（ハード／ソフト／ペア切替）＋右に「この場面」インスペクター（マスにホバー／タップで各手の期待値バー、次善の手との差、理由）と覚え方のコツ。凡例とハウスエッジは表の下。行の高さは画面の高さに合わせて伸縮（PCでスクロールなし）。
  - ハウスエッジ：上段＝ハウスエッジ＋1時間の損／ルール別、下段3列＝ルールの損得・デッキ数・サイドベット。
  - カウンティング・戦い方の検証も同じパネル様式。スマホはルール欄を1行の要約に折りたたみ。
- 資金リセット・破産時の再補充では session.buyin も START に戻す（資金プランの目標・損切り判定の基準。バカラも同様）。
- 差分描画（morphKids）は消える要素を先に削除してから並べ替える（残る要素を動かすとCSSアニメが再生され、カードが配り直されるように見えるため。ポーカー・バカラも同様）。
