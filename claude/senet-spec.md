# セネト（senet/）設計仕様

世界のボドゲ大百科のタイトル。カテゴリ「ヒストリカル」（cat: `hist`）の第2作（第1作はウル、`claude/ur-spec.md`）。台帳の色 `#8c9a2e`。
テーマ：古代エジプトの「通過」のゲーム。ツタンカーメン王墓の黒檀×象牙の箱型盤を、2Dでも3Dでも「その現物で遊ぶ」感覚で。
構造はウル（`ur/`）を手本にしたフォーク。サイコロの代わりに4本の投げ棒。

## 1. ルール（ケンドール式 ＝ 採用）
古代のルールは残っていない。現代の復元のうち最も広く遊ばれるティモシー・ケンドール（1978/79）系を採用。根拠と異説は `senet/tools/RULES-RESEARCH.md`。
- 盤 3行×10列、道は逆S字：1→10（上段 左→右）、11→20（中段 右→左）、21→30（下段 左→右）、31＝盤外（上がり）。
- 駒：`std` 各5枚（既定）／`long` 各7枚（ケンドールの原案）。1〜10（`long` は 1〜14）に交互に並べ、先手が奇数マス。
- 投げ棒4本（片面が白）：白の本数 1〜4 がそのまま進む数、全部黒＝5。確率 1:4/16, 2:6/16, 3:4/16, 4:1/16, 5:1/16。**1・4・5 はもう一度投げる**（パスになっても）。
- 動かせる手があれば必ず動かす。なければパス。
- 自分の駒のマスには止まれない。相手の駒が1枚だけのマスに止まると**入れ替わる**（相手の駒は自分の出発マスへ）。
- 2枚以上並んだ相手の駒は入れ替えられない（ペア）。**3枚以上並ぶと壁**で、越えられない。
- 26「美の家」には必ずちょうど止まる（26を越える手は不可）。26・28・29・30 は安全（入れ替え不可）。
- 26 から：1→27「水の家」に落ちて 15「再生の家」へ戻る（15がふさがっていればその手前の空きマス）／2→28／3→29／4→30／5→上がり。
- 28 は 3、29 は 2、30 は 1 のちょうどでのみ上がり。それ以外の動きはない。
- 全部上がった方の勝ち。

## 2. 座標と描画（`senet/board2d.js` → `window.SenetBoard2D`）
- `coords(rule, side, i)` → `[r, c]`：r = floor((i−1)/10)、c = r==1 ? 9−k : k（k=(i−1)%10）。両者同じ道。
- 横（h）：cellXY = ((c−4.5)·100, (r−1)·100)。縦（v）は h を −90° 回したもの：((1−r)·100, (c−4.5)·100)。3D の盤も同じ回転で縦にする。
- 盤の絵は手続き生成のSVG（象牙・黒檀・ファイアンス・パピルス・夜空のフィルタ、マスの聖刻文字：15 アンク、26 ネフェル×3、27 水、28 III、29 II、30 ウジャトの目、各マスに小さな番号）。
- デザイン：盤 `tut`（ツタンカーメン：黒檀×象牙・金縁、既定）／`faience`（青いファイアンス）／`papyrus`（パピルス画）／`night`（夜空・モダン）。駒 `tut`／`faience`／`gold`／`modern`。
- 駒の形：side0＝糸巻き（spool）、side1＝円錐（cone）。3/4 見下ろしで描く。
- 投げ棒：`dice(host,{style})` → `{roll, show, setStyle}`。盤の両脇の帯（stickBox）で投げる。
- `mini(state, opts)`：チュートリアル・カード用の同じ絵。

## 3. エンジン（`senet/engine.js` → `window.SenetEngine`。Node でも require 可）
- API：`RULES, PROB, AGAIN(n), newGame(rule, first), legalMoves(s, n), apply(s, m, n) → {state, again}, rollDice(rng), key, moveText, winProb, evaluate, think(s, n, level, {rng,timeLimit}), hitRisk, raceCount, setNet` ほか。
- AI：expectiminimax ＋ TD(0) 学習の価値ネット（64入力・48隠れ、leaky ReLU。`tools/train_td.js` で15万局、`tools/embed_net.js` で engine.js に埋め込み）。
- レベル1〜20：ランダム手の混ぜ率で強さを作る（L1 100% … L17以上 0%）、深さ 1（L1–12）／2（L13–18）／3（L19–20、L20 は時間を長く）。温度式（softmax）は弱くなったので不採用。深さ4は3より強くならなかった。
- 投了寸前（最善でも勝率 3% 未満、L4以上）は「粘る手」（評価の logit 最大）を選ぶ。
- レート表 `RT_LV`（app.js）は `tools/ladder.js` で L10 相手に測った値から。強さ・探索を変えたら自己対局で確認してから。

## 4. 画面（ウルと同じ構成）
- テーマ：黒檀の茶 `#130c07` ＋ 金 ＋ トルコ石。横長盤のPCレイアウト（盤上段、情報を下に横一列）。スマホ縦は盤を縦に。
- ルール違い（ゲームタブ）：標準（5枚）／ロング（7枚）。
- 棋譜：「⇄」入れ替え、「↻」もう一度、「27≈15」水に落ちて戻った先。
- コーチ（`senet/coach.js`、8言語は `coach-i18n.js`＝`tools/build_coach_i18n.py` で生成）：勝率・レース差・壁・上がり数、方針（上がり／入れ替え／美の家／出口へ／ペア／壁／逃げる／安全／前進／水）、入れ替えられる確率、投げ棒の確率。
- オンライン：「準備中」（`firebase-config.js` は null）。
- 10言語：`senet/i18n.js` は `tools/build_i18n.py`（ウルの i18n ＋ `tools/i18n_over.py`）で生成。
- localStorage：`aicoding-senet`、`aicoding-senet-rules`（ルールツアー）、`aicoding-senet-online`、記録は `atlas-rec-senet`。

## 5. 学ぶ
- ルールツアー `senet/tour.js`（10言語、本物の盤で投げて動かす）：紹介 → 盤と道 → 投げ棒 → 進む → 自分の駒 → 入れ替え → ペア → 壁 → もう一度 → 美の家 → 水の家 → 出口 → パス → 勝ち。
- 紹介の史実（確実なものだけ）：名前は「通過」の意。第1王朝（前3100年頃）の断片、確実な最古の絵はサッカラのヘシラー墓（前2600年頃）、ネフェルタリ墓の壁画、ツタンカーメンの副葬品の盤、『死者の書』第17章。
- レッスン9（`lessons.json`）／パズル198問（`puzzles.json`）：`tools/gen_learn.js` が `tools/learn_themes.js`・`learn_text.js` から生成（テーマ：確率・入れ替え・ペア・逃げる・安全・美の家・水・出口・レース）。

## 6. 3D（ポータル・`?skin=atlas`）
- `atlas/models/senet.js`：ツタンカーメン風の黒檀の箱（金の縁、引き出し、ライオン脚の台とそり）。天板は board2d の絵をテクスチャに（board2d が未読込なら `../senet/board2d.js` を自分で読む）。
- `atlas/skin/senet.js`：全画面スキン（縦向きは盤を −90°）。`window.SenetSkin3D = {sync, animateMove, animateRoll}`。
- `atlas/games/senet.js`＋`senet-kit.js`：ポータルの卓上対局（AI／二人）。`atlas/rules/senet.js`：3Dルールコース（案内役 セティ）。
