## 1. コンセプト
- **デッキ構築型の将棋**。相手は強いAI（ふつうの将棋の駒・ふつうのルール）。プレイヤーだけが「駒のチート」をできる。
- 自陣3段のなかで駒を足したり入れ替えたりして「デッキ」を組む。駒にはコストがあり、**どれだけ低いコストのデッキでAIをわからせられるか**がテーマ。
- 逆に、コスト無制限でAIをボコボコにする（オーバーキルする）遊び方も公式に用意する（実績・演出で楽しむ）。

## 2. デッキの組み方（ユーザー決定）
- 出発点はふつうの将棋の初期配置。この状態がコスト **0**。
- **自陣3段（27マス）の中なら**どこにでも駒を足せる（空きマスに置く）。置いた駒のコストを足す。
- 元の駒を**交換**できる：外した駒の価値をデッキコストから引き、置いた駒のコストを足す（例：飛車を外して クイーン を置く ＝ −10 ＋15 ＝ +5）。
- 駒を外すだけ（空きにする）もできる → コストがマイナスになる＝駒落ちのハンデ。マイナスのデッキで勝つのが最高の「わからせ」。
- 自陣の中での並べ替え（同じ駒の位置を変える）は無料。
- 決まり：玉は必ず1枚（外せない・自陣の中なら位置は自由）。行き所のない駒は置けない（桂を1段目など）。二歩は禁止（ふつうの歩どうし）。初期配置で相手の玉に王手がかからないこと（自陣3段なので通常起きないが、遠くに効く駒で確認する）。
- 通常駒の価値（コスト）：**歩1・香3・桂4・銀5・金6・角8・飛10**（玉は外せないので価値なし）。よく知られた目安の値をまず使い、テストしながら調整する（ユーザー決定 2026-11-11：推奨値で開始）。

## 3. 駒の扱い（共通）
- 通常駒：ふつうの将棋どおり（成り・持ち駒・打ち）。プレイヤーが足した通常駒も同じ。
- **特殊駒は取られると盤から消える**（AIの持ち駒にならない）。AIはチート駒を使えない＝「チートはプレイヤーだけ」を守る。AIの通常駒をプレイヤーが取ったときは、ふつうどおり持ち駒になる。
- 特殊駒は成らない（書いてあるものを除く）。持ち駒にならないので打てない。
- 能力の使用は「手番を使う」（そのターンは駒を動かさない）。使用回数・クールダウンは駒ごと。

## 5. ゲームの流れ・モード
- **わからせモード**（本編）：AIのレベルを選ぶ → デッキを組む → 対局。勝てばそのレベル・そのコストを記録。各レベルの「最小コスト記録」が自己ベスト。
- **オーバーキルモード**：コスト無制限。勝った手数・取った駒・残った駒で派手な評価（「オーバーキル！」「完全粉砕」など）と実績。
- **お題**（日替わり・週替わり）：使える駒やコスト上限が決まったチャレンジ（例：「コスト0で Lv.5 を倒せ」「ナイトだけで」）。
- 引き分け（千日手・持将棋・核スイッチ）は勝ちに数えない。
- **オンライン（ユーザー決定 2026-11-11）**：
  - ランキング：AIのレベルごとの「最小コストで勝ったデッキ」、お題ごとの記録。
  - **対人戦**：コスト上限を決めて（例：0／10／30／無制限）、両者がその上限以内のデッキで対戦。両者とも特殊駒を使える（取られた特殊駒はどちらの側でも消える）。レート戦あり。
  - Firebase は将棋の `shogi-multiplay` を兼用（パスは `overkill/` 以下に分ける。セキュリティ規則・App Check は `claude/online-security-setup.md` どおり）。
- デッキは保存できる（5枠程度）。デッキコード（文字列）で共有。プリセット（初心者向け・ネタデッキ）を用意。

## 6. AI
- **実装済み（強いAI）**：`overkill/okengine.c` → `okengine.wasm` / `okengine_simd.wasm`（`overkill/tools/build-wasm.sh`）。Worker は `overkill/ok-ai.js`。
  - 将棋本体のエンジンと同じ探索（反復深化・aspiration・PVS・置換表・null move・LMR・killer/history・静止探索・王手延長）。
  - 評価は将棋本体の NNUE（`shogi/nnue.bin.gz`、H=512）を通常駒に使い、特殊駒は価値表＋相手玉への寄り（ポーンは前進）を足す。
  - 盤の層は新規：特殊駒18種の動きと能力（射撃・居食い・鉄砲・錬金・蘇生・爆発・結界・影武者〔玉の数で判定〕）。
  - 返す手は必ず `engine.js` の `legal()`（審判）と照合する。wasm が読めないときは旧JSの探索（`engine.js` の `search`）。
  - テスト：ランダム局面3.5万で合法手が `engine.js` と一致、6万手で指した後の局面が一致。旧JS AI（0.5秒）に4戦4勝（0.5秒で深さ10前後）。
  - レベル：Lv.1〜4 は深さ1の全手評価＋ノイズ、Lv.5〜8 は深さ2＋ノイズ、Lv.9〜12 は時間0.25〜0.7秒と深さ上限、Lv.13〜20 は0.9〜4秒。
  - ルールの修正：玉（影武者）が爆弾兵を取っても玉は消えない。爆風で鉄砲足軽が消えたら歩は残らない（JS と C で同じ）。
- 当初の方針（メモ）：本編の将棋AIは特殊駒を知らないので、**特殊駒も扱える専用エンジン**を作る。
  - 駒の動きはデータで定義（方向・距離・跳び・取り方の別）して、新しい駒を足しやすくする。
  - 評価：駒の価値（特殊駒のAI用の価値表）＋位置＋玉の安全度。探索は αβ＋静止探索、wasm 化（ほかのゲームと同じ）。
  - AIの側は通常駒だけなので、AIの持ち駒・打ちの扱いはふつうの将棋のまま。
- 強さ：Lv.1〜20（将棋本体の級・段とは別の物差し。大百科の「Lv.N＋入門〜最上級」表記）。高いレベルはチートなしではまず勝てない強さが目標。
- AIはプレイヤーの特殊駒の能力（射撃・爆発・蘇生・影武者）を読みに入れる。

## 7. 画面
- デッキ編集：盤（自陣3段が光る）＋駒のパレット（コスト順・種類別のタブ、各駒の動きの図と能力）。ドラッグで置く・入れ替える。上にデッキコストのメーター（マイナスは青、プラスは赤）。
- 対局：将棋本体と同じレイアウト・ヘッダーバー。能力のある駒を選ぶと「能力」ボタン（回数・クールダウン表示）。
- **専用の盤**（ユーザー決定：作る）：2D・3D とも。「作戦卓」＝黒い金属の卓にホログラムの升目、自陣3段が光る「配備ゾーン」、縁にコストのメーター。将棋の6種の3D盤も選べるようにする。
- 多言語14言語、ルール説明はチュートリアル式（駒の動きは実際に動かせる盤で）、コーチは特殊駒の使い方のヒント中心。
