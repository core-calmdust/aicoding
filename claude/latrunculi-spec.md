URL: https://core-calmdust.github.io/aicoding/latrunculi/ （cat: hist＝ヒストリカル、`also: ['chess']`。**ALPHA**（新作は ALPHA から。切り替えはユーザーの指示で）。2026-11-16 にトップページと大百科ポータルへ登録：下の「大百科への登録」）。テーマ色 #6a2358（ティリアン・パープル＝皇帝の紫。既存の赤・ワイン・青紫と被らない）。

## ルール（確実性優先：古代のルールは失われており、すべて現代の復元）
出典（2026-11 確認）：Locus Ludi（フリブール大学）のルールシート「Ludus latrunculorum — Seneca variant / Piso variant」（U. Schädler 1994・2001 に基づく）、Wikipedia「Ludus latrunculorum」（ウァロ・オウィディウス・マルティアリス・『ピソ頌』・イシドルス・マクロビウス、ローマ時代ブリテンの 7×8・8×8・9×10 の盤、ヴィンドランダ、Museum Quintana のルール）。

盤は 8×8。黒（P1）が先手。ゲームタブで3つの復元を選ぶ（`engine.js` の RULES）。

| キー | 名前 | 内容 |
|---|---|---|
| `seneca`（既定） | シェードラー式 | 空の盤に20個ずつ交互に置く（置く間は取れない）→ 縦横1歩、または**味方の駒**を跳び越える（連続可・向きを変えてよい）。相手の駒を2個で両側から挟むと**裏返って動けなくなる**（incitus）。挟んだ側の**次の番のはじめに必ず1個取り除き**、それから1手動かす（複数挟んでいても1手に1個、どれを取るかは選ぶ）。挟んでいる2個のどちらかが挟まれると、挟まれていた駒は自由になる。裏返った駒は挟む役にならない。 |
| `piso` | ピソ式 | 置き方・1歩移動は同じ。跳び越えなし。挟んだ駒はその場で取る（複数同時も全部）。 |
| `quintana` | クインタナ式 | 16個ずつ手前2列に並べて開始。縦横に好きなだけ進む。挟んだらその場で取る。隅の特則なし。動けなくなった側の負け。 |

共通：
- 隅の駒は、隅のとなりの2マスを押さえると挟まれる（seneca・piso）。辺の駒は辺に沿って両側から。
- 自分から相手2個の間に入っても挟まれない（挟めるのは動かした駒で両側がそろったときだけ）。
- 同じ駒を続けて行ったり来たりさせない（直前の自分の手を逆に戻す手は不可）。
- 終了：どちらかが1個以下 → 多い方の勝ち。動かせる手がない → seneca・piso は取った数の多い方（同数は引き分け）、quintana は動けない側の負け。
- **本作の取り決め**（対局を終わらせるため。出典はベルの「30手取りなし」規定を参考）：取り合いなしで30手ずつ（60手）続いたら終了し、取った数の多い方の勝ち・同数は引き分け（`QUIET_MAX`）。
- 出典で決まっていない点の扱い：跳び越えは Locus Ludi の本文どおり味方のみ（図Cの相手越えは採らない）。取り除き後に動かせる駒がなければ、取り除きだけで手番終了。先手は黒。

## エンジン（engine.js、純JS・1スレッド、Web Worker）
- 手 m = from + 64×to + 4096×(rm+1)。置く手は from = to。rm＝この番のはじめに取り除く裏返った駒（なければ −1）。取り除きだけの手は from = to = rm。
- `Pos`：sq（持ち主）・inc（裏返りの向き：1 横・2 縦・3 隅）・hand（置く残り）・cap（取った数）・last（直前の手：往復禁止）・quiet。`E.effect(pos, m)` が1手の中身（path・leap・blocks・takes・frees・rm）を返す：画面・コーチ・レッスン生成はすべてこれを使う。
- 棋譜：置く `d4`、移動 `d4-d5`、跳び `d4^d6`、取る `xe5`、挟む（裏返す）`!e5`、取り除いてから動く `xe5,d4-d5`。
- 評価：駒100・裏返った駒22・狙われた駒 −16・並び +5・隅 −14・動ける向き +2。negamax＋置換表＋キラー＋静止探索（挟む手・取り除き）。
- 20段階（Lv.表記）：Lv.1〜10 は深さ1〜4＋ノイズ、Lv.11〜18 は局面数（3千〜20万）、Lv.19・20 は 1.5 秒・3 秒。負け確定は `resist`（いちばん遅く負ける手）。
- ソルバー：`goalGood / goalMin / goalReply`（N 手以内に「取った数の差を+1（裏返った自分の駒が残らない）」または「勝ち」、相手は最長抵抗＋評価の良い受け）。
- 既知の課題：強いレベル同士は取り合いが少なく「30手」で終わりやすい（評価関数と探索の強化・WASM 化・マルチスレッドは未着手）。RT_LV（レート戦の基準値）はコナネの値のままで、実測での見直しが要る。

## 画面（konane/ から派生）
- 盤8種（tools/gen_art.py のレンダリング画像、格子の溝はページが描く）：大理石（既定）・トラバーチン・屋根瓦（テグラ）・モザイクの床・くるみ材・斑岩・スレート・アイボリー。駒4種：ガラス（既定、『ピソ頌』のガラスの駒）・色ガラス・骨と角・小石。**裏返った駒は裏面の絵**（pc-*-bx / wx.webp）＋細い赤い輪、挟んだ瞬間にくるっと返る。
- 入力：置く段階は空きマスをタップ。動かす段階は駒→行き先。取り除く駒が1個なら自動、複数なら先に取り除く駒をタップ。
- 盤の上下：取った数・手持ち（置く段階）・動けない駒の数。右下に手番の案内（置く／取り除く／あと何手で終了）。
- ルール（RuleTour）：紹介 → 置く → 1歩 → 跳び越え → 挟むと裏返る → 次の番に取る → 助ける → 隅 → 間に入っても安全 → 勝ち負け → 3つのルール。
- レッスン7（tools/gen_content.js、正解集合はエンジンで計算）：はじめて4（挟む・辺・隅・助ける。跳んで挟む課題は作らない：跳び越された駒が同じマスへ1歩で入れるため、跳びだけが正解の局面にならない）、作戦3（挟まれない・2個挟む・2手で取る）。各5問・満点20・合格75。準備ステップ（ramp）は未実装。
- パズル（同 gen_content.js、PZBook v2）：「N 手で駒を取れ」＝テーマ t2・t3・t4（駒を取れ）＋ corner（隅と辺）・double（テーマ別）、各20問。最短がちょうど N 手・初手は2通りまで・（2手は）効かない挟みが別にある局面だけ。
- コーチ（coach.js、ja/en）：方針分類＝勝ち筋・2個挟む・挟む・助ける・守る・跳ぶ・寄せる・並べる／離して置く。置く段階は定跡ではなく原則（並べる・隅を避ける）で解説。
- 振り返り解説：挟みを逃した・助けを逃した・挟まれる形を作った。
- オンライン：Firebase プロジェクト未作成のため準備中（firebase-config.js が null）。作成後に secrules.py へ追加。
- 言語：**14言語**（2026-11-16。残り12言語は i18n-lt-more.js・coach-i18n.js・lux.json。言語メニューは app.js の SUPPORTED / window.LT_LANGS。検査：全言語でキー206・コーチ113の抜けなし、差し込み記号一致、PC／スマホで表示確認。zh の題名「罗马强盗棋」は定訳未確認）。

## 画面の直し（2026-11-16 追記）
- **持ち時間のある対局（レート戦・オンライン）は、対局者の2人を上下に並べる**（`.card.players:has(.clk:not(:empty))`、2D・3D・PC・スマホ共通）。1行＝石・名前（R と側）・時計・数。横に2人並べたままだと時計の分だけ名前が「あな…」「AI L…」と切れ、スマホでは時計が名前に重なっていた。3D スキンは `atlas/skin/latrunculi.js` で共通スキン（skin.css）の2列指定を1列に上書きする。
- 時計のない対局で名前が箱に入らないとき（PC の 2D「AI Lv.6 · ガチョウ」など）は「…」で切らず2行に折り返す。
- 盤の右下の案内（`#prompt`）は1行のまま、入らなければ字を小さくする（`app.js` の `fitPrompt`、8px まで）。「…」で切らない。
- **既知の課題**：スマホ横持ち（844×390）の 3D スキン（`?skin=atlas`）は、大百科のヘッダー（64px）が残り、盤の下が切れる（盤は高さいっぱいに作られるがヘッダーの分だけ下にずれる）。`konane/` の 3D スキンも同じ状態なので、共通の作り（`ur/` の横持ちのような、ヘッダーを細いピルにする並び）を決めてから直す。2D の横持ちは盤が高さいっぱいに入り、遊べる。
- 3D スキンの PC のヘッダー：ゲーム名が長くてロゴの欄が狭くなり、下の英字（World Board Game Atlas）の右が切れていたので、欄の幅に合わせて字を小さくする（`atlas/skin/latrunculi.js`）。
