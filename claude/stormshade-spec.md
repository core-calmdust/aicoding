# 嵐影館 STORMSHADE MANOR — 仕様

ひとり用のマーダーミステリー（開発室・アルファ）。狼影灯（lampblack/）の影絵・舞台・文字の帯をそのまま使う。

## 構成

- `stormshade/index.html` 画面と CSS（lampblack の index.html から派生）
- `stormshade/engine.js` DOM を使わない事件の生成・推理・採点（`SSEngine`）
- `stormshade/game.js` 見せ方と進行（`SSGame`）。舞台・帯・シートの関数は lampblack/game.js から写したもの
- `stormshade/manor.js` 洋館の背景（`SSArt.scene(loc, seed)`）
- `stormshade/cases/<id>.js` 人物・場所・特徴、`<id>.story.js` 文章（凶器・謎・展開・役・序幕）
- `stormshade/sound.js` lampblack の sound.js の写し。BGM は `../lampblack/audio/` を読む
- 人形は `../lampblack/art.js`（WLArt）を読む。lampblack 側を変えるとこちらにも響く

## 遊びの流れ

タイトル → 事件をえらぶ → むずかしさ・役（4人＋おまかせ）→ 序幕（晩餐・人物紹介・ハンドアウト）→ 一日目の朝（遺体・検分・謎の提示）
→ 昼（調べる／話を聞く、回数制限）→ 夕刻の話し合い（皆の言い分が手帳に並ぶ・目撃や手がかりの共有・矛盾を突く）
→ 二日目の夜（展開「第二の事件」）→ 二日目の昼・話し合い → 三日目：解答シート → 真相・謎の答え・採点（S〜D）

## 三つの約束（推理の土台）

1. 痕跡は嘘をつかない（現場の特徴＝犯人の特徴）
2. 物は嘘をつくことがある（持ち物は罠として置かれることがある）
3. 人は他人のことでは嘘をつかない。自分の居場所は秘密のために偽ることがある。犯人だけは何でも偽る（罪を着せる目撃を作る）

## 事件の生成（engine.js）

- 4つの時刻 × 9つの場所。各人物に本当の居場所・言い分・目撃を持たせる
- 毎回くじで決まるもの：犯人・動機（人物ごと2種）・凶器（5種）・時刻・現場（動かされることがある）・謎（5種から2〜3）・展開（遺体の移動／第二の事件／毒の二重／共犯）・役の目的
- 生成した事件は「痕跡に合い、犯行時刻に現場の外で誰にも見られていない者」が犯人ひとりだけになることを確かめる（解けない事件は作らない）
- 痕跡の組み合わせは、合う者がちょうど `DIFF.pool` 人になるものを選ぶ（入門1・標準2・中級3・上級4・悪夢4）。残りは足取り（アリバイ）で絞る
- 中級から、第二の事件の痕跡で候補が一人に決まらないようにする。上級から、第二の被害者は候補の外から選ぶ

## むずかしさ（DIFF）

入門・標準・中級・上級・悪夢。調べる／聞く回数、目撃の多さ、秘密で嘘をつく割合、罠の物、犯人の偽の目撃（cunning）、懐中時計の偽装、展開の数、謎の数、的外れの許容回数、手帳の補助（入門のみ）が変わる。
シミュレーション（tools なし・/tmp の sssim.js 相当）での犯人正答率の目安：完全な推理役 100/98/90/87/84%、痕跡だけで選ぶ役 100/63/36/42/41%、でたらめ 約14%。

## 採点

犯人30・動機10・凶器10・時刻10・本当の現場10（動いた時）・謎ごと10・展開の問い10・役の目的15。割合で S/A/B/C/D。記録は `stormshade-rec-v1`。

## ポータル
